开场一句话：上一节我们用不等式的性质做"比较大小"，这一节要认识一条大名鼎鼎的公式级不等式——它长得很像乘法公式的"不等号亲戚"，是高中求最大值、最小值的第一把钥匙。教材原话："是否也有一些不等式，它们在解决不等式问题时有着与乘法公式类似的重要作用呢？"（p44）

读完这节你能：

  • 从完全平方公式出发，亲手推出基本不等式，并说清"当且仅当 a=b"的含义；
  • 用半圆几何图解释 √ab ≤ (a+b)/2 为什么成立；
  • 背出并会查"最值双引擎"：积定和最小、和定积最大；
  • 解出教材例1、例3、例4 这一类的最值题，并验证等号取得到。

第 0 站 · 预备块：你初中就有两件旧工具

旧工具一（完全平方公式）：(a±b)² = a² ± 2ab + b²，展开永远不错位。

旧工具二（平方非负）：任何实数的平方不小于 0，即 x² ≥ 0，等号当且仅当 x=0。就这两件，本节全靠它们起家。

第 1 站 · 重要不等式：从 (a−b)² 里长出来的不等号

把平方非负用在 (a−b) 上：(a−b)² ≥ 0。展开：

a² − 2ab + b² ≥ 0  ⟹  a² + b² ≥ 2ab

当且仅当 a=b 时（此时 (a−b)²=0），等号成立。教材称它为重要不等式（p44，∀a，b∈R）。

验一验①：取 a=3，b=5：a²+b²=34，2ab=30，34≥30 ✓；取 a=b=2：8=8，等号成立 ✓。对号入座：左边减右边=(a−b)²，永远非负。

易错变形："a²+b²≥2ab"对所有实数都成立，别只记正数情形。

特别地，如果 a＞0，b＞0，用 √a、√b 分别代替上式中的 a、b（教材原句），得：

√ab ≤ (a+b)/2  （1）  当且仅当 a=b 时等号成立

教材 p44：通常称不等式(1)为基本不等式（basic inequality）。

第 2 站 · 两个平均数：算 ≥ 几，外加一张半圆图

基本不等式里的两个"主角"（p44 原文定义）：

名字式子一句话
算术平均数(a+b)/2加起来除以 2（平常说的"平均"）
几何平均数√ab乘起来开平方

所以基本不等式读作：两个正数的算术平均数不小于它们的几何平均数（p44 原句）。

半圆几何解释：AB 是直径，C 在 AB 上，AC=a，BC=b，过 C 作 AB 的垂线交半圆于 D。可证 △ACD ∽ △DCB，于是 CD=√ab；而 CD ≤ 半径=(a+b)/2。当且仅当 C 与圆心重合（a=b）时，CD 恰好等于半径，等号成立。（p45 原文逻辑）

分析法证明（教材 p44 五步链，倒着读就是"显然成立"）：要证 √ab ≤ (a+b)/2（①），只要证 2√ab ≤ a+b（②），只要证 2√ab − a − b ≤ 0（③），只要证 −(√a−√b)² ≤ 0（④），只要证 (√a−√b)² ≥ 0（⑤）。⑤显然成立，当且仅当 a=b 时⑤中的等号成立。每一步"只要证"都是可逆的等价变形，所以链条成立。

第 3 站 · 最值双引擎：积定和最小，和定积最大

教材例2（p45-46）给出一对"发动机"，考试九成最值题由它们变形而来：

发动机条件结论（当 x=y 时等号成立）
① 积定 → 和最小xy = P（定值）x+y 有最小值 2√P
② 和定 → 积最大x+y = S（定值）xy 有最大值 S²/4

证明骨架（①）：(x+y)/2 ≥ √xy = √P，所以 x+y ≥ 2√P；等号当且仅当 x=y。（②）同理：√xy ≤ (x+y)/2 = S/2，所以 xy ≤ S²/4。

用引擎前必查"一正二定三相等"：①字母全为正；②积或和确实是定值；③等号能取到（x=y 在允许范围内有解）。三查缺一，结论报废。

教材例1（p45）：已知 x＞0，求 x + 1/x 的最小值。解：x + 1/x ≥ 2√(x·1/x)=2，当且仅当 x=1/x 即 x=1 时等号成立，最小值为 2。教材"想一想"追问：当 y₀＜2 时，x+1/x ≥ y₀ 恒成立，但 y₀ 不是最小值——因为 2 这个值确实取得到，而 y₀＜2 取不到。这就是"三相等"要查的原因。

验一验②（负数不能用引擎）：x＜0 时，x + 1/x 有最大值还是最小值？x+1/x = −[(−x)+(−1/x)] ≤ −2，最大值 −2（x=−1 时取到）。引擎只对正数有效，负数要提出负号再造。

易错变形（和没定）：x + 4/x（x＞0）最小值是 2√4=4？✓（x=2 取到）；但 x + 4/x² 想套"积定"就没那么直接——x·(4/x²)=4/x 不是定值，引擎失效，不能硬套。

验一验③（升幂变形）：x＞0 时 x² + 1/x² 的最小值？配成 (x+1/x)² − 2 ≥ 2² − 2 = 2，当 x=1 时取到（教材 p46 练习3）。

验一验④（等号取不到的经典）：x∈(0, 4)，求 x + 16/x 的最小值。若硬套得 8（x=4 取到），但 x=4 不在开区间内！真最小值在 x→4⁻ 处逼近 8 却取不到，此题无最小值——"三相等"第三查就是防这个。

（拓展 · 可跳过）综合运用4（p49）：x，y，z 都是正数，(x+y)(y+z)(z+x) ≥ 8xyz。骨架：x+y ≥ 2√xy，y+z ≥ 2√yz，z+x ≥ 2√zx，三式连乘即得，等号当 x=y=z。这是"双引擎"的连乘放大版。
（拓展 · 可跳过）拓广探索7（p49）天平称黄金：不等臂天平两次各称得 a g、b g，顾客实得 √ab g，由 √ab ≤ (a+b)/2 = 5 g 知总重 小于 10 g——几何平均数严格小于算术平均数（a≠b 时），顾客吃亏。

第 4 站 · 实战两例：把引擎装到应用题上

教材例3（p46-47）矩形菜园。（1）用篱笆围一个面积为 100 m² 的矩形菜园，边长多少时篱笆最短？设两边 x，y（m），xy=100，篱笆长 2(x+y) ≥ 2×2√(xy) = 40，当且仅当 x=y=10 时等号成立——边长 10 m 的正方形，最短篱笆 40 m。这里是"积定和最小"。

（2）用一段长为 36 m 的篱笆围矩形菜园，边长多少时面积最大？2(x+y)=36，xy ≤ ((x+y)/2)² = 81，当且仅当 x=y=9 等号成立——边长 9 m 的正方形，最大面积 81 m²。"和定积最大"。（教材 p47 解答逐句锚定）

教材例4（p47-48）无盖贮水池。容积 4800 m³、深 3 m，池底造价 150 元/m²，池壁 120 元/m²。设底面两边 x，y（m），总造价 z = 150×(4800/3) + 120(2×3x+2×3y) = 240000 + 720(x+y)；由 3xy=4800 得 xy=1600，所以 z ≥ 240000 + 720×2×40 = 297600，当且仅当 x=y=40 时等号成立——池底设计成边长 40 m 的正方形，最低总造价 297600 元（p48 解答逐句锚定）。

验一验⑤（教材 p48 练习1）：用 20 cm 铁丝折面积最大的矩形：周长定 20，和定积最大，x=y=5，最大面积 25 cm²。两问同构：一边靠墙（练习2）时 "30−2x ≤ 18" 的墙长限制要单独检查，x=7.5 合法，最大面积 112.5 m²。

收口站 · 三句话带走 + 自测四连

三句话带走：

  • ① (a−b)²≥0 ⇒ a²+b²≥2ab；换元得 √ab ≤ (a+b)/2（a,b＞0，当且仅当 a=b 等号成立）；
  • ② 半圆图里：半弦 CD=√ab 永不高于半径 (a+b)/2，C 与圆心重合时相等；
  • ③ 求最值先查一正二定三相等：积定→和最小 2√P；和定→积最大 S²/4。

自测四连（先做再看答案，全部取自教材本节域）：

  1. 判断结构：∀a,b∈R，"a²+b²≥2ab"等号成立条件？答：a=b（p44 原句）。
  2. 教材 p48 练习3：x 取何值时 x²+1/x² 最小？答：x=1 时最小值 2（x²+1/x²=(x+1/x)²−2≥4−2=2）。
  3. 教材 p48 习题2.2 复习巩固1(1)：x＞1，求 x + 1/(x−1) 的最小值。答：拆 (x−1)+1/(x−1)+1 ≥ 2+1 = 3，当 x=2 时取到。
  4. 教材 p48 习题2.2 复习巩固1(2)：求 √(x(10−x)) 的最大值。答：x(10−x) ≤ ((x+10−x)/2)² = 25（0＜x＜10），最大值 5，x=5 时取到。
