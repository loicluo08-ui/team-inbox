第 0 站 · 预备块：初中底账 + 本节两层拓展地图

初中三件老工具：① 平方根/立方根——如果 x²=a，那么 x 叫做 a 的平方根（±2 是 4 的平方根）；如果 x³=a，那么 x 叫做 a 的立方根（2 是 8 的立方根）。② 整数指数幂——a⁰=1、a−n=1/aⁿ（a≠0）。③ 整数幂运算性质——同底相乘指数相加、幂的幂指数相乘、积的幂各取幂。

为什么拓展：在学习幂函数时，我们把正方形场地的边长 c 关于面积 S 的函数 c=√S 记作 c=S1/2（p104）。像 S1/2 这样以分数为指数的幂，其意义是什么？初中没有定义——本节从已知的平方根、立方根的意义入手展开研究。

第 1 站 · 4.1.1 上半场：n 次方根与根式（p104-105）

定义（p104 原文口径）：一般地，如果 xⁿ=a，那么 x 叫做 a 的 n 次方根，其中 n>1，且 n∈N*。分 n 的奇偶两种情形：

n 是奇数时：正数的 n 次方根是一个正数，负数的 n 次方根是一个负数。这时 a 的 n 次方根用符号 ⁿ√a 表示。例如：

⁵√32 = 2，　⁵√(−32) = −2，　∛(a⁶) = a²

n 是偶数时：正数的 n 次方根有两个，这两个数互为相反数。这时正数 a 的正的 n 次方根用 ⁿ√a 表示，负的 n 次方根用 −ⁿ√a 表示，可以合并写成 ±ⁿ√a（a>0）。例如：

⁴√16 = 2，　−⁴√16 = −2，　±⁴√16 = ±2

两条红线（p104 原文）：负数没有偶次方根；0 的任何次方根都是 0，记 ⁿ√0=0。教材旁设问题框"为什么负数没有偶次方根？"——因为偶次幂非负：设 x^(2k)=a<0，但任何实数的偶次幂 ≥0，矛盾。（自答）

根式概念：式子 ⁿ√a 叫做根式（radical），这里 n 叫做根指数，a 叫做被开方数。根据 n 次方根的意义，可得：

(ⁿ√a)ⁿ = a　　例如 (√5)² = 5，(⁵√(−3))⁵ = −3

探究（p105·教材原题）：ⁿ√(aⁿ) 表示 aⁿ 的 n 次方根，ⁿ√(aⁿ)=a 一定成立吗？——不一定。可以得到：当 n 为奇数时，ⁿ√(aⁿ)=a；当 n 为偶数时，ⁿ√(aⁿ)=|a|={ a，a≥0；−a，a<0 }。（n 偶时先算出的是非负值，必须补绝对值再按 a 的符号拆）

例1（p105 原题）求下列各式的值：

(1) ∛((−8)³) = −8；　(2) √((−10)²) = |−10| = 10；　(3) ⁴√((3−π)⁴) = |3−π| = π−3；　(4) √((a−b)²) = |a−b| = { a−b，a≥b；b−a，a<b }

验一验①（符号自检）：例1(3) 为什么不是 3−π？——⁴√((3−π)⁴) 中根指数 4 是偶数，出来必须带绝对值：|3−π|。而 3−π<0（π≈3.14），去绝对值得 π−3。凡是"偶次方根套平方数"（ⁿ√(□ⁿ)，n 偶），先写 |□| 再判符号——π−3 型陷阱年年考。

第 2 站 · 4.1.1 下半场：分数指数幂 + 化简计算流水线（p105-107）

从根式到分数指数幂的桥（p105 原文口径）：根据 n 次方根的定义和数的运算，我们知道

⁵√(a¹⁰) = ⁵√((a²)⁵) = a² = a10/5（a>0），　⁴√(a¹²) = ⁴√((a³)⁴) = a³ = a12/4（a>0）

这就是说，当根式的被开方数（看成幂的形式）的指数能被根指数整除时，根式可以表示为分数指数幂的形式。思考（p105）：不能整除时呢？——教材直接给出：∛(a²)=a2/3（a>0），√b=b1/2（b>0），⁴√(c⁵)=c5/4（c>0）。

正式规定（p106 原文）：我们希望整数指数幂的运算性质，如 (ak)n=akn，对分数指数幂仍然适用。由此规定：

正分数指数幂：am/n = ⁿ√(am)（a>0，m，n∈N*，n>1）
负分数指数幂：a−m/n = 1/am/n = 1/ⁿ√(am)（a>0，m，n∈N*，n>1）

例如 5−4/3=1/54/3=1/³√(5⁴)，a−2/3=1/a2/3=1/³√(a²)。0 的口径：0 的正分数指数幂等于 0，0 的负分数指数幂没有意义。教材旁注两句思想提示："数学中，引进一个新的概念或法则时，总希望它与已有的概念或法则相容"；"这里，略去了规定合理性的说明"。规定了分数指数幂的意义以后，幂 ax 中指数 x 的取值范围就从整数拓展到了有理数。

有理数指数幂运算性质（p106 原文三条）：对于任意有理数 r，s：

(1) aras = ar+s（a>0，r，s∈Q）；　(2) (ar)s = ars（a>0，r，s∈Q）；　(3) (ab)r = arbr（a>0，b>0，r∈Q）

例2（p106）求值：(1) 82/3=(2³)2/3=23×2/3=2²=4；(2) (16/81)−3/4=(81/16)3/4=((3/2)⁴)3/4=(3/2)³=27/8。负指数一手换倒数、底数化成 质数幂或完全次方，指数约干净收工。

例3（p106）用分数指数幂的形式表示并计算（其中 a>0）：(1) a²·∛(a²)=a²·a2/3=a2+2/3=a8/3；(2) √(a∛a)=(a·a1/3)1/2=(a4/3)1/2=a2/3。

例4（p107）计算下列各式（式中字母均是正数）：

(1) (2a2/3b1/2)(−6a1/2b1/3)÷(−3a1/6b5/6) = [2×(−6)÷(−3)]a2/3+1/2−1/6b1/2+1/3−5/6 = 4ab⁰ = 4a；
(2) (m1/4n−3/8)⁸ = (m1/4)⁸(n−3/8)⁸ = m²n−3 = m²/n³；
(3) (∛(a²)−√(a³))÷⁴√(a²) = (a2/3−a3/2)÷a1/2 = a2/3−1/2−a3/2−1/2 = a1/6−a = ⁶√a−a

练习（p107·三题自测口径）：1. 用根式形式表示（a>0）：a1/2=√a，a3/4=⁴√(a³)，a−3/5=1/⁵√(a³)，a−5/6=1/⁶√(a⁵)。2. 化分数指数幂并计算：∛(x²)=x2/3（x>0）；⁵√((m−n)⁴)=(m−n)4/5（m>n）；√(p⁶)·⁶√(p⁵)=p³·p5/6=p23/6（p>0）；a³÷√a 化分数指数幂得 a5/2（a>0·教材原题 a³/√a 照录见随件附件1）。3. 计算：(36/49)3/2=(6/7)³=216/343；2√3×3√1.5×⁶√12=9·25/6·31/6=9⁶√96（sympy 核）；a1/2a1/4a−1/8=a5/8（a>0）；2x−1/3(½x1/3−2x−2/3)=1−4/x=(x−4)/x。

验一验②（计算流水线自检）：例4(1) 里 b 的指数 1/2+1/3−5/6 为什么得 0？——通分 12：6/12+4/12−10/12=0。三条运算性质分工明确：系数管系数（2×(−6)÷(−3)=4）、同底管指数（通分加减）、b⁰=1（a>0 语境下非零底数的零次幂）。任何一步乱序都会错底错指。

易错红卡（自编，据例1-例4 提炼）：① ⁿ√(aⁿ) 当 n 偶时等于 |a| 不是 a——π−3、a−b 型先绝对值后拆（例1(3)(4) 双坑）；② 分数指数幂 am/n 的合法底数是 a>0——0 的负分数指数幂没有意义、负数的分数指数幂本节不定义，看到负底数先停手；③ 性质 (2) (ar)s=ars 是"指数相乘"，别与 (1) 的"指数相加"混用（82/3 拆 (2³)2/3 用的正是相乘）；④ 化简结果最好回根式或最简幂——⁶√a−a 别"顺手"写成 a1/6−a 后再乱合并，两个项底数同但已是最简。

第 3 站 · 4.1.2 无理数指数幂：两串幂夹出一个确定的数（p107-109）

问题起点（p107 原文口径）：上面我们将 ax（a>0）中指数 x 的取值范围从整数拓展到了有理数。那么，当指数 x 是无理数时，ax 的意义是什么？它是一个确定的数吗？如果是，那么它有什么运算性质？——教材的方法：在初中，我们通过有理数认识了一些无理数；类似地，也可以通过有理数指数幂来认识无理数指数幂。

探究实验（p108 原题）：根据 √2 的不足近似值 x 和过剩近似值 y（表 4.1-1），利用计算工具计算相应的 5x，5y 的近似值并填入表中，观察它们的变化趋势。

1.41≈9.67271.42≈9.8297
1.414≈9.73511.415≈9.7505

…………

（表 4.1-1 节录复刻：左列不足近似 1.4→1.41→1.414→1.4142→1.41421→1.414213→…，右列过剩近似 1.5→1.42→1.415→1.4143→1.41422→…，5x 值列为本席用计算工具代验补入·教材原表留白由学生计算。）

教材结论（p108 原文）：可以发现，当 √2 的不足近似值 x 和过剩近似值 y 逐渐逼近 √2 时，5x 和 5y 都趋向于同一个数，这个数就是 5√2。也就是说，5√2 是一串逐渐增大的有理数指数幂 51.4，51.41，51.414，51.4142，…和另一串逐渐减小的有理数指数幂 51.5，51.42，51.415，51.4143，…逐步逼近的结果，它是一个确定的实数。

思考（p108）：参照以上过程，你能再给出一个无理数指数幂，如 2√3，说明它也是一个确定的实数吗？——同样的夹逼：√3≈1.7320508…，用不足近似串 1.7, 1.73, 1.732, … 对应 2x 递增串，过剩近似串 1.8, 1.74, 1.733, … 对应 2y 递减串，两串同夹一个确定实数 2√3（自答，sympy 值 ≈3.3220）。

一般化（p108 原文）：一般地，无理数指数幂 aα（a>0，α 为无理数）是一个确定的实数。这样，我们就将指数幂 ax（a>0）中指数 x 的取值范围从整数逐步拓展到了实数。实数指数幂是一个确定的实数。

实数指数幂运算性质（p108 原文）：整数指数幂的运算性质也适用于实数指数幂，即对于任意实数 r，s，均有：

(1) aras = ar+s（a>0，r，s∈R）；　(2) (ar)s = ars（a>0，r，s∈R）；　(3) (ab)r = arbr（a>0，b>0，r∈R）

与 p106 有理数版三条逐字同构，只有 Q→R 一处升级——这就是"相容性"思想的落点：新范围进来，老性质全保。

练习（p109·两题口径）：1. 计算：(1) (2√3·√(m√3))2√3=(2√3)2√3·(m√3/2)2√3=22×3·m3=64m³（sympy 核）；(2) aπ/3·a2π/5·a−π=aπ/3+2π/5−π=a−4π/15。2. 利用计算工具探究变化规律：(1) x 取负实数且 |x|→∞，2x 的值趋近 0；(2) x 取正实数且 x→∞，(1/2)x 的值同样趋近 0——两问合看：底数与 1 的位置关系决定"哪头趋 0"，这正是下一节 4.2 指数函数图象的两个基本走势。

第 4 站 · 习题4.1 精讲：复习巩固 1-5 + 综合运用 6-8 + 拓广探索 9-10（p109-110）

复1（求值四连）。(1) ⁴√100⁴=100；(2) ⁵√((−0.1)⁵)=−0.1（n 奇·直接出原底数）；(3) √((π−4)²)=|π−4|=4−π（n 偶·绝对值拆负）；(4) ⁶√((x−y)⁶)=|x−y|（n 偶·字母型保留绝对值）。

选2（运算正误辨析）。(1) 设 a>0：(A) a4/3a3/4=a25/12≠a ✗；(B) a÷a2/3=a1/3≠a3/2 ✗；(C) a2/3a−2/3=a⁰=1≠0 ✗；(D) (a1/4)⁴=a1/4×4=a ✓——答案 D。(2) am/n=ⁿ√(am)、a⁰=1、a−m/n=1/ⁿ√(am) 三式（a>0，m,n∈N*，n>1）全部符合规定——正确个数 3，答案 A。

填3。(1) 四数比大小：(−1/2)−1=−2，2−1/2≈0.707，(1/2)−1=2，2−1=0.5——最大是 (1/2)−1=2（负指数=换倒数，倒数越大原数越小）。(2) 排序 2√3，3√2，π√5，2π（可用计算工具）：数值 3.3220、4.7288、12.9319、8.8250——从小到大 2√3 < 3√2 < 2π < π√5（sympy 逐值核）。

习4（分数指数幂表示并计算·字母均正）。(1) √(b³/a·√(a²/b⁶))：内层 √(a²/b⁶)=a/b³，则 b³/a·a/b³=1，原式=1；(2) √(a1/2√(a1/2√a))：由内向外逐层换指数 a1/2·a1/2=a、√a=a1/2、a1/2·a1/2=a、√a=a1/2；(3) (√m·∛m·⁴√m)/((⁶√m)⁵·m1/4)：指数 1/2+1/3+1/4=13/12 对 5/6+1/4=13/12——m13/12/m13/12=1。

习5（计算四连·字母均正）。(1) a1/3a3/4a7/12=a4/12+9/12+7/12=a5/3；(2) a2/3a3/4÷a5/6=a8/12+9/12−10/12=a7/12；(3) (x1/3y−3/4)12=x⁴y−9=x⁴/y⁹；(4) 4a2/5b−2/3÷(−(2/3)a−1/3b−1/3)=−6a2/5+1/3b−2/3+1/3=−6a11/15b−1/3。

综6（细菌分裂·幂模型首秀）。细菌每 10 min 分裂 1 次（1 个分裂成 2 个），经过 1 h（=60 min，分裂 6 次），1 个细菌分裂成 2⁶=64 个。（这就是章首"细胞分裂"指数模型的离散版）

综7（条件求值·指数搬运）。(1) 已知 10m=2，10n=3，求 10(3m−2n)/2：=103m/2÷10n=(10m)3/2÷10n=23/2/3=2√2/3；(2) 已知 a2x=3，求 (a3x+a−3x)/(ax+a−x)：分子提出公因式 (ax+a−x)，剩 a2x−1+a−2x=3−1+1/3=7/3——原式=7/3。

习8（条件求值·平方套娃）。已知 a1/2+a−1/2=3（a>0）：(1) 两边平方：a+a−1+2=9⟹a+a−1=7；(2) 再平方：a²+a−2+2=49⟹a²+a−2=47。

拓9（倒酒精·剩余幂串）。从盛有 1 L 纯酒精的容器中倒出 1/3 L，然后用水填满；再倒出 1/3 L，又用水填满……(1) 连续 5 次：每次操作纯酒精剩 2/3，剩 (2/3)⁵=32/243 L；(2) 连续 n 次：(2/3)ⁿ L。

拓10（(1+1/n)ⁿ·e 的伏笔）。(1) 当 n=1，2，3，10，100，1 000，10 000，100 000，…时用计算工具算 (1+1/n)ⁿ：2、2.25、2.3704、2.5937、2.7048、2.7169、2.7181、2.7183，…逐步逼近一个常数；(2) 底数越来越小、指数越来越大，(1+1/n)ⁿ 是否也越来越大？有没有最大值？——单调递增但没有最大值，上界是 e≈2.71828（自然对数的底）——教材在此为后续对数与 ex 埋伏笔，首学知道"数列递增有上界、极限无最大"的直觉即可（自答）。

拓展 · 可跳过 拓展方法论收口（自编）：本节所有"规定"背后是一条主轴——相容性（p106 旁注原话）。分数指数幂规定 am/n=ⁿ√(am) 是为了保住运算性质；无理数指数幂用夹逼定义是为了保住"确定的实数"；性质三条原封不动升级到 R 是为了保住已有计算习惯。以后学对数、学向量扩充，还会反复见到这套"新概念须与旧法则相容"的建桥术。

收口三问（合上书自答）：
