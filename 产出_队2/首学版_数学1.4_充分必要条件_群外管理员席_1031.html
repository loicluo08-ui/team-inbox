数学1.4 充分条件与必要条件

零基础首学版 v1.0 · 人教A版必修第一册 p17-23 · 第一收官节：集合工具+逻辑用语在此会师 · 出品：群外管理员席 · 1031

先看一件小事。妈妈说："如果你考试进了班级前十，我就带你去游乐园。"

这话你可以放心——只要"进前十"（记它叫 p）发生，"去游乐园"（记它叫 q）就一定发生。但反过来，你去了游乐园，却不一定是"进前十"换来的（过生日也可能去）。一件事情可以"保证"另一件，反过来未必——这种方向性，就是本节要研究的全部内容。数学里每条定理、每道证明，都在说这种"谁保证谁"。

学完这节你不但能听懂"充分条件、必要条件"这两个词，还能一眼看出高考题里那句"p 是 q 的什么条件"该答四个答案中的哪一个。

读完这节你能

① 给一个"若 p，则 q"的命题，判断真假，并说出 p 是 q 的充分条件还是 q 是 p 的必要条件；

② 对假命题举出反例（这是判假的标准动作）；

③ 判断 p 是 q 的"充分不必要 / 必要不充分 / 充要 / 既不充分也不必要"四种情况之一；

④ 用集合的包含关系（1.2 的工具）解释条件关系——两个章节在这里会师。

30秒立好地基

命题：可以判断真假的陈述句（教材p17："用语言、符号或式子表达的，可以判断真假的陈述句叫做命题"）。"3是奇数"是真命题；"x²=1则x=1"是假命题（x=−1也行）。初中都打过交道，本节只是给它装上仪表。

把命题写成"若 p，则 q"：p 叫条件，q 叫结论（教材p17原话）。整个1.4节就研究一件事：p 和 q 之间，箭头朝哪边、几条箭头。

第①站充分条件——"p 是 q 的入场券"

教材p17思考框给了四个命题，先自己判一遍真假：

（1）若平行四边形的对角线互相垂直，则它是菱形；（2）若两个三角形周长相等，则它们全等；（3）若 x²−4x+3=0，则 x=1；（4）若平面内两条直线 a、b 均垂直于直线 l，则 a∥b。

验一验①（先答，再看答案）

四个命题，哪些真、哪些假？假的能举出反例吗？

答案：（1）真——这是菱形的一条判定（初中定理）。（4）真——"垂直于同一条直线的两直线平行"。（2）假——周长相等形状可以完全不同，反例：边长3,3,3的三角形与边长2,3,4的三角形，周长都是9，但三边不对应相等（SSS判全等失败），不全等。（3）假——解方程：x²−4x+3=0 即 (x−1)(x−3)=0，x=1 或 x=3，所以"x=3"就是反例（sympy解集={1,3}·代验留痕）。

教材p17给（1）（4）这种"由 p 推理能得出 q"的真命题起了正式名字：由 p 可以推出 q，记作 p⇒q，这时说——

p 是 q 的充分条件（sufficient condition），q 是 p 的必要条件（necessary condition）

方向锁死（本节第一坑）："p 是 q 的充分条件"和"q 是 p 的必要条件"是同一句真命题的两种说法，说的都是 p⇒q 这一个箭头。谁充分谁必要，看箭头：箭头尾=充分，箭头头=必要。

为什么叫"充分"？有 p 这张入场券，进 q 这扇门就够了（p 一出现 q 必出现）。为什么 q 叫"必要"？教材p17脚注①原话："此时，如果 q 不成立，则 p 一定不成立"——没有 q，p 根本没戏，q 是 p 成立绕不开的底线。教材脚注还留了一问"请举例说明"，第②站接住它。

再接教材p18例1（六连问·哪些 p 是 q 的充分条件），挑三道有 representative 的看判断手法：

（1）若四边形的两组对角分别相等，则是平行四边形——判定定理，p⇒q，是。（4）若 x²=1，则 x=1——反例 x=−1：p⇏q，不是。（6）若 x, y 为无理数，则 xy 为无理数——反例 √2×√2=2（两个无理数乘出有理数），p⇏q，不是。

教材p18侧栏把判断手法点破：举反例是判断一个命题是假命题的重要方法。真命题找定理撑腰，假命题找反例定罪——两手都要有。

教材p18-19还有一层要紧话：这样的充分条件不止一个。"两组对边分别相等""一组对边平行且相等""两条对角线互相平分"都是"是平行四边形"的充分条件——每条判定定理都是一张不同的入场券，都通向同一个门。

第②站必要条件——"q 是 p 的底线"

把箭头反过来问：q 是 p 的必要条件，怎么判？教材p19例2给六问，看三道：

（1）若四边形是平行四边形，则两组对角分别相等——性质定理，p⇒q，所以 q 是 p 的必要条件。（3）若四边形对角线互相垂直，则是菱形——教材画了个风筝形反例（图1.4-1：对角线垂直但不是菱形），p⇏q，q 不是 p 的必要条件。（5）若 ac=bc，则 a=b——反例 c=0：−1×0=1×0 但 −1≠1，不是。

教材p19把判断动作说透了：判 q 是不是 p 的必要条件，只需判"若 p，则 q"是不是真命题——还是那一个箭头，只是站的位置换了。

教材p20把定理分了工：判定定理=充分条件的来源（p19："数学中的每一条判定定理都给出了相应数学结论成立的一个充分条件"），性质定理=必要条件的来源（p20："数学中的每一条性质定理都给出了相应数学结论成立的一个必要条件"）。

验一验②（先答，再看答案·承接教材p17脚注"请举例说明"）

脚注说"q 不成立，则 p 一定不成立。请举例说明。"你来举一个。

答案（自编·示例）：取 p："四边形是正方形"，q："四边形四个角都是直角"。q 不成立的四边形（比如有个角是60°的），p 一定不成立——因为正方形四角必是90°。一句话：底线破了，入场券自动作废。

易错变形（自编）："小明及格了，所以小明及格是'小明考了60分以上'的什么条件？"——及格（通常≥60分）⇒60分以上？如果及格线就是60，那么"及格"⇒"≥60分"是真命题，所以"及格"是"≥60分"的充分条件，而"≥60分"是"及格"的必要条件。别被"必要"两个字骗去选"必要"——问的是谁是谁的什么。

第③站充要条件——"双向通行证"

教材p20思考框问：哪些命题和它的逆命题（条件结论互换：若 q 则 p）都是真命题？四个里（1）（4）双向都真，（2）单向，（3）反向单向。双向都真的，教材p21正式命名：

既有 p⇒q，又有 q⇒p，记作 p⇔q，p 是 q 的充要条件（充分必要条件）

教材p21例3四问，看两道：（2）p：两三角形相似，q：三边成比例——"若p则q"是相似的性质定理、"若q则p"是相似的判定定理，双向都真，充要。（3）p：xy>0，q：x>0 且 y>0——p⇒q 是假的（x=−1, y=−3：xy=3>0 但都不正），非充要。

教材p21-22探究框往深走了一步："两组对边分别相等""一组对边平行且相等""对角线互相平分"……既充分又必要，全是"平行四边形"的充要条件——所以它们个个都能当定义用（"对角线互相平分的四边形叫做平行四边形"完全合法）。充要条件=等价刻画：一个概念可以有很多句长得不一样的定义，句句等价。

教材p22例4示范了"证充要"的标准动作：证"d=r 是直线 l 与⊙O 相切的充要条件"，分两步——充分性（p⇒q：d=r 时垂足在圆上，其余点都在圆外，l 与⊙O 只有一个公共点，相切）+必要性（q⇒p：相切则切点连线垂直于 l，d=r）。证充要=证两次，方向各一次，一步都省不得。

验一验③（先答，再看答案）

（自编）"x²=1"是"x=1"的什么条件？"x=1"是"x²=1"的什么条件？两句一起答。

答案：x²=1⇒x=1 是假命题（x=−1 反例），所以 x²=1 不是 x=1 的充分条件；反过来 x=1⇒x²=1 是真命题。所以：x²=1 是 x=1 的必要不充分条件；x=1 是 x²=1 的充分不必要条件。同一对命题，两问答案相反——全看箭头方向（sympy：solve(x²−1)={−1,1}⊇{1}·代验留痕）。

易错变形（自编）："a+b+c=0"是"方程 ax²+bx+c=0 有根 x=1"的什么条件？（教材p21例3(4)）——把 x=1 代回去：a+b+c=0，充要！这正是"因式定理"的雏形，高二用得上。

第④站四分类判断+集合会师

习题1.4（教材p22-23）要求用四种话回答：充分不必要 / 必要不充分 / 充要 / 既不充分也不必要。判断动作固定两步：

①验 p⇒q 真假；②验 q⇒p 真假；两个答案一拼，四选一：

⇒真⇒假=充分不必要 ｜ ⇒假⇒真=必要不充分 ｜ 双真=充要 ｜ 双假=既不充分也不必要

这张图在说什么：把条件和集合接上（习题1.4第4题）——条件越"苛刻"，圈越小；小圈是大圈的充分条件。特征越强越充分，特征越弱越必要。

验一验④（先答，再看答案·教材p23习题1.4第4题改述）

A={x|x 满足条件 p}，B={x|x 满足条件 q}。①若 A⊆B，p 是 q 的什么条件？②若 B⊆A 呢？③若 A=B 呢？

答案：①A⊆B：满足 p 的都满足 q，p⇒q 真——p 是 q 的充分条件（若只此一箭，答"充分不必要"）。②B⊆A：q⇒p 真，q 是 p 的充分条件，即 p 是 q 的必要条件。③A=B：双箭头，充要条件。

易错变形（自编·教材p23习题2同族）："x>y"是"x²>y²"的什么条件？——x=1, y=−2：x>y 真而 x²>y² 假（1>4 不成立），⇒假；x=−2, y=1：x²>y² 真而 x>y 假，⇐假。双假——既不充分也不必要条件。负数一进场，"平方保序"就失效。

卡住了？（三个最容易卡的地方，就地给出路）

· "必要"两个字总觉得别扭？——别用中文语感猜，就记一个画面：箭头图。p⇒q 里，p 是入场券（充分），q 是底线（必要）。读题时先把命题改写成"若p则q"，画出箭头，再对号入座。

· "p 是 q 的充分条件"和"q 的充分条件是 p"绕不清？——主语永远跟在"是"前面：谁是"……的充分条件"，谁就是箭头的尾巴。把句子还原成"p⇒q 成立"再判断。

· 四分类总答错？——先别背表。固定动作：两次真假判断写下来（p⇒q：□ q⇒p：□），按"⇒真⇒假=充分不必要｜⇒假⇒真=必要不充分｜双真=充要｜双假=都不"对号。动作固定就不会错。

收口三句话带走 + 自测四连

1. p⇒q 为真时：p 是 q 的充分条件（有p就够），q 是 p 的必要条件（没q就没p）——一个箭头两个名字，方向锁死。

2. 真命题找定理撑腰，假命题找反例定罪；判定定理发入场券（充分），性质定理画底线（必要）。

3. p⇔q=充要=等价定义；四分类判断=两次真假+对号；条件接集合：A⊆B 时"∈A"是"∈B"的充分条件（小圈充分，大圈必要）。

自测四连（先自己答，再对答案；答案直接给你）：

①（教材p17思考(3)改述）"x²−4x+3=0"是"x=1"的什么条件？
答案：解集{1,3}，x=3 时前真后假，⇒假；x=1⇒方程成立真。必要不充分条件。

②（自编）"两个三角形全等"是"两个三角形面积相等"的什么条件？
答案：全等⇒面积相等（性质），真；面积相等⇏全等（形状可不同，如3,3,3与2,3,4周长不等但可构造等积），假。充分不必要条件。

③（自编）"b²−4ac≥0"是"ax²+bx+c=0（a≠0）有实数根"的什么条件？（教材p23习题2(2)同族）
答案：判别式双向都真（有实根⇔判别式≥0）——充要条件。这是九年级判别式的"逻辑用语版身份证"。

④（自编）"a∈P∩Q"是"a∈P"的什么条件？"a∈P∪Q"是"a∈P"的什么条件？（教材p23习题2(3)(4)）
答案：交集：a∈P∩Q⇒a∈P 真，反向假——充分不必要（交集是小圈）。并集：a∈P∪Q⇏a∈P（可能在Q不在P），a∈P⇒a∈P∪Q 真——必要不充分（并集是大圈）。1.3的两个运算在这里各领一个方向。

练什么题：教材p20练习1-3（判充分/判必要/a∥b的角条件开放题——∠1=∠2等既是充分又走必要需分情况，开放题练"说理"）；p22练习1-3（充要判定+等腰梯形证明题练"两步证"）；p23习题1.4（四分类主战场：复习巩固2的5小题+判断4小题+综合运用4的集合会师题+拓广探索6的勾股逆定理）。时间紧就先做：习题2(1)(5)+习题3(3)(4)+综合运用4——四分类和集合会师是高考主考位。
