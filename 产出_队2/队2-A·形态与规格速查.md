## 一、两份黄金样本的结构件组织顺序与写法要点

### 1.1 共同装配序（两样本一致的8段结构，即 v2"课时块结构规格"的实物落地）

```
① 卷首引言块（标题下的 > 引用区）
② 课时开篇页（四件套：知识点清单/能力目标/难点预警/前置依赖）
③ 速览卡（10秒版，三问小表）
④ 正文讲解（小节化，含深入层引用块）
⑤ 经典例题（真题四段式）
⑥ 易错卡（表格，3~4张）
⑦ 应试打法（题型→通用思路编号清单）
⑧ 本节串联图（文字版五行）＋ 附：自检记录
```

### 1.2 卷首引言块（定位声明，两样本均有）

- 校准件写法：`> 用途：逸翔验收"能不能自学"的样本。只做一节，验收过→按此规格放量六科。` ＋对照阅读建议＋`本文件同时是形式规格的实物展示（速览卡/开篇页/例题四段/易错卡/轻量分层标记）`。
- 首件写法：`> 地位：全生产线首件——首件检验制试金石。终态标准产出，非草稿。` ＋`知识源：v18原节18项知识点逐条对账（零丢失清单见文末自检）｜规格：v2全项灌入`。
- 要点：开头三行说清**用途/地位、知识源、规格版本**，不写寒暄。

### 1.3 课时开篇页四件套写法（两样本同构）

1. **本节知识点清单**：一行顿号串联全部知识点（光合9项/呼吸10项），形态=先列全、一眼看清本课范围，不加解释。
2. **学完这节你能做到**（固定4条）：句式="给你X，你能Y / 能写出Z / 遇到W能V"，全部**可自查**。与知识点清单并列、不互相替代。
3. **难点预警**（固定3条，说话式）：原句示范——"这节最容易晕的地方是……先记住'一个拆水放氧，一个把二氧化碳做成糖'，细节再往里装""别背结论，背推导链（后面给你三步法）""O₂只在第三阶段出场。前面所有阶段都不需要氧——记住这一点，一半的题已经赢了"。句式=点名最容易错处＋给一句先手防御。
4. **前置依赖**：指名节号（⑬酶/⑭ATP）＋不过关的后果量化（"本节30%的题建立在ATP知识上"）＋回补指令（"先回去补"）＋镜像关系预告（"和⑮/⑯是镜像关系，学完互看"）。

### 1.4 速览卡（10秒版）

- 形态：三行小表 `| 问题 | 答案 |`，三问=**这节是什么 / 为什么重要 / 怎么考**（规格v2原文表述为"一句话本质 / 为什么存在（真实困境驱动）/ 怎么考（考位+题型）"）。
- "是什么"=一句话本质（光合："绿色细胞用光能，把CO₂和水做成有机物（糖），并放出氧气"）。
- "为什么重要"=真实困境/切身驱动（呼吸："你的每一次抬手、每一次心跳，此刻的能量都从这条链上来"），**禁金融商业比喻**。
- "怎么考"=考位＋题型枚举（光合骤变分析/同位素标记/科学史配对/净光合计算，四类题型）。

### 1.5 正文讲解写法要点（含深入层）

- **全景先行再拆解**："光合作用分两个阶段，场所不同、分工不同、互相配合。先给全景，再拆开讲。"
- **认知负荷显式分层**："第一遍读只需记住三件事的名字，NADPH的细节第二遍再回来看——一次别装太多"；呼吸件每阶段末尾固定收束行"*到此记住：糖在细胞质基质被拆成丙酮酸，少量产能，不用氧。*"
- **术语首现必带人话解释**（括号随文，日常语域）：丙酮酸="葡萄糖拆出来的'半成品'"；NADH="一种'携带氢和能量的分子'，此刻先记住名字"；类囊体薄膜="就是⑨讲叶绿体时说的那种堆叠起来的膜"；后续使用保持同名。
- **名称陷阱直说**："'暗'字是最大的坑：它指'不直接依赖光'，不是'在黑暗里进行'——白天光反应暗反应同时跑"+教材依据（2019教材正文保留此称呼）。
- **数量关系显式化**："1个C₅进去，2个C₃出来——这个'1变2'是后面骤变分析的数学基础。"
- **◎辅助理解｜单行轻量标记**（规格五-D定版形态，禁色块/边框/大段隔离）：样本B仅1处示范——"◎辅助理解｜为什么'线粒体是有氧呼吸的主要场所'而不是'全部场所'？——因为第一阶段在细胞质基质。题目最爱在这个'主要'上埋坑。"
- **深入层=必然性追问**（引用块形态）：`> 为什么这个设计是必然的（深入层，43秒）：光能有个天生缺陷——来得快，断得也快……两阶段设计本质就是这个能量转换层。这不是比喻，是这个化学系统存在的理由本身。` 时长标注（43秒）控制阅读预期。
- **数字口径标版本**："数字口径（2019人教版）：每mol葡萄糖约生成30mol ATP、约977.28kJ……旧教材'38ATP/1161kJ'是旧口径，别混用。"
- **独家边界事实加粗**："原核生物边界（独家边界事实，考试高频）……**别用'有没有线粒体'判断'能不能有氧呼吸'。**"
- **概念辨析前置**（呼吸件开篇即"先分清两个'不等于'"：细胞呼吸≠呼吸运动、有氧呼吸≠燃烧）。
- **记忆口令压缩清单**（应试打法内）："酒酵母淹根苹果；乳酸肌菌薯甜菜"。

### 1.6 经典例题·四段式（数学队重头，细写）

四段固定标签=`【题干】【解答】【思维标注】【定级】`，样本A另挂第五件**【同类一题自测】**。

1. **【题干】**：完整可读原题，前括号标注题型定位——样本A：`（高考骤变分析母题）将正常进行光合作用的植物突然停止光照……写出推导过程`；样本B：实验装置题含两个设问（`问：①B装置为何先密封放置一段时间？②能否只用"是否变浑浊"判断呼吸方式差异？`）。多设问编号①②，一题可多问。
2. **【解答】**：**箭头链式推导，一环不跳**——样本A：`停光→光反应立刻停止→ATP和NADPH断供→C₃的还原这一步缺了原料，受阻变慢→但CO₂的固定不需要光，照常进行，继续消耗C₅生产C₃→**C₃升、C₅降**`（最终结论加粗）；样本B按设问①②分段作答，每问先给结论句再给理由。
3. **【思维标注】**：本题方法论内核，两样本统一公式=**"唯一正确的做法是沿X推"＋显式步骤＋为什么背结论必翻车**。样本A：`本题唯一正确的做法是沿"场所—反应—物质流向"推，三步：①哪个反应停了？②下游谁缺原料？③上游谁还在供货？——背"C₃升C₅降"必翻车，因为题目换个条件（停CO₂）结论就反过来`；样本B：`第一步先问"装置的每一件东西排除了什么干扰"——NaOH除CO₂、封口除O₂，都是控制变量。第二步明确检测指标的灵敏度……`。**数学队对应动作：把解题的思维触发点、第一步看什么、为什么某类背法会翻车写透，不写"细心即可"类空话。**
4. **【定级】**：考频/难度＋考点归属＋衍生关系——样本A：`高考B5章最高频大题骨架，衍生题全部是这条推导链的变形`；样本B：`中等｜考点=实验装置逻辑+产物检测。同类变式：换溴麝香草酚蓝问颜色变化顺序（蓝→绿→黄）`。
5. **【同类一题自测】**（"先试后看"结构，测试效应落地）：给一条单变量变式＋激励语——`若突然停止CO₂供应呢？（答案：固定停、还原还在→C₃降、C₅升。自己推一遍，推对了这类题就毕业了。）`答案附后但明确要求先自推。
6. **宁缺毋编红线**（首件自检原文）：`例题为题型示范（结构还原自v18题8骨架），未标注具体真题年份号——真题号回源后补标，不编造。`——**没有真题号的题宁可声明待回源，不许编造题源**。

### 1.7 易错卡（现象→错因→维持机制→钉死）

- 形态：四列表格 `| 症状 | 错因 | 维持机制 | 钉死 |`，校准件3张、首件4张，取"本节最高频"。
- 逐列写法：**症状**=学生原话级错误表述（"暗反应必须在黑暗中进行"）；**错因**=认知根源一句话（被"暗"字骗了/把总反应式里的O₂平移到每一步）；**维持机制**=为什么会反复犯（错一次后凭字面再犯，不查定义/直觉与同位素证据冲突时靠直觉/"光合需要光"被泛化成"呼吸也要等光"）；**钉死**=反例或证据＋改写后的正确表述（同位素实锤：¹⁸O标记水→氧气有放射性……氧全部来自水）。
- 规格v2对应要求：易错题结构=**现象→错因→维持机制→处置**；生成效应落地=误解卡"先给现象后给解释"。

### 1.8 应试打法／串联图／自检记录

- **应试打法**：编号清单，每条=题型名＋该题型通用思路，**从真题归纳，不抄套路书**。样例："骤变分析题：三步推导法（停了什么→下游谁断供→上游谁还在跑），永不用背结论""装置图题：每件仪器问一句'它排除了什么干扰'"。
- **本节串联图**（文字版）：固定五行=`上游：…／本节：…／镜像：…（O₂/CO₂互为原料）／下游：…／边界：…`（边界行给易混概念切割，如"自养≠光合——硝化细菌走化能合成"）。**节标题固定写法=`## 本节串联图（文字版）`，括注内禁带逗号（1023晚残逗号×8源头即本行，勿再复制旧形态）。**
- **跨章指涉硬规（1024凌晨终验裁定③·全队2执行）**：正件/串联图跨章指涉一律**「节号+节名（第X章）」制**——如"2.3二次函数与一元二次方程、不等式（第二章·解集书写）""第四章指数函数与对数函数（定义域先行）"；**M系编号废止**（M1/M2/M3…系v18章末卡内部编号，学生无此坐标系，不得入正件——1.x/2.x存量件"M2解集书写"等由升格批次清洗）；未回源节名的章只写章名（如"第五章三角函数（角集表示）"），宁缺毋编不造节名。（事故源头=1.x/2.x代差层M系指涉×多处+1.4对位表语句×1，1024凌晨终验先导批§五实扫）
- **附：自检记录**：三块——①知识零丢失逐条对账（首件18项逐条打钩"18/18零丢失"）②规格合规机检（金融语域机检零命中/认知负荷分层/◎标记/术语首现/黑名单二级词零命中/发前三查）③过程实锤与声明（第二轮复扫抓出自己换血时自造的金融比喻并清除；宁缺毋编声明）。

## 二、设计规格v2·正文制作硬性要求逐条清单

> 源：《学习资料设计规格 v2.0》（生成2026-10-22 23:05，母表=57条理解锁定表）。总纲口径："本规格是校准件与六科放量的唯一依据。与57条锁定表冲突时以锁定表为准。"以下仅收**与正文/制卡制作直接相关**的硬性条款。

### 2.1 课时块结构规格（每节的装配序，v2标准形态）

1. **课时开篇页**（35+22合体）：知识点清单（先列全、一眼看清范围）＋能力目标2-4条（"会解X类题/能解释Y现象"句式，可验收，与清单并列不互替）＋难点预警1-3条（说话式）＋前置依赖（"你需要前面的X（没有→先回哪节哪卡）"）。
2. **速览卡**（2条，10秒级）：一句话本质／为什么存在（真实困境驱动）／怎么考（考位+题型）。
3. **正文讲解**（1/4/8/19/44）：零背景可读——所有前置概念随文解释，**术语首现必带人话解释**；难点拆解层——大步→小步→每步为什么，读起来不断线；深入层——**为什么必须这样定义/这样规定（必然性追问≥3层，服务理解不炫技）**。
4. **例题区**（18/7/31）：经典例题=**真题四段式（题干/解答/思维标注/定级）**；易错题=**现象→错因→维持机制→处置**；应试打法=该题型通用思路（从真题归纳，不抄套路书）。
5. **章级收口**（39/29）：章尾思维导图＋章首全章地图（页码齐全）；节间串联显式化——每节标依赖，章内逻辑线成图。

### 2.2 表达规格

6. **语感基准**：读出来像人说的话；类比语域=日常生活零学习成本场景（游戏/做饭/运动/校园）；**金融商业语域全清除**（票据/汇率/存货/变现/回收/收购/现金流……生物册光合段为第一换血对象）。
7. **删减判据**：每段问"删掉会不会丢信息/丢理解"——不会就删；**结论在段首**；知识获取效率是唯一判据。
8. **辅助内容分层**：考点内容无标记为主干；高效辅助理解内容用轻量视觉语言显式隔离（侧栏/浅底纹，不用大块标签砸脸）；金融类等零收益内容删除不留。
9. **术语规则**：首现必带人话解释；解释必须是日常语域；后续使用保持一致。
10. **亮点归槽**：亮点盘点后归入固定槽位（速览卡"最反直觉"/误解卡/应试打法），散落的全收（评分权在逸翔）。

### 2.3 形式规格

11. **目录**：补页码＋页码与正文严格对齐。
12. **净化**：AI制作过程内容（审计/版本/过程说明）全部清出学生版；净化复查进验证轮。
13. **公式与图像**：生产层生成实体——**分数式LaTeX/MathML渲染，图像管线产出（结构图/示意图），占位符禁止入册**。（数学队重点：一切公式必须可渲染实体，禁止文本近似或占位。）
14. **排版**：12.6px衬线基线＋第一版优点保留（盘点清单随校准件交付）＋段距/分栏/卡片化。
15. **视觉呼吸**：块间距明确，信息层级一眼清，不黏连。

### 2.4 质量规格

16. **事实溯源**：每条溯源（教材页/真题号/官方文件号），**无溯源不进册**；"绝对正确"做不到，做到工程极限＋发现即修。
17. **验证制度化**：每版双轮复扫（修复轮→复扫→换失效模式→零新发现收敛），非可选。
18. **真实度基准**：不低于生物册v18。
19. **覆盖双清单**：高考考点＋平时练习考点；教材外但真题在考的点单列"教材外考点"层标注来源；考点底表机检逐节打钩。
20. **不确定如实标注**，禁止含糊带过。

### 2.5 流程规格

21. **设计先行顺序锁定**：对标→规格→校准件→验收→放量。
22. **修复制度化**：每轮修复必须更新规格/清单/流程文件，不许靠单次努力。
23. **制作日志全程留痕**，每步对账总锚（总锚=快速自学四条：单位时间获取效率最大化／册子+视频不依赖老师的完整闭环／学=直接得分能力／长期可持续不断链）。
24. **重复检查**：改过的必回头看，走过的路日志可回溯。
25. **成本约束解除**（逸翔23:33令）：复扫N轮跑到零新发现为止；事实核验抽检改**全检**；退回重做免费且不设次数；所有环节按质量天花板排。

### 2.6 数学思维骨架（队2专属，五-A节）

26. **数学=逻辑链推导观**：每个定义问**"为什么必须这样规定"**，**从反例与不定义的后果讲必然性**。讲解组织方式禁套其他科模板（生物=结构-功能对应观/物理=建模观/化学=三重表征观，各有其骨架）。
