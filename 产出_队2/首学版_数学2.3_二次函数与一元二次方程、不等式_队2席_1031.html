读完这节你能做到（对照教材p50-55）：

③ 背出并会画表2.3-1：Δ>0、Δ=0、Δ<0 三种情况下，方程的根与两个不等式的解集；

④ 处理两个常见变装：a<0（先化正）和根号包装（如 √(x²−4x+9) 有意义）；

⑤ 用三步法解应用题（摩托车创收、刹车车速这类"列式→整理→三步走→答"）。

30秒立好地基（全是初中存货+1.1的话术，本节新概念只有一个）

· 二次函数 y=ax²+bx+c：图象是抛物线，a>0 开口向上（两头上翘），a<0 开口向下；

· 一元二次方程 ax²+bx+c=0：判别式 Δ=b²−4ac。Δ>0 两个不等实根，Δ=0 两个相等实根 x₁=x₂=−b/(2a)，Δ<0 没有实数根——初中"根的判别式"换了个花名；

· 解集记号 {x|…}：1.1 学过，如 {x|2<x<10} 读作"使 2<x<10 成立的所有 x 组成的集合"；

· 本节新词只有"零点"：第②站登场，其实就是方程的根换了件马甲。

第①站园艺师的问题——从不等式①到"一元二次不等式"

教材p50问题1（原题）：园艺师打算在绿地上用栅栏围一个矩形区域种植花卉。若栅栏的长度是24 m，围成的矩形区域的面积要大于20 m²，则这个矩形的边长为多少米？

图A · 问题1矩形示意（按教材p50题面绘制）

设这个矩形的一条边长为 x m，则另一条边长为 (12−x) m（总长24的一半是12）。由题意，得

(12−x)x > 20，

其中 x∈{x|0<x<12}（边长必须为正）。整理（去括号、移项）得

x² − 12x + 20 < 0，x∈{x|0<x<12}。　　①

教材p50接着说："求得不等式①的解集，就得到了问题的答案。"

于是教材给出定义（p50原话）：一般地，我们把只含有一个未知数，并且未知数的最高次数是2的不等式，称为一元二次不等式（quadratic inequality with one unknown）。一元二次不等式的一般形式是

ax² + bx + c > 0 或 ax² + bx + c < 0，

其中 a，b，c 均为常数，a≠0。

红批（为什么必须a≠0）：若a=0，式子退化成 bx+c>0——那是一元一次不等式，"二次"二字就落空了。定义里的a≠0不是挑刺，是保住"二次"的身份。

教材p50思考框（原话）："在初中，我们学习了从一次函数的观点看一元一次方程、一元一次不等式的思想方法。类似地，能否从二次函数的观点看一元二次不等式，进而得到一元二次不等式的求解方法呢？"——这个"能否"，就是全节的发动机。

验一验①（判型，答案就在冒号后）

· "x²−12x+20<0 是一元二次不等式吗？"——是：一个未知数x，最高次数2。

· "那 (12−x)x>20 呢？"——整理前带着积的形式不好认，整理成①后就是。判断前先整理成一般式，这是好习惯。

· 易错变形（自编）："ax²+bx+c>0 中把a取成0行不行？"——不行，退化成一元一次；同理 2x²−13x+20≤0（2.1欠的账）里 a=2≠0，是货真价实的二次。

第②站零点登场——一张图把三兄弟焊在一起

教材p50说：先考察 x²−12x+20<0 与 y=x²−12x+20 之间的关系。如图2.3-1画出抛物线，图象与x轴有两个交点，横坐标正是方程 x²−12x+20=0 的两个实数根 x₁=2，x₂=10，交点即 (2,0) 和 (10,0)。

然后是本节唯一的新定义（p51原话）：一般地，对于二次函数 y=ax²+bx+c，我们把使 ax²+bx+c=0 的实数x叫做二次函数 y=ax²+bx+c 的零点。于是 y=x²−12x+20 的两个零点就是 x₁=2，x₂=10。

图B · 图2.3-1精确重绘（Python逐点计算：零点(2,0)(10,0)，顶点(6,−16)）

三段分析（p51原话的逻辑，一步不跳）：两个零点 x₁=2，x₂=10 把x轴分成三段。

· 当 x<2 或 x>10 时，图象位于x轴上方，此时 y>0，即 x²−12x+20>0；

· 当 2<x<10 时，图象位于x轴下方，此时 y<0，即 x²−12x+20<0。

所以一元二次不等式①的解集是

{x | 2 < x < 10}。

回看问题1：因为 {x|2<x<10} ⊆ {x|0<x<12}，所以当边长x满足 2<x<10 时，面积大于20 m²——园艺师的问题答完。

验一验②（代值实验：让图象说话）

· x=6（两零点正中间）：36−72+20=−16<0 ✓ 中段确实小于0；

· x=0（区间外）：0−0+20=20>0 ✓ 外段确实大于0；

· 易错变形：x=2呢？4−24+20=0。0不小于0，所以x=2不在解集里！零点是"分界牌"，不是"解员"——①里的"<"不带等号，解集就是开区间(2,10)。（自编提醒）

· 变式1（自编，只改不等号方向）：x²−12x+20>0 的解集？——同一张图反着读：图象在x轴上方的部分，即 {x|x<2 或 x>10}。

第③站表2.3-1——三情况全表，背图不背死表

教材p51把这套"看图说话"一般化（原话逻辑）：上述方法可以推广到求一般的一元二次不等式 ax²+bx+c>0(a>0) 和 ax²+bx+c<0(a>0) 的解集。因为一元二次方程的根是相应一元二次函数的零点，所以先求出一元二次方程的根，再根据二次函数图象与x轴的相关位置确定一元二次不等式的解集。

设 Δ=b²−4ac，方程的根按 Δ>0、Δ=0、Δ<0 分三种情况，图象与x轴的位置关系也随之三种，于是解集分三种情况讨论（表2.3-1）。

表2.3-1　二次函数与一元二次方程、不等式的解的对应关系（教材p51原表复刻）：

（原表中"图象"一栏是三幅小图，这里用图C替代表格内的图，含义一致。）

红批（自编口诀·标注自编）：开口向上（a>0）前提下，"大于0取两边，小于0取中间"——两边就是{x|x<x₁或x>x₂}，中间就是{x|x₁<x<x₂}。Δ=0时"中间"缩成一个点，解不了"x=它"这件事，所以<0变∅、>0变成"挖掉一个点"。Δ<0时整条抛物线悬在上方，>0全体实数都行（R），<0谁也不行（∅）。

验一验③（表格活用·双向踩坑，答案在冒号后）

· "x²−3x+4>0 的解集？"——Δ=9−16=−7<0，开口向上悬空 → R。易错点：别看见Δ<0就写∅！Δ<0只说"方程没根"，">0"的解集恰恰是全体实数。

· "(x−1)²>0 的解集？"——Δ=0型，唯一零点x=1被"挖掉" → {x|x≠1}。既不是R（x=1使式子=0）也不是∅。

· 易错变形（自编）："∅ 什么时候出现？"——开口向上时，只有"<0"配上"Δ≤0"：Δ=0给∅（如(x−1)²<0），Δ<0也给∅（如x²−x+1/4<0，(x−1/2)²<0）。"方程无实数根"和"不等式解集为空"是两句话，别混写。

第④站例题实战——三条路线+流程图+两道应用

例1（Δ>0路线·教材p52）求不等式 x²−5x+6>0 的解集

分析（教材原话逻辑）：方程x²−5x+6=0的根是函数y=x²−5x+6的零点，所以先求根，再结合图象写解集。

解：对于方程 x²−5x+6=0，因为 Δ>0，它有两个实数根，解得 x₁=2，x₂=3（因式分解(x−2)(x−3)=0，或求根公式）。画出 y=x²−5x+6 的图象（图2.3-2），结合图象得解集为

{x | x<2，或 x>3}。

· 变式2（自编）：只把">0"改成"<0"：x²−5x+6<0 → {x|2<x<3}。同一根、同张图，方向一翻，答案从"两边"变"中间"。

例2（Δ=0路线·教材p52）求不等式 9x²−6x+1>0 的解集

解：对于方程 9x²−6x+1=0，因为 Δ=0，它有两个相等的实数根，解得 x₁=x₂=1/3（9x²−6x+1=(3x−1)²）。画出 y=9x²−6x+1 的图象（图2.3-3），结合图象得解集为

{x | x≠1/3}。

图象只在x=1/3处碰一下x轴，其余全部悬在上方——所以除1/3外处处大于0。

例3（a<0先化正·教材p52）求不等式 −x²+2x−3>0 的解集

解（教材原样）：不等式可化为 x²−2x+3<0（两边同乘−1，不等号方向改变——2.1性质4在岗）。因为 Δ=(−2)²−4×1×3=−8<0，所以方程 x²−2x+3=0 无实数根。画出 y=x²−2x+3 的图象（图2.3-4），结合图象得 x²−2x+3<0 的解集为∅。因此，原不等式的解集为∅。

教材侧栏红批（p52原话）："对于二次项系数是负数（即a<0）的不等式，可以先把二次项系数化成正数，再求解。"——乘负要变向，这是2.1不等式性质4的直接应用。

· 变式3（自编）：把例3的">0"改成"<0"：−x²+2x−3<0 ⇔ x²−2x+3>0，Δ=−8<0悬空 → R。同一式子，方向一翻，∅变R——做题前先看清不等号！

例4（应用·摩托车创收·教材p53-54）

题面（教材原文）：一家车辆制造厂引进了一条摩托车整车装配流水线，这条流水线生产的摩托车数量x（单位：辆）与创造的价值y（单位：元）之间有如下关系：y=−20x²+2200x。若这家工厂希望在一个星期内利用这条流水线创收60000元以上，则在一个星期内大约应该生产多少辆摩托车？

解（教材路线）：设一周生产x辆，根据题意得 −20x²+2200x>60000。移项整理（两边减60000）：x²−110x+3000<0。对于方程 x²−110x+3000=0，Δ=100>0，两个实数根 x₁=50，x₂=60。画出 y=x²−110x+3000 的图象（图2.3-6），结合图象得解集 {x|50<x<60}。

回到实际（教材原话逻辑）：因为x只能取整数值，所以当这条流水线在一周内生产的摩托车数量在51~59辆时，这家工厂能够获得60000元以上的收益。

例5（应用·刹车距离·教材p54）

题面（教材原文）：某种汽车在水泥路面上的刹车距离s（单位：m）和汽车刹车前的车速v（单位：km/h）之间有如下关系：s=(1/20)v+(1/180)v²。在一次交通事故中，测得这种车的刹车距离大于39.5 m，那么这辆汽车刹车前的车速至少为多少（精确到1 km/h）？

解（教材路线）：根据题意 (1/20)v+(1/180)v²>39.5。两边乘180（正数，方向不变）：9v+v²>7110，即 v²+9v−7110>0。对于方程 v²+9v−7110=0，Δ>0，两个实数根 v₁=(−9−√28521)/2，v₂=(−9+√28521)/2。结合图象（图2.3-7），解集为 {v|v<v₁，或 v>v₂}。

因为车速v>0，所以取 v>v₂。教材估计：79.9<v₂<80（自验算：80代入 v²+9v−7110 得 6400+720−7110=10>0，79代入得 −158<0，根夹在79和80之间且靠近80），所以刹车前的车速至少为80 km/h。

教材侧栏（p54）："刹车距离是指汽车刹车后由于惯性往前滑行的距离。"——物理直觉：越快越刹不住，所以"距离超限"推出"车速偏高"（v>v₂），而不是偏低。

回环——2.1欠的账，今天结清（教材p54原话）

教材p54："类似地，第2.1节的不等式①经移项整理，得 2x²−13x+20≤0。用上述方法解这个不等式，得 {x|2.5≤x≤4}。所以，当每本杂志的定价不低于2.5元且不超过4元时，提价后的销售总收入不低于20万元。"

自验算：2x²−13x+20=0 的根 x=(13±√(169−160))/4=(13±3)/4，即 x=2.5 或 x=4；开口向上，"≤0"取中间（含等号），所以 {x|2.5≤x≤4} ✓。注意这里带等号——"<"变"≤"，边界零点就收进解集（验一验②的易错点在此兑现）。

验一验④（a<0化正+根号伪装，答案在冒号后）

· "13−4x²>0 的解集？"（习题2.3第1(1)提前试）——a=−4<0，两边乘−1/4变向：x²−13/4<0 → {x|−√13/2<x<√13/2}（约−1.80<x<1.80）。化正、取中间、一步到位。

· 易错变形（习题2.3第2(1)）："x是什么实数时，√(x²−4x+9) 有意义？"——根号里需 x²−4x+9≥0。配方：(x−2)²+5≥5>0恒成立 → 一切实数（R）。Δ=16−36=−20<0披了件根号外衣，本质还是"Δ<0时>0解集是R"。别被根号吓住，先配方或算Δ。

收口·60秒复述（读完合上件，这三句话能背出来就算通）

第一句：零点是焊接点——方程ax²+bx+c=0的根 = 函数y=ax²+bx+c的零点 = 图象与x轴交点的横坐标，三者一个东西。

第二句：三步走——化成a>0（负系数乘−1变向）→ 算Δ求根 → 开口向上看图：大于0取两边，小于0取中间；Δ=0挖点，Δ<0悬空。

第三句：坑在边界与方向——a<0先化正；"<"不带等号零点不进解集，"≤"才带；Δ<0时">0"解集是R不是∅；应用题最后回实际（取整、单位、范围）。

节末自测·四连（教材原题·答案直接写在下方，先做后看）

① （p53练习1(1)）(x+2)(x−3)>0；　② （p53练习1(3)）−x²+4x−4<0；

③ （p53练习1(4)）x²−x+1/4<0；　④ （p55习题2.3·综合运用3）已知 M={x|4x²−4x−15>0}，N={x|x²−5x−6>0}，求 M∩N，M∪N。

答案：① 零点−2和3，取两边：{x|x<−2 或 x>3}。② 化正：x²−4x+4>0，(x−2)²>0，Δ=0型挖点：{x|x≠2}。③ (x−1/2)²<0，平方不小于0（开口向上最小值0在x=1/2处取到，仍不<0）：∅。④ M：4x²−4x−15=(2x−5)(2x+3)>0 → {x|x<−3/2 或 x>5/2}；N：x²−5x−6=(x−6)(x+1)>0 → {x|x<−1 或 x>6}；M∩N={x|x<−3/2 或 x>6}，M∪N={x|x<−1 或 x>5/2}（并集左边取更宽的N臂：x<−3/2被x<−1整段吸收）。

高考怎么考（T11考位锚·候采）
