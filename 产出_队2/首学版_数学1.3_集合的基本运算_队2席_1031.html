集合的基本运算：给集合装上"合并、取公共、挖掉"三个按钮

数学1.3 · 集合与常用逻辑用语 · 零基础首学版 v1.0 · 前置：认识 ⊆ 和 ∅（1.2学过；模糊了？往下30秒补齐）

开场实数能加减，集合也能"算"

数能算：3+5=8。集合呢？教材p10开场就这样问："实数有加、减、乘、除等运算。集合是否也有类似的运算呢？"

有，而且就三个按钮：合并两个集合（并集）、取公共部分（交集）、在一个范围内挖掉一部分（补集）。学会这三个按钮，"由一大堆元素组成的一坨"就变成了能运算的对象——后面解不等式写解集、求定义域，全是这三个按钮在后台干活。

读完这节你能

① 给两个集合算并集和交集，写出记号 ∪、∩ 并画出Venn图；
② 在一个全集里算补集 ∁UA，说清"为什么要先指定范围"；
③ 在数轴上做区间的并、补，端点开闭不写错；
④ 避开"公共元素重复写""忘指定全集"这两个新手坑。

预备30秒补齐两个记号（已会的跳过）

A ⊆ B 读"A是B的子集"：A里的每一个元素，B里都有（1.2学的"装得下"关系）。

∅ 读"空集"：一个元素都没有的集合。它是集合里的"0"。

还有一个约定：集合常用大括号装元素，如 A = {1, 2, 3}；也可以用"描述法"装一整类数，如 {x | x > 1} 读"所有满足 x>1 的 x 组成的集合"——竖线意思是"满足"。

验一验（10秒）：{a, b} 和 {b, a} 是同一个集合吗？
→ 是。集合只看"有哪些元素"，不看排队顺序（1.1的老规矩：无序、互异、确定）。

第一站并集 ∪：两个集合"合起来"

先看教材p10"观察"栏给的两组例子，找感觉：

（1）A = {1, 3, 5}，B = {2, 4, 6}，C = {1, 2, 3, 4, 5, 6}；

（2）A = {x | x 是有理数}，B = {x | x 是无理数}，C = {x | x 是实数}。

每组里，C 恰好是"把 A 和 B 的元素全部倒进一个锅"——教材原话：C 是由所有属于 A 或属于 B 的元素组成的。

把"全部倒进一个锅"写成正式定义（教材p10原文）：

并集（union set，教材定义）：由所有属于集合 A 或属于集合 B 的元素组成的集合，称为 A 与 B 的并集，记作 A∪B（读"A并B"），即

A∪B = {x | x∈A，或 x∈B}

"或"在这里不是日常的"二选一"，是"至少占一个"：只在A、只在B、两边都在——三种都收进并集。

这张图在说什么：并集 = 两个圈整体（含重叠部分）。教材图1.3-1同款。

坑1（教材p10边栏框原话）："在求两个集合的并集时，它们的公共元素在并集中只能出现一次。如元素 5，8。"

教材举例的5、8来自例1里A、B共有的元素。集合的元素讲"互异"——{3, 4, 5, 5, 6, 8, 8}这种写法不合法，重复的必须合并成一个。

例1（教材p10原题）：离散集合的并

设 A = {4, 5, 6, 8}，B = {3, 5, 7, 8}，求 A∪B。

解（教材原文）：A∪B = {4, 5, 6, 8}∪{3, 5, 7, 8} = {3, 4, 5, 6, 7, 8}。

逐步看：把A的4个全写下 → 补上B独有的3、7 → 5和8两边都有，只写一次（坑1）。这就是教材边栏框说的"如元素5，8"。

例2（教材p10原题）：区间（不等式）集合的并

设集合 A = {x | −1 < x < 2}，B = {x | 1 < x < 3}，求 A∪B。

解（教材原文）：A∪B = {x | −1 < x < 2}∪{x | 1 < x < 3} = {x | −1 < x < 3}。

为什么能合并成一段？A 管 −1 到 2 之间，B 管 1 到 3 之间——中间 1 到 2 这段两边都管（"或"=至少占一个），所以从 −1 到 3 无缝连成一整段。

这张图在说什么：教材图1.3-2同款——A 在上、B 在中、A∪B 在下。两段一拼，中间无缝；端点 −1 和 3 保持空心（x=−1、x=3 都不满足"严格小于"）。

坑2：区间并集最容易把端点写错。并集的端点 = 原来各段端点"谁更外面用谁，开闭跟着原段走"。例2里 −1 是A的开端 → 并集在 −1 处仍开；3 是B的开端 → 并集在 3 处仍开。别一合并就全改实心。

思考（教材p11原题）：下列关系式成立吗？　(1) A∪A = A；(2) A∪∅ = A。

都成立。(1) 自己和自己合并，元素没多没少；(2) 跟空集合并，∅ 一个元素都不提供——等于白并。记住：∅ 在并集运算里扮演"加0"的角色。

验一验（30秒，自编题）：{x | x 是正偶数} ∪ {x | x 是正奇数} = ?
→ {x | x 是正整数}。每个正整数至少是"正偶数或正奇数"之一——"或"字收编全部。

第二站交集 ∩：只留"两边都要"的

再看教材p11"思考"栏两组例子：

（1）A = {2, 4, 6, 8, 10}，B = {3, 5, 8, 12}，C = {8}；

（2）A = {x | x 是立德中学今年在校的女同学}，B = {x | x 是立德中学今年在校的高一年级同学}，C = {x | x 是立德中学今年在校的高一年级女同学}。

每组里，C 只收"既在 A 又在 B"的成员。教材原话：C 是由所有既属于 A 又属于 B 的元素组成的。

交集（intersection set，教材p11定义）：由所有属于集合 A 且属于集合 B 的元素组成的集合，称为 A 与 B 的交集，记作 A∩B（读"A交B"），即

A∩B = {x | x∈A，且 x∈B}

"且"比"或"严：两边必须同时满足，缺一不可。并集"或"收得宽，交集"且"卡得严。

这张图在说什么：交集 = 只染重叠月牙。教材图1.3-3同款。

例3（教材p11原题）：运动会里的交集

立德中学开运动会，设 A = {x | x 是立德中学高一年级参加百米赛跑的同学}，B = {x | x 是立德中学高一年级参加跳高比赛的同学}，求 A∩B。

解（教材原文）：A∩B 就是立德中学高一年级中那些既参加百米赛跑又参加跳高比赛的同学组成的集合。所以

A∩B = {x | x 是立德中学高一年级既参加百米赛跑又参加跳高比赛的同学}

"既……又……"就是"且"的日常版。一个同学只跑百米不跳高？只在A不在B——交集不收。

例4（教材p12原题）：用交集给直线位置关系"记账"

设平面内直线 l₁ 上点的集合为 L₁，直线 l₂ 上点的集合为 L₂，试用集合的运算表示 l₁，l₂ 的位置关系。

解（教材原文）：平面内直线 l₁，l₂ 可能有三种位置关系，即相交于一点、平行或重合。

（1）直线 l₁，l₂ 相交于一点 P 可表示为 L₁∩L₂ = {点P}；

（2）直线 l₁，l₂ 平行可表示为 L₁∩L₂ = ∅；

（3）直线 l₁，l₂ 重合可表示为 L₁∩L₂ = L₁ = L₂。

翻译一下：交出一个点 = 相交；交出空集 = 平行（永不见面）；整条线都交 = 重合。交集反过来当"探测器"——看交出来是什么，就知道位置关系是哪种。这是"几何问题翻译成集合语言"的第一课。

思考（教材p12原题）：下列关系式成立吗？　(1) A∩A = A；(2) A∩∅ = ∅。

都成立。(1) 自己∩自己=自己；(2) 空集里没有任何元素能满足"既在A又在∅"——交出来还是∅。对照着记：∅ 在并集里是"加0"，在交集里是"乘0"。

验一验（30秒，自编题）：{x | x 是你们的班主任} ∩ {x | x 是你们的数学老师} = ?
→ 若班主任恰是数学老师本人，交集就是{他/她}；若不是，交集是 ∅。交集大小取决于"两边都要"能筛出谁。

练习（教材p12原题，先做再看答案）

1. 设 A={3, 5, 6, 8}，B={4, 5, 7, 8}，求 A∩B，A∪B。

2. 设 A={x | x²−4x−5=0}，B={x | x²=1}，求 A∪B，A∩B。

3. 设 A={x | x 是等腰三角形}，B={x | x 是直角三角形}，求 A∩B，A∪B。

4. 设 A={x | x 是幸福农场的汽车}，B={x | x 是幸福农场的货车}，求 A∪B。

答案：1. A∩B={5, 8}（两边都有的只有5和8），A∪B={3, 4, 5, 6, 7, 8}。
2. 先解方程：x²−4x−5=0 得 x=5 或 x=−1，A={−1, 5}；x²=1 得 x=±1，B={−1, 1}。A∪B={−1, 1, 5}，A∩B={−1}。先解出元素再运算——负根−1别漏。
3. A∩B={x | x 是等腰直角三角形}（既等腰又直角），A∪B={x | x 是等腰三角形或直角三角形}。
4. A∪B={x | x 是幸福农场的汽车}。想通它：农场里的货车也是汽车，所以B（货车）的每个元素都在A（全部汽车）里，即B⊆A——大圈并小圈还是大圈，A∪B=A。

第三站全集与补集：先画个圈，再谈"挖掉"

问："{x | x 不是 1.2 班的同学}"——这个集合有多大？全校？全市？全人类？没说范围，"不是"就没法收尾。所以做"取反、挖掉"这类运算前，必须先画一个圈，把讨论限制在圈内。这就是全集。

全集（universal set，教材p12定义）：一般地，如果一个集合含有我们所研究问题中涉及的所有元素，那么就称这个集合为全集，通常记作 U。

教材边栏框补了一句："通常也把给定的集合作为全集"——题目给谁当U，圈就画到哪，别自己扩大战场。

为什么范围重要？教材p12用解方程举例（原文展开）：

方程 (x−2)(x²−3)=0 的解集：

· 在有理数范围内讨论：√3、−√3 不是有理数，进不了圈——{x∈Q | (x−2)(x²−3)=0} = {2}，只有一个解；

· 在实数范围内讨论：三个解全进来——{x∈R | (x−2)(x²−3)=0} = {2, √3, −√3}。

同一个方程，圈画得不同，答案就不同。范围（全集）是答案的一部分。

补集（complementary set，教材p13定义）：对于一个集合 A，由全集 U 中不属于集合 A 的所有元素组成的集合，称为 A 相对于全集 U 的补集，简称为 A 的补集，记作 ∁UA，即

∁UA = {x | x∈U，且 x∉A}

卡住了？记号怎么读："∁"读"补"，下标 U 写明"在谁的圈里补"。∁UA 读"A在U中的补集"。下标不是装饰——换个圈，答案就变（教材p13练习2专门练这个）。

这张图在说什么：补集 = 大矩形里圆外的全部阴影。圆A自己不在补集里。

例5（教材p13原题）：先展开U，再挖洞

设 U = {x | x 是小于 9 的正整数}，A = {1, 2, 3}，B = {3, 4, 5, 6}，求 ∁UA，∁UB。

解（教材原文）：根据题意可知，U = {1, 2, 3, 4, 5, 6, 7, 8}，所以

∁UA = {4, 5, 6, 7, 8}，　∁UB = {1, 2, 7, 8}

套路两步：第一步展开U（把"小于9的正整数"点齐：1到8）；第二步挖洞（U里划掉A的成员，剩下的抄出来）。注意3同时在A和B里——分别被各自挖掉，两次挖掘互不干扰。

例6（教材p13原题）：文字集合的补集

设全集 U = {x | x 是三角形}，A = {x | x 是锐角三角形}，B = {x | x 是钝角三角形}，求 A∩B，∁U(A∪B)。

解（教材原文）：根据三角形的分类可知

A∩B = ∅，　∁U(A∪B) = {x | x 是直角三角形}

一个三角形能同时是锐角三角形和钝角三角形吗？不能——A∩B=∅。A∪B 收了"锐或钝"，挖掉它们，U 里剩下直角三角形。教材这题还藏着一句潜台词：∪ 和 ∁ 可以套着用——先算括号里的并，再对结果取补。

练习（教材p13原题，先做再看答案）

1. 已知 U={1, 2, 3, 4, 5, 6, 7}，A={2, 4, 5}，B={1, 3, 5, 7}，求 A∩(∁UB)，(∁UA)∩(∁UB)。

2. 设 S={x | x 是平行四边形或梯形}，A={x | x 是平行四边形}，B={x | x 是菱形}，C={x | x 是矩形}，求 B∩C，∁AB，∁SA。

3. 图中 U 是全集，A、B 是 U 的两个子集，用阴影表示：(1) (∁UA)∩(∁UB)；(2) (∁UA)∪(∁UB)。

答案：1. 先各自展开：∁UB={2, 4, 6}，∁UA={1, 3, 6, 7}。A∩(∁UB)={2, 4}；(∁UA)∩(∁UB)={6}。
2. B∩C={x | x 是正方形}（既菱又矩=正方形）；∁AB=∅（菱形都是平行四边形，在A里挖不出去东西）；∁SA={x | x 是梯形}（S里去掉平行四边形，剩梯形——这就是"换圈答案变"的活例子）。
3. (1) 阴影=A、B两圆外面的区域（既不在A也不在B）；(2) 阴影=两圆重叠月牙之外的所有区域（不在A或不在B——只有"A∩B"那一小块被排除）。

验一验（30秒，自编题）：U={1, 2, 3, 4, 5}，A={1, 2}。算 ∁UA，再算 ∁U(∁UA)。
→ ∁UA={3, 4, 5}；再补一次，U里挖掉{3,4,5}，剩{1, 2}——补回来又变成A自己了。连补两次回到原地（"负负得正"的集合版）。

第四站坑点汇总区（三个高频翻车点）

坑1·公共元素重复写：并集是"倒进一个锅"，锅里的元素不重复（教材p10边栏框原文钉死）。{1,2}∪{2,3} = {1,2,3}，不是 {1,2,2,3}。

坑2·区间端点开闭：做区间的并、补，先在数轴上画出来，端点谁开谁闭一眼定。补集端点还要"反向翻转"：∁R{x | x>1} = {x | x≤1}——">"翻成"≤"，1从取不到变取得到。端点定生死，考场高频扣分位。

坑3·忘指定全集：写补集必须带下标圈（∁UA）。同一个A，在U={1..8}里补和在U={1..5}里补，答案不同（例5的A={1,2,3}换个U自己试试：∁UA={4,5}——对，就是变了）。教材p12的Q/R方程例子就是铁证：没说范围，"不是"没法收尾。

课本习题习题1.3（p14·做完这组就毕业）

复习巩固：
1. 集合 A={x | 2≤x<4}，B={x | 3x−7≥8−2x}，求 A∪B，A∩B。
2. 设 A={x | x 是小于9的正整数}，B={1, 2, 3}，C={3, 4, 5, 6}。求 A∩B，A∩C，A∩(B∪C)，A∪(B∩C)。
3. 学校开运动会，设 A={x | x 是参加100m跑的同学}，B={x | x 是参加200m跑的同学}，C={x | x 是参加400m跑的同学}，学校规定：每个参加上述比赛的同学最多只能参加两项比赛。请你用集合的运算说明这项规定，并解释以下集合运算的含义：(1) A∪B；(2) A∩C。

答案：1. 先解不等式：3x−7≥8−2x → 5x≥15 → x≥3，即 B={x | x≥3}。数轴上画：A=[2, 4)，B=[3, ∞)。并：从2到∞无缝一整段，A∪B=[2, ∞)；交：重叠部分从3到4，左端3在A、B里都取得到→闭，右端4只在A里且取不到→开，A∩B=[3, 4)。口诀：交的端点"两边都取得到才闭"，并的端点"有一边取得到就闭"。
2. A={1,…,8}。A∩B={1, 2, 3}；A∩C={3, 4, 5, 6}；B∪C={1, 2, 3, 4, 5, 6}，A∩(B∪C)={1, 2, 3, 4, 5, 6}；B∩C={3}，A∪(B∩C)={1, 2, 3, 4, 5, 6, 7, 8}=A（A把B∩C整个装下）。
3. "最多参加两项"用集合语言说：A∩B∩C=∅（不存在同时报三项的同学）。(1) A∪B={x | x 是参加100m跑或200m跑的同学}；(2) A∩C={x | x 是既参加100m跑又参加400m跑的同学}——规定允许这种"两项组合"，但不允许三项全报。

综合运用与拓展探索：
4. 已知集合 A={x | 3≤x<7}，B={x | 2<x<10}，求 ∁R(A∪B)，∁R(A∩B)，(∁RA)∩B，A∪(∁RB)。
5. 设 a∈R，集合 A={x | (x−3)(x−a)=0}，B={x | (x−4)(x−1)=0}，求 A∪B，A∩B。
6. 已知全集 U=A∪B={x∈N | 0≤x≤10}，A∩(∁UB)={1, 3, 5, 7}，试求集合 B。

答案：4. 数轴画开：A=[3,7)，B=(2,10)，A整段在B内。A∪B=(2,10)；A∩B=[3,7)；∁R(A∪B)=(−∞,2]∪[10,∞)；∁R(A∩B)=(−∞,3)∪[7,∞)；(∁RA)∩B=(2,3)∪[7,10)（B里挖掉A占的[3,7)一段，剩左边(2,3)和右边[7,10)两截）；A∪(∁RB)=(−∞,2]∪[3,7)∪[10,∞)（B挖掉后剩圈外两段，再并上A）。
5. B={1, 4}。A的元素看参数a，四类：a∉{1,3,4}时 A={3, a}，A∪B={1, 3, 4, a}，A∩B=∅；a=1时 A={1, 3}，A∪B={1, 3, 4}，A∩B={1}；a=4时 A={3, 4}，A∪B={1, 3, 4}，A∩B={4}；a=3时 A={3}（两因式同根，元素不重复），A∪B={1, 3, 4}，A∩B=∅。含参题先问"A里有谁"——a撞进B或撞成3，都要单独分家。
6. U={0, 1, 2, …, 10}。A∩(∁UB) 的意思是"在A、又不在B"——这4个数{1,3,5,7}就是"只在A不在B"的部分。U=A∪B，所以 U 里除掉"只在A"的部分，剩下的都在B里：B = {0, 2, 4, 6, 8, 9, 10}。

收口三句话带走 + 自测五连

三句话：
1. 并集 ∪："或"收编两边的全部（公共元素只写一次）；交集 ∩："且"只留两边都有的。
2. 补集 ∁UA：先定圈（U），再挖洞——圈换了答案就换；连补两次回原地。

自测五连（先做再看答案，答案直接给你）：

① {1, 2, 3}∪{2, 3, 4} = ?（教材坑1同款）

② A={x | x²=4}，B={x | x=2}，求 A∪B 和 A∩B。

③ U={1, 2, 3, 4, 5}，A={2, 4}，求 ∁UA，并问 (∁UA)∪A = ?

④ {x | −2≤x<1} ∪ {x | 0<x≤3} = ?（端点综合）

⑤ U={x | x 是小于6的正整数}，A={1, 3}，求 ∁UA 及其元素个数。

答案：① {1, 2, 3, 4}——2和3只写一次。② A={−2, 2}（负根别漏），B={2}；A∪B={−2, 2}，A∩B={2}。③ ∁UA={1, 3, 5}；(∁UA)∪A=U={1, 2, 3, 4, 5}——挖掉的并回来=整个圈。④ 数轴：[−2,1)与(0,3]拼起来中间(0,1)无缝，−2闭、3闭 → [−2, 3]，即 {x | −2≤x≤3}（1和0都在内部，自动被收编）。⑤ U={1, 2, 3, 4, 5}，∁UA={2, 4, 5}，共3个元素——教材例5同款套路：先展开U再挖洞。

想多走一步？（可选·教材p15-16"阅读与思考"栏目：集合中元素的个数）

有限集合 A 的元素个数记作 card(A)（cardinal=基数），如 A={a, b, c} 则 card(A)=3。

教材的例子：超市两次进货，第一次6种（圆珠笔、钢笔、橡皮、笔记本、方便面、汽水），第二次4种（圆珠笔、铅笔、火腿肠、方便面）。两次共进了几种？答10=6+4？错！两单里有4样重合（圆珠笔、方便面等）——

card(A∪B) = card(A) + card(B) − card(A∩B)

教材原例：card(A)=6，card(B)=4，card(A∩B)=2，所以 card(A∪B)=6+4−2=8。运动会版：田径8人、球类12人、两项都报3人，总参赛=8+12−3=17（教材p16原算式）。重合的被减一次——这就是容斥原理，数不清圈里圈外时的标准工具。

教材还留了两个开放问句：三集合的 card(A∪B∪C) 公式长什么样？（提示：三类重合都要处理，减多了再加回来）以及：A={1, 2, 3, …}和 B={2, 4, 6, 8, …}都是无限集，"个数"数不出来，你能设计比较它们多少的办法吗？（这问题通往现代数学的无穷观，高中不打分，但很开脑洞。）
