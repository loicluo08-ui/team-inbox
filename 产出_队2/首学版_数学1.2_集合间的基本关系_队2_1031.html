子集：集合世界里的"≤"号

数学1.2 · 集合与常用逻辑用语（一） · 零基础首学版 v1.0 · 前置：1.1 的 ∈ 符号和列举法/描述法（忘了？往下30秒有补丁）

开场数字会比大小，集合比什么？

两个实数能比：5=5，5<7，5>3。那两个集合呢——{1, 2, 3} 和 {1, 2, 3, 4, 5}，它们之间有没有类似"小于"的关系？

有，而且比你想的直接：看元素。{1,2,3} 里的每一个数，都在 {1,2,3,4,5} 里——这就像 3 比 5 小一样，是一个可以定符号、写等式的关系。这一节就干一件事：给集合之间的"谁装着谁"起名字、定符号。名字一共四个：子集、相等、真子集、空集。

读完这节你能

① 用 ⊆ 判断两个集合谁装着谁，用 ⫋ 说"装着还有剩"；
② 分清 0、{0}、∅ 这三个长得像的东西，不再把"点"和"圈"搞混；
③ 写出一个小集合（如 {a, b}）的全部子集，一个不漏；
④ 避开本节最爱挖的坑：忘算空集。

预备30秒补齐 1.1 的三样工具（已会的跳过）

① a ∈ A：a 是集合 A 里的元素——一个点在圈里。如 2 ∈ {1, 2, 3}。

② 列举法 {1, 2, 3}：把元素一个个列出来。③ 描述法 {x | x 是等腰三角形}：竖线前说元素是什么，竖线后说它满足的条件。

本节还要认识一个新符号 ⊆（读"包含于"）——别背长相，往下走两步你自然会读它。

第一步子集：A 的元素全都在 B 里

教材先摆了三组例子，你自己先扫一遍（人教A版p7"观察"）：

(1) A = {1, 2, 3}，B = {1, 2, 3, 4, 5}；

(2) C = 高一(2)班全体女生组成的集合，D = 这个班全体学生组成的集合；

(3) E = {x | x 是有两条边相等的三角形}，F = {x | x 是等腰三角形}。

三组例子是同一个模式：左边集合的每个元素，在右边集合里都找得到。女生个个是学生；1、2、3 个个在 B 里。这种关系教材给它起名——

子集（教材定义，人教A版p7）：一般地，对于两个集合 A，B，如果集合 A 中任意一个元素都是集合 B 中的元素，就称集合 A 为集合 B 的子集（subset），记作

A ⊆ B（或 B ⊇ A），读作"A 包含于 B"（或"B 包含 A"）

"任意"是关键词——A 的元素要全部无一例外都在 B 里，挑一两个在的不算数（跟 3.2 判奇偶要"对任意 x 成立"是同一种话术）。

符号怎么记：⊆ 的开口朝 B，像 A 这个小容器整个被 B 撞进去抱着——"A 装在 B 里"。或者记方向：开口那边是大哥（装人的），尖头那边是小弟（被装的）。

数学里配这种关系必有一张图——Venn 图：用平面上封闭曲线的内部代表一个集合（教材p7原文："我们经常用平面上封闭曲线的内部代表集合，这种图称为Venn图"）。

图1 · 子集的 Venn 图。小圈整个待在大圈里——这就是"包含于"。

验一验（20秒）：C = {x | x 是等边三角形}，D = {x | x 是三角形}。C ⊆ D 吗？反过来呢？
→ C ⊆ D ✓：等边三角形个个是三角形。反过来 D ⊆ C ✗：三边为 3、4、5 的三角形是 D 的元素，不是等边三角形——"任意"一票就否了。

第二步相等：互相装 = 一模一样

回看例 (3)：E = {x | x 是有两条边相等的三角形}，F = {x | x 是等腰三角形}。"有两条边相等"不就是"等腰"嘛——E 里每个元素都在 F 里，F 里每个元素也都在 E 里。两个集合的元素一模一样。

相等（教材定义，人教A版p7）：如果集合 A 的任何一个元素都是集合 B 的元素，同时集合 B 的任何一个元素都是集合 A 的元素，那么集合 A 与集合 B 相等，记作 A = B。

教材等价说法（p8）：也就是说，若 A ⊆ B，且 B ⊆ A，则 A = B。

这一条是本节最有用的工具：想证明两个集合相等，不用一个一个元素对——证"互相包含"两句话就够了。

类比锚（教材p8思考框原话就是它）：实数里"若 a≥b 且 b≥a，则 a=b"。≥ 之于数，就是 ⊆ 之于集合。以后 1.4 学逻辑用语时还会再遇到这种"双向奔赴"的套路。

验一验（30秒·易错点在内）：{1, 2}、{2, 1}、{x | x²−3x+2=0} 三个集合，相等吗？
→ 全部相等 ✓。集合只认"有哪些元素"，不认书写顺序：解 x²−3x+2=0 得 x=1 或 x=2（机器代验通过：solve 得 {1,2}），元素就是 1 和 2。三种写法 = 同一个集合。（坑：以为"{2,1}顺序反了所以不等"——元素一样的集合就是同一个集合）

第三步真子集：装着，还剩一截

A={1,2,3} ⊆ B={1,2,3,4,5}，但 B 里还有 4 和 5 是 A 没有的——B 比 A 真的大。这种"装进去还不满"的关系，教材也起了名字：

真子集（教材定义，人教A版p8）：如果集合 A ⊆ B，但存在元素 x ∈ B，且 x ∉ A，就称集合 A 是集合 B 的真子集（proper subset），记作 A ⫋ B（或 B ⫌ A），读作"A 真包含于 B"（或"B 真包含 A"）。

教材马上用它回看例(1)：A ⊆ B，但 4∈B 且 4∉A，所以 A 是 B 的真子集。

符号怎么记：⫋ 比 ⊆ 底下多一道闸门——那道闸门拦住"相等"。读法：真子集 = 子集，但不许等于。

图2 · 相等与真子集只差一句话："B 里有没有 A 装不下的元素"。有 → 真子集；没有 → 相等。

验一验（20秒）：N = 自然数集 {0,1,2,…}，Z = 整数集。N ⊆ Z 吗？是真子集吗？
→ N ⊆ Z ✓（每个自然数都是整数），且 N ⫋ Z ✓——−1、−2 是整数但不是自然数，"剩下"的找到了。

第四步空集 ∅：没有元素的集合（本节第一大坑）

方程 x² + 1 = 0 有实数根吗？实数的平方都 ≥ 0，加 1 只能更大——没有。所以"x²+1=0 的实数根"组成的集合里，一个元素都没有。

空集（教材定义，人教A版p8）：一般地，我们把不含任何元素的集合叫做空集（empty set），记为 ∅，并规定：空集是任何集合的子集。

为什么这样规定不别扭：A ⊆ B 说的是"B 的每个元素都能在 A 里找到"——∅ 根本没有元素，这句话永远没机会被违反（你找不到一个 ∅ 的元素不在 A 里）。空口袋装进任何袋子都不违规。

∅ 的三条纪律（易错集中区）
① ∅ ⊆ A：对任何集合 A 都成立（规定）；
② ∅ ⫋ A：只要 A 不是 ∅ 就成立——{0} 里有元素 0，"剩下"找到了；但 ∅ ⫋ ∅ ✗（自己等于自己，不算真）；
③ {0} ≠ ∅：{0} 是装着一个 0 的盒子，∅ 是空盒子——差一个元素，天壤之别。
验一验（30秒·四连）：∅ ⊆ {0}？∅ ⫋ {0}？{0} ⊆ {0}？{0} ⫋ {0}？
→ ✓ / ✓ / ✓ / ✗。最后那个：{0} 和 {0} 相等，没有"剩下"的元素，不是真子集。第一个：空集是任何集合的子集，{0} 也是"任何集合"。

第五步∈ 还是 ⊆？——"点"与"圈"（本节第二大坑）

教材 p8 有个思考题，正戳在新手最容易混的地方：

教材思考（p8原文）：包含关系 {a} ⊆ A 与属于关系 a ∈ A 有什么区别？试结合实例作出解释。

区别就一句：∈ 是"点在圈里"，⊆ 是"圈在圈里"。

左边是谁，决定该用哪个符号：单个东西（元素）→ 用 ∈；带着花括号的一整个集合 → 用 ⊆（或 ⫋、=）。

图3 · 0 与 {0} 不是一回事：0 是元素（点），{0} 是装着 0 的集合（圈）。

写法读法对错一句话理由
0 ∈ {0}0 是 {0} 的元素✓点是 0，圈里正好装着 0
0 ⊆ {0}0 包含于 {0}✗0 是点不是圈，⊆ 左边必须是集合
{0} ∈ {0}{0} 是 {0} 的元素✗{0} 这个圈里只有元素 0，没有"装着 0 的圈"这个元素
{0} ⊆ {0}{0} 包含于 {0}✓任何集合是自己的子集（下一步就讲这条性质）
∅ ⊆ {0}空集包含于 {0}✓规定：空集是任何集合的子集
验一验（40秒·对齐教材练习2题型）：用 ∈、⊆、= 填空：a ___ {a,b,c}；{a} ___ {a,b,c}；∅ ___ {a,b,c}；{a,b,c} ___ {a,b,c}
→ ∈；⊆；⊆（规定）；=。口诀自查：左边带花括号没？没带 → ∈；带了 → 在 ⊆ 和 = 里挑（元素全同才是 =）。

第六步两条性质：自己装自己 + 套娃传递

教材把两条结论直接给了出来（p8原文："由上述集合之间的基本关系，可以得到下列结论"）：

(1) 任何一个集合是它本身的子集，即 A ⊆ A；

(2) 对于集合 A，B，C，如果 A ⊆ B，且 B ⊆ C，那么 A ⊆ C。

(1) 为什么对：A 的每个元素当然都在 A 里——"任意元素都在"这句话自动成立。注意别推过头：A ⊆ A 成立，但 A ⫋ A 不成立（相等不算"真"）。

(2) 叫传递性——套娃逻辑：女生 ⊆ 全班学生 ⊆ 全年级学生，那女生当然 ⊆ 全年级学生。

图4 · 传递性：包容链可以一路传下去。

方法怎么写出一个集合的全部子集（教材例1全展开）

例1（教材原题，人教A版p8）：写出集合 {a, b} 的所有子集，并指出哪些是它的真子集。

解（教材原答）：集合 {a, b} 的所有子集为 ∅，{a}，{b}，{a, b}。真子集为 ∅，{a}，{b}。

答案背下来没用，要看懂怎么数才不漏——按"装几个元素"分类：

装 0 个：∅　→　装 1 个：{a}、{b}　→　装 2 个：{a, b}

四类合并 = 4 个子集，齐了。真子集 = 子集里抠掉自己 {a, b}（因为真子集不许等于），剩 3 个。

最容易漏的是 ∅数子集时 ∅ 经常被忘掉——它是"装 0 个元素"的那一类，天生就是成员之一。考试里子集个数少算一个，九成九是丢了 ∅。
自编变式一（自编·机器代验通过）：写出 {a} 的所有子集和真子集。
→ 子集 2 个：∅，{a}；真子集 1 个：∅。数法同上：装 0 个 ∅，装 1 个 {a}；抠掉自己剩 ∅。
自编变式二（自编·∅ 特例）：∅ 的子集有哪些？真子集呢？
→ 子集只有 ∅ 自己（∅ ⊆ ∅，"任何集合是自己的子集"）；真子集 0 个——∅ 连"剩下元素"的地方都没有。数 ∅ 的子集别手滑写 0 个，是 1 个。

换成数轴上的集合，"谁装着谁"看得更直：{x | x < 0} 和 {x | x < 1}（自编，同构自教材p9练习3(1)）：

图5 · 数轴看包含：线段短的整段落在线段长的内部。0.5 就是那个"x∈B 且 x∉A"的证人。

方法判断"A ⊆ B 吗"——两板斧（教材例2全展开）

方法只有两斧：要判 A ⊆ B，检查 A 的每个元素是否都在 B 里；发现一个不在 → 立刻否掉（一个反例就够）。

例2（教材原题，人教A版p8）：判断下列各题中集合 A 是否为集合 B 的子集，并说明理由：

(1) A = {1, 2, 3}，B = {x | x 是 8 的约数}；　(2) A = {x | x 是长方形}，B = {x | x 是两条对角线相等的平行四边形}。

解 (1)（教材原答）：因为 3 不是 8 的约数，所以集合 A 不是集合 B 的子集。

先把 B 数出来：8 的约数 = {1, 2, 4, 8}。3 不在 → 一票否决。描述法给出的集合，先"翻译成列举"更好比。

解 (2)（教材原答）：因为若 x 是长方形，则 x 一定是两条对角线相等的平行四边形，所以集合 A 是集合 B 的子集。

长方形的两条对角线相等（矩形对角线互相平分且等长，这是长方形的固有性质）——A 的每个元素都符合 B 的条件 → 全都在。

验一验（30秒）：A = {x | x 是菱形}，B = {x | x 是平行四边形}（同构自教材p9习题1(3)）。A ⊆ B 吗？
→ ✓。菱形按定义是"四边相等的四边形"，而四边相等当然满足"两组对边平行"——菱形个个是平行四边形。反方向不成立：长方形是平行四边形但四边不必相等。

收口合上这件，三问自查

能复述才算学会

① A ⊆ B 和 A ⫋ B 差在哪一句话？
→ 差"B 里有没有 A 装不下的元素"：有 → ⫋；没有（= 相等）→ 只是 ⊆。

② 0、{0}、∅ 各是什么？∅ ⊆ {0} 对吗？
→ 0 是元素（点）；{0} 是装着 0 的集合（圈）；∅ 是空盒子。∅ ⊆ {0} 对——空集是任何集合的子集（规定）。

③ {a, b} 的全部子集怎么数？
→ 按装 0 / 1 / 2 个分类：∅、{a}、{b}、{a, b}，共 4 个；真子集抠掉自己剩 3 个。

自测四连（先自己做，再看答案——答案就在下面）

① 判断对错：0 ∈ {0}；0 ⊆ {0}；∅ ⊆ {0}；{0} ⊆ {0}
→ ✓ ✗ ✓ ✓。0 是点用 ∈（✓）；点是点不是圈，⊆ 不了（✗）；规定（✓）；自己是自己的子集（✓）。
② 写出 {2, 3} 的所有真子集。
→ ∅，{2}，{3}，共 3 个。全部子集 4 个，抠掉自己 {2,3}。（丢 ∅ 的举手——这就是那条纪律存在的意义）
③ 用 ⊆、⫋、=、∈ 填空：{x | x²=1} ___ {−1, 1}；a ___ {a, b}；{a} ___ {a, b}；∅ ___ {a}
→ =；∈；⫋；⊆。第一空：x²=1 解得 x=±1（机器代验通过），元素同为 −1 和 1，相等；第三空：b 是"剩下"的元素；第四空：规定。
④ A = {x | x 是等边三角形}，B = {x | x 是等腰三角形}。A ⊆ B 还是 B ⊆ A？是真子集吗？
→ A ⫋ B。等边必等腰 → A ⊆ B；等腰不等的（如三边 3、4、5）∈ B ∉ A → 真子集。这正是教材观察例(3)的镜像：{x | 有两条边相等} = {等腰}，它的子集 {等边} 只是其中一小块。

考位锚高考怎么考

考什么：子集/真子集的个数、空集的规定、∈ 与 ⊆ 的辨析、含参数的集合包含关系（B ⊆ A 求参数范围）。

怎么考：多为小题，常与 1.3 运算、1.4 逻辑用语联动；含参题的隐雷就是本节纪律——B ⊆ A 时先问一句"B 能不能是 ∅"（能则 ∅ 是一解，漏掉即错）。本节先把"∅ 是任何集合的子集"焊死，含参套路 1.3 之后解锁。

频率：集合是全卷开胃菜，基本每卷 1~2 题，难度轻、拼细心。（真题锚：候采——本件暂未采到带卷源的 1.2 专题，不代拟；后续件随卷源补锚。）

下一站1.3 集合的基本运算

会"比"集合了，下一步"算"集合：教材 p10 开场原话——"实数有加、减、乘、除等运算，集合是否也有类似的运算呢？"答案是并、交、补三种，全配 Venn 图。你今天学的 ⊆ 就是那边很多结论的零件（比如 A ∪ B ⊇ A 这种句子）。

想多走一步？（可选——跳过不影响后面任何一节）

① 子集个数公式：n 个元素的集合，子集总数 = 2ⁿ。为什么：每造一个子集，每个元素二选一（进 / 不进），n 个元素就是 2×2×…×2 = 2ⁿ 种选法。{a, b}：2² = 4 ✓（∅、{a}、{b}、{a, b}）；{a, b, c}：2³ = 8 个——教材 p8 练习1 正好请你写全这 8 个，写完数一数，公式自己长在纸上。真子集 = 2ⁿ − 1（抠掉自己）；空集 n=0：2⁰ = 1 个子集（就是 ∅ 自己）——公式连空集都服帖。

② 含参包含第一例（教材 p9 习题5(2)）：A = {x | 0 < x < a}，B = {x | 1 < x < 2}，若 B ⊆ A，求 a 的范围。数轴上把 B 整段往 A 里放：A 的左端 0 < 1 已经罩得住左端点，右端 a 必须罩住 B 的右端 → a ≥ 2。（用今天的语言：B 的每个元素都要在 A 里，就要求 x→2 时仍有 x < a。）
