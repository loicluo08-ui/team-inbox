开场什么是命题，什么要"推理"

数学里到处都是"判决句"——命题（教材 p17 定义原文）：把用语言、符号或式子表达的，可以判断真假的陈述句叫做命题。判为真=真命题，判为假=假命题。"3>2"是真命题；"明天下雨"没法判真假，不是（数学意义上的）命题。

中学数学的很多命题长一个样："若 p，则 q"（如果 p，那么 q）。p 叫条件，q 叫结论。比如"若平行四边形的对角线互相垂直，则这个平行四边形是菱形"——p=对角线互相垂直，q=是菱形。这一节就研究一件事：p 和 q 之间，推得动、推不动。工具是三个新词：充分条件、必要条件、充要条件。

读完这节你能

① 看一个"若 p 则 q"，判断 p 推不推得动 q，并说出谁是谁的充分/必要条件；② 用一个反例否掉假命题；③ 把任何一对 p、q 归入四类之一（充分不必要/必要不充分/充要/都不）；④ 会用集合观点一眼看穿条件关系。

第一步充分条件：p 是 q 的"保证书"

先看教材 p17 思考的四个命题，判真假：
(1) 若平行四边形的对角线互相垂直，则它是菱形——真（初中学过）；
(2) 若两个三角形周长相等，则它们全等——假（边长 3、4、5 和 2.5、4.5、5 周长都是 12，形状不同）；
(3) 若 x²−4x+3=0，则 x=1——假（解方程得 x=1 或 x=3，x=3 就是反例；sympy 解集 {1,3} 在案）；
(4) 若平面内直线 a、b 都垂直于直线 l，则 a∥b——真。

(1)(4) 由 p 推得出 q，(2)(3) 推不动。教材把"推得动"正式定名：

教材定义（p17 原文）：一般地，"若 p，则 q"为真命题，是指由 p 通过推理可以得出 q。这时，我们就说，由 p 可以推出 q，记作 p ⟹ q。并且说，p 是 q 的充分条件（sufficient condition），q 是 p 的必要条件（necessary condition）。

为什么 q 反而叫 p 的"必要"条件？教材脚注①给了钥匙：如果 q 不成立，则 p 一定不成立——q 是 p 成立绕不开的地基。比如"若x>3则x>2"里，"x>2"就是"x>3"的必要条件：一个数连 2 都不超过，绝不可能超过 3。

若"若 p，则 q"是假命题，记作 p ⇏ q：p 不是 q 的充分条件，q 也不是 p 的必要条件。

验一验（20 秒）

"若 x=1，则 x²=1"是真命题。谁是谁的充分条件？谁是谁的必要条件？
答案：x=1 ⟹ x²=1 ✓。p（x=1）是 q（x²=1）的充分条件；q（x²=1）是 p（x=1）的必要条件。

反例的力量（教材 p18 框注原文）："举反例是判断一个命题是假命题的重要方法。"要否定 p⟹q，只需要一个满足 p 但不满足 q 的例子。教材例1(4)：由于 (−1)²=1 但 −1≠1，所以"x²=1⟹x=1"是假的；例1(6)：√2 是无理数，但 √2×√2=2 是有理数，所以"两个无理数的积还是无理数"是假的。

充分条件不唯一（教材 p18-19 思考原文结论）："对给定结论 q，使得 q 成立的条件 p 是不唯一的。"四边形是平行四边形的充分条件就有一堆：两组对角分别相等✓、两组对边分别相等✓、一组对边平行且相等✓、对角线互相平分✓——教材总结成一句：数学中的每一条判定定理都给出了相应结论成立的一个充分条件（p19 原文）。

第二步必要条件：从"另一头"看同一条推力

教材例2 问的是反方向：哪些命题里 q 是 p 的必要条件？秘诀只有一句（p19 原文）："要判断 q 是否为 p 的必要条件，只需判断是否有 p⟹q，即'若 p，则 q'是否为真命题。"——不用新方法，还是判原命题真假，只是"叫法"换了位置：

命题真假p 是 q 的…q 是 p 的…
若 p 则 q 为真（p⟹q）充分条件必要条件
若 p 则 q 为假（p⇏q）不是充分条件不是必要条件

例2 里三个假命题的反例都值得记：对角线互相垂直⇏菱形——教材图 1.4-1 画了个"筝形"（两组邻边相等），对角线垂直却不是菱形；(−1)×0=1×0 但 −1≠1，所以"ac=bc⟹a=b"假（c=0 时两边全变 0）；1×√2=√2 是无理数但 1 是有理数，所以"xy 无理⟹x、y 都无理"假。

对称地，教材 p20 总结：数学中的每一条性质定理都给出了相应结论成立的一个必要条件。比如"两直线平行⟹同位角相等"是性质定理——"同位角相等"就是"两直线平行"的必要条件：同位角不相等，两直线就绝不可能平行。

验一验（20 秒）

"若 x 是无理数，则 x² 也是无理数"——q（x² 无理）是 p（x 无理）的必要条件吗？
答案：看原命题真假：x=√2 时 x²=2 是有理数——原命题为假 → q 不是 p 的必要条件（p 也不是 q 的充分条件）。

第三步充要条件：双向都通 = "双行道"

教材 p20 思考：哪些命题和它的逆命题都真？先把"逆命题"钉住（框注原文）：把"若 p，则 q"的 p、q 互换，得到"若 q，则 p"，叫原命题的逆命题。四句话的组合只有四种：

原命题逆命题结论
真真p⟺q，充要（教材思考(1)(4)）
真假充分不必要（思考(2)：全等⟹周长相等，反过来不行）
假真必要不充分（思考(3)：两不等实根⇏ac<0，但 ac<0⟹判别式>0 有两不等实根 ✓）
假假既不充分也不必要

教材定义（p21 原文）：如果"若 p，则 q"和它的逆命题"若 q，则 p"均是真命题，即既有 p⟹q，又有 q⟹p，就记作 p ⟺ q。此时，p 既是 q 的充分条件，也是 q 的必要条件，我们说 p 是 q 的充分必要条件，简称为充要条件（necessary and sufficient condition）。如果 p 是 q 的充要条件，那么 q 也是 p 的充要条件——概括地说，p 与 q 互为充要条件。

教材例3 两个充要、两个不充要：(2) 相似 ⟺ 三边成比例（性质定理+判定定理两头都真）；(4) x=1 是 ax²+bx+c=0 的根 ⟺ a+b+c=0（把 x=1 代入就是 a+b+c=0，两方向是同一步代入，sympy 恒等验 ✓）。(1) 正方形 ⇏"对角线垂直且平分"（菱形就是反例）；(3) xy>0 ⇏ x>0 且 y>0——x=y=−1 时 xy=1>0 但两个都负（sympy 验 ✓）。

教材 p21 探究还补了一刀：平行四边形的定义（两组对边分别平行）本身就是它自己的充要条件——所以数学概念的定义永远和概念互为充要，这就是为什么教材 p24-25 阅读材料说"定义=充要条件、判定定理=充分条件、性质定理=必要条件"（这个三分法记住，几何命题全梳顺）。

方法一四分类判断流程（考试最常见题型）

给定 p、q，三步走：①判 p⟹q 真假；②判 q⟹p 真假；③查表归档。

演示（教材 p23 习题2(1)）：p：三角形是等腰三角形，q：三角形是等边三角形。
①等腰⟹等边？假（等腰不等的反例，如三边 3、4、4——等等 3、4、4 是等腰（4=4）但三边不全等，反例成立）；②等边⟹等腰？真（等边三角形三边都相等，当然等腰）；③查表：p 是 q 的必要不充分条件。

演示（p23 习题2(5)）：p：x>y，q：x²>y²。①x>y⟹x²>y²？假（x=0,y=−1：0>−1 但 0²<(−1)²）；②x²>y²⟹x>y？假（x=−2,y=1：4>1 但 −2<1，sympy 验 ✓）；③既不充分也不必要条件。

演示（p23 习题3(3)判断真假）："A∪B=A 是 B⊆A 的必要不充分条件"——真还是假？A∪B=A 的意思本来就是"B 的元素全在 A 里"=B⊆A，两句话互为充要（sympy 集合验 ✓）。所以这句话说"必要不充分"是假的——正确答案：充要条件。这是教材借习题提醒你：1.3 的集合语言和本节是一回事（见方法二）。

方法二集合观点：条件关系=集合关系（大杀器）

设 A={x | x 满足 p}，B={x | x 满足 q}（教材 p23 习题4 的设定），那么"p⟹q"逐字翻译就是"A 里的每个元素都在 B 里"=1.2 的 A⊆B！全套对应：

集合关系条件关系记忆
A ⊆ B（A 小圈在 B 里）p 是 q 的充分条件小范围⟹大范围
B ⊆ Ap 是 q 的必要条件大范围被推不出小范围
A = Bp 是 q 的充要条件同一个圈
A ⊊ B（真子集）充分不必要B 比 A 大=推过去回不来

图2 集合观点一眼看穿（本件自绘·圆=元素全体地盘）——这张图在说什么：条件的"强弱"=圈子的大小。A 越小条件越强（越充分），A=B 才是互为充要。

验一验（30 秒）

p：x>2，q：x>1。用集合观点说 p 是 q 的什么条件？
答案：{x|x>2} ⊊ {x|x>1}（真子集）→ p 是 q 的充分不必要条件。

方法三证明"充要"的标准格式+一道配方证明

要证 p 是 q 的充要条件，必须分两段证：充分性（p⟹q）+必要性（q⟹p），一段都不能省。教材例4 做了示范（p22）：证 d=r 是直线 l 与 ⊙O 相切的充要条件——充分性：作 OP⊥l，d=r 时 P 在圆上，l 上任取另一点 Q 都有 OQ>OP=r 在圆外，故只有一个公共点=相切；必要性：相切时切点 P 满足 OP⊥l，d=OP=r。两段合起来=充要。

代数版看教材 p23 习题5：证 a=b=c 是 a²+b²+c²=ab+ac+bc 的充要条件。核心是一步配方（sympy 恒等验 ✓）：

a²+b²+c²−ab−ac−bc = ½[(a−b)²+(b−c)²+(a−c)²] ≥ 0，等号成立 ⟺ 三个平方全为 0 ⟺ a=b=c。
充分性：a=b=c 时右边=0 即等式成立；必要性：等式成立即和为 0，三个平方都为 0，得 a=b=c。两段合证=充要 ✓。

大坑本节三大坑

坑1·方向搞反

"p 是 q 的充分条件"≠"q 是 p 的充分条件"。读题先圈出主语：谁是条件、谁是结论，箭头永远从条件指向结论（p⟹q）。填"充分/必要"前先写一遍箭头，20 秒防全错。

坑2·一个反例就够，但别拿"没找到"当"不存在"

否命题只需一个反例（框注原文）；但确认"推得动"必须说理（定义/定理/计算），"我试了几个都行"不算证明。

坑3·"x=1 是根"类条件自带方向

"x=1 是 ax²+bx+c=0 的一个根"⟺"a+b+c=0"（例3(4)）——看到"x=1 是根"直接翻译成"代入得 a+b+c=0"，两个方向是同一步，考试常设"必要不充分"陷阱选项，别跳。

收口合上这件，三问自查

①p⟹q 为真时，谁是谁的充分、谁是谁的必要？（p 充分、q 必要）②四分类靠哪两个真假判定？（原命题+逆命题，或 p⟹q 与 q⟹p）③"A⊆B"翻译成条件语言是什么？（p 是 q 的充分条件）——三问全对=过关。

自测四连（先自己做，再看答案——答案就在下面）

① 判断真假："x²=y² 是 x=y 的必要不充分条件。"
答案：真。x=y⟹x²=y² ✓（必要）；x²=y²⇏x=y（x=1,y=−1 反例）→ 恰是必要不充分。

② 写出"x=2"是"x²=4"的什么条件，并说明为什么"充要"不成立。
答案：充分不必要（x=2⟹x²=4 ✓；x²=4 解得 x=±2，x=−2 反例 → 不必要）。

③ 设 A={x|1<x<3}，B={x|0<x<4}，则"x∈A"是"x∈B"的什么条件？
答案：A ⊊ B → 充分不必要条件。

④ 判断："一次函数 y=kx+b 的图像过原点"是"b=0"的什么条件？
答案：充要条件——过原点 ⟺ x=0 时 y=b=0，两个方向是同一次代入（例3(4) 同型）。
