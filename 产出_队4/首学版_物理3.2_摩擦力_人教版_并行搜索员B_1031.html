摩擦力：拖后腿的力，也能帮你站稳——Ff = μF压 与"不动的力"

物理3.2 · "相互作用——力"模块第二件（第三章 第2节）· 前面已学：3.1 重力与弹力（G = mg、弹力垂直于接触面）· 零基础首学版 v1.0 · 前置：3.1＋初中的二力平衡＋小学的"正比例" · 预计45分钟

开场越重的箱子越难推——这股"拖后腿"的力有公式吗？

推箱子你有体感：箱子越沉，越难推动；地面越糙，越费劲。这股拖后腿的力叫摩擦力。教材p63问题框把体感变成了可测量的实验：用弹簧测力计拖动水平固定木板上的木块，使它做匀速运动，测力计的示数等于木块所受摩擦力的大小。改变木块和木板之间的压力，摩擦力的大小也随之改变。然后它提了一个"定量化"的问题：如果摩擦力的大小跟压力的大小存在某种定量关系的话，它们可能是怎样的关系呢？——这一节就回答它：滑动摩擦力有明明白白的公式（Ff = μF压），静摩擦力则是一条"看外力脸色"的变色龙（0 ＜ F ≤ Fmax）。

读完这节你能

① 说出滑动摩擦力与静摩擦力的定义，并会用"相对运动（趋势）方向相反"判方向——盯住"相对"两个字；
② 会用 Ff = μF压 计算滑动摩擦力，会用 μ = Ff/FN 结合教材动摩擦因数表查表；
③ 像教材例题一样，用二力平衡求"匀速拉动"时马/人的水平拉力（980 N 这类）；
④ 理解静摩擦力是"被动力"：它随外力变化、大小与推力保持相等，有上限 0 ＜ F ≤ Fmax；
⑤ 看懂力传感器 F-t 图像上那个"尖峰"：最大静摩擦力略大于滑动摩擦力；顺带认识"流体的阻力"。

本节只借四个旧工具：① 3.1的重力——G = mg（例题里雪橇的"分量"就靠它）；② 3.1的弹力方向——支持力FN垂直于接触面（μ = Ff/FN要用它）；③ 初中的二力平衡——匀速直线运动＝合力为零；④ 小学数学的正比例——y = kx，Ff = μF压就是它的物理版。另带一个"先借后还"的结论：水平面上，木块对木板的压力大小等于支持力、也等于重力——教材脚注①明说"下节会学到这一知识"（3.3牛顿第三定律补证明），本节先放心用。

第一步滑动摩擦力——方向盯死"相对"两个字（p63）

教材p63原文：两个相互接触的物体，当它们相对滑动时，在接触面上会产生一种阻碍相对运动的力，这种力叫作滑动摩擦力（sliding frictional force）。滑动摩擦力的方向总是沿着接触面，并且跟物体相对运动的方向相反。

两个要点（教材p63）：① 方向沿着接触面（不是随便反着指）；② 参照物是"相对运动"——阻碍的是甲相对乙的滑动，不是甲相对地面的运动。
大小先定性（教材p63）：滑动摩擦力的大小跟接触面上压力的大小有关，对同一接触面来说，压力越大，滑动摩擦力越大；滑动摩擦力的大小还跟接触面的粗糙程度、材质等有关，在相同压力下，不同接触面间的滑动摩擦力的大小一般不同。
图A（重绘自教材图3.2-1）｜这张图在说什么：测力计拖着木块匀速滑——示数才等于摩擦力（平衡了才相等）；FN垂直于接触面向上，摩擦力沿接触面、跟木块相对木板滑动的方向相反。
坑点·"相对运动"≠"运动"　超市传送带把行李箱往前送：箱子相对地面在往前运动，但它相对传送带没动（静摩擦）；启动瞬间行李箱相对传送带向后蹭，传送带给它向前的摩擦力带着它走——摩擦力的参照物是"接触的另一个物体"，不是地面。判方向三步走：①谁跟谁接触？②谁相对谁往哪蹭？③摩擦力就把"蹭"反着顶回去。
验一验①（自编·判方向）：黑板擦在黑板上向左擦动：黑板擦相对黑板向左滑 → 黑板给擦子的滑动摩擦力向右（沿黑板面）；同时擦子给黑板的摩擦力向左——摩擦力成对出现、方向相反（分别作用在两个物体上），"拖后腿"从来都是双向的。

第二步Ff = μF压——比例常数μ登场（p63-64）

教材p63接着定量：通过进一步的定量实验，测量同一接触面不同压力下的滑动摩擦力大小，结果表明：滑动摩擦力的大小跟压力的大小成正比。如果用Ff表示滑动摩擦力的大小，用F压表示压力的大小，则有

Ff = μF压
其中，μ是比例常数，叫作动摩擦因数（dynamic friction factor）。它的值跟接触面有关，接触面材料不同、粗糙程度不同，动摩擦因数也不同。（教材p63原话）

教材p64把F压落到实处：在图3.2-1中，以木块在水平木板上滑动为例，木块所受的支持力为FN。由于木块对木板的压力大小等于FN，①所以动摩擦因数μ也可以表示为

μ = Ff / FN
教材脚注①照录：下节会学到这一知识。——"压力大小等于支持力"要到3.3牛顿第三定律才正式证明，本节按教材节奏先直接使用。Ff和FN是接触面上木块所受的两个力，Ff在接触面内且与相对运动方向相反，FN与接触面垂直。

教材p64表·几种材料间的动摩擦因数（查表口算全靠它）：

材料动摩擦因数材料动摩擦因数
钢—钢0.25钢—冰0.02
木—木0.30木—冰0.03
木—金属0.20橡胶轮胎—路面（干）0.71
皮革—铸铁0.28木—皮带0.40
坑点·μ是"接触面的性格"，不是算出来的数　μ由接触面的材料与粗糙程度决定——钢对冰0.02（滑！），橡胶轮胎对干路面0.71（抓地！）。式子 μ = Ff/FN 只是测μ的尺子（测出摩擦力和压力一除就得到μ），不能反过来说"μ跟Ff成正比、跟FN成反比"——换了压力，Ff跟着变，比值μ纹丝不动。
验一验②（自编·查表计算）：木块在水平木面上滑动，木块重50 N（压力＝重力＝50 N）。查表木—木 μ = 0.30 → Ff = 0.30×50 = 15 N。若把它压到冰面上（木—冰 μ = 0.03），同样压力下 Ff = 0.03×50 = 1.5 N——差10倍，这就是冰道省力的账。

第三步例题精读（教材p64-65原题）——四个力、一次平衡、查一张表

【例题】（教材p64原题）　在我国东北寒冷的冬季，有些地方用雪橇作为运输工具。一个有钢制滑板的雪橇，连同车上木料的总质量为 4.9×10³ kg。在水平的冰道上，马要在水平方向用多大的力，才能够拉着雪橇匀速前进？g 取 10 N/kg。

分析（教材原话）：将雪橇抽象为一个物体，如图3.2-2，雪橇在重力mg、支持力FN、马的拉力F和滑动摩擦力Ff四个力的作用下，沿水平面匀速前进。根据二力平衡条件，拉力F与滑动摩擦力Ff的大小相等，而Ff与FN有关，FN的大小又等于mg，故可以求得拉力F。

解（教材p64）：雪橇所受重力 mg = 4.9×10⁴ N，查表得 μ = 0.02。雪橇匀速运动，拉力F与滑动摩擦力Ff大小相等，即

（教材p65续）由于

FN = mg，　Ff = μFN = μmg

故

F = μmg = 0.02 × 4.9×10³ × 10 N = 980 N

（教材答案）马要在水平方向用 980 N 的力，才能够拉着雪橇匀速前进。

图B（重绘自教材图3.2-2）｜这张图在说什么：把雪橇看成一个点，四个力摆到位——水平方向一对（拉力F ↔ 摩擦Ff，匀速所以相等），竖直方向一对（支持FN ↔ 重力mg，所以相等）。链条：F = Ff = μFN = μmg。
验一验③（自编·同题换面）：同一个雪橇（总重4.9×10⁴ N）换到木—皮带滑道上（查表μ = 0.40）匀速拖动：F = μmg = 0.40×4.9×10⁴ = 1.96×10⁴ N——是冰道980 N的20倍。视角换成"已知拉力反查μ"也行：匀速时 μ = F/mg，测出F和重一除即得。

第四步静摩擦力——不动的力，是个"变色龙"（p65-66）

教材p65先抛问题：相互接触的物体处于相对静止时，是不是也可能存在摩擦力？接着给场景：如图3.2-3，人用平行于地面的力推沙发，沙发有相对地面运动的趋势，但它没有被推动，沙发与地面仍然保持相对静止。根据二力平衡的知识可知，这时一定有一个力与推力平衡。这个力与人对沙发的推力大小相等、方向相反。这个力就是沙发与地面之间的摩擦力。

定义与方向（教材p65）：由于这时相互接触的两个物体之间只有相对运动的趋势，而没有相对运动，所以这时的摩擦力叫作静摩擦力（static frictional force）。静摩擦力的方向总是跟物体相对运动趋势的方向相反。只要沙发与地面间没有产生相对运动，静摩擦力的大小就随着推力的增大而增大，并与推力保持大小相等。

教材p65-66"演示"栏目把这条变色龙请进实验室：把木块放在水平长木板上，用弹簧测力计沿水平方向拉木块。在拉力F增大到一定值之前，木块不会运动，此种情况下静摩擦力的大小等于拉力的大小。在弹簧测力计的指针下轻塞一个小纸团，它可以随指针移动，并作为指针到达最大位置的标记（图3.2-4）。继续用力，当拉力达到某一数值时木块开始移动，此时拉力会突然变小。教材还给了"进阶版"：如果用力传感器代替弹簧测力计做这个实验，能够在计算机屏幕上直接得到拉力随时间变化的F-t图像（图3.2-5）。

图C（重绘自教材图3.2-5·原照片读数为目测近似：峰值略低于4 N、平稳段约2.7-2.8 N，以原影印为准）｜这张图在说什么：拉力慢慢加，静摩擦力跟着长（0→Fmax）；一超过Fmax木块"嗖"地动了，曲线突然跳水落到平稳段——那段平稳值才是滑动摩擦力。尖峰＞平台＝最大静摩擦力略大于滑动摩擦力。
限度（教材p66）：静摩擦力的增大有一个限度。图3.2-5中木块所受静摩擦力的最大值Fmax在数值上等于物体即将开始运动时的拉力。两物体之间实际产生的静摩擦力F在0与最大静摩擦力Fmax之间，即
0 ＜ F ≤ Fmax
（教材p66）瓶子可以拿在手中，靠的是静摩擦力的作用。皮带运输机能把货物送往高处，也是静摩擦力作用的结果。
坑点·静摩擦力不是"定值"，是"看外力脸色的被动力"　水平推箱子：推10 N没推动 → 静摩擦10 N；推15 N没推动 → 静摩擦15 N——它始终跟外力打平，上限才是Fmax。上来就写 f = μFN 是这类题的第一大错——那条公式是滑动摩擦力的；物体没动，先问"外力多大"，静摩擦力就多大。反之，一旦滑动起来，摩擦力反而锁死在μFN不再随推力变。
验一验④（自编·三段状态）：木箱重100 N、地板间Fmax=35 N、滑动摩擦30 N（本节练习第3题数据先借用）：①推20 N→没动，静摩擦=20 N（不是30也不是35）；②推40 N→动了，摩擦=30 N（锁死在μFN）；③匀速拖动→拉力必为30 N（平衡）。三个数对应三条规则：随外力、被锁死、平衡相等。

栏目科学漫步（教材p66-67照录）·流体的阻力

教材p66-67"科学漫步"：气体和液体都具有流动性，统称为流体。物体在流体中运动时，要受到流体的阻力，阻力的方向与物体相对于流体运动的方向相反。汽车、火车和飞机等在空气中运动，要受到空气的阻力。轮船、潜艇在水面或水下航行，要受到水的阻力。流体的阻力跟物体相对于流体的速度有关，速度越大，阻力越大。雨滴在空气中下落，速度越来越大，所受空气阻力也越来越大。当阻力增加到跟雨滴所受的重力相等时，二力平衡，雨滴匀速下落。流体的阻力还跟物体的横截面积有关，横截面积越大，阻力越大。跳伞运动员、飞船返回舱在空中张开降落伞，凭借降落伞较大的横截面积获得较大的空气阻力，安全落地。流体的阻力还跟物体的形状有关系。头圆尾尖的物体所受的流体阻力较小，这种形状通常叫作流线型。为了减小阻力，轮船的水下部分采用了流线型（图3.2-6）。一般来说，空气阻力比液体阻力、固体间的摩擦力都要小。气垫船靠船下喷出的气体，浮在水面航行，受到的阻力小。磁浮列车靠电磁力使列车悬浮在轨道上，速度可达500 km/h。

验一验⑤（自编·回链2.2）：雨滴匀速下落 = 平衡态（阻力 f ＝ 重力 mg）——正是2.2"匀速直线运动＝合力为零"的实战版。先加速（f＜mg）、f随速度变大、f＝mg起匀速：这条"加速→平衡"曲线，等学到4.2牛顿第二定律还能再算一遍。

节末自测先自己做，再对答案（教材p67练习与应用原题）

第1题（教材p67原题）手压着桌面向前移动，会明显地感觉到有阻力阻碍手的移动。手对桌面的压力越大，阻力越大。试一试，并说明道理。

参考答案：手与桌面发生相对滑动 → 手受到滑动摩擦力，方向沿桌面、与手相对桌面运动的方向相反（向后）。道理：滑动摩擦力与压力成正比（Ff = μF压）——手压得越重，压力越大，Ff越大，阻力感越明显。

第2题（教材p67原题·四连判）一只玻璃瓶，在下列情况下是否受到摩擦力？如果受到摩擦力，摩擦力朝什么方向？（1）瓶子静止在粗糙水平桌面上。（2）瓶子静止在倾斜的桌面上。（3）瓶子被瓶口朝上握在手中静止。（4）瓶子压着一张纸条，扶住瓶子把纸条抽出。

参考答案：（1）不受——水平方向既没运动也没趋势，没有摩擦力"登场"的理由（若有，瓶子就没法平衡了）。（2）受静摩擦力，沿斜面向上——瓶子有沿斜面下滑的趋势，静摩擦力与趋势方向相反。（3）受静摩擦力，竖直向上——瓶子有下落的趋势（重力），手给的静摩擦力与重力平衡。（4）受滑动摩擦力，方向与纸条被抽出的方向相同——纸条相对瓶向前滑，瓶相对纸条向后蹭，纸条给瓶的摩擦力阻碍"后蹭"、指向抽出方向（抽得快时瓶子会跟着挪一点，就是这个力）。

第3题（教材p67原题·填空四连）所受重力为 100 N 的木箱放在水平地板上，至少要用 35 N 的水平推力，才能使它从原地开始运动。木箱从原地移动以后，用 30 N 的水平推力，就可以使木箱继续做匀速直线运动。由此可知：木箱与地板之间的最大静摩擦力 Fmax = ______；木箱所受的滑动摩擦力 Ff = ______，木箱与地板之间的动摩擦因数 μ = ______；如果用 20 N 的水平推力推这个静止的木箱，木箱所受的摩擦力大小为 ______。

参考答案："至少35 N才能动" → Fmax = 35 N；"匀速30 N" → 滑动摩擦 Ff = 30 N；μ = Ff/FN = 30/100 = 0.30；20 N ＜ Fmax = 35 N → 推不动 → 静摩擦与推力打平 = 20 N（千万别填30或35——它根本没滑动）。顺带一读：35 ＞ 30，教材数据再次印证"最大静摩擦略大于滑动摩擦"。

第4题（教材p67原题）所受重力为 500 N 的雪橇，在平坦的雪地上用 10 N 的水平拉力恰好可以拉着空雪橇做匀速直线运动。如果雪橇再载重 500 N 的货物，那么，雪橇在该雪地上滑行时受到的摩擦力是多少？

参考答案：空载匀速 → 摩擦＝拉力：Ff = 10 N = μ×500 → μ = 0.02（雪橇—雪地，跟例题钢—冰同量级）。载货后总压力 FN = 500＋500 = 1000 N，滑行时 Ff′ = μFN = 0.02×1000 = 20 N。μ不变、压力翻倍 → 摩擦翻倍——"正比"关系的直接演练。

· 怎么考：选择题判断摩擦力方向与大小（传送带/斜面/手握瓶情境——教材练习第2、3题同款）、实验题（探究静摩擦/滑动摩擦、力传感器F-t图像——教材"演示"栏目的直改）、大题第一问受力分析打底，后续与牛顿第二定律深度组合。
· 真题锚：候采——对证源卷源池（v2.8-v2.11）暂未录入 3.2 对口卷源，不代拟；候池内补录后回填。

想多走一步？（可选·跳过不损失主干）　① "被动力"这个词：静摩擦力与支持力都属"被动力"——它们不主动定值，随外力/形变"应变"（静摩擦随外力，支持力随压紧程度）；而重力这种"主动性"的力不看谁的脸色。② Fmax ≈ μFN 的近似：很多题目把最大静摩擦力近似取成滑动摩擦力（图C尖峰→平台落差很小），但教材第3题特意给了 35 vs 30 让你看出差别——审题时看清给的是哪个数。③ 测μ的实验思想：匀速拉动时拉力=摩擦力（二力平衡），读出拉力、称出重力，μ = F/mg 一把出——"平衡法测摩擦"是后续实验题的常客。④ 增大与减小摩擦：鞋底花纹/轮胎纹（增大粗糙程度）、刹车捏闸（增大压力）都是增大有益摩擦；滚动轴承（滚动代滑动）、加润滑油（润滑）、气垫船磁浮列车（接触面分离——回链科学漫步500 km/h）都是减小有害摩擦。
