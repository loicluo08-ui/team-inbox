# 物理-2.3 匀变速直线运动的位移与时间的关系

## 课时开篇页

**本节知识点清单**：位移式 x=v₀t+½at²（梯形面积推导）· 平均速度=(v₀+v)/2（仅匀变速）· 速度-位移式 v²−v₀²=2ax（消t的无时间投影）· 五量知三求二路由表②③到货 · 推论A Δx=aT²（匀变速指纹·2.1纸带的公式化·v18原话：纸带、频闪照片求a的标准工具）· 推论B 中间时刻=(v₀+v)/2（v18原话：建立"平均速度=(v0+v)/2"仅匀变速成立）与中间位置=√((v₀²+v²)/2)不可互换 · 刹车截断位移版（40m对30m）· 比例结论1:3:5/1:4:9与两把锁 · 追及相遇三大判据（共速临界/位移关系+判别式/图像面积差）· 判别式三情况（Δ>0两次/Δ=0擦边/Δ<0没戏）· 刹车特例封顶进判别式 · 时间平移修正 · 差值函数思维

**学完这节你能做到**（4条，全部可自查）：
1. 给 v₀、a、t 能用②式算位移，给 v₀、a、x 能用③式反求任意量——列五量表路由，不背"什么题用哪条"
2. 纸带/频闪题见 Δx 恒定，能条件反射写出 a=Δx/T²（推论A），并说出它与逐差法的关系
3. 刹车位移题先算 t停 再代——6s内刹车位移答 30m 的卷面，这一节之后不应再出现
4. 追及题会列位移约束方程并用判别式三情况下结论，共速、相遇、"恰好不相撞"三个判据分得清

**难点预警**（3条，说话式）：
- 中间时刻和中间位置是两个不同的点：前者=(v₀+v)/2，后者=√((v₀²+v²)/2)且恒更大——匀加速时后半段走得快，走到"位置中点"的时刻比"时间中点"晚，那一刻速度已经被拉高了。选择题常客，图像一画就破
- 追及题的方程会"说谎"：甲刹车追乙解出t=9s，可甲4s就停了——方程把"甲倒车"的数学解也算进去。凡见"刹车/停止"，第一动作是算t停、位移封顶，再进判别式
- 判别式给的是"数学上几个交点"，不是"物理上追上几次"——Δ>0的两根必须物理筛根：乙越跑越快的题，甲在首次追上后就再没机会，第二根是模型边界的牺牲品

**前置依赖**：这节直接建在 2.2 速度式（①式）与"v-t图线下面积=位移"的图形直觉上——②式就是把那块梯形面积写成公式；追及判据还要用 2.2 的共速概念（交点=共速≠相遇）。本节同时回收 2.1 的实验：纸带Δx恒定在这节拿到公式身份 Δx=aT²。

## 正文

### 先回答一个问题：位移式从哪来

2.2说好"面积=位移正式展开"——兑现就在这一步。匀变速的v-t图是直线，0到t时间内的位移=图线下梯形面积=（上底+下底）×高÷2=(v₀+v)t/2，把①式v=v₀+at代入：

x = (v₀+v)t/2 = v₀t + ½at²

这就是②位移式。推导顺手送出一件副产品：**平均速度=(v₀+v)/2——注意它仅对匀变速成立**（梯形中位线=算术平均；变加速图线弯曲，中位线漂移，这个式子就不准了）。

### ③号公式：消去t的"无时间投影"

从②解出t代入①，消掉时间，得到③速度-位移式：**v²−v₀²=2ax**。它的用途一句话：题目不给t也不求t时一步到位。比如"刹车距离"：末速度v=0，x=v₀²/(2|a|)——20m/s刹车、5m/s²减速，一式得40m，连时间都不用碰。

### 五量知三求二：路由表正式扩容

2.2立的骨架"①号上岗、②③2.3到货"——现在三式凑齐，路由表就是点菜单翻到后两页：

| 已知 → 求 | 路由 |
|---|---|
| v₀、a、t → x | ②式 |
| v₀、a、x → v（t未知） | ③式 |
| v₀、v、x → a | ③式变形 |

先列五量表（v₀、v、a、t、x），已知三、未知二，找恰好覆盖的公式——查表调用，不背"什么时候用哪条"。

### 推论A：Δx=aT²——匀变速的"指纹"

相邻相等时间间隔T内的位移差恒定：**Δx=aT²**。这是2.1纸带处理的公式身份：纸带连续三段8cm、10cm、12cm，Δx=2cm恒定→匀变速实锤，a=Δx/T²=2m/s²。反过来也成立：Δx不恒定就不是匀变速——它是判匀变速的口算判据。

### 推论B：中间时刻与中间位置——不能互换的双胞胎

**中间时刻速度=(v₀+v)/2**（推论B，匀变速专属）；**中间位置速度=√((v₀²+v²)/2)**。后者恒更大——均方根压算术平均。物理画面：匀加速时后半段走得快，走到"位置中点"的时刻比"时间中点"晚，那一刻速度已经涨上去了。两者选择题里专门设卡，画图一秒分清，死记反而混。

### 刹车截断的位移版：40m对30m

2.2例1预告的位移侧正式展开：20m/s刹车、5m/s²减速，问6s内位移。t停=20/5=4s<6s——4s末车已停，位移封顶：x=v₀t停+½at停²=20×4−½×5×16=40m（或x=v₀²/(2|a|)=40m）。直接代t=6得120−90=30m，错——公式把"静止后又倒车"的2s算进去了。公式给的是数学解，物理场景裁决：停稳后a已不是−5（静摩擦接管），匀变速前提失效，那个"倒车解"必须人工丢弃。

### 追及相遇：把两个运动减成一个差值

多体第一纪律：**同一参考系、同一时间零点**——乙晚出发，它的公式里时间就是(t−t₀)，t<t₀段乙没动。然后盯一个量：距离函数Δx(t)=x前(t)−x后(t)。它的变化率=速度差，所以**速度差为零（共速）的时刻=距离取极值的时刻**——这就是"共速是临界"的完整含义。

三大判据按题型取用：
- **①速度相等判据**：追不上先共速→距离最大；能追上则共速时距离最小（临界：恰好共速追上=一擦而过）。
- **②位移关系判据**：追上 ⇔ x后−x前=初始间距Δx₀——代入公式解一元二次方程，判别式Δ给三种情况：Δ>0两次相遇（先追上后反超）、Δ=0恰好共速擦边、Δ<0永远追不上。
- **③图像判据**：v-t图两线间的"面积差"=位移差，共速点两侧面积差直读最大/最小距离。只问极值距离不问时间时，这是降维打击——甲6m/s匀速、乙静止1m/s²加速：共速t=6s，最大距离=36−18=18m；追上6t=½t²→t=12s、位置72m，图像与公式两法互验。

**刹车特例进判别式**：前车减速必须先算t停、位移封顶——否则"前车倒车"会污染整个方程。

### 适用边界：本节新增的几道闸

- 比例结论两把锁：**初速为零+连续相等时间间隔**——漏验v₀=0是刷题最高频翻车点（边界④）；
- 平均速度=(v₀+v)/2与"中间时刻速度"仅限匀变速（边界⑤）；
- 追及判据在匀变速框架内成立；变加速只能回v-t图像面积法或数值积分（簇⑥边界②）；
- 一维前提：环道追逐、船渡河是二维问题，本章判据不直接迁移（簇⑥边界④）；
- "恰好避免相撞"=此刻共速且位置恰好差一个安全距离——共速是临界，不是"碰前瞬间"（簇⑥边界⑤）。

### 常见误解（四条全）

| # | 错误说法 | 纠偏 |
|---|---|---|
| 1 | "中间时刻速度=中间位置速度" | 前者=(v₀+v)/2，后者=√((v₀²+v²)/2)更大——匀加速后半段快，位置中点来得晚、速度已涨 |
| 2 | "相遇时速度必相等"／"共速即相遇" | 相遇=位置相同（撞上的情况速度不等）；共速=此刻一样快（位置可差很远）——查位置与查速度是两个动作 |
| 3 | "追上后一定反超" | 临界情形Δ=0：追上瞬间恰好共速，之后可保持并排——解出t后把共速时刻与追上时刻对比再下结论 |
| 4 | "乙晚出发t₀，直接代t" | 乙的公式里时间是(t−t₀)，t<t₀段乙位移为零——分段写或换元τ=t−t₀ |

### 最小验证（三题）

1. 纸带连续三段T=0.1s位移8cm、10cm、12cm，求a。——Δx=2cm恒定→a=0.02/0.01=2m/s²，方向与运动方向相同。
2. 初速为零的匀加速，第1、2、3个T内位移比？——1:3:5（前nT总位移比才是1:4:9——先问清"第几个"还是"前几个"）。
3. 甲10m/s匀速，乙同地同时6m/s、1m/s²加速追。何时共速？相距多远？何时追上？——共速t=4s（10=6+t），此时Δx=40−32=8m为最大距离；追上10t=6t+½t²→t=8s，双方均80m。

## 经典例题精讲

### 例1（判别式三情况完整示范）

乙在甲前方L=20m，甲以10m/s匀速追，乙同时以2m/s²从静止加速。能否追上？

**解**：追上条件：甲位移=乙位移+20 → 10t=20+½·2·t² → **t²−10t+20=0** → Δ=100−80=20>0 → 两根t=(10±√20)/2≈**2.76s与7.24s**。物理筛根：乙一直在加速、越来越快，甲匀速在首次追上后再也追不上——t₁≈2.76s首次追上（此后乙反超），t₂=7.24s是二次曲线的第二个数学交点，物理上无意义（模型边界：匀加速无限持续的假设在长时间下失真）。结论：**能追上，首次用时约2.76s**。

**图B规格（v-t图，供装配层渲染）**：横轴t、纵轴v；甲=10m/s水平线，乙=过原点斜线（斜率2）；交点(5s, 10m/s)=共速t=5s时甲领先最大（5m）；追上前最大间距=初始20m；追上在t₁≈2.76s；到t=5s两线间累计面积差=甲领先值=50−25−20=5m；两线间面积在t₁≈2.76s前累计差恰好=20m（初始间距补齐=追上）。

**【怎么想到的】**看到"前后车+初始间距L+一个加速一个匀速"，先别急着套"追及公式"——第一动作是列位移约束：追上=甲走的=乙走的+L，这一行列对，后面全是解方程。最容易走的岔路是把判别式的两根都抄上去，还配一句"两次追上"——死因：乙一直在加速，10m/s的匀速甲在t₁之后再无反超机会，t₂只是两条曲线的第二个交点，"匀加速无限持续"的模型在7秒尺度上已经失真。你最容易卡的是"Δ=20>0到底几次"——判别式只回答"数学上几个交点"，物理筛根是必做的一道安检；以及设未知数时忘了L该加在乙那边——谁在前方，L就加在谁的位移上。一句话带走：判别式是"能否追上"的体检表——Δ>0追得上、Δ=0擦边共速、Δ<0没戏，但体检表不替你筛根。

**【定级】**标准（判别式+物理筛根双考点；本节母题型）

### 例2（防追尾设计：刹车封顶+反应期联演）

前后车均以20m/s行驶，间距12m。前车随时可急刹（a=−5m/s²），后车发现险情需0.5s反应后以相同a刹车。这个间距安全吗？最小间距多大？

**解**：前车刹车距离=20²/(2×5)=40m；后车总需=反应距离20×0.5=10m＋刹车距离40m=50m。最终间距=12+40−50=**2m>0，安全**。过程账：反应期内两车同速、间距保持12m；后车刹车后（与前者同减速度、但晚刹车0.5s），后车速度恒大于前车，间距单调减小，最小值2m出现在后车停稳时刻（t=4.5s；前车4s已停时间距2.625m）。工程结论：安全车距至少要覆盖"反应距离"——跟车"2秒法则"的物理来源。

**图C规格（v-t图，供装配层渲染）**：两车v-t线同高20m/s起点；前车t=0起斜率−5直线，t=4s落零；后车0.5s内水平，之后平行斜率−5、t=4.5s落零；两线间"错位平行四边形"面积=反应距离10m——前车多停0.5s的差异全部由初始间距12m兜底，剩2m。

**【怎么想到的】**看到"反应时间+前后车刹车"，先别急着列一个大方程——拆成三笔账：反应期（后车多走10m）、刹车期（两车刹车距离同40m，抵消）、封顶时刻（前车4s先停、后车4.5s后停，间距最小在后车停稳时）。最容易走的岔路是直接对全程列位移等式判判别式——死因：前车4s就停了，判别式方程把"前车倒车"的解也算进去，结论整体作废；刹车封顶必须走在方程前面。最容易卡的一步是"最小间距出现在哪个时刻"——不是共速时刻（本题两车从未共速到零以下），而是后车停稳、前车早已停稳、两者都不再动的时刻，此刻间距=12+40−50=2m。一句话带走：防追尾=让"刹车距离差"（这里是反应距离10m）永远小于初始间距。

**【定级】**标准（三段分账+封顶时刻判断；工程情境综合题）

## QA·考前60秒

1. 路由表②③怎么查？——已知(v₀,a,t)求x→②式；已知(v₀,a,x)求v→③式；已知(v₀,v,x)求a→③式变形——五量表先列，恰好覆盖。
2. 中间时刻与中间位置谁大？——中间位置大：√((v₀²+v²)/2)>(v₀+v)/2（均方根>算术平均）——选择题常客。
3. 比例结论1:3:5什么时候能用？——仅v₀=0的匀加速、且是"连续相等时间间隔内"——两把锁缺一不可；"前nT总位移比"是1:4:9。
4. "恰好不相撞"的数学语言？——共速时Δx=0（距离最小值恰为0）——临界=判别式Δ=0，"一擦而过"。
5. 追及题动笔前必检哪三坑？——①参考系统一②时间零点统一（晚出发要修）③刹车封顶。
6. 公式里的s和x有区别吗？——没有，都是位移（一维带符号）；题目给"路程"要先换算成位移才能代公式。

## CX·跨簇连接

**等距+时间比 → 推论B快刀（簇04 CX照录）**：匀加速物体依次经过A、B、C，AB=BC=6m，tAB:tBC=2:1。求vA:vB:vC与加速度。谱：设tBC=t、tAB=2t，等位移+速度关联解得vA:vB:vC=1:5:7、a=2m/s²（取t=1s：vA=1、vB=5、vC=7；位移验证AB=1×2+½×2×4=6✓、BC=5×1+½×2×1=6✓）。快刀验法：等距时平均速度与时间成反比（v̄AB:v̄BC=1:2），用推论B"中间时刻速度=段平均速度"直接列v(1s):v(2.5s)=3:6=1:2——推论B把二次方程降成一次口算。本桥连着：2.1纸带（等时隔数据）、2.2共速、本节推论B。

## 深读区：因果与为什么（不读不影响做题，想深究再看）

**为什么恰好是"三个公式、两条独立链"？**匀变速运动由v₀、a两个参数完全确定，t是自由变量，所以独立的函数关系只有两条：v(t)与x(t)。③式v²−v₀²=2ax是两链消去t的"无时间投影"——它不携带新信息，只是换了记账视角。看清"自由参数数=独立关系数"，任何运动学公式组都能自动重组——这一语法同样适用于自由落体（v₀=0、a=g特化）与竖直上抛（a=−g分段）。（段尾延伸：这套"几个参数锁定系统"的识别动作，是建模的第一课。）

**为什么x=面积？**把总时间切成小段，每段内速度近似不变，v·Δt≈一小段位移，全部累加=图线下总面积；Δt→0就是积分思想。"累积"语法第一次给出可计算的预测——后面算功（F-s图面积）、算冲量（F-t图面积）都是同一个语法，认出它就永远不用重学。

**差值函数思维与极值判据。**别盯着两个物体各自的位置，盯"差值"这一个量——变量从2个降到1个，问题立刻降维。为什么"速度相等"恰好是距离极值点？Δx(t)对t求导=速度差——距离函数的斜率=速度差，斜率为零处取极值。位移是t的二次函数，两条二次曲线求交点=解二次方程，"能否追上"被翻译成"判别式正负"——物理问题与代数结构一一对应：认识结构，而不是记住题型。
