**本节知识点清单**：计时器原理与两机型对比（电磁式4-6V低压交流·复写纸／电火花220V·墨粉纸盘）·五步操作流程与"先通电后放车"铁律·计数点与时间间隔T=0.10s·中间时刻速度法vₙ=(xₙ+xₙ₊₁)/2T（v18原话：中间时刻平均速度=该点瞬时速度）·逐差法（9T²/4T²两式）·v-t图斜率法·匀变速判据Δx=aT²·误差两分法（偶然/系统）与减误差操作·频闪照片/滴水计时器等效迁移·纸带疏密判运动方向

**学完这节你能做到**（4条，全部可自查）：
1. 给一条打点纸带，能算出任意计数点的瞬时速度和全段加速度
2. 能把"铺木板→穿纸带→通电→放车→取带"按正确顺序排出，并说出"先通电后放车"的理由
3. 看到"每两个计数点间还有4个点未画出"，0.5秒内反应出T=0.10s
4. 能判断一条纸带是不是匀变速，并说出两种判法（位移差恒定 / v-t图成直线）

**难点预警**（3条，说话式）：
- 这节最容易晕的是"纸带上那串数字怎么变成速度和加速度"——先记住本质就两个动作：点距当位移用，平均速度当瞬时速度用，公式都是这两句话穿上符号外衣
- 逐差法公式分母那个9T²长得吓人，但来历只有一行：三组3aT²相加。下面给你完整算例，数字一步不跳，看完你会发现它根本不用背
- "先通电还是先放车"这类排序题年年见，别死记顺序，记住一个理由就够了：刚通电打点还不稳

**前置依赖**：这节要用到 平均速度与瞬时速度、加速度的定义、匀变速判据Δx=aT²（都是第1章正文的旧知识）。教材里"误差与有效数字"有专门小节（鲁科2.3前置节），没学过也不挡路——本节把用到的读数规则直接给。思维方式上，这节是"近似与理想化"的第一次实战（用平均速度近似瞬时速度）。节位对照：鲁科版2019第2章§4（p51，独立设节"科学测量：做直线运动物体的瞬时速度"）；人教2019对照=第二章§1"实验：探究小车速度随时间变化的规律"。

## 正文：从一条纸带读出运动（器材/步骤/数据处理/误差分析四段）

### 第一段｜器材：两位"盖章员"，一条赛道

想象你没法一直盯着一辆越跑越快的小车，于是请来一位摄影师：**每隔0.02秒按一次快门**，把小车的位置一张张拍下来。打点计时器就是这位摄影师——它是一种**等时间隔**在纸带上打出点的计时仪器（等时间隔=相邻两个点之间的时间都一样长，这是全部数据处理的根基）。

它吃的是**交流电**（电流方向来回变的电，教室插座供的就是这种，频率50Hz）。每打相邻两个点花0.02秒，这个固定时长叫**打点周期**。

实验里实际有两位"摄影师"，考试爱考它们的区别：

| 机型 | 工作电压 | 打点周期 | 留印部件 |
|---|---|---|---|
| 电磁打点计时器 | 4-6V低压交流电 | 0.02s | 复写纸（压在纸带上、一压就留印的复写用纸） |
| 电火花计时器 | 220V交流 | 0.02s | 墨粉纸盘（类似打印机色带的墨粉盘） |

**到此记住**：两种机型、两档电压（4-6V对220V）、两种留印部件（复写纸对墨粉纸盘）——这三组对应关系就是判别题的答案库。

### 第二段｜步骤：五步流水线，顺序本身就是考点

1. **铺赛道**：把附有滑轮的长木板平放在桌上，打点计时器固定在木板一端，连好电路。
2. **上纸带**：纸带穿过**限位孔**（计时器上约束纸带走向的窄孔，让纸带只走直线）连在小车尾部；小车停靠在靠近计时器的一端。电磁式记得把复写纸压在纸带上方。
3. **先通电**：接通电源，等打点稳定。
4. **再放车**：释放小车拖动纸带（小车由重物经定滑轮牵引；也可以把木板一端垫高，让小车沿斜面自己滑）；车到滑轮前用手按住。
5. **收纸带**：先断电，再取纸带；换新纸带重复2-3次，选一条点迹最清晰的来算。

★高频排序题就埋在这里：**必须先接通电源、待打点稳定后再释放小车**（v18原话·★易错排序题高频·2019教材原文级考点）。理由就是第3步那五个字——"待打点稳定"。◎辅助理解｜先开摄像机再让运动员起跑，别等人家冲过终点才想起开机。

**到此记住**：顺序链"铺→穿→通→放→取"（通电在放车之前，断电在取带之前）。

### 第三段｜数据处理：从点距到速度和加速度

开工前先立四个路标（本节的思维骨架，建模观四步显式化）：

#### 第1步：定时间刻度——计数点与T

0.02s一个点太密，全都用会把读数误差放大。做法：**每隔4个间隔圈一个计数点**（计数点=你圈出来参与计算、点上标了字母的点），相邻计数点间的时间间隔：

T = 5 × 0.02 s = **0.10 s**

题目里两种说法是同一件事："每五个点取一个计数点" = "每隔四个点取一个"（中间隔4个点，跨过5个间隔·v18原话：两说法等价）。

#### 第2步：求某点瞬时速度——中间时刻技巧

匀变速运动里，**一段时间的中间时刻，瞬时速度恰好等于这段的平均速度**。所以求C点的瞬时速度，就量它前后两段位移：

v_C = x_BD / 2T

点破思维方式：vₙ=(xₙ+xₙ₊₁)/2T 本来是个平均速度，匀变速里它严格等于中间时刻的瞬时速度——实验里我们**有意**用平均速度近似瞬时速度，这就是"近似与理想化"，是这节真正要练的判断力。

#### 第3步：求加速度——逐差法（完整算例，数字一步不跳）

**先立判据**：匀变速=连续相等时间的位移差恒定，即 x₂−x₁ = x₃−x₂ = … = aT²。

**六段数据的通式推导**（纸带划出x₁~x₆六段，"远减近"分三组）：

x₄−x₁=(x₂−x₁)+(x₃−x₂)+(x₄−x₃)=aT²+aT²+aT²=3aT²

同理 x₅−x₂=3aT²、x₆−x₃=3aT²，三式相加：

9aT²=(x₄+x₅+x₆)−(x₁+x₂+x₃)　⟹　a=[(x₄+x₅+x₆)−(x₁+x₂+x₃)] / 9T²

分母9T²的来历就这一行：三个3aT²相加。忘了公式就现场推，三行而已。

**四段数据的真题算例**（数据即下面例2·2019全国ⅠT22）：
四段相邻位移 AB=1.20、BC=1.95、CD=2.70、DE=3.45（单位cm）。先做"匀变速体检"：BC−AB=0.75、CD−BC=0.75、DE−CD=0.75（cm），位移差恒定✓——这一眼就是"回归检验"步。然后：

a=[(s_CD+s_DE)−(s_AB+s_BC)] / 4T² = (2.70+3.45−1.20−1.95)×10⁻² m / 4×(0.10 s)² = 3.00×10⁻² m / 0.040 s² = **0.75 m/s²**

分子一步不跳：2.70+3.45=6.15，1.20+1.95=3.15，6.15−3.15=3.00（cm）；分母一步不跳：4×0.10²=0.040（s²）。

#### 第4步：v-t图像法——斜率即加速度

把每个计数点的瞬时速度（第2步技巧）算出来描点，**图像规格（供装配层渲染真图）**：横轴t/s，以计数点时刻为刻度（0、0.10、0.20、0.30……）；纵轴v/(m·s⁻¹)；把5~6个(v, t)数据点逐一描出；用直尺画一条直线，让数据点大致均匀地分居直线两侧（不是把点连成折线）；**直线斜率=加速度a**。若点明显弯成曲线，说明不是匀变速——图像形状本身就是"回归检验"。

#### 第5步：判匀变速（不用图像的口算法）

连续相等时间的位移差Δx为定值（v18原话：连续相等时间位移差Δx为定值，此即匀变速判据） → 匀变速。上面算例里"相邻差恒为0.75cm"就是现场示范。

**到此记住**：数据处理三件套——T=0.10s（换算）、vₙ=(xₙ+xₙ₊₁)/2T（中间时刻）、逐差法（全数据上场）；外加一张v-t图（斜率=a，顺带验匀变速）。

### 第四段｜误差分析：投篮手感 vs 装歪的篮筐

误差分两种性格：**偶然误差**——忽大忽小，多测几次能摊平，像投篮手感时好时坏；**系统误差**——总往同一个方向偏，多测也消不掉，像篮筐装歪了球总往一侧弹。本节的来源与对策：

| 来源 | 类型（v18标注） | 对策 |
|---|---|---|
| 刻度读数估读有起伏 | 偶然 | 最小刻度1mm的尺，读数**估读到0.1mm**（毫米的下一位）；这个"可靠位+1位估读位"的记法就是有效数字的实际操作 |
| 量距方式不当（分段量） | —（操作性问题） | **一次量出各计数点到O点的距离，再相减得各段x**——勿分段量（v18原话）：每段都重新对零，估读误差会叠起来 |
| 打点摩擦 | 系统 | 知道它存在；多测摊不平，分析时要心里有数 |
| 空气阻力 | 系统 | 同上 |
| 开头点迹过密 | — | **舍去开头过密集的点迹（v18原话）**，从点距清晰处开始选计数点 |

**到此记住**：两类误差性格不同（偶然能摊平、系统消不掉）；两个减误差动作=估读到0.1mm + 一次量到O点再相减；开头密点舍掉。

### 例1【保底】计时器判别+纸带基础处理（2023·福建部分地市一检（福州市卷）·T11，5分）

**【题干】**打点计时器是高中物理实验中常用的实验器材，请你完成下列有关问题：
(1) 图示计时器带墨粉纸盘，它是____（选填"A"或"B"）。A. 电磁打点计时器　B. 电火花计时器
(2) 一小车在重物牵引下拖着穿过限位孔的纸带沿平直轨道加速运动，下图是打出的纸带的一段，相邻两个计数点之间还有4个点未画出。已知打点计时器使用的交流电频率为50Hz。纸带上O、A、B、C、D为计数点，OA=3.18、OB=6.74、OC=10.69、OD=15.05（单位：cm）。①图中标出的相邻两计数点的时间间隔T=____s；②小车的加速度a=____m/s²（计算结果保留2位有效数字）。

**【解答】**
(1) 墨粉纸盘是电火花计时器的特征部件（电磁式用复写纸压纸带）→ 选**B**。
(2)① 相邻两计数点间还有4个点未画出 → 跨5个打点周期：**T = 5×0.02s = 0.10s**。
② 先把"到O点距离"换成"相邻段位移"（正是误差分析说的"一次量到O点，再相减"）：
s₁=OA=3.18cm，s₂=OB−OA=6.74−3.18=3.56cm，s₃=OC−OB=10.69−6.74=3.95cm，s₄=OD−OC=15.05−10.69=4.36cm
匀变速体检：s₂−s₁=0.38、s₃−s₂=0.39、s₄−s₃=0.41（cm），近似等差渐增✓。四段逐差，分数式完整展开：

a = [(s₃+s₄)−(s₁+s₂)] / 4T² = (3.95+4.36−3.18−3.56)×10⁻² m / 4×(0.10 s)² = 1.57×10⁻² m / 0.040 s² = 0.3925 ≈ **0.39 m/s²**

分子一步不跳：3.95+4.36=8.31，3.18+3.56=6.74，8.31−6.74=1.57（cm）。保留2位有效数字→**0.39**。

**【怎么想到的】**看到"带墨粉纸盘"，触发的是第一段那张判别对照表：墨粉纸盘＝电火花、复写纸＝电磁——两档电压、两种留印部件，答案库直接查，不用想第二秒。第二问最可能卡在两处：一是把"到O点距离"直接当位移代进逐差法——先相减换成相邻段位移（"一次量到O点再相减"在这题里就是得分动作本身）；二是分母随手写9T²——手里是四段数据，分母跟段数走（四段4T²），六段才轮到9T²。

**【定级】**保底（基础操作/读数）

### 例2【标准】倾斜木板加速下滑（2019·全国卷Ⅰ·T22）——本节母题

**【题干】**某小组利用打点计时器对物块沿倾斜的长木板加速下滑时的运动进行探究。物块拖动纸带下滑，打出的纸带一部分如图。交流电频率50Hz，纸带上每两个相邻计数点间还有4个点未画出。A、B、C、D、E五个点中打点计时器最先打出的是____点；打出C点时物块速度大小为____m/s（3位有效数字）；物块下滑加速度大小为____m/s²（2位有效数字）。

**【解答】**
① 定时间刻度：还有4个点未画出 → T=5×0.02s=0.10s。
② 判先后：物块**加速**下滑 → 点距越打越大 → 点距小（密）的一端是先打的 → **A**。
③ 求vC：C是B到D这段的中间时刻。四段相邻位移AB=1.20、BC=1.95、CD=2.70、DE=3.45（cm），则xBD=BC+CD=1.95+2.70=4.65cm：

v_C = x_BD / 2T = 4.65×10⁻² m / 0.20 s = 0.2325 ≈ **0.233 m/s**

④ 求a（四段逐差，完整展开）：

a = [(s_CD+s_DE)−(s_AB+s_BC)] / 4T² = 3.00×10⁻² m / 0.040 s² = **0.75 m/s²**

**【怎么想到的】**看到"加速下滑+纸带"，先别急着找公式——纸带题的第一动作是把"点"翻译成"时间"：还有4个点未画出，跨5个间隔，T=0.10s，这步定错后面全错。三问的作答顺序也别跟着题目走：先判先后（疏密定方向），再求中间量vC，最后逐差求a。最容易走的岔路是"最先打出"填E——"图从左往右画、阅读顺序就是打点顺序"的错觉；死因：加速下滑点距越打越大，密的一端才是先打的，A端最密。另一处暗卡在vC的分子——不是BC段也不是CD段，是B到D整段（C是这段的中间时刻，前后各占一个T）；逐差法分母忘了就来历现场推：相邻差恒为aT²，隔两段的差是2aT²，四段式分子（s₃+s₄）−(s₁+s₂)=4aT²，分母4T²。一句话带走：纸带是一串等时快照，点距就是速度的影子——先读影子疏密，再动笔。

**【定级】**标准（数据处理）

**【同类一题自测】**若换成"减速下滑"，最先打出的是哪个点？（点距渐小 → 疏的一端先打 → E。想通"疏密=快慢"，方向题就毕业了。）

### 例3【进阶】纸带+牛顿第二定律测动摩擦因数（2019·全国卷Ⅱ·T22）

**【题干】**用铁架台、长木板、铁块、米尺、电磁打点计时器（50Hz）测铁块与木板间动摩擦因数。木板倾角θ=30°，接通电源释放铁块，由纸带测得加速度a（计数点间还有4点未画出）。(1) μ=____（用θ、g、a表示）；(2) 由逐差法得a=1.97m/s²，g取9.80m/s²，求μ。

**【解答】**
(1) 对铁块沿斜面列牛顿第二定律：mgsinθ−μmgcosθ=ma，两边约去m：

μ = (g·sinθ−a) / (g·cosθ)

(2) 代入数字，一步不跳：g·sin30°=9.80×0.5=4.90；g·cos30°=9.80×0.866=8.49（三位有效数字）：

μ = (4.90−1.97) / 8.49 = 2.93 / 8.49 = 0.345 ≈ **0.35**

**【怎么想到的】**看到"测动摩擦因数"，触发的是分工意识：纸带只负责把a量出来，剩下的交给受力分析——两段式流水线（纸带：逐差出a；斜面：牛顿第二定律出μ）。看着像要死算的"用θ、g、a表示"，其实正交分解列完式子约掉m，μ自己就解出来了。最可能卡在sin30°和cos30°谁乘谁——重力沿斜面的分量是mgsinθ（驱动下滑），压斜面的分量是mgcosθ（决定摩擦），口诀"驱动用sin、压力用cos"；另一处小卡是有效数字：0.345按题目要求保留2位得0.35，别把中间值抄上去。超纲注记：牛顿第二定律第三章才正式展开——本节先认"分工"即可，式子会照抄就行。

## 应试打法

1. **计数点换算**：见"还有N个点未画出"→间隔=(N+1)个→T=(N+1)×0.02s；N=4最常见，条件反射T=0.10s
2. **求某点瞬时速度**：找它前后两段，v=(x前+x后)/2T，套中间时刻技巧
3. **逐差法求a**：先数有几段位移——四段用[(s₃+s₄)−(s₁+s₂)]/4T²，六段用[(x₄+x₅+x₆)−(x₁+x₂+x₃)]/9T²；"最优算式"选择题认准"用满全部数据"的那一个（2024甘肃T11(2)考过选D）
4. **操作排序题**：默写链条"固定→穿纸带→通电→稳定→放车→按住→断电→取带"
5. **等效迁移题**：滴水计时器（水滴当打点）、频闪照片（闪光当打点）、手机拍摄逐帧（2017全国ⅠT22、2020江苏T11）——本质都是"等时间间隔记录位置"，套同一套数据处理
6. **疏密判方向**：先判趋势（点距变大=加速），再定先后（加速密端先打，减速疏端先打）

## 深读区：因果与为什么（不读不影响做题，想深究再看）

**为什么需要逐差法**（逐差法=把纸带各段位移分组相减、再合起来解出a的方法）：只用相邻两段算a=(x₂−x₁)/T²的话，这两段的读数误差直接决定答案；逐差法让**每一段数据都上场**，像全班接力不许任何人坐冷板凳，偶然误差被摊平。

**"中间时刻=瞬时速度"为什么只在匀变速严格成立？**匀变速的v-t图是直线，一段时间内的图线是梯形，平均速度=中位线=(v₀+v)/2，而梯形中位线恰好落在中间时刻——所以"取前后两段求平均"（vₙ=(xₙ+xₙ₊₁)/2T）严格等于该点的瞬时速度。非匀变速图线弯曲，中位线漂移，平均与瞬时错开——这就是第2步必须先判匀变速（或题给匀变速）的原因。2.2会把这个事实写成推论B。

**从纸带到频闪到手机慢动作：等时距采样的一般观**。打点0.02s一拍、频闪灯固定间隔闪光、相机每秒几十帧——本质全是"固定Δt记录位置序列"。采样越密，位置变化被记录得越细，但读数与处理成本越高；计数点"隔4个取1"就是在精度与工作量之间做权衡。科学测量永远是"精度—成本"的谈判桌，这是"近似与理想化"的第二课。
