# 节1 断句题（题型簇）

## 课时开篇页

**本模块知识点清单**：断句题3分的规则化拿法·标志词四组（句首/句尾/时间词/对话）·断句口诀·官方三步流程·"80%标志+20%大意"的配合比

**学完这模块你能做到**（3条，全部可自查）：
1. 拿到断句题，先圈标志词再动笔——句首组、句尾组、时间词组、对话组四组标志能脱口而出
2. 能按"通读圈标志→先易后难断开→回读检验"三步完成一道断句，而不是凭感觉乱点
3. 断错时能说出"漏了哪个标志"，两周内找出自己的标志盲区

**难点预警**：
- 标志是概率线索不是铁律——见"曰"就断、见"也"就停的机械操作会翻车，"断完后根据文意检验"这一步不可省。
- 时间词组只覆盖史传类文本（高考文言主粮），散文类题目要用大意兜底，别指望清单包打天下。

## 速览卡（10秒版）

| 问题 | 答案 |
|---|---|
| 这块是什么 | 文言文卷面的"技术分"题（3分）：给一段去掉标点的文言，让你选/填正确的断法——v18口径：标志法能解决80%的断句，这是"语感穷人"的规则化路线 |
| 为什么存在 | 语感要靠长年积累，但标志是显性规则——1小时学习+每天5分钟，就能把碰运气的3分变成准规则题，文言板块单位时间得分效率最高的一招 |
| 怎么考 | 客观选择为主：四个断法选一个对的；近三年一卷文言均为"史传+评论"双文本制，断句材料以史传叙事段为主 |

## 正文

### 1.1 断句题是什么：把语感题变成规则题

先给判断句：**断句考的不是"你读没读懂"，是"你认不认识文言句子的路标"。**

文言句子有固定的"进出场规矩"：句首常有发语词，句尾常有语气词，说话必有"曰"，叙事常带时间词。这些规矩是显性的、可以清单化的——所以零语感的学生照样能拿分，前提是把路标背下来。

背路标之前先背口诀（v18照录）："内容大意先理解，熟读精思把句断。紧紧抓住曰云言，对话最易被发现。常用虚词是标志，更有规律供参看。习惯句式掌握住，固定结构莫拆散……"

口诀第一句就是答案的边界：**大意理解打底，标志词执行，缺一不可。**

### 1.2 标志词四组清单（断句的全部家当）

- **句首组**（前面通常要断开）：盖 / 夫 / 惟 / 凡 / 故 / 今 / 若夫 / 且夫 / 至于 / 至若
- **句尾组**（后面通常要断开）：也 / 乎 / 焉 / 矣 / 耳 / 哉 / 与（欤）
- **时间词组**（前后常断，史传高频）：顷之 / 向之 / 未几 / 已而 / 斯须 / 既而 / 俄而
- **对话组**（"曰/云/言/谓"前后断）：对话最易被发现——引语起点必断

【辅助理解】为什么"也"在句尾就能断？"也"是判断和肯定的收束词，一句话说完它才出场——所以"也"后面就是下一句的起点。这不是玄学，是文言的句法习惯。

### 1.3 官方三步流程（v18口径照录）

1. **先通读圈标志**：不急着断，先把全段的曰/也/夫/未几……圈出来
2. **先易后难断开**：标志密集处先断，把长段切成短段
3. **回读检验**：按大意通读一遍，发现"人名被劈开""动词没了宾语"就回改

### 1.4 防坑与复盘

- **坑一：机械断**。标志是概率线索，"先帝知臣谨慎"的"知"后面没有句读——别见词就切，回读检验兜底。
- **坑二：只背清单不做题**。考场提取速度靠真题喂出来，每天1道断句真题（v18口径：5-10分钟）。
- **复盘动作**：断错处标注"漏了哪个标志"，累积两周自检标志盲区（v18口径照录）——盲区清单比错题本值钱。

## 经典例题（节1）

**题干**（教学自拟示意，方法与检验机制均出自v18册方法5"断句标志法"，不含编造真题事实）：

> 给下列文字断句（自拟示意）：未几敌大至万夫莫当所向披靡

**解答**：
①圈标志："未几"是时间词组（史传高频，前后常断）——先断第一刀："未几 / 敌大至……"。
②先易后难："敌大至"主谓宾完整（敌人大规模到来），是一个独立短句。
③回读检验：剩下的"万夫莫当所向披靡"是两个四字评价语并列，对称结构处断开——"万夫莫当 / 所向披靡"。

**思维标注**：第一步圈标志只找到"未几"一处——时间词组是史传类文本的稳定路标；第二步"敌大至"靠"主谓宾完整"这一大意判断收口；第三步两个四字格并列按对称断——对照1.4：标志（未几）+大意（敌大至）+对称（四字格）三路配合，没有一路是纯语感。

**定级**：基础档·规则主干考法（定级为讲解归纳；标志词清单与三步流程系v18册方法5原文口径）。

## 易错卡（节1·四元：症状/错因/维持机制/钉死）

**卡1·见"曰"就断、见"也"就停**
- 症状：机械执行标志，"曰"前一刀"也"后一刀，结果把人名或固定结构切烂
- 错因：把"概率线索"背成"铁律开关"
- 维持机制：清单背熟后执行特别顺，正反馈让它越过"文意检验"直接开断
- 钉死：三步流程里"回读检验"永远最后一步，省不得——发现句子讲不通，先怀疑刚才的刀

**卡2·标志全找齐还是不敢下笔**
- 症状：圈了一堆标志，四个选项看着都像，选不出来
- 错因：只用了标志路，没配"大意兜底"路（口诀第一句"内容大意先理解"）
- 维持机制：背清单的时候把"检验"也跳过了，考场只剩单腿
- 钉死：标志解决80%，剩余20%靠通读大意——两腿走路才稳

**卡3·时间词组用到散文上翻车**
- 症状：在散文/议论类文本里狂找"未几、既而"，一篇下来一个没有
- 错因：忘了时间词组是**史传类专属路标**（v18风险栏原文口径）
- 维持机制：平时练的全是史传，形成了路径依赖
- 钉死：动笔前先判文体——叙事史传用四组清单，议论散文转大意+虚词判断

**卡4·只做不记，盲区永不收敛**
- 症状：每天做断句题，同一类错误反复犯
- 错因：做完对答案就扔，漏了"标注漏了哪个标志"的复盘动作
- 维持机制：刷题量看起来在涨，其实盲区清单是空的
- 钉死：断错处当场写"漏了哪个标志"，两周自检一次盲区清单（v18口径照录）

## 应试打法（节1）

- **考场流程单**（对照1.3三步）：通读圈标志→先易后难下刀→回读检验讲不讲得通
- **时间口径**：断句3分题，目标2分钟内收卷——省下的时间给翻译（分值最大的单题，见节2）
- **文体预判**：拿到题先扫一眼是史传还是散文——史传开"四组清单"，散文转"大意+虚词"
- **双文本边界**（v18·R-语.文言-03口径）：2024-2026一卷文言均为"史传+评论"双文本制，单文本断句练习需加双文本比对训练
- **复盘动作**：盲区清单两周一检；标志组里自己最常漏的那组，下周专项喂题

# 节2 翻译题（题型簇）

## 课时开篇页

**本模块知识点清单**：翻译是文言板块分值最大的单题（新高考8分口径/旧全国卷10分口径）·依点赋分刚性踩点制·赋分公式·四步写译文·五字诀"留换删补调"·限时6分钟自评

**学完这模块你能做到**（4条，全部可自查）：
1. 看到"翻译下面两个句子"，知道阅卷是按得分点赋分的——句意顺但漏关键词照样丢分
2. 能圈出一句话里的"可疑词"（活用/通假/古今异义/重点实词虚词），说出这句大概踩哪几个点
3. 能按"圈得分点→单字变双字→句式调序→补全省略"四步写出一条直译
4. 译完能用五字诀"留换删补调"自检一遍，并用答案反查漏点

**难点预警**：
- 最大的错觉是"翻译得通顺就行"——阅卷按点采分、扣完为止，"句法正确但词义错误不能得大意分"（v18口径），通顺只是兜底分。
- 第二个坑是"死译"：直译=字字落实+补全省略，不是逐字硬翻成翻译腔——句子没人话，同样是档位杀手。

## 速览卡（10秒版）

| 问题 | 答案 |
|---|---|
| 这块是什么 | 文言板块分值最大的单题：把两句话译成现代汉语——命题人选定的句子必有特殊之处（活用/通假/句式），这些"特殊之处"就是预设得分点 |
| 为什么存在 | 学生以为翻译靠语文素养，其实它是全卷最"刚性"的题：实词1分/虚词0.5-1分/句式1分/漏译每处扣1分——公式化动作能把"看懂"直接转成"拿满" |
| 怎么考 | 主观翻译2句；限时6分钟/句（v18口径）；官方按点采分"扣完为止"（2024卷翻译8分官方踩点实锤：三个关键词各占一分） |

## 正文

### 2.1 翻译题是什么：按给分公式写译文

先给判断句：**翻译题不是"中文表达竞赛"，是"找点—对译—顺句"的公式题。**

阅卷逻辑是"依点赋分"：命题人选句子时就把得分点埋好了——重点实词、关键虚词、特殊句式各占一定分值，阅卷人拿踩点表逐点对照。你写译文时不知道点在哪，等于闭卷答题。

### 2.2 赋分公式与得分点构成（v18口径照录）

- **公式**：重点实词1分/个；关键虚词0.5-1分/个；特殊句式1分/个；漏译/误译/语序错误每处扣1分；句意通顺另有兜底分。
- **单题构成**：实词2-3个+虚词1个+句式1个+通顺兜底1分（v18·文言全卷分值结构分析口径）。
- **得分点主体是课本实词**（学术统计口径）：2020年起新高考文言翻译得分点大部分是实词，且"这些实词来源于高中、初中甚至小学的课本"——课内原型迁移就是拿分主干。

### 2.3 官方踩点实锤：一个"当"字一分

2024年卷翻译题（8分）官方踩点示例（v18·R-语.文言-01照录）：

- "当"＝**主持/率领**（语境义，不是"应当"）
- "乡"＝同"**向**"（通假字，卷面明示踩点）
- "文"＝**文饰**（引申义，按"文章"硬译=踩点归零）

这三个词的共性：**都是课本高频实词，考的都是"句中义"不是"词典第一义"**。对照节3的推断三法——通假代入、引申义链、语境校验，正是拿到这三个分的钥匙。

### 2.4 四步写译文＋五字诀自检

**四步**（v18口径照录）：
1. **圈得分点**：先圈出句中"可疑词"——活用/通假/古今异义/重点实词虚词
2. **单字变双字**：直译字字落实（"当"译"主持"，不译"当"）
3. **句式调序**：判断句加"是"、宾语前置调回、被动补"被"
4. **补全省略成分**：主语宾语该补就补（补了才通顺，通顺才有兜底分）

**五字诀自检**："**留**换删补调"——保留专名 / 替换古义 / 删虚词 / 补省略 / 调语序。

**执行流程**（每周3次×15分钟，v18口径）：圈可疑词→逐词对译写直译→最后顺句子。

### 2.5 防坑与复盘

- **坑一：只找点不顺句**。得分点拿到了但译文不通，"句意分"照样丢——直译与通顺缺一不可。
- **坑二：死译**。逐字硬翻成翻译腔，阅卷读不懂照样降档。
- **坑三：只对答案不复盘**。用答案反查"每个得分点拿到了吗"，漏点写进错题本；漏点词**回填实词卡片盒**（与积累线闭环，见"输入-模仿-输出"）——复盘才是得分环节。

## 经典例题（节2）

**题干**（考位与踩点词系v18册R-语.文言-01原文口径：2024年卷翻译8分官方踩点"当/乡/文"；原句文本未随源件收录，本件只作踩点推演示意，不重构真题题干）：

**解答**（踩点推演框架）：
①圈点：拿到句子先问"这三个分藏在哪个字上"——通假候选（乡）、语境义候选（当）、引申义候选（文）。
②对译：每个踩点词按"单字变双字"落实——"当"落"主持/率领"，"乡"落"向着"，"文"落"文饰"。
③收口：句式调序+补省略，通顺成句。

**思维标注**：本题教学价值在"踩点意识"——同一句话，不知道踩点的人译通顺了拿兜底分，知道踩点的人把"当/乡/文"三个字字落实就多拿3分。对照2.2公式：实词2-3个正是分值大头，而它们**来源于课本**（学术统计口径）——课内原型迁移是拿分主干。

**定级**：基础档·高频主干考法（定级为讲解归纳；2024卷官方踩点系v18·R-语.文言-01照录，真题原句不重构、候回源）。

## 易错卡（节2·四元：症状/错因/维持机制/钉死）

**卡1·通顺幻觉**
- 症状：译文读起来很顺，分数只有兜底分
- 错因：不知道"依点赋分"——句意通顺只是兜底，踩点词漏了就扣
- 维持机制：平时默译没人逐点批改，"顺=对"的错觉反复被强化
- 钉死：译完先自问"这句的实词点/句式点在哪"，再对答案逐点核销

**卡2·词典第一义硬贴**
- 症状："当"译"应当"、"文"译"文章"，踩点归零
- 错因：把背过的常用义直接贴上，跳过"语境校验"（节3·推断三法第三步）
- 维持机制：背卡片时背的就是第一义，考场优先提取
- 钉死：每个重点实词译完回读整句，问"讲得通吗"——不通就换引申义再试

**卡3·死译腔**
- 症状：逐字硬翻，句子没人话，阅卷降档
- 错因：把"直译=字字落实"执行成"逐字硬翻"，忘了第四步"补全省略"
- 维持机制：怕漏点，不敢增删任何一个字
- 钉死：直译之后必须"顺句子"——该补的补、该调的调，五字诀收尾

**卡4·对完答案不复盘**
- 症状：翻译练了几十句，同一类点反复漏
- 错因：只核分数不看"自己漏了哪个点"
- 维持机制：对答案的即时反馈快感替代了复盘
- 钉死：漏点词回填实词卡片盒（与积累线闭环）；每两周把漏点归类（实词/句式/固定结构），高频类型专项补

## 应试打法（节2）

- **考场流程单**（对照2.4四步）：圈得分点→单字变双字→句式调序→补全省略→五字诀自检→通读收口
- **时间口径**：限时6分钟/句（v18·R-语.文言-01口径），对照官方踩点自评——"扣完为止"的刚性题最吃时间纪律
- **课内回滚**（v18方法2口径）：得分点主体是课本实词——课内例句是考场迁移联想的合法依据；实词用"本义→引申"字源法起步（教师讲法口径）
- **复盘动作**：漏点回填卡片盒；每两周归类漏点类型（实词/句式/固定结构），高频类型专项补
- **早读加餐**（v18口径）：朗读自己写的"标准直译"，培养直译语感，抑制意译腔

```
   ├─ 五字诀自检：留 / 换 / 删 / 补 / 调
   │
   ├─ 踩点意识：官方踩点实锤（当=主持·乡=向·文=文饰）——都是课本实词
   │
   └─ 复盘闭环：漏点 → 回填实词卡片盒 → 两周归类 → 专项补
```

# 节3 实词推断与文意把握（题型簇）

## 课时开篇页

**本模块知识点清单**：生词推断是可教的算法（不是玄学语感）·四大推断路径（字形/语境/句式对称/课文迁移）·推断三法校验序（通假先行/引申跟上/语境定案）·双文本读文法（传记四槽位+史评回溯）·推断的失效边界

**学完这模块你能做到**（4条，全部可自查）：
1. 考场上遇到没背过的实词，能按"字形→语境→对称→课文迁移"四条路径给出有依据的猜测，而不是慌
2. 能区分"通假代入/引申义链/语境校验"三步的先后顺序，按序校验
3. 拿到"史传+评论"双文本，能按"传主/官职/事件/评价"四槽位快速建立人物档案
4. 明白推断只有六到七成命中率——关键句必须用注释验证，不全卷裸猜

**难点预警**：
- 推断是概率工具不是定律——形旁推断有反例（假借/通假字不服从），六到七成命中率的工具，用错地方就是灾难。
- 双文本是新常态：2024-2026一卷文言均为"史传+评论"制，只练单文本的学生在"跨材料论据概括"题上会直接断档。

## 速览卡（10秒版）

| 问题 | 答案 |
|---|---|
| 这块是什么 | 文言文的"兜底算法"层：120实词之外的生词靠四条推断路径解出大半；配合双文本读文法，把整篇材料的结构在3分钟内立起来 |

## 正文

### 3.1 推断是什么：给猜测装上依据

先给判断句：**推断不是"蒙"，是"带着证据的猜"——每猜一个词，都要说得出"我为什么这么猜"。**

v18的训练法照录：每周用2-3篇课外短文做"只圈推断依据"练习——遇到生词先写"我猜它的依据是什么"，再看注释。先猜后验，依据才会长在手里。

### 3.2 四大推断路径（v18口径照录）

1. **字形推断**：看偏旁部首猜义符——"贝"旁多与钱财有关（货/贷/贫/贱）；"彳"旁多与行走道路有关（行/循/径）；"氵"与水、"讠"与言说。遇到生词先拆形旁。
2. **语境推断**：前后文的逻辑关系（因果/并列/反对）限定词义方向——先看整句再定词义。
3. **句式对称推断**：对仗句/排比句中对应位置的词性词义常对称——"通五经，贯六艺"，"通"的词义可以参照"贯"。
4. **课文迁移推断**：把生词与已背课文中的同形词比较（与课内回滚线联动）。

### 3.3 推断三法校验序（R-语.文言-02口径照录）

拿到一个可疑词，按序执行：

1. **通假先行**：先判有没有通假（"乡"同"向"）——不识别通假，顺读成"家乡"全句崩
2. **引申跟上**：本义→语境义的引申链（"文"按"文章"硬译=踩点归零的教训，见节2）
3. **语境定案**：代入回读，看句意是否自洽

顺序不能反：通假没排除就谈引申，整条推理建立在这条路径本身是错的基础上。

### 3.4 双文本读文法：四槽位+史评回溯

2024-2026一卷文言均为"史传+评论"双文本制（v18·R-语.文言-03口径）。读法两步：

- **史传建档案**：按"传主 / 官职 / 事件 / 评价"四槽位快速立卡——人物做了什么、职位怎么变、关键事件、作者评价，一目了然。
- **史评回史传**：评论类材料的观点，回史传里找论据支撑——跨材料论据概括题的答案结构就是"史评观点→史传论据回溯"。

【辅助理解】为什么先读史传后读史评？史传是"素材库"，史评是"读后感"——读后感的每个论断都要在素材库里找到出处，这个"对号入座"的动作就是跨材料概括题的答题动作本身。

### 3.5 失效边界：什么时候推断会背叛你

- **形旁有反例**：假借/通假字不服从偏旁规律——推断当概率用，不当定律用。
- **六到七成命中率**（v18口径）：关键句（翻译踩点句）必须用注释/词典验证，禁止全卷裸猜。
- **只学技巧不验真题**=纸上谈兵——每周2-3篇"只圈推断依据"练习是路径长在手里的唯一方式。

## 经典例题（节3）

**题干**（推断演示例，词例系v18册方法4原文口径；自拟语境句为教学示意，已声明）：

> "通五经，贯六艺"——"通"字什么义？（自拟语境句：某传主博学条，示意对称推断的用法学）

**解答**：
①判句式："通五经，贯六艺"是对仗句——对应位置词性词义常对称。
②对称求义："贯"="贯通"，则"通"也取"贯通"义（不是"通过"也不是"通晓一切"的泛义）。
③语境校验：代入回读——"贯通五经、融会六艺"，句意自洽，定案。

**思维标注**：本题是句式对称推断的标准应用——对仗结构给了"参照词"（贯），把生词的词义锁死在同一个语义档位。对照3.3校验序：对称给出候选义，语境校验定案——两步走完才敢落笔。

**定级**：基础档·规则主干考法（定级为讲解归纳；"通五经，贯六艺"词例系v18册方法4原文载明，语境句为教学自拟）。

## 易错卡（节3·四元：症状/错因/维持机制/钉死）

**卡1·形旁迷信**
- 症状：见"氵"就往水里猜，遇到假借字全军覆没
- 错因：把"六到七成命中率"的概率工具当成了定律
- 维持机制：前几次猜对了，正反馈固化成肌肉记忆
- 钉死：形旁只是第一候选，通假排除+语境校验（3.3序）走完才定案

**卡2·通假漏判**
- 症状：把通假字当本字硬解，全句崩
- 错因：校验序错乱——直接谈引申，没先排查通假
- 维持机制：通假是"少数派"，存在感低
- 钉死：可疑词第一动作永远是"通假先行"（R-语.文言-02口径）——顺序不能反

**卡3·史传读得细，史评直接跳**
- 症状：双文本只读史传，做题时才发现第二则材料没读
- 错因：把双文本当单文本读——没意识到评论材料是概括题的答案骨架
- 维持机制：单文本训练的历史惯性
- 钉死：拿到卷面先数材料数——两则就是"史传建档案+史评回史传"双动作（3.4）

**卡4·推断裸奔**
- 症状：全卷靠推断，没有一个词查注释验证
- 错因：把"不会词不慌"错放大成"不用验证"
- 维持机制：推断省时间，验证显得"不自信"
- 钉死：关键句（翻译踩点句）必须验证——v18口径"禁止全卷裸猜"

## 应试打法（节3）

- **考场流程单**：数材料定读法（单/双文本）→史传四槽位建档案→史评观点圈出→逐题回溯作答→生词走四路径推断→踩点句验证
- **时间口径**：生词推断单题不超1分钟——它是效率工具，陷进去就挤占翻译的6分钟
- **课内回滚**（v18方法2口径）：把学过的课文当"实词字典"——生词先问"课文学过吗"；实词积累用"本义→引申"字源法起步（教师讲法口径）
- **复盘动作**：每周2-3篇"只圈推断依据"练习；猜错的词登记"哪条路径骗了我"（形旁？对称？），路径错误率就是你的短板图
