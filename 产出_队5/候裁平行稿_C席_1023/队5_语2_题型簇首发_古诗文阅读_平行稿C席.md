# 节1 古诗鉴赏·炼字题（题型簇）

## 课时开篇页

**本模块知识点清单**：炼字题的考点本质·三步答法（本义→句中义→表达效果）·"空"字范式精讲·动词与形容词的关注优先级·防坑清单

**学完这模块你能做到**（4条，全部可自查）：
1. 见到"某字用得好不好/为什么好/有何效果"这类题，能说出它考的是"字在句中的岗位"，而不是背词典义
2. 能按"本义→句中义→表达效果"三步写出一条完整的炼字答案，每步都有落点
3. 拿到一个写景句，能圈出最该被"炼"的那一两个动词或形容词，并说明理由
4. 能避开"只答字典义、只贴形容词、答成翻译"三个高频丢分动作

**难点预警**：
- 最大的坑是"词典义硬贴"——学生把注释抄上去就完事，丢掉的是"句中义"这一步，而这一步才是给分主体。
- 第二个坑是"形容词空转"——写"生动形象、传神"却不说是怎么生动的，这类答案在阅卷时按踩点对照几乎拿不到分。

## 速览卡（10秒版）

| 问题 | 答案 |
|---|---|
| 这块是什么 | 古诗鉴赏里最"小"的题型：只盯一个字，却要答出它在整句里的作用——炼字题的本质是"字的岗位说明" |
| 为什么存在 | 诗的字数是锁死的，每个字都要"干活"；命题人挑一个字让你解释它干了什么活，就是在考你有没有真读懂这句诗 |
| 怎么考 | 主观简答：给出诗句，问某字的表达效果；答对要踩三层——这个字本来是什么义、在这句里成了什么义、让画面和情感发生了什么变化 |

## 正文

### 1.1 炼字题是什么：一个字的岗位说明

先给判断句：**炼字题问的不是"这个字什么意思"，是"这个字在这句诗里干了什么活"。**

诗的字数是锁死的——五言二十个字、七言二十八个字，没有一个字能闲着。命题人从中挑一个字设问，考的是你能不能看出：这个字被作者选中，是因为它让整句诗"活"了。

判断哪个字最可能被"炼"，看词性就有方向：

- **动词优先**：写景句里，动词让静止的画面动起来。"云破月来花弄影"，一个"弄"字，花和影就有了互动。
- **形容词次之**：形容词决定画面的"质感"——冷还是暖、空还是满。
- **数量词、虚词偶尔入题**："一" "自" "空" "独"这类字，看着不起眼，往往扛着整句的情感底色。

【辅助理解】把诗想成一间屋子，每个字是一个零件。炼字题=让你讲清楚其中一个零件装在哪、干什么用、拆掉它屋子塌在哪。比喻到此为止，下面全是操作。

### 1.2 三步答法：本义→句中义→表达效果

v18册内给的标准三步（册内"默写与古诗文"板块·快问快答第5条原文口径）：

1. **本义**：这个字本来是什么意思（一句带过，不展开）
2. **句中义（语境义）**：它在这句诗里具体指什么、写出了什么状态
3. **表达效果**：这个用法让画面/情感发生了什么变化

三步的分量不是平均的。**本义一笔带过，句中义和表达效果才是给分主体**——这就是"词典义硬贴"丢分的根源：只做了第一步。

### 1.3 范式精讲："空"字的孤寂账

v18册内原例（快问快答第5条）："空"字写出诗人独有天地无人共赏的孤寂。

把这句范例按三步拆开，看清给分点怎么落：

| 步骤 | 落点 | 说明 |
|---|---|---|
| 本义 | 空旷、空荡 | 一句带过 |
| 句中义 | 天地之间仿佛只剩诗人一人 | 从"字的语境角色"入手——"空"把周围的一切都"清空"了 |
| 表达效果 | 独有天地、无人共赏的孤寂感 | 落到情感上收口 |

看清楚这个结构：**"空"字的高明不在它"表示空"，而在它把"周围的人、声、色"全部清场，只留诗人一个**。这就是"句中义"——不是字典义，是这个字在这句诗里干的具体活。

### 1.4 防坑与复盘

三个高频丢分动作，动笔前对照一遍：

- **坑1·只答字典义**：把注释抄上去收工——只完成了三步的第一步，句中义与表达效果两步空白。
- **坑2·形容词空转**：写"生动形象地表现了……"，但"怎么生动"全程没说——阅卷按点给分，空转的形容词不是点。
- **坑3·答成翻译**：把整句诗白话翻译一遍，字的意义分析一句没有——炼字题不是翻译题。

复盘动作：做完一道炼字题，把答案按"本义/句中义/效果"三栏切开，看哪栏是空的——空的那栏就是你丢的分。

## 经典例题（节1）

**题干**（示范句为教学自拟，三步答法与给分结构均出自v18册内快问快答第5条口径，不含编造真题事实；真题考位锚见节2例题）：

> 问：下面写景句中的"闹"字用得好，为什么？
> "枝头春意闹"（教学自拟示意句，化用宋祁"红杏枝头春意闹"的千古名句情境）

**解答**：
- 本义：闹，喧嚷、喧闹。
- 句中义：春天枝头繁花盛放、蜂蝶穿飞，一片喧腾的热闹气象——"闹"字把无声的春景写出了声音。
- 表达效果：化静为动（视觉的繁盛转成听觉的热闹），画面瞬间活了，春意的"浓"和"欢"全从这一个字里透出来。

**思维标注**：第一步审题——问"为什么用得好"，答的不是"好不好"是"好在哪"，落点必须是三步；第二步定词性——"闹"是形容词化的动词，写景句里的活跃字；第三步自查——每步都有落点，"表达效果"一步点到了画面变化（化静为动）和情感方向（欢）两层。

**定级**：基础档·高频主干考法（定级为讲解归纳；炼字三步答法系v18册内载明口径，示范句声明教学自拟）。

## 易错卡（节1·四元：症状/错因/维持机制/钉死）

**卡1·注释搬家**
- 症状：答案只有一句"X是……的意思"，收工
- 错因：把炼字题当成解词题
- 维持机制：解词题做惯了，见到"某字"就启动"查词典"反应
- 钉死：动笔前默念三步口诀——本义、句中义、表达效果，缺一步等于缺一大半分

**卡2·形容词空转**
- 症状：答案里"生动形象、传神入化"连用，却不说是怎么生动的
- 错因：把背熟的"万能评价词"当答案主体
- 维持机制：万能词哪道题都能写，写上去就有"答满了"的安全错觉
- 钉死：每个评价词后面必须跟一个"怎么个X法"的具体说明，说不出来就删掉

**卡3·炼字变翻译**
- 症状：整句白话翻译写满答题区，字的分析一句没有
- 错因：分不清"读懂诗"和"答炼字题"是两件事
- 维持机制：翻译让答案显得"满满当当"，产量错觉顶替了踩点意识
- 钉死：翻译最多一句话用来铺垫句中义，主体永远是"这个字"的三步

**卡4·情感脱钩**
- 症状：画面分析头头是道，最后一句情感收口没有或贴错
- 错因：把炼字答成了纯画面题
- 维持机制：画面好分析、情感要推断，惯性选好走的路
- 钉死：答案最后一步必须落到情感（或景物背后的心境），v18原例"空"字的收口就是"孤寂"二字——没有这一步，三步塌掉三分之一

## 应试打法（节1）

- **考场流程单**（对照1.2三步）：圈出题干问的字→判词性（动词/形容词优先关注）→三步连写（本义一句、句中义两三句、效果两三句）→最后检查情感收口在不在
- **时间口径**：炼字是古诗板块的小题，答案篇幅四行上下即可，不给单题超时——省下的时间给手法与情感题（见节2）
- **动笔纪律**：先写"本义"垫一句，立刻转"句中义"——本义超过一行就说明在凑字数
- **复盘动作**：错题按"哪一步丢的"归因（本义丢=没看题；句中义丢=没读懂句；效果丢=不会收口），归到"句中义"的最多——回1.3把范式重推一遍

# 节2 古诗鉴赏·手法辨识与情感定位

## 课时开篇页

**本模块知识点清单**：手法辨识的正确姿势（找投射、不报菜名）·物象投射法（石砚之"坚"→友人之"心"）·"困境—突围"读诗主线·情感基调定位·课内篇目三层复用·与意象模块的拼图关系

**学完这模块你能做到**（4条，全部可自查）：
1. 拿到一首没读过的诗，能先定情感基调，再去找承载它的物象与手法——顺序不乱
2. 能解释"手法题答的是投射"：说出某个物象（如石砚之"坚"）指向了什么样的情感或人格
3. 能用"困境—突围"这条主线快速给一首诗定位：诗人此刻卡在哪，往哪突围
4. 能把课内背过的篇目（默写层）当鉴赏素材库（鉴赏层）和作文论据库（作文层）三层复用

**难点预警**：
- 手法题最大的坑是"报菜名"——比喻、拟人、对偶罗列一串，一个都不分析。命题人要的不是你认得多少手法，是你看懂"这个手法把什么投射成了什么"。
- 情感定位最容易"贴标签"——写"思乡""壮志难酬"四个字完事，没有任何文本证据。标签必须挂在具体的句子和物象上。

## 速览卡（10秒版）

| 问题 | 答案 |
|---|---|
| 这块是什么 | 古诗鉴赏的"大头"：识别诗人用了什么手法、往哪里投射了什么情感——手法是路，情感是终点 |
| 为什么存在 | 诗不直说情感，全靠物象和手法"绕着说"；不懂投射机制，读到的是一堆景物，读不到那个人的心事 |
| 怎么考 | 主观简答为主：问某联用了什么手法、抒发了什么情感；采分点=手法名+文本对应+指向的情感，三者缺一不可 |

## 正文

### 2.1 手法辨识：考的是"投射"，不是"报菜名"

先给判断句：**手法题的答案不在手法名上，在"手法把什么变成了什么"上。**

比喻、拟人、对比、虚实……这些名词你都得认得，但认得只是入场券。命题人问"用了什么手法、有何效果"，他等的是你指出：

- 诗人拿什么**投射**了什么（物象→情感/人格/事理）
- 这个投射让表达**多出了什么**（直说给不出的那一层）

【辅助理解】手法名像菜名，投射才是菜本身。报一串菜名等于没吃饭。比喻到此为止。

v18册内古诗鉴赏方法卡（R-语.现代-03）给的动作顺序是：**意象/典故解码→情感基调定位→手法辨识**——注意，手法辨识排在第三步，前面还有两步。这个顺序本身就是答案：先懂诗说什么，再谈怎么说的。

### 2.2 物象投射法：石砚之"坚"→友人之"心"

v18册内载明的真题锚（2025·王安石《元珍以诗送绿石砚》，卷别篇名照录、考法照录）：

> 石砚之"坚"→友人之"心"的物象投射。

拆开看这个投射怎么运作：

- 石砚是**物象**——它有一个物理属性："坚"（硬、不磨灭）
- 友人之心是**投射终点**——坚贞、不变的心意
- 诗人送一方石砚，实际送的是"我们的情谊像这方砚一样坚"——物象的属性和情感的属性在"坚"这个字上重合，投射就成立了

**这就是意象解码的核心机制：找到物象的属性，再把属性翻译成人情。** 上一模块（语文模块2）的"意象四步法"练的是"见意象调情感包"，本模块往前多走一步：当意象的情感不直接对应时，用"属性投射"去解码——砚之坚、松之直、水之柔，物性即人性。

### 2.3 "困境—突围"读诗主线

v18册内教师讲法八条的第三条（册内口径照录）：八首诗词按"人生困境与超越"一条线串讲——曹操之困→李清照家破之困，意象手法在"困境—突围"里自然带出，避免清单化背诵。

把这条讲法转成考场动作，就是**读诗先问两个问题**：

1. **诗人此刻卡在哪？**（困境：仕途受挫/家国离乱/羁旅漂泊/年华老去……）
2. **他往哪突围？**（超越：借酒/借景/借梦/借历史人物自我宽解……）

这两个问题一问，整首诗的结构就立起来了：写景段是"困"的背景板，转折段是"突围"的发力点，结尾往往落"超越"的姿态。手法和情感不再是散落的考点，而是这条线上拴着的一串珠子——**曹操的困境里"月明星稀"是求贤不得的焦灼，李清照的家破之困里"物是人非"是无可安放的漂泊**——同一个"月"字，困境不同，投射完全不同。

**到此记住**：先问卡在哪，再问往哪突围；意象手法别死背清单，沿这条线把它们一个个认出来。

### 2.4 情感基调定位：先定调，再抠细节

R-语.现代-03的第二步是"情感基调定位"——它排在手法辨识之前，顺序有讲究：

- **先定基调**：通读全诗，先回答"这首诗整体是暖的还是冷的、扬的还是抑的"——不必精确，先定大方向
- **再抠细节**：基调定了，再去逐联找承载它的物象、手法、字眼

为什么顺序不能反？因为**同一批物象在不同基调下读出来完全不同**：同是写"空山"，快意的诗里是清净自在，失意的诗里是空无一人。先入细节再定情感，等于没拿地图就下山——走两步就迷。

**自查动作**：答完情感题，回头看你引的每条文本证据——它能不能反过来支撑你定的基调？能，答案立得住；不能，基调大概率定错了。

### 2.5 课内是原料库：三层复用与"自我辩难"样本

v18册内跨方向联动条（册内口径照录）：默写怎么反哺古诗鉴赏和作文？同一批篇目三层复用——

- **默写层**：原文级零错（这是语文模块"默写"线的任务）
- **鉴赏层**：意象/手法/情感直接迁移——背熟《赤壁赋》的"水月之辨"，古诗里的"水月"意象秒懂
- **作文层**：名句作论据+结构模板（《劝学》的"设喻—类比—结论"论证链就是议论文段落范本）

同一层课文在三个考场反复起效——学一遍，处处能用。

鉴赏层再给一个"情感结构"样本（教师讲法七照录）：《赤壁赋》主客问答="主=苏子，客=苏子的另一面"，情感三变是"自我辩难"结构。

这个样本的价值在于：**它示范了"情感可以有层次、有转折"**。古诗同理——情感定位不等于一句话定死，全诗情感常有三变（由悲转喜、由喜转悲、由抑转扬），定位时问一句"情感变了几次、转折点在哪一联"，答案立刻立体。

### 2.6 与上一模块的拼图：诗歌鉴赏三件套

到此为止，诗歌鉴赏的三个模块已经拼齐：

| 模块 | 管什么 | 核心动作 |
|---|---|---|
| 语文模块2·诗歌意象 | 内容层：诗里有什么 | 高频意象调情感包→意象四步法→新形态应对 |
| 本模块节1·炼字 | 语言层：字怎么干活 | 本义→句中义→表达效果 |
| 本模块节2·手法与情感 | 表达层：怎么说的、说的什么心 | 先定基调→物象投射→"困境—突围"主线 |

做题时三件套是叠着用的：意象给你"诗里有什么"，炼字给你"哪个字最关键"，手法与情感给你"怎么组织成答案"。残缺文本、古今对读这些新形态的应对，模块2已载，不重复。

## 经典例题（节2）

**题干**（真题考位锚照录：v18册内方法卡R-语.现代-03载明2025年卷王安石《元珍以诗送绿石砚》，考法=意象/典故解码+物象投射分析；原诗题干文本未随源件收录，不重构，考位与考法照录——宁缺毋编）：

> 考位锚：2025年卷·王安石《元珍以诗送绿石砚》——考"石砚之'坚'→友人之'心'的物象投射"。

**解答框架**（按2.2物象投射法组织）：
- 第一步·找物象与属性：绿石砚——"坚"（坚硬、经久不磨）
- 第二步·找投射终点：友人——"心"（情谊坚贞、心意不因岁月磨损）
- 第三步·说清投射的"巧"：以物性写人情，赠物即赠言——砚之坚与心之坚在同一个字上重合，既是咏物又是寄情
- 收口·点出命题人要的那层：答手法不只说"托物言情"四个字，要把"物性→人性"的对应关系说透

**思维标注**：第一步按2.4先定基调——赠友诗，暖调；第二步按2.3问"困与突围"——此诗无困，属"情谊的确认"型，投射直接；第三步按2.2三步组织答案，每个采分点（物象属性/投射终点/对应关系）都有落点。

**定级**：进阶档·物象投射型（定级为讲解归纳；真题仅载考位锚与考法，题目文本候回源后补全，本件不重构——v18册内口径）。

## 易错卡（节2·四元：症状/错因/维持机制/钉死）

**卡1·手法报菜名**
- 症状：比喻、拟人、夸张、对偶罗列四五个，一个都不展开
- 错因：把手法的"识别"当成手法的"作答"
- 维持机制：名词背得熟，写起来快，产量错觉顶替踩点意识
- 钉死：每个手法名后必须跟"把什么投射成什么"，说不出投射的手法名删掉

**卡2·情感裸标签**
- 症状："表达了诗人思乡之情"一句话收工，无文本证据
- 错因：把情感定位当成填空题
- 维持机制：情感词背过就写，写上就心安
- 钉死：每个情感词必须挂一个具体证据（哪联哪个意象哪个字），挂不上的标签不算数

**卡3·基调定错全盘歪**
- 症状：把快意诗读成失意诗，全文答案跟着歪
- 错因：跳过"先定调"直接抠细节，被个别字眼带偏
- 维持机制：细节永远比基调"显眼"，先抠细节省力气
- 钉死：通读一遍先答"暖/冷、扬/抑"，再动笔；答案与基调对不上的细节，先怀疑是自己读偏

**卡4·情感一刀切**
- 症状：全诗情感答成一个词，转折点视而不见
- 错因：不知道"情感有层次"是常态（对照2.5"自我辩难"样本）
- 维持机制：一个词的答案好写，层次分析费脑子
- 钉死：定位情感先问"变了几次、转折在哪一联"——有转折的诗，答案必须分段落点

## 应试打法（节2）

- **考场流程单**（对照2.1-2.4动作序）：通读定基调（暖/冷、扬/抑）→问"困境—突围"定位主线→按题干圈定作答区间→找物象与手法→按"手法名+文本对应+情感指向"三点连写→自查每点有证据
- **时间口径**：手法与情感题是古诗板块的主观题大头，答案篇幅六行上下——比炼字题多，时间相应倾斜；先把基调判断做对，避免返工
- **衔接纪律**：意象题调用模块2的情感包（月=思乡、雁=音信/乡愁、柳=惜别、梧桐=凄凉、菊=隐逸），但**调包之后必须结合语境微调**（模块2口径）——情感定位的最终裁判是本诗的基调与主线
- **复盘动作**：错题按"基调错/投射错/证据缺"三栏归因；基调错的回2.4重做通读定调，投射错的回2.2重推"物性→人性"翻译

## 本节串联图（节2·文字版）

```
拿到一首诗
   │
   ├─ ①通读定基调（暖/冷、扬/抑）——先拿地图
   │
   ├─ ②"困境—突围"定位主线（卡在哪？往哪突围？）
   │
   ├─ ③按题干作答
   │     ├─ 手法题 → 手法名 + 把什么投射成什么（物性→人性）
   │     ├─ 情感题 → 情感词 + 文本证据（挂哪联哪个意象）
   │     └─ 问"变了几次" → 有转折必须分段落点
   │
   └─ 三件套叠用：意象（模块2）×炼字（节1）×手法情感（节2）
          │
          └→ 课内三层复用：默写层零错 → 鉴赏层迁移 → 作文层论据
```

## 输入-模仿-输出（技能观落点）

- **输入**：课内必背篇目按默写线推进时，顺手做"鉴赏层预演"——背《赤壁赋》当天，把"水月之辨"的情感转折口述一遍（三层复用的第一层联动）
- **模仿**：每周精读一首课外古诗，按"基调→主线→投射"三步写五行笔记；素材用v18册内载明的真题锚（2025《元珍以诗送绿石砚》型）对表校准
- **输出**：炼字与手法情感各限一道小题（四行/六行篇幅），对照本模块两套"考场流程单"逐项自查；错题归因进"哪一步丢的"三栏账
