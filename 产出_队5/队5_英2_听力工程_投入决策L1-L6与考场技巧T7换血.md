**学完这块你能做到**（5条，全部可自查）：
1. 能说出你省听力分算不算进高考总分，并知道高三报考当年要去哪里复核最新口径
2. 面对"要不要练听力"的问题，能用三选项对照表按自己的词汇量给出档位判断，而不是凭感觉
3. 今天就能把L4三步嵌进晨/午/睡三个既有时段，一周后能展示一页做满标记的课文文本
4. 词汇过500后，能独立完成一次60分钟周末听写四步，并按"生词/熟词/语音现象"给错误归因
5. 月考听力开考前，能按五动作排出15分钟操作序列：抢读划差异词→首两题稳拿→转折处竖耳→数字题预判抢答→完全听不懂时按三保留蒙

**难点预警**（3条，说话式）：
- 这块反直觉的地方在于：听力提分的第一动作是**背词不是练耳**。词汇≈0时砸时间练听力，等于给没有油的发动机踩油门——每分钟投词汇换来的分约是投听力的3-5倍
- L4是"假精听"（没有声音端），它只负责预备，**不能替代**周末L5真听写——只做L4不做L5，"看得懂"永远变不成"听得懂"
- 蒙题规律（如"女士保留原则"）只许当最后一步的排除参考：命题越来越语境化，纯蒙的收益在下降，读题预测才是主体

**前置依赖**：需要先确认你省的听力计分口径（第0步，2分钟）——它决定你走主线还是走"零投入合法"分支。与词汇模块（英1）是燃料与引擎关系：L5启动线＝词汇>500、L1升级评估＝3500词，本块不替代背词。全程不需要额外设备：周中只有纸笔，周末需要一次能放音频的设备日（教材录音即可起步）。

## 正文：先决策，再执行，最后上考场（表达换血版）

### 第0步 先查省份：30分在不在总分里

**计分口径是什么（人话版）**：你这省高考的听力分，算不算进英语总分。这一步只要2分钟，但它决定后面所有决策的合法性——不计分省练听力投入，是把劲使在不算分的地方。

| 省型 | 听力计分口径 | 来源 |
|---|---|---|
| 河南 | 2025/2026年暂不计入（笔试120×1.25折算150）；**2027年起计入外语总分** | 省教育厅原文·官方一手源 |
| 广东 | 听说考试卷面60÷3＝20分计入英语150总分（笔试120×13/12＝130折算） | 省教育考试院·官方 |
| 云南 | 听力30分计入；口语不计入仅供录取参考（2025年起只考1次） | 省教育厅通知PDF·官方 |
| 贵州 | 一年两考（1月＋6月），取最高一次计入30分 | 多站转载交叉 |
| 新疆型 | 听力必考但不计入总分（非听力120×1.25＝150折算） | 阳光高考平台·官方 |

**默认情形**：2029届主流省份（含河南）听力计入总分——本模块全部决策按"30分算在总分里"构建；新疆型不计分省自动切换到L系列的"零投入合法"分支。

**复核条款**：政策有时变变量，高三报考当年必须以本省考试院最新文件复核一次。河南就是活例子——同一个省，2025/2026不计、2027计入，口径会变。

> 出处｜v18原册·3.2听力计分省际对照（政策事实层·官方一手源）

◎到此记住｜第一层：先花2分钟查省口径，再决定投不投。第二遍回来看：口径会变（河南2027并轨），高三复核一次。

### L1 三选项决策对照：该投多少

**核心命题（判断句）**：听力得分＝词汇量×耳朵熟练度×技巧系数。词汇量≈0时，前两项都≈0——此时砸时间练听力，越投越不划算。这不是努力问题，是劲往哪使的问题。

| 选项 | 做法 | 判定 |
|---|---|---|
| A 全投入 | 每天30分钟精听/泛听 | **当前否决**：词汇<1000时，听不懂的根源是词不是耳；同样30分钟投给词汇，换来的阅读＋完形分更多 |
| B 半投入（推荐主线） | 零设备零新时段：周中纸面伪精听（L4）＋周末60分钟真听写（L5） | **当前阶段标准解**；词汇过1500后升级评估 |
| C 裸考 | 零准备上场，蒙题四原则锁底（L6） | 仅应急兜底：预估8-12分，主动放弃约18-22分 |

**决策规则（随词汇量换挡）**：

| 词汇量 | 档位 |
|---|---|
| <1000 | B（轻） |
| 1000–1500 | B（标准） |
| >1500 且阅读正确率>50% | 按剩余跑道评估升级A |
| 查实省份不计分（新疆型） | 任何阶段选C都合法 |

**对照表结论**：零基础期，每分钟投给词汇，换来的分≈投给听力的**3-5倍**（37.5分的阅读 vs 词汇≈0的听力）。

> 出处｜v18原册·07章L1（三选项全项＋动态规则）

◎到此记住｜第一层：选B半投入，L4＋L5两台执行器。第二遍回来看：档位随词汇量换，规则表四行；A不是永远否决，>1500词后重新评估。

### L2 词汇先行：为什么不先练听力

**v18双源锚原话**："对于第二外语，你最多只能听懂你读得懂的东西——精听是锻炼方法，阅读（词汇量、语法基础）才是根本。"（实践wiki）＋"全国卷听力无生僻单词、简单句为主"（近五年真题试题分析）。两个独立来源指向同一结论，交叉可信。

**执行口径（判断句）**：听力是词汇计划的下游产出——词汇每过500词，做一次**裸听自测**（人话版：放一段录音，只记录听懂的比例，不训练、不纠错，像体检不治疗）。

- 自测≥50% → 才启动L5真听写；之前维持L4纸面替代
- 自测<50% → 继续背词，听力不加码

**防懒病条款**：词汇达标不等于自动会听。"滞后溢出"不会自动生效——词汇>1500的升级触发点必须执行。音形映射（听得懂的音和认得出的形对上号）这一步只有真听写能完成，"词汇先行"不能变成"永远不练听力"的借口。

> 出处｜v18原册·07章L2（双源交叉＋裸听自测＋防懒病条款）

### L3 考场技巧包：半投入选项的主体

动作细节归T7考场五动作（下一节），这里只说三件事：

1. **独立价值**：技巧系数是唯一能独立于词汇量提升的变量——词汇没达标也要月考/期末上场，约40分钟学习＋零维护，换考场预估＋3-6分。
2. **警示一**："女士保留原则"类蒙题规律有反例，只作最后排除参考。
3. **警示二**：个别技巧来源年代较早，命题越来越语境化，纯蒙题收益在下降——必须与读题预测组合使用。

### L4 纸面伪精听：周中无设备的文本工作法

**伪精听是什么（人话版）**：没有声音端的"假精听"——用课文文本做听写式工作。它练的是听力预备（眼熟句子结构、笔头反应），不是真听。

**三步嵌入法（每日约20分钟，全部嵌进既有三时段，材料就用W2-W13配套课文文本，零新增）**：

| 时段 | 时长 | 动作 |
|---|---|---|
| 晨间 | 8分钟 | 朗读当日课文文本＋听写式抄写关键句 |
| 午休 | 7分钟 | 遮住上半句，凭记忆＋拼读规则复现，红笔改 |
| 睡前 | 5分钟 | 过红笔改正词，标注错误原因三分类：生词／熟词拼错／连读弱读现象（连读弱读＝单词连着念或轻轻带过，用符号标记在文本上，周末设备日验证） |

**定位警示（v18原句级）**：这是"听力预备训练"，不是真精听——没有声音端，音形映射没完成，**周末必须补L5真听写**；选的文本必须带配套音频来源，否则等于普通抄写。

> 出处｜v18原册·07章L4（三步嵌入法＋定位警示；流程源自单源实践社区，已按零基础改写，v18附录披露）

### L5 周末真精听：听写四步（设备日限时版）

**真听写是什么（人话版）**：放音频，一句一句写下来——这是把"看得懂"转成"听得懂"的唯一动作，也是全流程里唯一需要设备的环节。

**每周1次×60分钟，卡表执行**：

| 时长 | 动作 |
|---|---|
| 10分钟 | 盲听记大意（只抓主题，不写词） |
| 25分钟 | 逐句听写，一句最多放5遍 |
| 15分钟 | 对照原文红笔改＋归因三选一：生词→回词表／熟词没认出→做音形卡／语音现象→在文本上标记 |
| 10分钟 | 重听，专听标记处 |

**材料阶梯（N+1原则：材料只比现有水平难一点点）**：教材录音 → 中考听力 → 高考真题；语速阶梯VOA Special<VOA<BBC<CNN，零基础从最慢端起。

**启动条件**：词汇>500后收益才明显——<500时逐句听写这步会全程卡死，退回L4。

> 出处｜v18原册·07章L5（听写四步＋材料阶梯＋启动线；流程源自单源实践社区，周末60分钟封顶）

### L6 裸考保底包：应急兜底，不是路线

**仅两种情形合法**：①查实省份不计分（此时整套听力决策作废，用本包兜底）②突发零准备上场。

**不可当主线**：30分里裸考预估仅8-12分，与半投入路线（预估15-20分）差一倍。

**四条纪律**：①不留空白（防无效卷：不许整卷同一字母）②第一遍只落笔有把握的，第二遍只验证不推翻 ③四原则蒙题（同T7动作⑤）④数字/时间/地点题靠听前预判抢答。30分钟学习，零维护。

> 出处｜v18原册·07章L6（合法边界＋四条纪律）

### T7 听力考场五动作（应试执行层）

**分域声明（判断句）**：本节只管"考场上怎么做"；"要不要长期投入"归L1决策对照。两者拼装使用，互不替代。

| 动作 | 做法 | 依据 |
|---|---|---|
| ①抢读划差异词 | Directions（听力开头的题目说明广播）间隙抢读选项，圈出选项间的差异词，预判对话场景 | 读题预测把"被动接收"变"主动狩猎"——放音前快速圈题干名词＋选项差异词，耳朵只负责确认 |
| ②首两题稳拿 | 语速最慢＋官方两次播放设计＝全卷最容易的3分，开局稳住心态 | 两次播放是官方降低基础失分的设计 |
| ③转折处竖耳 | but／however／unfortunately之后＝答案高发区 | 转折词后是出题人埋答案的位置 |
| ④数字题预判抢答 | 数字/时间/地点题听前预判，听到即答 | 这类题不靠理解靠捕捉 |
| ⑤完全听不懂时 | 相关保留／异项保留／概括抽象保留；不留空白、不整卷同字母、第二遍只验证不推翻 | 三保留＋两不，锁住蒙题下限 |

**分数预估**：纯蒙≈7.5分 → 用技巧12-15分（进取口径8-15）；训练侧成本为零——考前用2套真题各演练10分钟"读题划差异词"即可。

**周中零投入纪律**：寄宿期间不做任何听力专项——"每天睡前听真题音频"类建议违反四约束（零基础/寄宿无设备/碎片时段/纸面执行），属废件；周末可选15分钟跟读文本，是加餐不是必选。

### 避坑三条

1. **政策想当然**：不听"听说河南不计分"的传言，直接查省考试院文件——且口径会变（河南2025/2026不计、2027计入）。高一不对听力做重大投入，是无论政策怎么变都不后悔的决策。
2. **材料难度失控**（听力头号杀手）：执行N+1，听不懂就降级到教材录音，别硬上真题。
3. **单源方法当主线超时**：真听写流程周末60分钟封顶，这是硬止损——单源流程只当参考执行，不加码、不加密、不替代词汇主线。"听力很重要不能放弃"式劝学是无信息量废件，要的是对照表的理性计算。

## 经典例题（方法模块的"例题"＝执行示范题）

> 三道均为流程/决策示范题（依据v18原文场景组装），不含编造的真题听力材料。

### 例1 泛听诊断题（基础）

**【题干】**有同学周中戴耳机"泛听"BBC 30分钟，听完什么也没留下。诊断：这个投入方式错在哪，怎么改？（依据v18·精进模块听力区易错现场）

**【解答】**诊断：泛听是"陪伴式输入"，对零基础考生约等于听白噪音——没有提取，没有记忆，只有挫败感。改法两步：①周中这类时段改成L4纸面伪精听（用课文文本做三步嵌入，见L4）；②"泛听找语感"是伪需求，"精听抓细节"才是考分来源——真精听放到周末设备日按L5四步执行，一句一听写。

**【思维标注】**①错误根源是"用输入量代替提取"——听力得分来自"写下来对不对"，不是"听了多久"；②改法不是加量而是换动作：同样30分钟，L4三步有红笔改错有归因，泛听只有挫败感；③寄宿无设备约束下，周中本来就不该有"戴耳机"这个动作。

**【定级】**基础题（启动级——不清醒认识这一条，后面所有投入都会变形）。

**【同类一题自测】**"每天睡前听真题音频培养语感"行不行？（答：不行——违反四约束，属废件建议；周中零投入纪律见T7。）

### 例2 河南决策题（进阶）

**【题干】**你是2029届河南考生，听同学说"河南听力不计分"。现在是高一上，词汇量约300。问：听力要不要投入？投什么？

**【解答】**第一步查口径：河南2025/2026暂不计，但**2027年起计入**——你高考那年恰好计入，"不计分"是过期信息。第二步定档：词汇300<500 → 半投入·轻档（速查表第1行）。第三步定动作：周中L4嵌三时段＋周末暂不练真听写（词汇不够，<500启动线）＋现在就把T7五动作学掉（40分钟，月考直接用）。结论：技巧包照学，纯听音训练等词汇过500再加码。

**【思维标注】**①政策判断必须落到"你高考那年"的口径，不是"今年"的口径——河南2027并轨是本例的全部关键；②"技巧包照学"的依据：技巧系数是唯一独立于词汇量的变量，且技巧同时是阅读和完形的技能；③整个决策没有一处靠感觉，全部落在速查表和开关总表的具体行上。

**【定级】**进阶题（需要跨第0步/速查表/开关总表三处联动）。

**【同类一题自测】**同一问题换成新疆考生，答案变哪两条？（答：①口径=必考但不计入总分→整套L1-L5关闭，选C合法；②动作只剩L6裸考包四条纪律，30分钟学习零维护。）

### 例3 考场流程演示题（流程演示·非真题）

**【题干】**月考听力开考，从发卷到第一节放音结束，排出你的15分钟操作序列。（依据v18·T7五动作组装）

**【解答】**①发卷后：抢读前几题选项，圈差异词（疑问词what/when/where/who/how much优先），预判场景——Directions广播的间隙都在做这件事；②第一节前两题：语速最慢＋两次播放，目标全拿（全卷最容易的3分）；③放音中：转折词（but/however/unfortunately）出现立刻竖耳；数字/时间/地点题听到即落笔；④第一遍：只落笔有把握的；第二遍：只验证不推翻；⑤某题完全没听懂：三保留（相关/异项/概括抽象）选一个，立刻放手跟下一题——不留空白、不整卷同字母。

**【思维标注】**①这是考场执行序列不是知识题——考的是"动作有没有顺序"，五动作各就各位；②"第二遍只验证不推翻"最容易违反：第一遍的手感往往比第二遍的犹豫值钱；③蒙题动作只出现在第⑤步，且是三保留不是瞎猜——与L6四条纪律同源。

**【定级】**基础题（零训练成本，考前2套真题各演练10分钟即可形成动作记忆）。

**【同类一题自测】**第二遍播放时想推翻第一遍的答案，规则是什么？（答：只验证不推翻——除非第二遍明确听到了与第一遍判断矛盾的信息。）

## 应试打法（这块怎么变成分数）

### 30分的兜底拆法

先钉结论：听力/30，保守口径预估8-10分、进取口径预估8-15分——兑现手段就两件：T7技巧底线（考场层）＋L1投入决策（执行层）。两件拼装：T7负责"上场怎么拿"，L1负责"平时练多少"。整条听力线的时间开销极小：T7约40分钟一次性学习＋考前2套真题演练；L4每天约20分钟寄生在既有三时段；L5每周30-60分钟周末设备日——合计是所有大项里最轻的。

### 水位路由（自测→动作）

听力错 → L4纸面伪精听 → 词汇>500升L5（v18异形思维卡路由原口径）。月考后按此路由检查自己的档位，别跳档。

### 分数预期的诚实口径

纯蒙≈7.5分；T7技巧12-15分；半投入路线预估15-20分；全投入升级后才有冲击18-22分的资格。60分总目标下，听力按"低配可达"档取分即可——它的30分不必吃满，阅读＋完形＋词汇主线的性价比永远更高。

> 出处｜v18原册·3.3拆分表＋T7分数预估＋L6合法边界＋执行摘要结论①
