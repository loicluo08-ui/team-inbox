# 任务标准库 S1-S7（10/23 18:3x建——派发机制重构第一件）

> 用法：任务卡纪律段只写"参照S3"一行，不重复全文。标准修订走版本号（S1.1=v1.1），旧版作废留痕。

## S1 交付纪律
正件净化（git注记/自检对账/换血对照/返修史/待核区/制作层词一律不进正件，留工作单）｜工作单分离交付｜开篇页第一速览卡第二｜零序号标题｜LaTeX禁用（Unicode形态：₂³⁺→）｜金融语域零容忍（黑名单机检+豁免须注记）

## S2 思维标注四要素（15:19定版标准）
触发点（题干信号→联想链）｜岔路排除（死路+死因）｜卡壳预判（断点+原因）｜外行连接（一句话）
生产用清单（工作单可验收）→入册融合叙事流。缺岔路排除或卡壳预判=退回。保底级例题减配两要素（触发点+卡壳预判）。参照：任务卡_思维标注四要素规格v1.2双改造样例。

## S3 深读区边界条款
主线因果（教学顺序必需的"先为什么后是什么"骨架）留主线｜附加深究（升维/深度追问/边界讨论）进深读区（应试后串联前，标"不读不影响"）｜判定权生产席，工作单标注分类｜存量件不硬抽

## S4 费曼题验收四线
1.系统整合度：一题覆盖本节≥2知识点（与自测单点分工）2.三步引导链齐：结论→为什么→例子 3.照妖镜典型错误：须易错卡可溯或经验可溯，禁编造 4.简化边界标注：参考讲法必带"省了什么/完整版在哪"。六科实例库见任务卡v1.2表。

## S5 装配八块checklist
1.开篇页第一 2.速览卡第二 3.主线零序号 4.例题"怎么想到的"叙事流 5.易错卡 6.应试打法 7.深读区（应试后串联前）8.费曼检验段——外加：锚点目录/荧光判据句/SVG导图/零过程内容。逐块对照黄金样本_装配_第1章实切包_1023.html。

## S6 git通道SOP
claim_队N登记→产出_队N/交付→push；撞车pull --rebase再推循环勿弃；push被拒=rebase循环；夜间照常push验收晨检集中跑；commit署名=队号；禁碰claim_board与他人claim；禁force push

## S7 claim格式标准
四类行格式：`- 认领 | MM-DD HH:MM | 任务名`／`- 交付 | MM-DD HH:MM | 文件名（一句话要点）`／`- 整改 | MM-DD HH:MM | 退回原因+修复动作`／`- 裁定 | MM-DD HH:MM | 裁定内容+留痕`。一行一事，时间用实际操作时刻。

PASS（全绿）/PASS-W（带伤过，标注伤处）/REJECT（退回，附原因码：R1结构缺/R2净化违/R3语域违/R4锚点缺/R5序号残留/R6深读区位置/R7四要素缺/R8事实错）——首件回流30分钟内出码。
