# 任务卡模板 v2（10/23定型——派发机制重构第二件）

> 任务卡只填五字段，纪律/格式/通道一律引标准库编号（S1-S7），不重复全文。模板化后单卡目标≤400字。

```markdown
# 任务卡N｜队X｜P0/P1/P2

**内容**：做什么（对象文件/章节/改造点，一段话说清）
**验收线**：怎么算过（引用S编号+本任务特有判定2-3条）
**参照标准**：S1/S2/S3…（编号列举）
**交付**：产出_队X/文件名+工作单，claim登记
**死线/批次**：首件即交校准/全量死线（无则不填）
```

## 示范样例（真实任务改写）

```markdown
# 任务卡041｜队4｜P0
内容：物理2.2匀变速直线运动的速度与时间重制，四要素叙事流入册，对位表簇04拆分2.2/2.3零丢失
验收线：S2四要素齐；金融语域机检零命中；例题v18照录零自编
参照：S1、S2、S6、S7
交付：产出_队4/物理-2.2.md+工作单_2.2重制台账，claim登记
批次：首件即推即验（30分钟内我侧出验收码）
```

## 版本纪律（治版本混乱）
- 任务包单文件增量更新：修订只改对应任务卡条目+顶部版本号+变更行，**禁止重写全文换版**
- 版本号规则：内容变更+0.1（v2.0→v2.1），结构性重排才+1.0
- 逸翔侧只看最新版，队伍pull即得——**不再生成"合并版/干净版"副本**（10/23五版混乱根治）
