# 编排层：任务依赖图与自动解锁（v2扩展件1/5，10/23）

> 总锚对账：装配放量是死线最紧的一环，编排层让"过验即解锁"替代"人肉串行派发"，吞吐提速不加人。

## 六科单章标准流水链（每一环过验自动解锁下一环）

```
对位表(自动通过制,候裁定) → 正件重制/升级(P0) → 抽验(30min SLA) → 费曼段四要素(P0) → 装配八块(P1) → 终验+入册(P1)
```

## 自动解锁规则

| 触发 | 自动动作 |
|---|---|
| 正件验收码=PASS | 同队同章后续任务卡状态置"解锁"，claim里直接开工，**不需新触发指令** |
| 正件=PASS-W | 解锁但伤处列进下一环工作单必修项 |
| 正件=REJECT | 下游全部冻结，整改完重验才解锁 |
| 首件PASS | 同队同批同类任务全量放行（首件检验制放量规则） |
| 装配件PASS | 该章进"终验队列"，我侧终验后标"入册" |

## 解锁的登记方式
