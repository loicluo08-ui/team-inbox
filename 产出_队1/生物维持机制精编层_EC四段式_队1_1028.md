## 二｜路由层（结构卡·R-B.M）

### 【路由层】本层骨架一句话

**生物错题七成不输在"不知道"，输在"知道但想歪"——每个惯性错误背后都有一个自维持的认知回路，钉死它要靠四段式：见到现象、拆穿错因、点破回路、给出口诀与反例。**

### 【结构视图】错误三族框架

```
概念置换族：两个近邻概念互换（虎克↔列文虎克·染色质↔染色体·凋亡↔坏死·着丝点↔着丝粒）
   ↑ 病根：标签先于定义——记住了名字没锚住判据
过程错序族：把"分布/阶段/去向"装错位置（O₂只在第三阶段·肽链合成在核糖体·暗反应光下照跑）
   ↑ 病根：流程想象替代流程实证——课本流程图没过第二遍
边界越位族：把一般结论推到特例翻车（所有细胞都有核·核酸=DNA·分化程度越高全能性越高）
   ↑ 病根：全称量词漏特例——"主要/一般/成熟"三个限定词没看见
```

## 三｜素材层：EC四段式精编条目（S-B.M·59条）

> 段1照录v18册mis现态；段2/段3为册内派生分析；段4口诀+反例（真题实锚处挂锚·缺位处如实标注"反例候补"）。

### ①章

**S-B.M-①-01｜虎克看到了活细胞**
- 段1 现象：✗ 虎克看到了活细胞——✓ 虎克看到的是死细胞的细胞壁（软木）；看到活细胞的是列文虎克——两人常被互换，这是学说史第一大陷阱。【v18册①章mis现态】
- 段2 错因结构：两人绑定同一"显微镜+细胞"标签输入，差别（死壁/活体·命名/观察）未随名字入账；教材两处相隔数页，先入为主的"第一个看细胞的人"占位。
- 段3 维持机制：名字相似度（都是显微镜观察者）制造提取干扰，一次混淆未被纠正即固化；排序题两人又总同框出现，反复同框强化"绑定错误"而非区分。
- 段4 处置：口诀"虎克钉壁列文活"。反例候补（学说史排序题见科学史裁定区母表双轨定年）。

### ②章

**S-B.M-②-01｜蓝细菌有叶绿素藻蓝素所以有叶绿体**
- 段1 现象：✗ 蓝细菌含叶绿素和藻蓝素，所以有叶绿体——✓ 前半句对，结论错：蓝细菌是原核，只有核糖体一种细胞器；光合能力由光合膜结构上的色素与酶承担——"有功能没厂房"。【v18册②章mis现态】
- 段2 错因结构："功能⇒厂房"的默认推理——真核世界功能总在细胞器里，把经验规则当成了普适定律；原核/真核判据（核膜包被）没有前置检查。
- 段3 维持机制：先判"功能"再判"结构"的顺序恰好颠倒；且"叶绿素"与"叶绿体"字面强相似，词面联想绕过了原核判据这道闸。
- 段4 处置：口诀"原核只一种：核糖体；功能不 presuppose 厂房"。反例候补。

### ③章

**S-B.M-③-01｜鲜重里C元素最多**
- 段1 现象：✗ 鲜重里 C 元素最多——✓ 鲜重里是 O（水占85%-90%）；干重里才是 C。"质量分数最多"与"原子个数最多"也是两套口径——鲜重中原子个数最多的是 H。【v18册③章mis现态】
- 段2 错因结构：C是"生命核心元素"的定性印象顶替了定量口径；鲜/干两态与质量/个数两轴共四个格子，记忆时压扁成了一格。
- 段3 维持机制：四格混淆在单选题里常只考一格，其余三格不被检查，错一格订正一格永远拼不回四格全景；"C最重要"的修辞反复出现持续供血。
- 段4 处置：口诀"鲜O干C，个数H最多，题干问哪套答哪套"。反例候补。

### ④章

**S-B.M-④-01｜晒干种子把种子晒死了**
- 段1 现象：✗ 晒干种子的过程把种子杀死了——✓ 晒干失的是自由水，种子休眠但存活，浸水可复活；烘干/炒熟才夺结合水，不可逆失活。【v18册④章mis现态】
- 段2 错因结构："失水=死"用了日常直觉（人脱水会死）替代生物定义（自由水/结合水比例决定代谢与抗性）。
- 段3 维持机制：日常经验在生活化题干（晒粮食）里反复"验证"错误直觉，负反馈缺席；自由水/结合水只记名词未记行为差异。
- 段4 处置：口诀"晒干休眠可复活，炒熟夺合不可逆"。反例候补。

### ⑤章

**S-B.M-⑤-01｜淀粉糖原纤维素单体不同**
- 段1 现象：✗ 淀粉、糖原、纤维素的单体不同——✓ 三者基本单位（水解终产物）都是葡萄糖；差别在数目与连接方式。【v18册⑤章mis现态】
- 段2 错因结构：把"功能不同"倒推成"零件不同"；蛋白质21种氨基酸的多样性样板被错误迁移。
- 段3 维持机制：功能差异（储能/储能/结构）显眼易记，连接方式差异（α/β糖苷键）抽象难记，记忆权重倒挂；同构逻辑（零件相同装配不同）未迁移成功。
- 段4 处置：口诀"多糖一种单：葡萄糖；变的是接法不是件"。反例候补。

### ⑥章（2条）

**S-B.M-⑥-01｜一种蛋白质必然含全部21种氨基酸**
- 段1 现象：✗ 一种蛋白质必然含有全部21种氨基酸——✓ 不一定——一种蛋白质可以只含其中几种；21种是"全体蛋白质的字母表"，不是每种蛋白质都用满。【v18册⑥章mis现态】
- 段2 错因结构："字母表共21个字母"被读成"每个单词用全21个字母"；全体/个体的量词错误。
- 段3 维持机制：教材先讲"21种氨基酸"再讲多样蛋白质，阅读顺序造成"21种=标配"暗示；全称判断题里"必然"类词的敏感性训练不足。
- 段4 处置：口诀"字母表21，单词随便挑几个"。反例候补。

**S-B.M-⑥-02｜折叠无条件（🚧边界型·原卡即提醒条）**
- 段1 现象：🚧 折叠有前提——自动折叠依赖合适的pH、温度、离子环境——体外让蛋白复性成功率有限，"序列决定一切"是简化说法，环境是隐藏变量。【v18册⑥章mis现态·🚧边界提醒条】
- 段2 错因结构：中心法则叙事链"序列→结构→功能"被读成单因素决定链，环境条件在链条里隐形。
- 段3 维持机制：考试主线考序列决定论，环境变量只在变性/复性情境出现，非主线情境记忆衰减快。
- 段4 处置：口诀"序列定折叠，环境给许可"。反例候补。（🚧型条目处置：册内原卡即边界提醒而非错误判断，四段式照实精编为"边界认知"条，不虚构错误现象，宁缺毋编。）

### ⑦章

**S-B.M-⑦-01｜核酸=DNA**
- 段1 现象：✗ 核酸=DNA——✓ 核酸=DNA+RNA两大类；"核酸只存在于细胞核"连名字误会带分布误会一起错。【v18册⑦章mis现态】
- 段2 错因结构：词根联想（核酸→核→DNA）双错联动：名字误会（核酸≠核内专属）+分布误会（RNA主要在细胞质）。
- 段3 维持机制：真核细胞DNA确以核内为主，局部事实支撑整体误判（特例：线粒体/叶绿体DNA、原核拟核）；"核"字词根每次提取都在强化错误链。
- 段4 处置：口诀"核酸两家：DNA+RNA；核质都有，别看名字"。反例候补。

### ⑧章（4条）

**S-B.M-⑧-01｜细胞膜是静态完整封闭的墙**
- 段1 现象：❌ "细胞膜是静态完整封闭的墙"——流动性是结构特点，磷脂与大多数蛋白质都能运动，"墙是流动的"。【v18册⑧章mis现态】
- 段2 错因结构：把"边界"读成"静态墙"——功能语义（屏障）覆盖结构语义（流体镶嵌模型）。
- 段3 维持机制："边界/屏障/保护"等词日常语义全是静态的，生物学"流动的边界"反直觉，日常语义每次复述都在回拉；人鼠融合实验只背结论不挂结构解释时，结论与心智模型两张皮。
- 段4 处置：口诀"边界是流体的：磷脂漂、蛋白航（人鼠融合为证）"。反例候补。

**S-B.M-⑧-02｜选择透过性=只让有利的进**
- 段1 现象：❌ "选择透过性=只让对细胞有利的物质进"——控制作用相对，筛网按物理性质工作，病菌病毒有时也能进。【v18册⑧章mis现态】
- 段2 错因结构："选择"被赋予目的论色彩（细胞挑好的），实际是物理化学性质（脂溶性/大小/电荷/载体）的筛选。
- 段3 维持机制："选择"一词的目的论暗示强；"有利/有害"价值判断比"物理性质"判断更符合直觉叙事，价值叙事每次占上风。
- 段4 处置：口诀"筛网按性质办事，不问善恶；病毒能骗过门禁"。反例候补。

**S-B.M-⑧-03｜信息交流都必须经过膜上受体**
- 段1 现象：❌ "细胞间信息交流都必须经过膜上受体"——胞间连丝是通道直连，不走受体。【v18册⑧章mis现态】
- 段2 错因结构：三方式（化学分子+膜受体/通道/胞间连丝）记成单一方式"受体中介"，通道直连型被吞并。
- 段3 维持机制：受体路径是教材主叙事且高考题高频，其他两方式曝光率低；"必须/都"全称判断的敏感度不足，主路径记忆抑制辅路径提取。
- 段4 处置：口诀"三通道：受体收、通道递、连丝直连；问'都'先想反例"。反例候补。

**S-B.M-⑧-04｜糖被分布在内侧或两侧都有**
- 段1 现象：❌ "糖被分布在内侧或两侧都有"——糖被在外侧（识别功能决定朝向）。【v18册⑧章mis现态】
- 段2 错因结构：膜结构的"两侧对称"直觉（磷脂双分子层本身对称）被外推到糖蛋白，忽略功能决定朝向。
- 段3 维持机制：双分子层对称图式是先学的强图式，糖被朝向是后学的弱知识；识别/润滑功能与"朝外"的因果链（识别要接触外环境）未建立时，图式回拉。
- 段4 处置：口诀"糖被站岗一律朝外——识别对象在胞外"。反例候补。

### ⑨章（5条）

**S-B.M-⑨-01｜核糖体和中心体也是膜性细胞器**
- 段1 现象：❌ "核糖体和中心体也是膜性细胞器"——两台裸机无膜；"无膜"不等于"不重要"。【v18册⑨章mis现态】
- 段2 错因结构：把"细胞器"与"膜结构"绑死；实际细胞器分类三档（无膜/单膜/双膜）。
- 段3 维持机制：绝大多数细胞器题以膜性为背景，无膜成员（核糖体/中心体）曝光少；三档分类未成表，只有"有膜/无膜"二元粗糙分类。
- 段4 处置：口诀"裸机两台：核糖体、中心体；双膜三件：核膜、线粒体、叶绿体"。反例候补。

**S-B.M-⑨-02｜分泌蛋白=细胞内起作用的蛋白**
- 段1 现象：❌ "分泌蛋白=细胞内起作用的蛋白"——分泌蛋白的"岗位"在细胞外：血红蛋白、呼吸酶不是分泌蛋白。【v18册⑨章mis现态】
- 段2 错因结构："分泌"的主体错位——合成在胞内≠岗位在胞内；按"在哪合成的"分类替代"在哪工作的"分类。
- 段3 维持机制：分泌蛋白合成运输全程（核糖体→内质网→高尔基体→膜外）章节主线在"胞内流程"，注意力锚在胞内，终点站（胞外岗位）反而失焦；血红蛋白/呼吸酶作为"胞内岗位"反例反复出现在判断题，错一次只修一处。
- 段4 处置：口诀"看岗位不看出生地：出胞上班=分泌蛋白"。反例候补。

**S-B.M-⑨-03｜肽链在内质网合成**
- 段1 现象：❌ "肽链在内质网合成"——核糖体只产肽链；内质网做的是"加工"不是"合成"。【v18册⑨章mis现态】
- 段2 错因结构：分泌蛋白流水线两站工序合并——"合成（脱水缩合）"与"加工（折叠/糖基化）"未分账。
- 段3 维持机制：内质网大面积附着核糖体，"东西从内质网上出来"的表象支持"内质网造的"误判；"合成"一词未锚定到化学反应级（肽键形成）。
- 段4 处置：口诀"核糖体焊肽链，内质网折整形，高尔基体打包发"。反例候补。

**S-B.M-⑨-04｜液泡只存在于植物细胞、动物完全没有**
- 段1 现象：❌ "液泡只存在于植物细胞、动物完全没有"——主考点在植物成熟细胞的大液泡；题目问"主要"层级，注意审题粒度。【v18册⑨章mis现态】
- 段2 错因结构：教材叙事焦点（植物成熟细胞大液泡）被绝对化为排他判断；"主要/显著"与"独有"两级混读。
- 段3 维持机制：考试题干问法常是"成熟植物细胞特征"（答案含大液泡），反复正确反馈固化"液泡=植物专属"过强结论；动物低配液泡从未入题，负例缺席。
- 段4 处置：口诀"大液泡是成熟植物细胞标签，不是液泡结构专利"。反例候补。

**S-B.M-⑨-05｜囊泡运输不需要能量**
- 段1 现象：❌ "囊泡运输不需要能量"——膜泡融合与转运全程耗能（线粒体供能）。【v18册⑨章mis现态】
- 段2 错因结构："被动运输不用能"的正确结论被过场外推到膜泡运输（非跨膜但耗能的大分子通道）。
- 段3 维持机制："不跨膜=不耗能"的直觉公式；三类物质进出方式（自由/协助/主动）表格里没有囊泡行，表外路径无能量标注习惯。
- 段4 处置：口诀"胞吞胞吐囊泡跑，全程烧线粒体的油"。反例候补。

### ⑩章（4条）

**S-B.M-⑩-01｜所有细胞都有细胞核**
- 段1 现象：❌ "所有细胞都有细胞核"——哺乳动物成熟红细胞、植物成熟筛管细胞无核；原核细胞无核膜包被的核。【v18册⑩章mis现态】
- 段2 错因结构：真核中心法则图式全称化；三类无核/无核膜细胞（哺乳成熟红细胞/成熟筛管/原核）未入反例库。
- 段3 维持机制："细胞核是控制中心"主叙事强，反例是"功能性牺牲"（红细胞腾空间装血红蛋白）需额外知识才理解；三个反例分散在三处，从未组队出现，各击破时互不支援。
- 段4 处置：口诀"无核三户：哺乳红细、植物筛管、原核全家"。反例候补。

**S-B.M-⑩-02｜核孔是全开的通道**
- 段1 现象：❌ "核孔是全开的通道"——核孔有选择性：RNA可出、DNA不出；大分子过孔是受控过程。【v18册⑩章mis现态】
- 段2 错因结构："孔"的日常图式（洞=随便过）顶替生物学"受控通道"图式。
- 段3 维持机制：与膜孔/气孔等"孔=通道"心智模型共享；RNA出核/ DNA不出核的方向性知识只在具体题里被检查，平时无复述场景。
- 段4 处置：口诀"核孔查证放行：RNA可出，DNA终身不出"。反例候补。

**S-B.M-⑩-03｜染色质和染色体是两种物质**
- 段1 现象：❌ "染色质和染色体是两种物质"——同一物质不同时期的两种状态。【v18册⑩章mis现态】
- 段2 错因结构：两个名字+两种形态（丝状/杆状）→判定两种物质；名称差异掩盖成分同一（DNA+蛋白质）。
- 段3 维持机制："不同名字≈不同东西"是语言学习的默认策略；分裂期前后两种形态分属不同图幅，从未同框比较。
- 段4 处置：口诀"一套料两种态：间期染色质，分裂期染色体"。反例候补。

**S-B.M-⑩-04｜细胞核单独培养可存活**
- 段1 现象：❌ "细胞核单独培养可存活"——核质互依：无质的核无法长久维持。【v18册⑩章mis现态】
- 段2 错因结构："核=总控"升级为"核=自足"；控制权与自足性混同。
- 段3 维持机制：强调核地位的叙述（蓝图/总控/母带库）过密，核的"供养依赖"（蛋白与原料全靠细胞质）叙事权重低；失衡后"总控=能独立存活"的推论自然生成。
- 段4 处置：口诀"总控也要饭：蛋白原料质供给，核质互依谁也离不开谁"。反例候补。

### ⑬章（汇总卡拆解5条·反例真题实锚）

**S-B.M-⑬-01｜酶=消化液里的酶，离体失效**
- 段1 现象：🚫①酶≠消化液里的"酶"那么简单——活细胞内也能起作用（离体照样可催化）。【v18册⑬章高频误解卡①】
- 段2 错因结构：初中学的"消化酶"场景覆盖了酶的完整分布域（胞内/胞外/离体均可）。
- 段3 维持机制：首次习得的"消化液"标签是提取起点，后续扩展（胞内酶）需主动修正标签，未修正则一直旧标签提取。
- 段4 处置：口诀"酶不问出身：胞内胞外离体，只要条件合适就干活"。反例候补（本章在库实锚唯北京T18·卡面考位="检测不干扰自变量"纪律区·与本条离体考位不同族，不硬凑·见§4.3）。

**S-B.M-⑬-02｜口服酶片有效**
- 段1 现象：🚫②口服酶片多数会被消化失效（蛋白质被水解）。【v18册⑬章高频误解卡②】
- 段2 错因结构："酶=药"的商品直觉顶替"酶=蛋白质→会被蛋白酶水解"的化学身份判断。
- 段3 维持机制：保健品广告叙事（口服补充酶）在课外持续供血；"蛋白质会被消化"知识与"酶片"场景从未强制同框。
- 段4 处置：口诀"酶是蛋白，口服进肚先被消化"。反例候补（生活应用判断题位）。

**S-B.M-⑬-03｜低温不催化=失活**
- 段1 现象：🚫③低温"不催化"≠失活（可恢复）。【v18册⑬章高频误解卡③】
- 段2 错因结构：低温抑制与高温失活两种"不催化"表象归并同因；未区分"活性抑制（结构未坏）"与"结构破坏（不可逆）"。
- 段3 维持机制："不干活=坏了"的等号在高温情境学到后泛化到低温；低温可恢复的实验证据（回升复活性）课堂曝光率低。
- 段4 处置：口诀"高温拆房不可逆，低温冬眠可叫醒"。反例：北京卷T18·TS抗旱机制-酶BG结合实验大题（存档北京卷P5-7·sha16=09e066bf588621f5·载记答案申报态）——考位=实验设计"检测不干扰自变量"纪律区【卡面四要素照登·与温度可逆性考位不同族如实注记，候复验】。

**S-B.M-⑬-04｜酶的化学本质只答蛋白质**
- 段1 现象：🚫④酶的化学本质判断不能只答"蛋白质"（少数RNA）。【v18册⑬章高频误解卡④】
- 段2 错因结构：萨姆纳1926脲酶结晶→"酶是蛋白质"的教科书定论覆盖少数RNA（核酶）修正条目。
- 段3 维持机制：主结论（绝大多数蛋白质）考试权重高，RNA催化是边界修正条目（切赫&奥尔特曼1982/1983·见科学史裁定区母表精度差异目），记忆权重倒挂；判断题反例出口（核酶）训练少。
- 段4 处置：口诀"绝大多数蛋白，留一手核酶RNA"。反例候补（本章实锚唯北京T18·卡面考位="检测不干扰自变量"纪律区·与酶本质判断考位不同族不硬凑·见§4.3）。

**S-B.M-⑬-05｜加酶=加能量**
- 段1 现象：🚫⑤加酶=加能量（错，只降门槛）。【v18册⑬章高频误解卡⑤】
- 段2 错因结构："催化剂加速=提供动力"直觉；活化能门槛模型未替换"加油站"模型。
- 段3 维持机制："加速"的生活语义自带"给劲"暗示；降门槛模型需要图像化理解（翻山 vs 隧道），只背结论时旧模型仍在后台。
- 段4 处置：口诀"酶挖隧道不加油：降低活化能，不供能不改平衡点"。反例候补（本章实锚唯北京T18·考位不同族不硬凑·见§4.3）。

### ⑭章（汇总卡拆解5条·反例真题实锚T3＋T13双挂）

**S-B.M-⑭-01｜A=腺嘌呤**
- 段1 现象：🚫①"ATP=A+腺嘌呤+三个磷酸"（错，A=腺苷=腺嘌呤+核糖）。【v18册⑭章高频误解卡①】
- 段2 错因结构：A-P~P~P结构式里"A"的身份未锚死（腺苷=腺嘌呤+核糖），字母简写被读成单个碱基。
- 段3 维持机制：RNA里A=腺嘌呤的先学知识负迁移；"腺苷"一词只在ATP处出现一次，曝光率极低。
- 段4 处置：口诀"ATP里的A=腺苷=腺嘌呤+核糖（A比RNA的A多半边）"。反例：重庆卷T3·能量胶营养成分-核糖与ATP组成（存档P1-2·载记T3=A三级申报态）——考位"组成成分（腺苷含核糖）"【卡面四要素照登】。

**S-B.M-⑭-02｜ATP与ADP转化是可逆反应**
- 段1 现象：🚫②"ATP与ADP转化是可逆反应"（三不同）。【v18册⑭章高频误解卡②】
- 段2 错因结构：化学平衡的"可逆"符号（⇌）迁移，忽略物质可逆与反应不可逆（酶/能量/场所三不同）。
- 段3 维持机制：双向箭头⇌的视觉输入强；"三不同"（酶不同/能量不同/场所不同）为列表知识，无图像支撑易衰减。
- 段4 处置：口诀"物质循环转，反应不可逆：酶、能、场所三不同"。反例候补。

**S-B.M-⑭-03｜ATP储量越多越好**
- 段1 现象：🚫③"ATP储量越多越好"（瞬时库存+快速周转才是设计逻辑）。【v18册⑭章高频误解卡③】
- 段2 错因结构："能源物质=多存越好"直觉；未理解ATP是高速周转的活水不是囤货（化学性质不稳+分子小用量大）。
- 段3 维持机制：储能物质（脂肪/淀粉）叙事的"多存"逻辑负迁移；"稳定大库存"（糖原脂肪）与"高速小周转"（ATP）的双轨设计观未建立。
- 段4 处置：口诀"ATP是零钱不囤仓：现挣现花，周转为王"。（注：本条口诀系册内ATP卡面比喻族在档延展，语境沿c0181b1 O10族豁免判例口径。）反例候补。

**S-B.M-⑭-04｜吸能反应自己会吸**
- 段1 现象：🚫④"吸能反应自己会吸"（必须与ATP水解对应偶联）。【v18册⑭章高频误解卡④】
- 段2 错因结构：吸能/放能的热力学标签被读成"自动发生"；偶联机制（吸能反应与ATP水解相耦联）未入模型。
- 段3 维持机制："吸能反应"字面自带动词性暗示；偶联概念抽象，考试只在具体题干检查，平时无复述。
- 段4 处置：口诀"吸能不能白吸：ATP水解偶联供能，一手交钱一手干活"。反例候补。

**S-B.M-⑭-05｜萤火虫发光与ATP无关**
- 段1 现象：🚫⑤"萤火虫发光是发光器的事，与ATP无关"（直接能源实证）。【v18册⑭章高频误解卡⑤】
- 段2 错因结构：器官分工叙事（发光器专管发光）覆盖能量学叙事（一切耗能生命活动以ATP直接供能）。
- 段3 维持机制：器官分工是组织学直觉，"一切耗能活动共用同一直接能源"的跨章能量观是抽象观；实验（切断供能则不发光）证据只在教材一处。
- 段4 处置：口诀"发光、肌缩、主动转运——只要耗能，直接刷ATP卡"。反例候补。

### ⑮章（汇总卡拆解6条·反例真题实锚T13·⑭⑮双挂）

**S-B.M-⑮-01｜呼吸作用O₂全程参与**
- 段1 现象：🚫①"呼吸作用的O₂全程参与"（只在第三阶段）。【v18册⑮章高频误解卡①】
- 段2 错因结构：总反应式（需O₂产CO₂）整体输入，三阶段分工（O₂只在第三阶段与[H]结合产水）未拆账。
- 段3 维持机制：总式是唯一的"整体记忆物"，阶段拆解只在题目检查时被迫进行，整体式反复复述不断加固"O₂全程在场"印象。
- 段4 处置：口诀"O₂只打卡第三阶段：与前两阶段的[H]会师产水"。反例：重庆卷T13·T细胞凋亡/坏死-ATP生成速率×O₂消耗（存档P6·载记T13=A三级申报态·⑭⑮双挂沿卡面合法）——考位"O₂消耗在线粒体内膜＋产物对账·曲线组图"【卡面四要素照登】。

**S-B.M-⑮-02｜CO₂中的O来自O₂**

**S-B.M-⑲-01｜个体衰老=体内细胞同步衰老**

- 段2 错因结构：整体/局部两级混同；个体衰老是多细胞群体统计学状态，非细胞级齐步走。
- 段3 维持机制："老人=老细胞"直觉；年轻体内也有衰老细胞更替、老年体内也有新生细胞的动态事实无场景入账。
- 段4 处置：口诀"个体衰老是统计画像，不是细胞齐步走"。反例候补。

**S-B.M-⑲-02｜细胞凋亡是病理性坏事**
- 段1 现象：❌"细胞凋亡是病理性坏事"→正常发育必需的主动过程；病理性的叫坏死。【v18册⑲章mis现态】
- 段2 错因结构："死=坏"的价值直觉直接覆盖 programmed death（程序性·主动性）概念。
- 段3 维持机制："凋亡"词面（凋零死亡）自带消极色彩；胚胎发育实例（指间细胞凋亡成指）不常与判断题同框。
- 段4 处置：口诀"凋亡=按程序体面退场（发育必需），坏死=事故现场（病理性）"。反例候补。

**S-B.M-⑲-03｜坏死也是程序性的**
- 段1 现象：❌"坏死也是程序性的"→坏死无程序。【v18册⑲章mis现态】
- 段2 错因结构：凋亡/坏死二分概念的外延边界（程序性为凋亡专属）未锚定，反向误装。
- 段3 维持机制：两概念常并列出现，"都有程序"的对称化错觉；"程序性细胞死亡=凋亡"的等式反推"坏死也可能有程序"。
- 段4 处置：口诀"程序性=凋亡专属商标；坏死是意外，无剧本"。反例候补。

**S-B.M-⑲-04｜原癌基因=致癌的坏基因**
- 段1 现象：❌"原癌基因=致癌的坏基因"→正常状态下是生长调控必需基因，突变累积后才致病。【v18册⑲章mis现态】
- 段2 错因结构：名字判罪（"癌"字定罪）——基因本体功能（调控生长分裂）与致病条件（突变累积）未分层。
- 段3 维持机制："原癌/抑癌"命名的语用暗示每次读都在定罪；"正常细胞人人有原癌基因"的反直觉事实无复述场景。
- 段4 处置：口诀"原癌基因是好员工，突变累积才叛变——名字里没罪，突变里才有"。反例候补。

**S-B.M-⑲-05｜癌细胞=脱分化回来的干细胞**
- 段1 现象：❌"癌细胞=脱分化回来的干细胞"→突变累积与选择的结果。【v18册⑲章mis现态】
- 段2 错因结构：无限增殖表象（癌细胞像干细胞）→机制误判（脱分化）；实际路径是突变累积+克隆选择。
- 段3 维持机制：表象相似（都疯长）直接归因；突变累积的渐进过程与"脱分化"的一步转化在时间感上难区分。
- 段4 处置：口诀"癌细胞不是返老还童，是 successive 突变+劣币驱逐"。反例候补。

**S-B.M-⑲-06｜白发/老年斑=衰老唯一指标**
- 段1 现象：❌"白发/老年斑=衰老唯一指标"→五特征成组记忆。【v18册⑲章mis现态】
- 段2 错因结构：显性外观指标（白发/斑）覆盖细胞内指标（水分减少/酶活性降/色素积累/呼吸减速/膜透性变）。
- 段3 维持机制：外观可见性决定记忆权重；五特征成组无口诀捆扎，散记易掉队。
- 段4 处置：口诀"五特征打包记：水少、酶慢、色沉、呼吸缓、膜透变——白发斑只是门面"。反例候补。
