开场一句话：3.1 教会我们用集合与对应定义函数，3.2 教会我们用单调性、奇偶性给函数"体检"。这一节把两件工具合起来，研究第五类新朋友——幂函数：买菜付款 p=w、正方形面积 S=a²、立方体体积 V=b³、场地边长 c=√S、骑车速度 v=1/t（p89 五个实例）。它们长得都像 y=xα——底数是自变量 x，指数是常数 α。读完这节，"研究一类新函数"的完整套路就归你所有了。

读完这节你能：

  • 从五个实例里认出幂函数，背出定义"函数 y=xα 叫做幂函数（power function），其中 x 是自变量，α 是常数"（p89 原文），并一眼排除 y=2x²、y=x+1 这类冒牌货；
  • 在同一坐标系里画出 y=x、y=x²、y=x³、y=x1/2、y=x−1 五条图象，并填写表3.3-1（定义域/值域/奇偶性/单调性）五列；
  • 复述教材四条结论：都过 (1,1)、三个奇一个偶、(0,+∞) 上四个增一个减、y=x−1 的无限接近趋势；
  • 照教材例题的作差＋分子有理化五步证明 f(x)=√x 是增函数，并用同样套路解"过点求解析式、比大小、管道流量"三道应用。

预备预备块：你早已认识的"幂"，和刚领到的两件工具

旧工具一（初中·幂）：x·x=x²，x·x·x=x³，√x=S1/2，1/x=x−1——幂就是"底数连乘与它的推广"，教材边注提醒：√S 也可以表示为 S1/2（p89）。

旧工具二（3.1+3.2·研究函数的路线图）：3.1 的函数概念（定义域→对应关系→值域）＋3.2 的性质工具箱（单调性=增减体检、奇偶性=对称体检）。教材 p90 开场原句把路线图说穿了："通常可以先根据函数解析式求出函数的定义域，画出函数的图象；再利用图象和解析式，讨论函数的值域、单调性、奇偶性等问题。"——本节就是照这张路线图走一遍。

第一步五个实例看一眼：什么是幂函数（p89）

教材一口气给了五个真实情境（p89），先看清它们各自"谁是谁的函数"：

实例（p89）解析式谁是函数幂的形状
① 张红以 1 元/kg 买蔬菜 w kg，需支付 p 元p=wp 是 w 的函数w¹（指数1）
② 正方形边长 a，面积 SS=a²S 是 a 的函数a²（指数2）
③ 立方体棱长 b，体积 VV=b³V 是 b 的函数b³（指数3）
④ 正方形场地面积 S，边长 cc=√S（=S1/2）c 是 S 的函数S1/2（指数½）
⑤ 某人 t s 内骑车行进 1 km，平均速度 v km/sv=1/t（=t−1）v 是 t 的函数t⁻¹（指数−1）

验一验①（p89 观察框）：观察 (1)～(5) 中的函数解析式，它们有什么共同特征？——解析式都具有幂的形式；都以幂的底数为自变量；幂的指数都是常数，分别是 1、2、3、1/2、−1。

一般地，函数 y = xα 叫做幂函数（power function），其中 x 是自变量，α 是常数。（p89 定义原文）

两个教材边注都要接住：④的 √S 也可以表示为 S1/2（分数指数与根式互通）；另一个边注说"幂的指数除了可以取整数之外，还可以取其他实数，当它们取其他实数时幂也具有各自的含义，这些会在后面学习"——所以本节只研究 α=1，2，3，1/2，−1 五个值（p89 原句），别急着问 y=x√2 长什么样。

拓展 · 可跳过 冒牌货辨析（自编辨析，非教材原文；教材口径=定义形如 y=xα）：y=2x² 不是幂函数——系数是 2 不是 1，它是二次函数；y=x+1 不是幂函数——多了一项，不是"幂的形式"；y=2ˣ 更不是——它底数是常数、指数是变量，和幂函数正好反着，这是后面要学的指数函数。一句话口诀："底变指不变才是幂，指变底不变是指数"（自编口诀）。

验一验②（p89 思考框）：结合以往学习函数的经验，你认为应该如何研究这些函数？——照 p90 路线图：先由解析式求定义域→画图象→再讨论值域、单调性、奇偶性。这正是 3.2 练过的"定义法"全套。

教材四条结论（p90 原文口径）：

  1. 五个函数的图象都通过点 (1,1)（1 的任何次幂都是 1，y=x1/2 在 x=1 处也是 1）；
  2. y=x、y=x³、y=x⁻¹ 是奇函数，y=x² 是偶函数（y=x1/2 定义域不含负数，谈不上奇偶）；
  3. 在区间 (0,+∞) 上，y=x、y=x²、y=x³、y=x1/2 单调递增，y=x⁻¹ 单调递减；
  4. 在第一象限内，y=x⁻¹ 的图象向上与 y 轴无限接近，向右与 x 轴无限接近（"无限接近"= 渐近趋势的白话版）。
易错红卡（自编，据教材图3.3-1与结论(3)(4)提炼）：① y=x⁻¹ 在两个区间上各自递减，但不能写成"在定义域内整体递减"——取 x=−1 与 x=1，f(−1)=−1 < f(1)=1，跨过 y 轴反而变大，"整体递减"是错的；② y=x1/2 定义域是 [0,+∞)，0 可以取（√0=0），别把 0 丢掉；③ 表里 y=x² 与 y=x1/2 值域同为 [0,+∞)，但一条是抛物线、一条是"右半支躺平"，值域相同≠图象相同。

第三步定义法证一次"新函数"：教材例题逐行拆（p90-91 例）

例（p90 原题）：证明幂函数 f(x)=√x 是增函数。

教材证明分四步，每一步都有"为什么能这么写"的底牌：

步骤（教材原文口径）写法底牌（为什么合法）
① 交代定义域函数的定义域是 [0,+∞)√x 要求 x≥0，0 也算；单调性必须在定义域内谈
② 任设两点∀x₁,x₂∈[0,+∞)，且 x₁<x₂"任意"两个字是定义法的命根（3.2.1 单调性定义同款开头）
③ 作差＋变形f(x₁)−f(x₂)=√x₁−√x₂=((√x₁−√x₂)(√x₁+√x₂))/(√x₁+√x₂)=(x₁−x₂)/(√x₁+√x₂)分子有理化：乘以共轭 (√x₁+√x₂)/(√x₁+√x₂)=1，把带根号的差变成纯分式
④ 定号→结论因为 x₁−x₂<0，√x₁+√x₂>0，所以 f(x₁)<f(x₂)，即 f(x)=√x 是增函数（p91 原文）分母恒正（根号非负且不同时为0）、分子为负，商为负

验一验③（p90-91 例题复述）：不看上表，默写四步——定义域 [0,+∞) → 任设 x₁<x₂ → 作差、分子有理化 → 定号得 f(x₁)<f(x₂)。抽验数值：x₁=0, x₂=4 时 f(x₁)−f(x₂)=0−2=−2<0 ✓；x₁=1, x₂=4 时 1−2=−1<0 ✓。

拓展 · 可跳过 方法论收口（自编，承 p89 思考框"如何研究"）："研究一类新函数"的完整五步——给定义 → 求定义域 → 画图象 → 填性质表 → 用定义证性质。3.2 证二次函数用"作差配方"，本节证根式函数用"作差有理化"，变的只是变形手艺，定义法骨架一个字不用改。

第四步幂函数怎么用：过点求式、比大小、管道流量（p91）

用法一：过点求解析式（p91 练习1）。已知幂函数 y=f(x) 的图象过点 (2,√2)，求解析式。——设 y=xα，代点：2α=√2=21/2，所以 α=1/2，y=x1/2。整节只用到"幂函数系数必为 1、指数待定"这一件事。

用法二：比大小（p91 练习2）——"同指不同底，看幂函数单调性"。

  • (1) (−1.5)³ 与 (−1.4)³：同用 y=x³（R 上增），−1.5<−1.4 ⟹ (−1.5)³<(−1.4)³。数值复核：(−1.5)³=−3.375，(−1.4)³=−2.744，−3.375<−2.744 ✓。
  • (2) 1/(−1.5) 与 1/(−1.4)：同用 y=x⁻¹ 在 (−∞,0) 上递减，−1.5<−1.4 ⟹ 1/(−1.5)>1/(−1.4)。数值复核：−2/3≈−0.667，−5/7≈−0.714，−0.667>−0.714 ✓（两个都是负数，"递减"方向的符号别搞反）。

用法三：管道流量（p91 习题3.3 综合运用2）——正比即幂函数。在固定压力差下，气体过圆形管道，流量 v（单位 cm³/s）与管道半径 r（单位 cm）的四次方成正比：

  • (1) "与 r⁴ 成正比"译成解析式：v=kr⁴（k>0 为比例常数）；
  • (2) r=3 时 v=400：400=k·3⁴=81k ⟹ k=400/81，所以 v=(400/81)r⁴；
  • (3) r=5：v=(400/81)·5⁴=(400·625)/81=250000/81≈3086.4，精确到 1 cm³/s 得 3086 cm³/s。

用法四：描点画 y=x⁻²（p91 习题3.3 第3题，思路带过）。定义域 {x|x≠0}；由 (±2)⁻²=1/4、(±1)⁻²=1 知 f(−x)=f(x)，偶函数；值域 (0,+∞)；在 (0,+∞) 上递减（可用第 3 站定义法证明，作差通分后分子 x₂²−x₁²>0、分母 x₁²x₂²>0）。图象两支像"更瘦的 y=x⁻¹"，在 y 轴两侧对称翘起。

验一验④（p91 习题3.3 复习巩固1 口头版）：y=√|x| 的图象与奇偶性？——x≥0 时 y=√x，x<0 时 |x|=−x，故 y=√(−x)，左右两支关于 y 轴对称，是偶函数；[0,+∞) 上递增、(−∞,0] 上递减，底牌是外层 √ 增、内层 |x| 左减右增的复合效果（复合细分到选择性必修才正式学，此处看图即可）。

收口三问（合上书自答）：

  • 幂函数和"长得像幂"的函数怎么区分？——形如 y=xα：系数 1、底数为自变量、指数为常数；y=2x²、y=x+1、y=2x 全都出局（自编口诀"底变指不变"）。

真题锚高考真题实证

2023年北京卷·第4题（4分）：下列函数中，在区间 (0, +∞) 上单调递增的是（　）
A. f(x) = −ln x　B. f(x) = 1/2ˣ　C. f(x) = −1/x　D. f(x) = 3^|x−1|

答案 C。0基础版拆解：先写依据——本题四个函数各带一种"基本初等函数"的底色，考的是"翻转变换后单调性怎么变"（考位锚存量行说的 x⁻¹ 变形就在 C 项）。代数——A：ln x 递增 → 加负号 → −ln x 递减 ✗；B：1/2ˣ = 2^(−x)，指数函数底 2、指数 −x → 递减 ✗；C：y = 1/x 在 (0,+∞) 递减 → 加负号翻转 → −1/x 递增 ✓（这就是幂函数 x⁻¹ 的翻转变形）；D：3^|x−1| 在 x=1 处折返 → (1,+∞) 段递增、(0,1) 段递减 ✗；读答案——选C。"底数谁、指数谁、有没有负号与绝对值"——翻转一次，单调方向翻一次。

选择3（难·自编综合） 已知幂函数 f(x) = (m² − 3m + 3)·x^(m+1) 是奇函数，则 m =（　）
A. 1　B. 2　C. 1 或 2　D. 3

填空（中·自编） 比较大小：2.5^(3/4) ______ 2.7^(3/4)（填“>”“<”）。

挑刺（中·自编） 小华复习完说：“①y = x^(1/2) 的定义域是 R——平方根嘛，谁都能开；②幂函数的图象都过点 (1, 1) 和 (0, 0)。”请你把两处错都挑出来。

解答1（中·自编） 已知幂函数 f(x) = x^α 的图象经过点 (8, 4)，求 f(x) 的解析式，并判断它在 (0, +∞) 上的单调性。

解答2（难·自编综合） 比较下列各组数的大小，并说明依据：⑴ 1.3^(2/5) 与 1.5^(2/5)；⑵ (1/2)^(−3) 与 (1/3)^(−3)；⑶ 0.8^(−1.3) 与 0.9^(−1.3)。

答案与解析（先做完再看）：
选择1：C。幂函数定义三查：系数为 1、只有 x^α 一项、没有其他运算。A：系数 2（y = 2x³ 是"二次项倍数"不是幂函数）；B：多了一项 +1；C：x⁻² = 1/x²，形如 x^α ✓；D：底 3 常数、指数 x——那是指数函数。
选择2：B。先求 α：2^α = √2 = 2^(1/2) → α = 1/2 → f(x) = x^(1/2)；f(9) = 9^(1/2) = 3。0基础版：过点定指数，就解一个"底同幂等"的小方程。
选择3：B。幂函数先要"长得像幂函数"：系数 m²−3m+3 = 1 → m²−3m+2 = 0 → m = 1 或 m = 2。再验奇偶：m=1 → f(x) = x²（偶）；m=2 → f(x) = x³（奇 ✓）。0基础版：双条件"系数归一"＋"奇偶验核"，两道闸依次过，C 选项"1或2"是没验第二道闸的陷阱。
填空：<。y = x^(3/4) 在 (0, +∞) 上递增（α = 3/4 > 0），2.5 < 2.7 → 同一增函数里大底数出大值。
挑刺：错①定义域看 α——x^(1/2) = √x 要求被开方数非负 → 定义域 [0, +∞)，不是 R。幂函数定义域随 α 变：α 为分数时先想根号。错②"都过 (0,0)"言过其实——幂函数必过 (1, 1)（1 的任何次方都是 1）；但过不过 (0,0) 看 α：α > 0 才过原点，x⁻¹、x⁻² 这类 α < 0 的函数在 x = 0 处根本没定义。
解答1：先写依据——过点定指数：8^α = 4。代数——8 = 2³、4 = 2² → 2^(3α) = 2² → α = 2/3 → f(x) = x^(2/3)。单调性：α = 2/3 > 0 → 在 (0, +∞) 上递增。读答案——f(x) = x^(2/3)，(0,+∞) 上递增。
解答2：先写依据——比大小三板斧：同指数用幂函数、同底数用指数函数、异底异指找中间量。代数——⑴ 同指数 2/5：y = x^(2/5) 在 (0,+∞) 递增，1.3 < 1.5 → 1.3^(2/5) < 1.5^(2/5)；⑵ 同指数 −3：y = x^(−3) 在 (0,+∞) 递减，1/2 > 1/3 → (1/2)^(−3) < (1/3)^(−3)（即 8 < 27 ✓）；⑶ 同指数 −1.3：y = x^(−1.3) 在 (0,+∞) 递减，0.8 < 0.9 → 0.8^(−1.3) > 0.9^(−1.3)。读答案——⑴ 小于；⑵ 小于；⑶ 大于。格式示范：判同异 → 定单调向 → 按序排大小。
