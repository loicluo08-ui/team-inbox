## §三 方案设计

### 3.1 拼接架构（新增"汇总线"脚本，打印线本体复用不改造）

```
章节装配件HTML×N → 汇总拼接器（新工具） → 全册汇总件HTML → 现有打印线 → PDF
```

- **拼接器职责**（与打印线解耦，打印线零改动）：
  1. 按科册序读取章装配件（件名序=章序·宁缺毋编：缺章如实空缺标注）
  2. 锚点id去重：各章内部s1/s2锚跨章冲突→统一改写为`ch{N}_s{M}`章前缀制（TOC href同步改写）
  3. 标题层级归一：章装配件内h2（课级）维持，章标题以`<h1>`插入章首（新增·带章号）；总目录条目=章h1+课h2两级
  4. 总TOC生成：锚链全名制（遵TOC全名化根修件口径——`h2全名`禁截断，三分类check先行）
  5. 封面+册信息页：科目/册号/生成时点/源件commit hash（可审计）

### 3.2 分页双层制（§八并入）

| 层级 | 规则 | 实现 |
|---|---|---|
| 章间 | 每章强制新页起排 | h1注入break-before:page |
| 课间 | 每课（h2"课时开篇页"）新页·首课不触发 | 现课间分页JS原样生效 |
| 节内 | 自然流式·表格/反馈框防断（现CSS已备） | 不加页 |

### 3.3 转译层装填位（§六并入·序列依赖）

- **实切先于转译**（§六.4）：实切卡壳点=转译层选址图——全册汇总版在序列④末段，转译层精炼装填（书面化+去噪+留口语亮点原句）完成后才出终版
- 汇总件HTML的讲法精华槽位=装配件"卡壳点装填区"（§七.3定位：装配件讲法精华=纸质轨·切片卡=屏幕轨资源目录·互补不重复）
- 字幕json依赖：交卡附字幕json（§六.2）→转译层原料——**登录墙期间AI字幕不可测（A线实锤在案），缺口节如实空槽不虚填**

### 3.4 页眉页脚与书签（可选增强·候Alex裁量）

- 页脚：`{科名}·{册号}｜第 X 页`——打印线margin已留12mm底边可承载
- PDF书签：pypdf按章h1注入outline（章级1层+课级2层）——打印装订无感、电子阅读有感
