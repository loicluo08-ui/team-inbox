奇偶性：给图像的对称发身份证

数学3.2 · 函数的基本性质（下） · 零基础首学版 v1.4 · 前置：会算 f(2) 这种（不会？往下30秒补齐）

开场对称你天天见，数学只是把它说精确

你脸的左右两半，照镜子时互为镜像；蝴蝶的左右翅膀，对折能重合。函数的图像也有对称：有的函数图像左右对折重合，有的绕中心转半圈重合。

"对折重合"是眼睛看的。数学的问题是：不用眼睛，只算数，能不能判断对称？这一节就干这一件事——把"看着对称"翻译成一条能检验的代数式子。翻译成功了，你就免费获得一个超能力：只研究函数的一半，另一半自动送。

读完这节你能

① 只算三行数，判断一个函数是偶、是奇、还是都不是；
② 说清为什么判型必须先查定义域；
③ 避开"只代正数就下结论"这个新手必踩的坑。

预备30秒补齐 f(x) 记号（已会的跳过）

把函数想成一台机器：左边塞进一个数，右边吐出一个数。机器的名字叫 f。

塞进 2，吐出 4，写成 f(2) = 4，读"f(2)等于4"。塞进 3 吐出 9，就是 f(3) = 9。

如果这台机器的规则是"塞进去的数平方后吐出来"（f(x) = x²），那么：

f(2) = 2² = 4　　f(-2) = (-2)² = 4　　f(3) = 3² = 9　　f(-3) = (-3)² = 9

f(-2) 的意思是"把 -2 喂进机器"。就这么多（这是 f(x) 记号的速成版，完整的函数定义在教材3.1节——先会用，以后补严格版）。

验一验（10秒）：若 f(x) = x + 1，f(2) 是多少？
→ 2+1=3。会了，往下走。

第一步f(x) = x²：左右两边的数，算出来居然一样

盯着上面那行算式看：f(2) 和 f(-2) 都是 4，f(3) 和 f(-3) 都是 9。 （注意：负数也要代——只代正数就下结论，图像的左半边就是这么漏掉的）2 和 -2 是什么关系？互为相反数——在数轴上关于原点对称的两个位置。

再多试几组：f(1.5)=2.25，f(-1.5)=2.25。f(100)=10000，f(-100)=10000。全部一样。

规律浮出来了：喂进 x 和喂进 -x，吐出来的数永远相同。把"永远相同"写成式子，就是：

f(-x) = f(x)　——这样的函数叫偶函数

偶函数（教材定义，人教A版p83）：设函数 f(x) 的定义域为 D，如果对任意 x∈D，都有 -x∈D，且 f(-x)=f(x)，那么 f(x) 就叫偶函数。

"任意"是关键词——不是挑几个成立的算数游戏，是全部、无一例外（挑样本=碰运气，不是证明）。图像上：偶函数的图像关于 y 轴对折重合——左边就是右边的镜像。

偶函数 = 图像沿y轴对折后与自己重合。任何一对 x 与 -x，函数值相等。

第二步f(x) = x³：这次吐出来的数互为相反数

换一台机器，规则是"塞进去的数三次方后吐出来"（f(x)=x³）：

f(2) = 2³ = 8　　f(-2) = (-2)³ = -8　　f(3) = 27　　f(-3) = -27

这次不一样了：f(2)=8 而 f(-2)=-8——不是相等，是互为相反数（8和-8，只差一个负号）。代数式子：

f(-x) = -f(x)　——这样的函数叫奇函数

奇函数（教材定义，p84原文）：设函数 f(x) 的定义域为 D，如果对任意 x∈D，都有 -x∈D，且 f(-x)=-f(x)，那么 f(x) 就叫奇函数。

图像上：奇函数关于原点转半圈重合（不是对折）。f(x)=x 就是奇函数——教材p84亲自演示：f(-3)=-3=-f(3)，f(-2)=-2=-f(2)，行行成立。

奇函数 = 图像绕原点旋转半圈后与自己重合。任何一对 x 与 -x，函数值互为相反数。
验一验（30秒）：f(x) = x³ + x 是奇函数吗？把 -x 喂进去算：
→ f(-x) = (-x)³+(-x) = -x³-x = -(x³+x) = -f(x)。相反数 ✓ 奇函数。（这也是教材p85思考题原题）

第三步不是每个函数都站队——非奇非偶

试 f(x) = x² + x：f(1) = 2，f(-1) = 0。2 和 0，既不相等（否了偶），也不互为相反数（否了奇）。

非奇非偶。奇偶是"户口本上的分类"——但有些函数两边都不沾，这是合法的第三状态，不用硬归类。

验一验（30秒）：教材例6原题 f(x) = x + 1/x：把 -x 喂进去，f(-x) = -x + 1/(-x) = -x - 1/x = -(x + 1/x) = -f(x)。
→ 相反数 ✓ 奇函数。注意这个函数定义域是 x≠0——负半轴正半轴都存在，检查得动。

第四步（最容易翻车的坑）先查定义域，再谈一切

坑：f(x) = x² 在 x∈[-1, 2] 上是偶函数吗？法则"长得像"偶函数（平方），但定义域是 [-1, 2]——-1 的镜像 -(-1)=1 在定义域内，可 2 的镜像 -2 不在！

判：非奇非偶——定义域不关于原点对称，f(-x) 对某些 x 根本无意义，奇偶性无从谈起。哪怕法则长得再对称，白搭。

教材p84框注原话："奇偶性是函数在它的定义域上的整体性质，所以判断函数的奇偶性应先明确它的定义域。"——教材把这条放在例6的框注里专门强调。

定义域 [-1,2]：镜子两侧不等长——对称关系无从建立，直接判"非奇非偶"，不用再算。
一个必须说清的边界：代值是侦察，不是证明。上面用 f(±1)、f(±2) 快速试出方向——但代多少个点都只算抽查，抽查通过不等于恒成立（有的函数会骗过你试的那几个点）。严格判型 = 验证 f(-x)=±f(x) 这个等式对定义域内每一个 x 都成立（数学叫恒等式）。初学阶段：选填题用代值侦察够快；解答题落笔必须写"f(-x) = … = ±f(x)"的变形过程。

正规判断流程永远两步，次序不可换：

两步判型清单：
第一步：查定义域——关于原点对称吗？（不对称 → 直接宣布非奇非偶，一步终结）
第二步：算 f(-x)——等于 f(x)？（→偶）等于 -f(x)？（→奇）都不等？（→非奇非偶）

送一个一行推出来的赠品：奇函数若在 x=0 处有定义，则 f(0)=0——代入 x=0：f(0) = -f(0)，移项 2f(0)=0，完。不用记图像，一行代数就出。

收口三句话带走 + 自测

三句话：
1. 偶函数：f(-x)=f(x)，图像左右对折重合——"输入变号，输出不变"。
2. 奇函数：f(-x)=-f(x)，图像绕原点转半圈重合——"输入变号，输出也变号"。
3. 判型永远两步：先查定义域对称，再算 f(-x) 比对。

自测四连（先做再看答案）：

① f(x) = 2x⁴ + 3x² 是奇是偶？（教材p85练习2原题）

② f(x) = x³ - 2x 是奇是偶？（同上）

③ f(x) = x²，x∈[-3, 3]，是奇是偶？换成 x∈[-3, 2] 呢？

④ 奇函数 f 在 x=0 有定义，f(0) 是多少？

答案：①偶（f(-x)=2x⁴+3x²=f(x)）②奇（f(-x)=-x³+2x=-f(x)）③[-3,3]对称→偶；[-3,2]不对称→非奇非偶（法则没变，定义域变了结果就变——这就是为什么先查定义域）④0

练什么题：教材p85练习1（看图补另一半）+练习2+习题3.2第5题。做完这三组，判型就肌肉记忆了。

高考怎么考（考位锚）：单独考"判奇偶"的题不多——奇偶性更多当工具用：和单调性联手出抽象函数题（给你 f(x+y)=f(x)+f(y) 这类条件，先推出它是奇函数，再拿单调性解不等式），全国卷和各省卷都是高频套路。你下一件要学的单调性，就是它联手的另一半。具体真题锚候采（卷源在库·宁缺毋编不代拟）。

下一站：你手里现在有两件武器——单调性（输入排序保输出排序）和奇偶性（对称保型）。它们联手出题的方式：偶函数在 y 轴右侧递增，左侧就递减（镜像单调）；奇函数两侧同向。下一件首学版候选：单调性（本节前面已预告过）或集合的基本运算——你点名。
