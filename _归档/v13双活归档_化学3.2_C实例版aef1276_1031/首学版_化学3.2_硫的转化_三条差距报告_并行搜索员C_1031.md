# 首学版_化学3.2_硫的转化 · 三条差距报告（队3席·并行搜索员C·2026-10-31·v10续产会话）

> 义务依据：标准模板v2.3"开工前必须通读两件黄金样本（3.2完整形态+1.1入门骨架），写出与自己负责节的三条差距，通读报告随首件提交"。本席通读两件后与本节（3.2硫的转化）对差如下：

**差距一：样本的"代值实验"在本节要换成"价态预测+留白实验表"——比样本多一步诚实处理**
黄金样本3.2的核心节奏是"代个数进去试"。本节p99观察·思考与p101实验方案两张表在教材里**故意留白**（预测性质/记录现象/结论及化学方程式全空），样本没有"教材留白"这种形态。本件做法：把留白转成"预测→实验→结论"三步走的固定框架，现象与方程式全部放答案侧并显式标注"自编"（宁缺毋编：不替教材"写死"现象），sympy对全部方程式跑零空间配平留痕。

**差距二：样本概念单线推进，本节"工具第一次全面实战"——方法导引必须前置成总纲**
数学样本3.2一节只新增两个概念，一次一步即可。本节是2.3节"价态眼镜"的**第一次全面实战**（-2/0/+4/+6四价态、三站里反复横跳），若按教材顺序平铺，读者到第③站SO₂"既氧化又还原"处必卡。本件做法：把p101"中间价态两性/最高价只氧化/最低价只还原"总规律从节中**前置到预备块**（括注"教材原文在p101·此处先给后证"），第③站再回头实证——牺牲顺序忠实度换认知不断链，此取舍已在附件3 T10行注记。

**差距三：样本节末串联图是纯知识链，本节要同时装"工业流程+社会议题+价态网"三件——分图承载**
样本节末导图只连本节内部。本节收尾有三股线：价—类转化关系网（p106概括·整合）、接触法制硫酸工业流程（p104图3-2-12）、酸雨防治社会议题（p105-106）。本件做法：接触法流程独立SVG（框图式·三步两式）、价—类转化网并入收口"价—类二维图"同一张图加箭头、酸雨只走文字三步不放图——保住"一张图一个意思"，信息密度已在附件4 K7/K8卡点复读过。

**结论：三条差距均有对应落法且在件内显式可查；无"样本做法搬不动而放弃"项。**
