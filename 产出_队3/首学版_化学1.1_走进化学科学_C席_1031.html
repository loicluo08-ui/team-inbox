走进化学科学：一门"研究物质、创造物质"的学问怎么认门

化学 1.1 · 第1章 认识化学科学（鲁科版·必修第一册） · 零基础首学版 v1.0 · 前置要求：小学科学常识即可，本节从零讲起

先别翻开化学课本。看一眼你身边：喝的水、刷牙的牙膏、身上的化纤校服、手里的手机屏幕、夜里亮着的LED灯——它们全是"物质"。

面对这个五彩缤纷的物质世界，人类从远古时代就在琢磨四个问题：物质究竟是什么？它由什么组成？为什么会变化、怎么变化？能不能有目的地让物质转化、创造出新物质？（这正是教材开篇的原话。）

几千年的琢磨与探究，攒出了一门正经学问——化学科学。这一节不教你任何一个方程式，只做一件事：带你认门——这门学问从哪来、它到底研究什么、它凭什么改变世界。

读完这节你能

① 一句话说出化学研究的对象，并把它的三个特征背出来；
② 把化学史上五座里程碑（谁、哪一年、干了什么）对上号；
③ 讲出青蒿素从发现到救人走过了哪几步——用它看懂"化学这门学问是怎么干活的"。

预备先拆掉两个可能的误会

进门前，先把你脑子里可能带的两个印象拆掉，不然会影响后面每一步的理解。

误会一："化学=危险、有毒、爆炸"。——错。你喝的水要净化、吃的药要合成、穿的布要染色，背后全是化学。化学本身是一门基础学科（和数学、物理平起平坐的那种），它是中性的工具：能造救命药，也能鉴别毒物。后面你会看到它救了几亿人的实例。

误会二："化学=死记硬背元素周期表"。——本节读完你会发现，这一节要记的东西一共就三样（定义一句话、五座里程碑、三个特征），而且都有逻辑勾连，不用硬背。后面的章节里，化学更多是观察—提出问题—实验验证—得出结论的推理活。

两个词先补上，后面要用（30秒）：

物质：构成世界的东西——水、铁、空气、药片，都是。
转化：一种物质变成另一种物质——铁放久了生锈（铁→铁锈）、米放久了发酸（米→酸），都叫转化。

第1步这门学问是几千年"攒"出来的

化学不是某一天突然出现的，它分三个阶段长成今天的模样。

远古：先有"化学活动"，后有"化学"这个名字

早在远古时代，我们的祖先就学会了取火和保存火种——从那时起人类就开始了"化学活动"。再往后，人们学会了烧制陶瓷、冶炼金属、酿造酒类（教材图1-1-3里那只青花瓷罐就是证据）。甚至有一批人——炼丹家、炼金士——试图炼出长生不老的丹药、把廉价金属炼成金子。他们目标错了，但那股"拿物质做实验"的劲头，客观上攒下了大量经验。

近代（1661—1869）：五座里程碑，化学变成"科学"

光有经验不够，要成为科学，得有理论。近代两百多年里，化学家们立起了五座里程碑——这是全节最值得记的一张图：

近代化学五座里程碑（教材图1-1-4转绘·鲁科版必修一 p3）——卡片按年份左右排布，坐标由脚本按年份线性映射生成

记这张图的口诀：波义耳开门（1661·近代化学诞生）→ 拉瓦锡革新（1777）→ 道尔顿打地基（1803·原子论）→ 阿伏加德罗补分子（1811）→ 门捷列夫收官（1869·周期律把一切纳入统一体系）。顺序就是时间顺序，一个"越干越明白"的过程。

不看上图，把"氧化学说 / 原子论 / 元素周期律 / 化学元素概念 / 分子学说"五张牌，分别配给"波义耳 / 拉瓦锡 / 道尔顿 / 阿伏加德罗 / 门捷列夫"。

答完再看：波义耳—化学元素概念（1661）· 拉瓦锡—氧化学说（1777）· 道尔顿—原子论（1803）· 阿伏加德罗—分子学说（1811）· 门捷列夫—元素周期律（1869）。配错的那张，回图上找到对应卡片再看一遍年份即可。

现代（20世纪至今）：化学开始"造物质"，并带动其他科学

进入20世纪，随着认识从宏观深入微观、从定性走向定量，现代化学飞速发展：现代量子化学理论、化学热力学与动力学、创造新分子的合成化学、高分子化学、化学工业，都是这个时代的重大成就。三个你该知道的实例：

  • 1965年，我国科学家成功合成了结晶牛胰岛素——在世界上首次实现蛋白质的人工合成（教材图1-1-5）。这是人类第一次"照着生命的样子造出生命物质"。
  • 合成氨的化工技术让人类造出大量氮肥、粮食增产，成千上万的人免于饥饿（教材图1-1-6）；新药物研制战胜疾病；合成高分子材料、以硅为原料的芯片和光导纤维（图1-1-7）让你我生活彻底改样。
  • 化学还带动了别的科学：研究生物之间化学联系的化学生态学于20世纪50年代末诞生；对蛋白质结构的研究促进了生命科学发展。

一句话：远古攒经验，近代立理论，现代开始"按需造物质"并反哺所有领域。

第2步化学到底是什么：一句话定义+三个特征

看了几千年历史，现在回答最核心的问题。先别往下看——你自己先试一句：如果只能用一句话说清"化学在研究什么"，你会怎么说？

……好了吗？教材（p5）给的是这个精确答案：

化学是在原子、分子水平上研究物质的组成、结构、性质、转化及其应用的一门基础学科。
（鲁科版必修一 p5 原文·逐字。）拆开看："原子、分子水平"=在微观粒子的尺度上看问题；"组成、结构、性质、转化、应用"=五个研究对象；"基础学科"=和数学物理并列的正经学问，不是手艺。

"原子、分子"没概念？30秒补齐：把物质想象成乐高作品——分子像拼好的小组件，原子像一颗颗积木颗粒。化学就趴在这个尺度上研究东西。

紧接着同一句，教材给出了化学的三个特征：

三特征记忆卡：宏观微观两头看 / 符号写出来 / 动手造出来

三特征不是空话，各配一个实例：

  • 宏观+微观两个角度：水"无色透明"是宏观性质；"1个水分子由2个氢原子和1个氧原子构成"是微观组成——化学两边都看。
  • 以符号形式表征：水的组成写成 H₂O，全世界化学家一眼看懂——符号是化学的"世界语"。
  • 不同层面创造物质：化学家已发现和创造了上亿种物质，其中大量是自然界原本不存在、被人类按需要造出来的新物质（p5原文）——所以化学是一门具有创造性的科学。

怎么研究？实验与理论并重：一边是分析和测试技术——波谱、色谱、X射线衍射、飞秒化学、原子示踪（p5-6·教材图1-1-8/9/10就是三台"神器"：质谱仪、核磁共振仪、X射线衍射仪）；另一边是理论计算配计算机模拟，预测反应活性、研究微观过程。

⚡ 30秒自验 2

下面哪几句说的是"化学研究范畴内"的事？
A. 水是无色透明的液体　B. 水分子由氢、氧两种原子构成　C. 今年台风路径会不会偏南　D. 用氢气和氮气造出氨肥

答完再看：A是（宏观性质）· B是（微观组成）· C不是（天气是大气运动，归气象学；化学研究的是物质本身）· D是（创造新物质=转化，这正是"合成氨化工"）。

红笔旁批：最容易混的是C这类——判断标准就一条：落点在"物质的组成、结构、性质、转化"上才是化学。

卡住了？换个说法
定义太长背不动？先抓主干："化学 = 在极小尺度上研究物质的学问"。五个研究对象（组成/结构/性质/转化/应用）可以想成认识一个人的五个侧面：他由什么组成（身体成分）、长什么样（结构）、有什么脾气（性质）、会变成什么（转化）、能干什么用（应用）。一个意思，换成人话。

第3步一次完整的化学研究长什么样：青蒿素之旅

历史和定义都过完了，现在看一场"实况"——教材用图1-1-12（p7）讲了青蒿素从发现到全球应用的完整故事。它就是本节的"例题"：把第2步的三个特征全用了一遍。先看路线：

七个节点一条线：从"病"到"药"到"全球救命"——这就是化学研究干活的全流程

这场旅程里藏着第2步那三个特征的"实战版"：

  • 提取有效成分、获得晶体——在宏观层面拿到那个"管用的物质"；
  • 确定组成（C₁₅H₂₂O₅）、测定结构（X射线衍射定原子位置）——钻到微观层面看它由什么原子构成、怎么排布，并用符号（分子式）表征出来；
  • 全合成、衍生药物——在不同层面创造物质：不光会提天然的了，还能自己造，还造出改良版。
看完这段，化学的"工作套路"你也能复述了：发现现象 → 提取有效成分 → 测组成定结构 → 合成与改造 → 应用。后面所有章节的实验探究，套路都是它的变体。

自编验算（标注：自编·非教材内容）：教材说"利用高分辨率质谱仪测得了青蒿素的相对分子质量"。这个数可以用分子式自己算——C₁₅H₂₂O₅ 的相对分子质量 = 15×12.011 + 22×1.008 + 5×15.999 = 282.34（sympy符号验算留痕随附件2）。质谱仪当年测出的就是这个量级。

⚡ 30秒自验 3

"确定组成"这一步把青蒿素写成了 C₁₅H₂₂O₅——这体现了三特征中的哪一个？"全合成"呢？

答完再看：C₁₅H₂₂O₅ → 以符号形式表征物质；全合成 → 在不同层面上创造物质。错位的回第2步三特征卡片对照。

第4步这门学问的边界在哪，未来去哪

探索空间：一张越来越大的网

现代化学的学科体系非常庞大：在原有的有机化学、无机化学、物理化学、分析化学、高分子化学之上，又长出许多新兴分支，并与材料、资源、能源、生态、环境、医药、生命、国防、信息技术等领域深度交叉融合（p8原文列举）。三个正在发生的前沿：

  • 微观操控：化学家已能在微观层面上操纵分子和原子，组装分子材料、分子器件和分子机器（教材图1-1-13的"分子齿轮"不是科幻图）；
  • 看清反应：我国化学家设计的"大连相干光源"——90%的仪器设备自主研发，是当今世界上唯一运行在极紫外波段的自由电子激光装置、世界上最亮的极紫外光源，能给分子、原子在化学反应中的过程"拍电影"（p8资料在线）；
  • 解决难题：我国化学家合成了水中超疏油的膜材料，油水混合物过膜时水自由通过、油被阻隔富集——油水分离这种全球性难题有了新武器（p9资料在线·超亲水+超疏油双功能复合体）。

往后看，化学将在资源能源开发、新型材料制造、环境监测治理、生命科学（分子层次上理解疾病、研制新药）、信息科学（光电子材料、传感与通信技术）上继续发力。教材给现代化学一个定位——"中心科学"（p9原话）：它与人类经济社会的各个领域都保持密切联系。你的未来也在这张网里：升学（化学、应用化学、化学工程与工艺、生物工程、药学、材料科学……）、职业（化学家、化学工程师、环境学家、药剂师、教师……）、生活（环保、家居装修、食品加工……处处是化学，p9交流研讨）。

⚠ 两个坑，进门前填平

坑1：把"化学产品有害"放大成"化学有害"。反过来用第2步的判断标准：化肥救人（图1-1-6）、青蒿素救命、膜材料治污——化学是中性工具，评判对象应是"某种物质的使用方式与剂量"，不是这门科学本身。

坑2：以为化学主要靠背。本节真正要记的只有三样（定义一句、五里程碑、三特征），而青蒿素之旅告诉你化学的日常是提取→测定→合成的探究活。从下一节起，你会大量碰到"设计实验、验证猜想"的推理题——背，只占很小一部分。

收口三句话带走 + 自测四连

① 化学是在原子、分子水平上研究物质的组成、结构、性质、转化及其应用的一门基础学科。
② 三特征：宏观微观两个角度认识 · 符号形式表征 · 不同层面创造。
③ 化学研究套路（青蒿素版）：发现 → 提取 → 测组成定结构 → 合成改造 → 应用。
✍ 自测四连

① 合上眼，把化学的定义一句话默出来（漏了"原子、分子水平"或五个研究对象哪个都不算过）。

② 反向配对：给年份 1661 / 1803 / 1869，报人名和成就。

③ 青蒿素"测定结构"用到了 X 射线衍射——它属于"实验与理论并重"里的哪一边？

④ 判断："化学只研究自然界里本来就有的物质。"对吗？

答完再看：① 见上方三句话第①句 ② 1661波义耳·元素概念／1803道尔顿·原子论／1869门捷列夫·周期律 ③ 实验这边（分析测试技术，教材p6） ④ 错——化学家已创造上亿种物质，大量是自然界原本不存在的新造物质（p5）。
