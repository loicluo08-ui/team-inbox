硫的转化：一张"价—类"地图走通硫的一家

化学 3.2 · 鲁科版《必修 第一册》第3章第2节 · 教材印刷页 p97–109 · 零基础首学版 v1.0（出品：并行搜索员C·队3席·1031）
火山喷发，熔岩喷涌、浓烟滚滚——这不仅释放出巨大的能量，还产生了许多含硫元素的气体，火山口上甚至能找到硫单质（p97 图3-2-1"火山口的硫单质"）。硫是人类最早认识的化学元素之一：古代炼丹家常拿硫单质及含硫化合物做实验，我国古代四大发明之一的黑火药，主要成分里就有它（p97 引言）。本节的四连问就在 p97 联想·质疑里：自然界中还有哪些含硫化合物？它们怎样产生、以什么形态存在？人们怎样把它们转化成所需物质？使用中遇到了哪些问题、又如何解决？我们把 2.3 节装好的"价态眼镜"戴起来，从 −2 价一路走到 +6 价，把硫的一家走个遍。
读完这节你能：
  • 用"价—类"二维图给含硫物质"定位"（−2、0、+4、+6 四种价态 × 氢化物、单质、氧化物、酸、盐五类），并说出自然界中硫循环的大致路径；
  • 说出硫单质的物理性质与两种同素异形体（正交硫、单斜硫），写出硫与铁、硫与氧气反应的化学方程式并指出化合价变化；
  • 总结二氧化硫的四类性质（还原性、氧化性、酸性氧化物通性、漂白性）与浓硫酸的三大特性（强氧化性、吸水性、脱水性），会用"⇌"书写可逆反应；
  • 说出硫酸型酸雨的成因、危害与防治思路，看懂接触法制硫酸的生产流程（p104 图3-2-12）。
    • 开讲前的三件预备（都没有就先补这三件）：

    ① 化合价怎么标（2.3 节工具）：单质中元素化合价为 0；化合物里 H 通常 +1、O 通常 −2。自己动手：H2S 里 S 是 −2，SO2 里 S 是 +4，SO3、H2SO4、Na2SO4 里 S 都是 +6——这四种价态正是本节地图的纵轴。

    ② 价态规律（2.3 节 p69–70 已学）：元素处于最高价态只可能表现氧化性、最低价态只可能表现还原性、中间价态两可。硫的 −2 / 0 / +4 / +6 四个价态把三种情形全占了——本节就是这套规律的实战演练场。

    ③ 酸性氧化物（初中 CO2 类比）：与水化合成酸、与碱反应成盐和水。SO2 是"硫版 CO2"，但它比 CO2 多两样东西：漂白性和还原性——学的时候留个心眼。

    第①站自然界中的硫：四个价态一张图（p97–98）

    硫元素广泛存在于自然界中：海洋、大气和地壳中乃至动植物体内，都含有硫元素（p97）。它的"旅行路线"是这样转圈的——火山喷发时，部分硫元素转化成硫化氢气体，部分转化成二氧化硫和三氧化硫气体；SO2 在大气中存在时间比较短，当有氧气、水蒸气、阳光等存在时会被氧化成 SO3；SO2 和 SO3 溶于水，分别生成亚硫酸和硫酸；一些微生物又会把部分亚硫酸和硫酸转化成硫单质或硫化氢（p97 原文口径，微生物这一手别漏）。

    地下与地表还各有一批含硫矿物（p98 图3-2-2）：火山喷发时，熔融态的含硫物质与含铁、砷、汞等元素的物质反应形成矿物——黄铁矿（FeS2）、雄黄（As4S4）、雌黄（As2S3）、辰砂（HgS）；暴露于地球表面的多种含硫矿物，受空气中氧气和水蒸气等的作用，转化成新的物质——如石膏（CaSO4·2H2O）、芒硝（Na2SO4·10H2O）等。

    2S（−2价） SO2、SO3（+4/+6） H2SO3、H2SO4 S、H2S（微生物转化） 溶于水 部分被微生物 转化为 S / H2S 地下：与 Fe、As、Hg 等化合 黄铁矿FeS2·雄黄As4S4·雌黄As2S3·辰砂HgS 地表：受 O2 和水蒸气作用 石膏 CaSO4·2H2O · 芒硝 Na2SO4·10H2O 四种价态 都在自然循环里

    这张图在说什么：自然界含硫物质在 −2、0、+4、+6 四个价态之间循环流转（p97–98 文字口径 + 图3-2-2 结构简画，仅示意不含数据）。

    把"旅行路线"上的物质全列出来：硫化氢、硫单质、二氧化硫、三氧化硫、亚硫酸、硫酸、硫酸钠等。怎么给这一大家子建户口本？教材用两个视角（p98）：从物质类别看，包括氢化物、单质、氧化物、酸、盐等；从硫元素化合价看，包括 −2、0、+4、+6 价。两个视角一交叉，就是下面这张"价—类"二维图（图3-2-3）——硫及其化合物之间可以相互转化。

    3 H2SO4 Na2SO4 SO2 H2SO3 Na2SO3 S H2S 最高价 +6：只可能氧化性 中间价 0 / +4：两可 最低价 −2：只可能还原性

    验一验①（30秒）：把 Na2SO3 和 Na2SO4 放进价—类二维图，各落在哪个格？
    都落在"盐"列：Na2SO3 中 S 为 +4（与 SO2、H2SO3 同排）；Na2SO4 中 S 为 +6（与 SO3、H2SO4 同排）——p98 图3-2-3 原图已把这两个盐画出，自验目的是让你把"同价态同排"刻进脑子。

    第②站认识硫单质：同素异形体与"两副面孔"（p99–100）

    教材先安排 观察·思考（p99"硫单质的性质"）：先预测硫单质会有哪些化学性质，再做三个小实验——【实验1】少量硫粉放入试管，观察颜色、状态，在酒精灯上加热观察现象；【实验2】研细的硫粉和铁粉按一定比例混合均匀，放在石棉网上堆成条状，用灼热的玻璃棒触及一端，当混合物呈红热状态时移开玻璃棒，观察发生的现象；【实验3】硫粉放入燃烧匙加热至熔化并燃烧后，迅速伸入盛满氧气的集气瓶（底部有少量水），观察发生的现象。观察记录表（实验编号/预测性质/实验现象/结论及化学方程式）在 p99 是空白留白，要自己填。

    硫单质（sulfur）俗称硫黄。通常状况下，它是一种黄色或淡黄色的固体；很脆，易研成粉末；不溶于水，微溶于酒精，易溶于二硫化碳（CS2）；熔点和沸点都不高（p100）。
    由同一种元素组成的性质不同的几种单质，叫作该元素的同素异形体（allotrope）。同素异形体之间的性质差异，主要表现在物理性质上。正交硫和单斜硫是常见的硫元素的同素异形体（p100）：正交硫熔点 112.8 ℃、单斜硫熔点 119.3 ℃（图3-2-7）。

    化学性质上，硫单质"两副面孔"（p100 原文口径）：能与金属铁反应生成硫化亚铁（FeS），体现了硫单质的氧化性；能与氧气反应生成二氧化硫，体现了硫单质的还原性——0 价的硫，降价做氧化剂、升价做还原剂，两头都能当。

    Fe + S Δ FeS　　（S：0 → −2，氧化剂）
    S + O2 点燃 SO2　　（S：0 → +4，还原剂）

    硫黄的用途（p100）：主要用于制造硫酸、化肥、火柴及杀虫剂等——注意第一项就是硫酸，为第③站的工业路线埋下伏笔。

    验一验②（30秒·实验2 现象与结论）：硫粉与铁粉混合物红热后移开玻璃棒，为什么还能继续红热下去？
    红热引发了 Fe + S Δ FeS 的反应，该反应放热（教材 p99 未明写"放热"，"呈红热状态时移开玻璃棒"仍持续反应为现象侧描述），维持反应自行进行下去；产物 FeS 中 S 为 −2 价，硫做氧化剂（结论及方程式一栏的填写口径，现象侧描述按 p99 实验记录表自填并标注）。
    坑点1：同素异形体必须是"单质对单质"。由同一种元素组成的性质不同的几种单质才互称同素异形体——正交硫与单斜硫算（熔点 112.8 ℃ / 119.3 ℃，差异主要在物理性质，p100）；O2 与 O3、金刚石与石墨也是同类关系（初中已知，自编类比注记）。但"硫单质"和"SO2"绝不能算——后者是化合物；同一元素的不同同位素更不是——那是原子层面的概念。三个"像"要分清：同素异形体（单质 vs 单质）、同位素（原子 vs 原子）、同分异构体（有机化学再会）。

    第③站实验室里研究不同价态硫元素之间的转化：SO2 与浓硫酸（p100–104）

    先拿到"探究说明书"（p100–101）

    本节安排了活动·探究（学生必做实验）"不同价态硫元素之间的转化"（p100）：实验目的是选取含有硫元素的物质，通过实验探究 0、+4、+6 这三种价态硫元素之间的相互转化。实验用品两栏：试剂有 SO2 水溶液、Na2SO3 溶液、浓硫酸、Na2S 溶液、稀硫酸、NaOH 溶液、酸性 KMnO4 溶液、氯水、KI 溶液、淀粉溶液、品红溶液、铜片；仪器有酒精灯、玻璃管、橡胶塞、导气管、试管夹、试管、胶头滴管、铁架台等。安全提示三条（p100 原框）：氯水、酸性 KMnO4 溶液、浓硫酸等具有腐蚀性，取用时应避免沾到皮肤或衣服上；二氧化硫气体有毒，应避免将其释放到空气中；涉及浓硫酸的实验由教师辅助学生完成。

    方法导引（p101）：探究不同价态硫元素之间相互转化的思路。①选物质——要选择含有不同价态硫元素的物质，如含 +4 价硫元素的物质可以选择二氧化硫或亚硫酸钠；②找对手——实现不同价态硫元素之间的相互转化，依据的是氧化还原理论，需要寻找合适的氧化剂或还原剂；③留证据——提供表明相应转化实际发生的证据。
    含有不同价态硫元素的物质之间转化时，所发生的反应属于氧化还原反应。当硫元素处于中间价态时，含有这种价态硫元素的物质（如硫黄、二氧化硫、亚硫酸钠），既具有氧化性又具有还原性；当硫元素处于最高价态时，含有这种价态硫元素的物质（如三氧化硫、浓硫酸），只具有氧化性；当硫元素处于最低价态时，含有这种价态硫元素的物质（如硫化氢、硫化钠），只具有还原性（p101 原文口径）。

    二氧化硫（SO2，sulfur dioxide）：中间价态的"多面手"（p102）

    SO2 是一种无色、有刺激性气味的有毒气体，易溶于水（p102）。它的四类性质按"价态账"分家——

    性质一：还原性。在催化剂和加热的条件下能被氧气氧化（p102）：

    2SO2 + O2 催化剂·Δ ⇌ 2SO3　　（S：+4 → +6）
    可逆反应（p102 原框）：在相同条件下能同时向正、反两个方向进行的反应称为可逆反应。二氧化硫与氧气的反应以及前面学过的氯气与水的反应都属于可逆反应。在可逆反应的化学方程式中用 "⇌" 代替 "="。书写要点：同页另一反应 SO2 + H2O ⇌ H2SO3 也用可逆号——"同时、双向、相同条件"三要素缺一不可。

    性质二：氧化性。能与硫化氢（或硫化钠）反应，体现了二氧化硫的氧化性及硫化氢（或硫化钠）的还原性（p102）：

    SO2 + 2H2S ═══ 3S↓ + 2H2O　　（S：+4 → 0；−2 → 0，"价态归中"，图3-2-8 溶液变淡黄色浑浊）

    性质三：酸性氧化物的一般性质（p102）：与水反应生成亚硫酸、与 NaOH 溶液反应生成亚硫酸钠和水——

    SO2 + H2O ⇌ H2SO3　　SO2 + 2OH− ═══ SO32− + H2O

    性质四：漂白性。二氧化硫具有漂白性，能使品红等有色物质褪色；但用二氧化硫漂白过的有色物质，在一定条件下会恢复原来的颜色（p102，图3-2-9：品红溶液→通入二氧化硫→褪色→加热→红色恢复）。

    用途链接（p102 末段）：二氧化硫是一种食品添加剂。我国《食品安全国家标准 食品添加剂使用标准》规定了二氧化硫作为漂白剂、防腐剂、抗氧化剂的使用范围、使用限量和残留量——"漂白性"落到生产里的正面用场。
    验一验③（30秒）：SO2 与 H2S 反应里，谁做氧化剂、谁做还原剂？转移几个电子？
    SO2 中 S +4→0 得 2e−，做氧化剂；2 个 H2S 中 S 各 −2→0 共失 2e−，做还原剂（0 价 S 都是还原产物）。同一反应里 +4 和 −2 向中间价态 0 靠拢——教材把这类反应叫"价态归中"没有明说，此归纳为自编注记，记住现象与电子账即可（p102 原式）。

    浓硫酸：最高价态的"强氧化剂"（p103）

    硫酸（H2SO4，sulfuric acid）中的硫元素处于最高价态。浓硫酸能与许多物质发生氧化还原反应，是常见的氧化剂。例如，在加热时浓硫酸可与铜、木炭等单质发生反应（p103）：

    2H2SO4(浓) + Cu Δ CuSO4 + SO2↑ + 2H2O　　（Cu：0→+2；S：+6→+4，图3-2-10 品红溶液褪色验证 SO2）
    2H2SO4(浓) + C Δ 2SO2↑ + CO2↑ + 2H2O　　（C：0→+4；S：+6→+4）

    两个方程式里的 2H2SO4 都只有一半被还原：CuSO4、盐里的 SO42− 那一份没变价——电子账别把两份都算成降价。

    钝化（p103）：在常温下，浓硫酸与铁、铝接触时，会使金属表面生成一层致密的氧化物薄膜而钝化，阻止了内部的金属继续与硫酸发生反应。因此，冷的浓硫酸可以用铁质或铝质容器储存。
    脱水性（p103）：浓硫酸具有脱水性，能按水的元素组成质量比脱去纸屑、棉花所含有机化合物中的氢、氧元素，使这些有机化合物炭化（图3-2-11：蔗糖加入浓硫酸后炭化蓬松成黑"面包"）。
    吸水性（p103）：浓硫酸还具有吸水性，能吸收气体中的水分，在实验室里常用于干燥不与它发生反应的气体。
    验一验④（30秒·辨析）：浓硫酸使蔗糖变成黑色多孔固体，体现的是吸水性还是脱水性？用它干燥 H2 气体呢？
    蔗糖炭化是脱水性（把有机物里的 H、O 按水的组成比"拆走"，生成了新的水分子——H、O 原来并不以水形式存在）；干燥气体是吸水性（吸收现成的水蒸气）。一个"造水"，一个"收水"（p103 两条定义对照）。
    坑点2："钝化"不是"不反应"，"冷的"三个字是前提。常温下浓硫酸把 Fe、Al 表面氧化成致密氧化物薄膜挡住内部（p103），所以冷的浓硫酸可用铁质或铝质容器储存；可一旦加热，膜挡不住，反应照常进行——铜与浓硫酸的反应就要加热。同款钝化后面学浓硝酸时还会再遇到。另外吸水性干燥气体有排他条款："不与它发生反应的气体"才行（p103），碱性气体 NH3 就不能用它干燥（NH3 是 3.3 节主角，先记一笔）。

    硫酸的用途与工业制法（p104）

    硫酸既是化学实验室中的重要试剂，也是重要的化工原料：工业上常用于制造化肥、农药、炸药、染料等，还用于石油精炼、金属加工等（p104）。含有不同价态硫元素的物质之间的转化在工农业生产中有着重要的应用：工业上常以氧气为氧化剂把硫单质或含硫矿物中的硫转化为二氧化硫，再将二氧化硫转化为三氧化硫，最后制得硫酸（p104）——这正是"价—类图"上 +4 → +6 的两连升。

    化学与技术：硫酸工业生产的演变（p104）。我国制造硫酸的历史可以追溯到7 世纪，炼丹家曾利用胆矾（CuSO4·5H2O）来制备硫酸（先除去胆矾中的水，再使之分解产生气体，溶于水制得硫酸）；国外早期的炼金士曾用绿矾（FeSO4·7H2O）。17 世纪，炼金士菲伏尔（N.Fevre）和药剂师勒梅里（N.Lemery）采用类似钟罩的装置点燃硫黄和硝石的混合物制得硫酸。1740 年，英国人瓦尔特（J.Ward）建立了人类历史上第一座生产硫酸的工厂。1831 年，英国人菲利浦（P.Philips）把硫黄装入内部镶有铂催化剂的瓷管里加热并通入足量空气，再将生成的三氧化硫溶于水制得硫酸——这就是接触法制硫酸的雏形。后来以钒代替铂为催化剂、用氧气代替空气等使生产效率极大提高；现代硫酸工业还注重原料来源多样化，如以煤、石油加工过程中产生的含硫化合物以及金属冶炼过程中产生的炉气（含二氧化硫）等为原料。
    2+O2 ⇌ 2SO3 400~500℃·常压 V2O5 做催化剂 用98.3%的浓硫酸吸收SO3：SO3+H2O═══H2SO4

    第④站酸雨及其防治：把价态工具用在真问题上（p105–106）

    工业生产和日常生活中要大量使用煤和石油等化石燃料。煤和石油中含有硫元素，燃烧时除了产生二氧化碳外还产生二氧化硫。硫的氧化物是形成酸雨的主要物质（p105）。排放到空气中的二氧化硫在氧气和水蒸气的共同作用下形成酸雾，随雨水降落就成为酸雨——这样形成的酸雨也常称硫酸型酸雨（p105）。教材给出两条转化路径（p105 原式）：

    路径A：2SO2 + O2 催化剂⇌ 2SO3，　SO3 + H2O ═══ H2SO4
    路径B：SO2 + H2O ⇌ H2SO3，　2H2SO3 + O2 ═══ 2H2SO4

    交流·研讨四问（p105）值得对着念一遍：①排放到大气中的二氧化硫是如何转化成硫酸的？请预测转化路径并说明依据；②酸雨有哪些危害？③如何防治酸雨——查找资料了解减少二氧化硫排放的具体措施并结合二氧化硫的性质分析；如何治理已酸化的湖泊和土壤？如何保护暴露在大气中的建筑？④谈谈科学、技术以及观念、法规在解决酸雨问题中的作用。

    危害清单（p105 原文口径）：酸雨会使湖泊的水质变酸，导致水生生物死亡；酸雨浸渍土壤，会使土壤变得贫瘠；长期的酸雨侵蚀会造成森林大面积死亡；酸雨腐蚀建筑，会使建筑变得面目全非；酸雨对人体健康也有直接影响——酸雨渗入地下会导致地下水中的重金属元素含量增加，饮用这样的水会危害人体健康（图3-2-13 被酸雨侵蚀的树木和雕像）。

    防治思路（p106 原文口径）：首先要从消除污染源着手——改变能源结构，开发利用氢能、风能、太阳能等清洁能源，从根本上解决问题；其次要从实际情况出发，对酸性物质的排放加以控制——利用物理方法和化学方法对含硫燃料预先进行脱硫，对废气中的二氧化硫进行回收处理等；为了防治酸雨，还需要健全法律法规，严格规定污染物的排放标准，提高人们的环境保护意识等（图3-2-14 太阳能和风能互补发电、图3-2-15 飞机向酸化的湖中撒石灰石粉——治理已酸化湖泊的一个实例）。

    验一验⑤（30秒·烟气脱硫）：教材 p109 练习11(3) 配图给出废气脱硫流程：煤燃烧排放的废气（O2、CO2、N2、SO2）与空气一起通入，加入 CaCO3 + H2O 浆状物，主要化学反应为 SO2→CaSO3、CaSO3→CaSO4，产物之一是石膏。写出对应的化学方程式。
    SO2 + CaCO3 ═══ CaSO3 + CO2；2CaSO3 + O2 ═══ 2CaSO4（教材流程图只给"SO2→CaSO3→CaSO4"转化箭头未写方程式，此两式为答案侧自编补写并已用机器配平验证；脱硫后气体 N2、CO2、O2 排放，p109 第11题图）。
