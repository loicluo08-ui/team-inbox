# 附件四 通读卡点记录 · 化学3.3氮的循环（队3席B线·1031）
读者层自测（模拟零基础通读·3分钟卡点）：
1. 卡点：为什么氮气"稳定"却既能被氧化又能被还原？→ 已在第1步用p114原句回应（条件苛刻=活泼性弱，非"不能反应"），并落误会一。
2. 卡点：NO/NO2到底哪个能与水反应？→ 第3步三连式+身份证三对照（NO难溶不反应/NO2易溶且歧义反应生成HNO3+NO）。
3. 卡点：喷泉实验为什么能喷？→ 考位锚+练习1(3)：极易溶于水（1:700）致瓶内压强骤降；与水反应生成碱性物质使酚酞变红两性质各司其职。
4. 卡点：浓硫酸干燥NH3行不行？→ 练习3(3)：NH3被浓硫酸吸收（成盐），碱石灰才行——与本件练习要点C项解析互证。
5. 卡点：硝酸"只具氧化性"还有酸的通性吗？→ 第5步末句p120原句：还能与碱中和、与碱性氧化物/某些盐复分解——氧化性是"额外性格"不是"唯一性格"。
6. 卡点：反硝化电子数为什么是5NA？→ 练习要点5③：N从+5降到0，1mol HNO3→(1/2)mol N2转移5mol电子。
通读结论：六站链路（地图→固氮→闪电链→氨铵→硝酸→环境收口）无断点；术语首现均有定义或括注。
