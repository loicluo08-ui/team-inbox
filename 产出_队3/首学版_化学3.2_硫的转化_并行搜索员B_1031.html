硫的转化：一条"−2→0→+4→+6"价态阶梯上的变身链

化学 3.2 · 第3章 物质的性质与转化（鲁科版《普通高中教科书·化学 必修 第一册》·山东科学技术出版社·正文 p97–109 · 影印图103–115）

📍 本件属于第3章"物质的性质与转化"第二节，前面已学：3.1铁的多样性（价-类二维图·双角度预测法·KSCN显色）。本节把3.1练熟的"类别+价态"双把尺子原样搬到硫身上——套路同款，元素换人。

看教材p97：硫是重要的非金属元素，也是人类最早认识的化学元素之一。古代炼丹家常拿它炼丹，它还是我国古代四大发明之一——黑火药的主要成分。火山喷发时熔岩喷涌、浓烟滚滚，火山口甚至能直接捡到黄色的硫单质（图3-2-1）——这是自然界中硫单质及含硫化合物的来源之一。

本节干一件事：跟着硫元素的四种价态（−2、0、+4、+6）走一遍它的"变身链"——从火山口的硫黄，到刺鼻的二氧化硫，到工业命脉硫酸，再到让森林枯死的酸雨。教材p98一句总纲：硫及其化合物之间可以相互转化——转化靠什么？同价态走复分解，不同价态走氧化还原（3.1的老规矩）。

② 说清硫单质的物理性质与两条化学性质（对铁显氧化性、对氧气显还原性），认识同素异形体；

③ 掌握SO₂三张面孔（酸性氧化物通性／氧化还原两性／漂白性）与浓硫酸三大特性（强氧化性、脱水性、吸水性），并知道"可逆反应"新记号⇌；

④ 讲出硫酸型酸雨的成因链条与"源头减污—过程脱硫—法律标准"三层防治思路（教材p106概括·整合）。

先拆掉三个旧印象

误会一："硫溶于水"。p100原句：硫单质不溶于水，微溶于酒精，易溶于二硫化碳（CS₂）——所以课本实验刷试管里的硫，用CS₂不用水。

误会二："SO₂漂白＝氯水漂白，褪了就回不来"。两者机理不同：SO₂的漂白是与非色物质化合生成不稳定无色物，加热会恢复原色（图3-2-9品红三联实验：褪色→加热→复红）；而氯水/HClO的漂白是氧化破坏、不可逆。

误会三："浓硫酸什么气体都能干燥"。浓硫酸吸水性只对不与它反应的气体成立（p103原句）——氨气（碱性气体）会跟酸反应，不能用它干燥。

名词补齐 同素异形体（allotrope）：由同一种元素组成的性质不同的几种单质（p100定义）——正交硫（熔点112.8℃）与单斜硫（熔点119.3℃）就是硫的两种常见同素异形体（图3-2-7）。可逆反应：相同条件下能同时向正、逆两个方向进行的反应，方程式用⇌代替"="（p102蓝框）——SO₂与O₂的反应、前面学的氯气与水的反应都属于它。黄铁矿FeS₂：含硫矿物"家族成员"之一（另有雄黄As₄S₄、雌黄As₂S₃、辰砂HgS，图3-2-2）。

第1步 先给硫画"价-类二维地图"（p98）

3.1的双角度尺子直接抄：横轴物质类别（氢化物／单质／氧化物／酸／盐），纵轴硫元素化合价（−2／0／+4／+6）。教材图3-2-3标的代表物质：

  • −2价：H₂S（氢化物）——最低价，只能升，只具还原性；
  • 0价：S（单质）——中间价，可升可降，两性都有；
  • +4价：SO₂、H₂SO₃、Na₂SO₃——中间价，两性都有；
  • +6价：SO₃、H₂SO₄、Na₂SO₄——最高价，只能降，只具氧化性（浓硫酸）。

p101给这条规律的标准表述：当硫元素处于中间价态时，含有这种价态硫元素的物质（如硫黄、二氧化硫、亚硫酸钠），既具有氧化性又具有还原性；处于最高价态（如三氧化硫、浓硫酸），只具有氧化性；处于最低价态（如硫化氢、硫化钠），只具有还原性。这就是全节的"方向盘"。

纵轴价态、横轴类别；金色箭头=升价（被氧化），绿色虚线=降价（被还原）。图A（aria-label：硫价类二维图，负二价硫化氢、零价硫单质、正四价二氧化硫亚硫酸亚硫酸钠、正六价三氧化硫硫酸硫酸钠）
自然界清册 p98图3-2-2把这条链放进地球：火山喷发（地下）→含硫物质与铁、砷、汞等元素化合成矿物（黄铁矿FeS₂、雄黄As₄S₄、雌黄As₂S₃、辰砂HgS）→暴露地表受空气氧气和水蒸气作用→石膏（CaSO₄·2H₂O）、芒硝（Na₂SO₄·10H₂O）等新物质；火山喷发（地表）→H₂S、SO₂、SO₃入大气→溶于水生成H₂SO₃、H₂SO₄→部分被微生物转化回S或H₂S——硫的地球版"变身循环"。

第2步 硫单质：黄色固体的一氧化一还原（p99–100）

观察·思考（p99）三个实验：实验1硫粉在试管中加热——观察颜色状态与熔化（淡黄色固体、受热熔化，图3-2-4）；实验2硫粉与铁粉按比例混合堆在石棉网上，灼热玻璃棒触及一端，红热后移开——反应自行持续（图3-2-5）；实验3燃烧匙中硫粉加热至熔化燃烧，迅速伸入盛O₂的集气瓶（底部少量水）——明亮的蓝紫色火焰（图3-2-6）。

两条化学性质（p100原句）：

① 氧化性：硫单质能与金属铁反应生成硫化亚铁（FeS）——S：0→−2，得电子，做氧化剂；

Fe + S Δ FeS

② 还原性：硫单质能与氧气反应生成二氧化硫——S：0→+4，失电子，做还原剂；

S + O₂ 点燃 SO₂

卡住了？换个说法 把0价硫想成"住中间楼层"：遇上不嫌弃电子的金属铁，硫把手里的"电子空位"租出去收电子（降价·氧化性）；遇上更凶的氧气，硫把电子交出去（升价·还原性）。上下楼都行=中间价态两性——和3.1的Fe²⁺一个道理。
用途锚点 p100：硫黄主要用于制造硫酸、化肥、火柴及杀虫剂等。结合p97：黑火药的主要成分（我国古代四大发明之一）。

第3步 SO₂：一张脸三副表情（p102）

物理性质（p102原句）：二氧化硫（SO₂，sulfur dioxide）是一种无色、有刺激性气味的有毒气体，易溶于水。

表情一·酸性氧化物通性：与水反应生成亚硫酸、与NaOH溶液反应生成亚硫酸钠和水——

SO₂ + H₂O ⇌ H₂SO₃　　SO₂ + 2OH⁻ = SO₃²⁻ + H₂O

表情二·氧化还原两性：在催化剂和加热条件下能被氧气氧化（+4→+6·还原性）；能与硫化氢（或硫化钠）反应（+4→0·氧化性）——

2SO₂ + O₂ 催化剂·Δ·⇌ 2SO₃　　SO₂ + 2H₂S = 3S↓ + 2H₂O

第二个式子（图3-2-8：H₂S溶液通入SO₂变淡黄浑浊）里，SO₂中+4价硫降到0价，H₂S中−2价硫升到0价——归中反应，硫"劫富济贫"两头拉到0价。

表情三·漂白性：SO₂能使品红等有色物质褪色，但漂白过的有色物质在一定条件下会恢复原来的颜色（图3-2-9：品红溶液→通入SO₂→无色→加热→恢复红色）。这与氯水的氧化漂白（不可逆）本质不同。

图A2（aria-label：硫家族变身链——硫化氢负二价最低，硫单质零价，二氧化硫正四价，三氧化硫与硫酸正六价最高；金色箭头表示升价转化）
图B（aria-label：品红溶液通入二氧化硫褪色，加热后恢复红色的可逆漂白三联示意）
本步钥匙 SO₂三副表情的"根"全在+4价中间态：对上（+6）能升、对下（0/−2）能降→两性；与有色物化合→漂白（可逆）；与水/碱→酸性氧化物通性。做题先问一句：这一步硫是升了还是降了？
生活锚点 p102：二氧化硫是一种食品添加剂——我国《食品安全国家标准 食品添加剂使用标准》规定了它作为漂白剂、防腐剂、抗氧化剂的使用范围、使用限量和残留量。"又毒又上餐桌"不矛盾：限量即安全边界。

第4步 浓硫酸：最高价态的三件套（p103）

硫酸（H₂SO₄，sulfuric acid）中的硫元素处于最高价态（+6）。浓硫酸能与许多物质发生氧化还原反应，是常见的氧化剂。加热时浓硫酸可与铜、木炭等单质反应：

2H₂SO₄（浓）+ Cu Δ CuSO₄ + SO₂↑ + 2H₂O

2H₂SO₄（浓）+ C Δ 2SO₂↑ + CO₂↑ + 2H₂O

配平自检（sympy验点同款）：Cu式——Cu失2e（0→+2），S得2e（+6→+4）×1，电子守恒；C式——C失4e（0→+4），S得2e×2，电子守恒。两个式子里的浓硫酸都只"降了一部分"：2分子浓硫酸只有1个硫降价、另1个硫价态不变只起酸的作用——浓硫酸既当氧化剂又当酸。图3-2-10的实验里，品红溶液褪色就是SO₂生成的铁证。

特性一·脱水性：能按水的元素组成质量比脱去纸屑、棉花所含有机化合物中的氢、氧元素，使这些有机化合物炭化（图3-2-11蔗糖变"黑面包"）。

特性二·吸水性：能吸收气体中的水分，实验室常用于干燥不与它发生反应的气体。

特性三·钝化：常温下，浓硫酸与铁、铝接触时，会使金属表面生成一层致密的氧化物薄膜而钝化，阻止内部金属继续反应——因此冷的浓硫酸可以用铁质或铝质容器储存（p103原句）。

易错点 ①"钝化"不是"不反应"，是反应生成了保护膜后停止——加热条件下铁铝照样与浓硫酸持续反应；②脱水性≠吸水性：脱水是把有机物里的H、O"按水的比例抽走"（化学变化·炭化），吸水是吸收现成的水分子（物理过程为主·做干燥剂）；③浓硫酸与铜反应不生成氢气（p107题5A就是考这个），生成的是SO₂。

第5步 实验室怎么研究转化＋工业怎么规模化（p100–104）

活动·探究（学生必做实验）：不同价态硫元素之间的转化（p100–101）

实验目的：选取含有硫元素的物质，通过实验探究0、+4、+6三种价态硫元素之间的相互转化。实验用品（p100原单）：SO₂水溶液、Na₂SO₃溶液、浓硫酸、Na₂S溶液、稀硫酸、NaOH溶液、酸性KMnO₄溶液、氯水、KI溶液、淀粉溶液、品红溶液、铜片；酒精灯、玻璃管、橡胶塞、导气管、试管夹、试管、胶头滴管、铁架台等。安全提示三条：氯水、酸性KMnO₄溶液、浓硫酸等具有腐蚀性，取用避免沾到皮肤或衣服；SO₂气体有毒，应避免将其释放到空气中；涉及浓硫酸的实验由教师辅助学生完成。

方法导引（p101蓝框·三步法）：①选择含不同价态硫元素的物质（如+4价硫可选二氧化硫或亚硫酸钠）②实现不同价态硫元素之间的相互转化，依据的是氧化还原理论，需要寻找合适的氧化剂或还原剂 ③提供表明相应转化实际发生的证据。

卡住了？换个说法 这套"三步法"=点菜（选原料）→配对（氧化剂降它／还原剂升它）→验货（现象当证据）。例如"+4→+6"：给Na₂SO₃配氧化剂氯水，"验货"看品红或褪色速率变化；"+4→0"：给SO₂配H₂S，验货看淡黄沉淀。

化学与技术：接触法制硫酸（p104）

工业上常以氧气为氧化剂把硫单质或含硫矿物中的硫转化为二氧化硫，再将二氧化硫转化为三氧化硫，最后制得硫酸——三步链条的工业化版本就是接触法（图3-2-12）：硫黄或黄铁矿矿石＋空气→生成二氧化硫→气体混合物通过静电除尘净化→混合气体发生反应 2SO₂ + O₂ ⇌ 2SO₃（条件：400～500℃、常压、V₂O₅做催化剂）→用98.3%的浓硫酸吸收三氧化硫（SO₃+H₂O=H₂SO₄，直接用水吸收易成酸雾，故用浓硫酸）。

图C（aria-label：接触法制硫酸流程——硫黄或黄铁矿与空气生成二氧化硫，静电除尘净化，四百至五百摄氏度常压五氧化二钒催化生成三氧化硫，用百分之九十八点三浓硫酸吸收）
史清册 p104"化学与技术·硫酸工业生产的演变"：我国制造硫酸的历史可追溯到7世纪，炼丹家曾利用胆矾（CuSO₄·5H₂O）制备硫酸；国外早期炼金士曾用绿矾（FeSO₄·7H₂O）；1740年英国人瓦尔特（J.Ward）建立人类历史上第一座生产硫酸的工厂；1831年英国人菲利浦（P.Philips）用铂催化剂瓷管创接触法雏形，后以钒代替铂、用氧气代替空气使效率极大提高。

第6步 酸雨及其防治：变身链的"事故现场"（p105–106）

成因链（p105原思路）：工业生产和日常生活中大量使用煤和石油等化石燃料→煤和石油中含有硫元素，燃烧时除了产生二氧化碳外还产生二氧化硫→硫的氧化物是形成酸雨的主要物质。排放到空气中的二氧化硫在氧气和水蒸气的共同作用下形成酸雾，随雨水降落就成为酸雨——这样形成的酸雨常称硫酸型酸雨。

2SO₂ + O₂ 催化剂·⇌ 2SO₃　　SO₃ + H₂O = H₂SO₄

SO₂ + H₂O ⇌ H₂SO₃　　2H₂SO₃ + O₂ = 2H₂SO₄

（p105蓝底原式·四式——两条路径殊途同归：都产出H₂SO₄。）

危害（p105）：酸雨会使湖泊的水质变酸，导致水生生物死亡；酸雨浸渍土壤，会使土壤变得贫瘠；长期的酸雨侵蚀会造成森林大面积死亡；酸雨腐蚀建筑，会使建筑变得面目全非；酸雨对人体健康也有直接影响，如酸雨渗入地下会导致地下水中的重金属元素含量增加（图3-2-13被酸雨侵蚀的树木和雕像）。

防治三层（p106原思路）：①源头——消除污染源，改变能源结构，开发利用氢能、风能、太阳能等清洁能源，从根本上解决问题；②过程——对酸性物质的排放加以控制，利用物理方法和化学方法对含硫燃料预先进行脱硫，对废气中的二氧化硫进行回收处理（p109第11题图的脱硫流程：浆状CaCO₃+H₂O吸收废气中SO₂→CaSO₃→氧化成CaSO₄石膏）；③制度——健全法律法规，严格规定污染物的排放标准，提高人们的环境保护意识。

考位锚 高考考向一①SO₂性质综合题——三副表情连考：使酸性KMnO₄溶液褪色考的是还原性（不是漂白性）、使品红褪色考漂白性（可逆）、使澄清石灰水变浑浊考酸性氧化物；题8族"SO₂与Cl₂共同作用"考归中反应（SO₂+Cl₂+2H₂O=H₂SO₄+2HCl，两者同时失效·漂白不增强）。高考考向二②工业与环保流程题——接触法三条件（400～500℃/常压/V₂O₅）、98.3%浓硫酸吸收、钙基脱硫（CaCO₃浆液→CaSO₃→CaSO₄石膏资源化）与黄铁矿计算（p109第12题：4FeS₂+11O₂高温2Fe₂O₃+8SO₂·硫损失为零时1吨含杂质25%的矿石可制98%浓硫酸1.25吨）。
