氧化还原反应：给化学反应装上一副"电子眼"

化学 2.3 · 鲁科版《必修 第一册》第2章第3节 · 教材印刷页 p66–75 · 零基础首学版 v1.0（出品：并行搜索员C·队3席·1031）
燃烧、冶炼金属，这些反应人类用了几千年（p66 引言）。初中我们戴着"得氧、失氧"的眼镜看过它们；2.1 节我们按物质类别给反应分了类；2.2 节又钻进水里看了离子怎么反应。可是有一幕始终解释不清：把铁丝插进蓝色的 CuSO₄ 溶液，红色的"铜树"长出来（p66 图2-3-1）——这个反应既不属于复分解，也谈不上"得氧失氧"，它凭什么和燃烧是一家人？本节换一副新眼镜：盯住化合价。只要化合价有升有降，背后就一定藏着电子的转移——这才是这类反应共同的底牌。
读完这节你能：
  • 用"有没有元素化合价变化"判断一个反应是不是氧化还原反应，并指出氧化反应、还原反应各在哪一侧；
  • 用双线桥、单线桥两种方式标出电子转移的方向和数目，说清"化合价升降"与"电子得失"的对应；
  • 给反应物贴上氧化剂 / 还原剂标签，并按"高价态可能氧化、低价态可能还原"预测物质性质；
  • 说出氧化还原反应的三大应用：研究物质性质、实现物质转化、获得能量。
    • 开讲前的三件预备（都没有就先补这三件）：

    ① 化合价标注怎么读：元素符号正上方的小数字是化合价——初中已学的记号。规定单质中元素化合价为 0；化合物里 O 通常 −2 价、H 通常 +1 价。p67 四个方程式上方标的 +2、−2 就是它。

    ② 两套记号别混：Cu2+（写在右上角）读"带两个单位正电荷的铜离子"；Cu 上方写 +2（正上方）读"铜的化合价是 +2"。同一个信息（一个铜相关微粒与两个电子的关系），离子符号用在 2.2 节的水里，化合价用在本节的方程式头上。

    ③ 对照组在 2.2 节：CuSO₄ + 2NaOH 这种复分解反应属于离子反应（p58），但其中没有任何元素化合价变化——p67 会拿它当"反面教材"。

    第①站四支试管两两对比：用"化合价"给反应分类

    教材开篇就摆出初中做过的四个关于铜的反应（p66 图2-3-1：铜丝在空气中加热、用氢气还原氧化铜、铁丝插入 CuSO₄ 溶液、向 CuSO₄ 溶液滴加 NaOH 溶液），并问：前三个和最后一个的特征有什么不同？把每个元素的化合价都标出来（p67），答案立刻现形：

    反应（p67 原式）化合价变化有无升降
    2Cu + O2 Δ 2CuOCu：0 → +2；O：0 → −2有
    H2 + CuO Δ Cu + H2OH：0 → +1；Cu：+2 → 0有
    Fe + CuSO4 ═══ Cu + FeSO4Fe：0 → +2；Cu：+2 → 0有
    CuSO4 + 2NaOH ═══ Cu(OH)2↓ + Na2SO4Cu 始终 +2，其余元素也全没动没有
    从反应过程中有无元素化合价变化的角度，可以将化学反应分为两大类。在反应过程中有元素化合价变化的化学反应称为氧化还原反应（redox reaction）（p67）。像 CuSO₄ 溶液与 NaOH 溶液的反应这样，没有元素化合价变化的化学反应则不属于氧化还原反应（p67）。

    在一个氧化还原反应内部还要再分家（p67）：反应物所含某种（或某些）元素化合价升高的反应，称为氧化反应（oxidation）；元素化合价降低的反应，称为还原反应（reduction）。例如氢气与氧化铜反应，氢元素化合价升高、发生氧化反应；铜元素化合价降低、发生还原反应。教材特别强调一句：氧化反应和还原反应这两个对立的过程相互依存，统一于一个氧化还原反应之中（p67）——有升必有降，像买卖双方，谁也离不开谁。

    验一验①（30秒）：CuSO₄ + 2NaOH 反应里，Cu、Na、S、O、H 五种元素的化合价从头到尾各是多少？
    Cu +2、Na +1、S +6、O −2、H +1，反应前后全部没变——所以它不是氧化还原反应（p67 原式上方标注）。

    第②站钻到底层：化合价为什么变？——电子在转移

    化合价升降只是表象，教材接着往下挖（p67 交流·研讨）：金属钠在氯气中剧烈燃烧生成氯化钠，这个反应是氧化还原反应吗？线索是微粒"变身"：氯气由氯分子构成，金属钠由钠原子构成，而氯化钠由 Na⁺ 和 Cl⁻ 构成——反应中钠原子变成了 Na⁺，氯原子变成了 Cl⁻。第二个线索更硬：用 p67 图2-3-2 的装置把铁片和碳棒插进 CuSO₄ 溶液接上电流表，铁与 CuSO₄ 反应时电流表指针发生偏转——反应体系里居然有定向的电子流动。

    教材给出两笔"电子账"（p68）：钠与氯气反应时，钠原子失去一个电子形成 Na⁺（化合价 0 → +1），氯原子得到一个电子形成 Cl⁻（0 → −1），Na⁺ 与 Cl⁻ 再通过静电作用形成氯化钠；铁与 CuSO₄ 溶液反应时，铁原子把电子转移给 Cu²⁺ 形成 Fe²⁺，Cu²⁺ 得到电子形成铜原子。

    研究表明，所有的氧化还原反应中都存在着电子转移，电子转移是氧化还原反应的实质。元素化合价的变化是电子转移的外在表现，可以通过分析反应中是否有元素的化合价发生变化来判断某个反应是否属于氧化还原反应（p68）。
    方法导引（p68）：怎么把电子账算清？某种元素的一个原子或离子失去电子，则该元素化合价升高，而且失去电子的数目与化合价升高的数值相等；得到电子则化合价降低，数目与降低的数值相等。对应关系（p68 原框）：
    元素化合价升高 ←→ 原子或离子失电子 ←→ 发生氧化反应
    元素化合价降低 ←→ 原子或离子得电子 ←→ 发生还原反应

    人们常用两种方式表示电子转移情况（p68 方法导引），以钠在氯气中燃烧为例——

    2 点燃 ═══ +1 −1 2NaCl 方式二：单线桥（箭头从失电子一方指向得电子一方，只标 2e⁻） 2e⁻ 2Na Cl2

    这张图在说什么：双线桥两条弧线各管一个元素（p68 方法导引图式）；单线桥一条弧线管"电子从谁流向谁"。数目 1e⁻×2 = 2 个钠原子各失 1 个电子，共 2 个。

    同一页的第二个例子（p68）：Fe + Cu2+ ═══ Fe2+ + Cu，双线桥标"化合价升高，失去 2e⁻×1，氧化反应 / 化合价降低，得到 2e⁻×1，还原反应"，单线桥标 2e⁻——一个铁原子失 2 个电子，正好被一个 Cu²⁺ 全收。

    验一验②（30秒·易错变形）：H₂ + CuO Δ Cu + H₂O（p67），生成 1 个 H₂O 转移几个电子？
    2 个。H₂ 里 2 个氢原子各失 1 个电子（合计 2e⁻，化合价 0→+1），CuO 里的 Cu 得 2 个电子（+2→0）。若按"×几"格式写就是"失去 1e⁻×2"——别写成"失去 2e⁻×2"，那等于 4 个电子。
    坑点1：双线桥的箭头"从价态数字出发、回到价态数字"，起点终点是同一种元素；单线桥箭头连接的是两种不同元素（失主→得主）。两座桥别画串门：把双线桥画成从 Na 直接连到 Cl 就错了——双线桥管"每个元素自己的升降"，跨元素的电子去向交给单线桥（p68 两种图式的分工）。另外"点燃""Δ"这类条件照旧写在等号上方，桥不占用它的位置。

    第③站氧化剂和还原剂：谁抢电子、谁给电子

    盯住化合价，还能给反应物"分工"（p69 交流·研讨先练三个）：以下反应中化合价升高的元素有哪些、降低的元素有哪些？（1）2Cu + O₂ Δ 2CuO；（2）H₂ + CuO Δ Cu + H₂O；（3）3CO + Fe₂O₃ 高温 2Fe + 3CO₂。据此教材给出定义：

    在氧化还原反应中，所含某种（或某些）元素化合价降低的反应物称为氧化剂（oxidizing agent）；所含某种（或某些）元素化合价升高的反应物称为还原剂（reducing agent）（p69）。

    两员大将的"行为特征"（p69 原文）：氧化剂具有氧化性，在反应中被还原，发生还原反应；还原剂具有还原性，在反应中被氧化，发生氧化反应。例如氢气与氧化铜的反应（p69 双线桥图）：氧化铜中的铜元素化合价降低，氧化铜是氧化剂；氢气中的氢元素化合价升高，氢气是还原剂。三个研讨反应的分工见下表（判定依据 p69 定义）：

    反应氧化剂（降价方）还原剂（升价方）
    2Cu + O₂ Δ 2CuOO₂（O：0→−2）Cu（0→+2）
    H₂ + CuO Δ Cu + H₂OCuO（Cu：+2→0）H₂（H：0→+1）
    3CO + Fe₂O₃ 高温 2Fe + 3CO₂Fe₂O₃（Fe：+3→0）CO（C：+2→+4）

    氧化还原反应还给认识物质添了新视角（p69 末段）：从氧化性、还原性的角度研究物质——当某物质所含元素处于较高价态时，元素有降低价态的趋势，该物质可能具有氧化性；处于较低价态时，元素有升高价态的趋势，该物质可能具有还原性。例：高锰酸钾中 Mn 为 +7 价，是锰的最高价态，高锰酸钾具有氧化性；碘化钾中 I 为 −1 价，是碘的最低价态，碘化钾具有还原性。实验表明，酸性 KMnO₄ 溶液与 KI 溶液能发生氧化还原反应：锰元素化合价降低，高锰酸钾做氧化剂；碘元素化合价升高，碘化钾做还原剂（p69，图2-3-3：溶液由紫色变成棕黄色，有碘单质和 Mn²⁺ 生成）。

    这张图在说什么：价态位置决定"升降余地"，升降余地决定可能表现的性质（p69 末段口径）——注意是"可能"，最终要靠实验验证。

    常见选手名单直接背（p70 原文口径）：

    阵营常见成员（p70）
    氧化剂氧气、氯气等活泼的非金属单质；硝酸、浓硫酸等含较高价态元素的含氧酸；高锰酸钾、氯酸钾、氯化铁等含较高价态元素的盐
    还原剂活泼的金属单质；碳单质、氢气等非金属单质；含较低价态元素的氧化物（如一氧化碳、二氧化硫）和盐（如碘化钾、亚硫酸钠、硫酸亚铁）
    验一验③（30秒·教材 p74 练习2 原题）：下列微粒中，只具有氧化性的是（　），只具有还原性的是（　）。A. Mg　B. Cu　C. Cu²⁺　D. H₂O₂　E. Cl⁻　F. Cl₂
    答案侧自编：只具氧化性选 C（Cu²⁺ 处最高价态，只能降价）；只具还原性选 E（Cl⁻ 处最低价态，只能升价）。D、F 处中间价态，两种可能都有——正是"可能"两个字的用武之地。
    坑点2："可能具有"不等于"一定具有"，中间价态最典型。过氧化氢（H₂O₂）中 O 为 −1 价（p70），介于 O₂ 的 0 价与 H₂O 的 −2 价之间，升、降两条路都开着——教材 p70 活动·探究让你自己设计实验去验证它是否具有氧化性或还原性，而不是直接给结论。别看到"含氧"就断言氧化性、看到"低价"就断言还原性——价态只给预测，实验才能定案（p71 方法导引口径）。

    第④站这副眼镜有什么用：三大应用

    应用一：研究物质的性质（p70–71）

    利用氧化还原反应，通过分析物质所含元素化合价的升降趋势，研究物质的还原性或氧化性（p70）。方法导引给了两步思路（p71 原框）：①先预测——所含某元素化合价有升高趋势→可能具还原性；有降低趋势→可能具氧化性；②再验证——预测某物质有氧化性，就找具有还原性的另一物质，通过实验检验两者能否发生氧化还原反应；预测有还原性，就找氧化性的"对手"来试。教材据此安排了学生实验（p70 活动·探究「探究物质的氧化性或还原性」）：5% H₂O₂ 溶液备着酸性 KMnO₄ 溶液、KI 溶液、淀粉溶液三样"探针"，自行设计表格记录实验内容、现象、结论。配套思考三问（p71）：从氧化还原角度归纳 H₂O₂ 的性质；证明氧化性或还原性的依据是什么；H₂O₂ 在催化剂作用下分解产生氧气（初中已知）是否属于氧化还原反应。

    验一验④（思考3·答案侧自编）：2H₂O₂ 催化剂 2H₂O + O₂↑ 属于氧化还原反应吗？
    属于。O 从 −1 价出发"分家"：一部分升到 0 价（O₂，被氧化），一部分降到 −2 价（H₂O，被还原）；H 始终 +1。同一元素的价态有升有降——这也解释了为什么 H₂O₂ 的氧化性、还原性都要靠实验说了算。

    强弱怎么比、环境怎么影响（p71）：物质的氧化性或还原性的强弱是由物质得失电子的能力决定的，借助氧化还原反应可以比较不同物质的强弱；环境条件也会影响强弱——例如我们常使用酸性条件下的 KMnO₄ 溶液做氧化剂（实际是其中的 MnO₄⁻ 参与反应），因为大部分含氧酸的酸根离子做氧化剂时，溶液酸性越强，含氧酸根离子的氧化性就越强。

    应用二：实现物质转化（p71–72）

    以金属冶炼为例，教材给出三种常见方法（p71 原文口径）：

    方法怎么干（p71）例子
    热还原法以碳、一氧化碳等作还原剂，加热条件下把金属氧化物还原为金属单质CO 还原铁的氧化物得金属铁
    金属置换法利用置换反应，以活泼金属为还原剂，把目标金属从其盐溶液中还原出来铁从 CuSO₄ 溶液中置换出铜
    电解法利用外加电源提供电子，使金属元素化合价降低电解氧化铝制备金属铝

    无论哪种冶炼方法，本质都一样（p71）：利用氧化还原反应中的电子转移，使被还原的化合物中金属元素的化合价从正价降低至 0 价，生成金属单质。高炉炼铁就是一连串热还原反应的接力（p74–75 练习5 配图）：

    这张图在说什么：高炉五个温度带各司一职——上面三个反应里 CO 是还原剂、铁逐级降价；下面两个反应再生 CO 并供热。任选两个反应都能标出电子转移（p75 练习5(2) 要求）。

    应用三：获得能量（p71–73）

    氧化还原反应不仅是获得物质的重要方式，也是获得能量的重要途径（p71）：利用可燃物作还原剂、选择合适的氧化剂与之反应获得热能；还可以利用氧化还原反应获得电能。教材在"化学与技术"栏目给了三个工业级实例（p72–73）：钛的冶炼两步走（金红石 TiO₂ 与碳、氯气高温反应制 TiCl₄；氩气氛围中加热，金属镁与 TiCl₄ 反应制金属钛）；硅的提纯三步走（碳还原 SiO₂ 得粗硅；粗硅与氯气生成 SiCl₄；净化后用氢气还原 SiCl₄ 得较纯硅）；燃料电池——氢气、天然气等燃料做电池负极反应物发生氧化反应，空气中氧气做正极反应物发生还原反应，连接外电路时电子从负极移向正极形成电流（p73）。

    本节还有一个"迁移·应用"重头戏（p72）：瑞典化学家舍勒（C.W.Scheele）最早发现氯气——他把浓盐酸和软锰矿（主要成分二氧化锰）混合加热，意外得到氯气，至今实验室还用这种方法制取：

    MnO2 + 4HCl(浓) Δ MnCl2 + Cl2↑ + 2H2O

    装置四件套（p72 图2-3-4）：分液漏斗装浓盐酸、圆底烧瓶装二氧化锰加热、集气瓶收集、尾气用 NaOH 溶液吸收。教材三连问值得认真做：（1）该反应属于氧化还原反应吗？氧化剂、还原剂各是谁（Mn：+4→+2 降价；Cl：−1→0 升价）；（2）写出 NaOH 吸收氯气的化学方程式、分析氯气表现的性质、想获纯净氯气装置还要怎么改进；（3）实验室也可用高锰酸钾与浓盐酸在常温下反应制氯气——预测产物、写出方程式（p72）。

    验一验⑤（30秒）：燃料电池工作时，电子从哪极流向哪极？负极发生的是氧化反应还是还原反应？
    电子从负极移向正极（p73 原文）；负极上燃料失电子，发生氧化反应——"负极氧化、正极还原"。

    收口：把这一节带走

    三句话（能默写才算读完）：

    ① 有元素化合价变化的反应=氧化还原反应；化合价升高的（半边）是氧化反应、降低的是还原反应，两者相互依存、统一于同一个反应（p67）。

    ② 化合价升降只是外表，电子转移才是实质：失电子数=升价数、得电子数=降价数；双线桥管"各元素自己的升降"，单线桥管"电子从谁流向谁"（p68）。

    ③ 化合价降低的反应物是氧化剂（被还原、显氧化性），升高的反应物是还原剂（被氧化、显还原性）；最高价态可能只氧化、最低价态可能只还原、中间价态两可——价态给预测，实验下定论（p69–71）。

    自测四连（改编自教材 p74–75 练习与活动·答案侧自编并标注）：
    1．（改编自 p74 练习1）判断是否氧化还原反应，是则指出氧化剂和还原剂：①CaCO₃ 高温 CaO + CO₂↑；②CH₄ + 2O₂ 点燃 2H₂O + CO₂；③2Na + 2H₂O ═══ 2NaOH + H₂↑——①不是（Ca +2、C +4、O −2 全程没变）；②是，O₂ 做氧化剂（0→−2），CH₄ 做还原剂（C −4→+4）；③是，H₂O 做氧化剂（H +1→0），Na 做还原剂（0→+1）
    2．（改编自 p74 练习3）下列变化中，可以通过加入氧化剂实现的是（　），可以通过加入还原剂实现的是（　）。A. Cl₂→Cl⁻　B. H⁺→H₂　C. CO₃²⁻→CO₂　D. SO₂→SO₃——加氧化剂=让目标元素被氧化升价→D（S +4→+6）；加还原剂=让目标元素降价→A（Cl 0→−1）、B（H +1→0）皆可；C 中 C 价态不变，走复分解即可，不需要氧化剂或还原剂
    3．（改编自 p74 练习4(2)）下列反应中，二氧化硫做氧化剂的是（　），做还原剂的是（　）。①SO₂+2NaOH═══Na₂SO₃+H₂O；②SO₂+2H₂S═══3S↓+2H₂O；③SO₂+Cl₂+2H₂O═══H₂SO₄+2HCl——②中 S +4→0 降价，SO₂ 做氧化剂；③中 S +4→+6 升价，SO₂ 做还原剂；①中 S 价态不变，不是氧化还原反应——SO₂ 中 S 处中间价态（−2 与 +6 之间），氧化剂还原剂都能当（呼应 p69–70"价态趋势"与 p70 名单中 SO₂ 属低价氧化物还原剂）
    4．（改编自 p75 练习6(1)）自然界中的元素大多以化合态存在，如果需要把某元素由化合态转变为游离态（单质），则该元素（　）。A. 被氧化　B. 被还原　C. 有可能被氧化，也有可能被还原　D. 由高价变为 0 价——C。化合态价态可正可负：正价降到 0 是被还原（如 Fe²⁺→Fe），负价升到 0 是被氧化（如 Cl⁻→Cl₂）——教材此题正是"价态升降方向"的照妖镜
    高考怎么考（考位锚）：①概念四连配对：给一个反应判"是不是氧化还原"，并配对氧化反应/还原反应/氧化剂/还原剂与"升失氧、降得还"的对应（自编口诀注记：升、失、氧化反应同侧）；②电子转移的表示与计算：双线桥/单线桥书写、转移电子数目（结合 NA 类选择题）；③价态规律预测性质：最高价只氧化、最低价只还原、中间价两性（如 H₂O₂、SO₂、Fe²⁺）；④情境应用：实验室制氯气与尾气处理、金属冶炼路线选择、燃料电池电极判断。考法示意·真题锚候采（对证源池无化学 2.3 行·如实申报不代拟）。
