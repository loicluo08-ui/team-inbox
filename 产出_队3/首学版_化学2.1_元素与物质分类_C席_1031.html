元素与物质分类：给上千万种物质"建档案柜"

化学必修第一册 · 第2章第1节（鲁科版 p44–52） · 零基础首学版 v1.0 · 2026-10-31
初中到现在，你见过的化学物质少说几十种：氧气、铁、盐酸、碳酸钠……但化学家登记在册的物质有上千万种。他们的记忆力和你一样有限，靠的不是背，而是分类——先把物质按组成分进几个"大柜子"，同类物质性质相似，认识一个就认识了一串。这一节教你亲手搭起整个化学的"档案柜"，高中化学所有知识都会挂进这个柜子里。
读完这节你能：

① 把任何一种常见物质准确放进"混合物/纯净物→单质/化合物→氧化物/酸/碱/盐"的柜子；
② 说清"元素的游离态/化合态"是什么，并用化合价给碳、铁的物质"定坐标"；
③ 用"酸性氧化物/碱性氧化物"类别预测一种陌生物质的反应；
④ 认出胶体，说出丁达尔现象、渗析、电泳、聚沉各自怎么用。

第0步先拆掉两个误会，再认识三个记号

误会一："纯净物"＝"干净的东西"？不。纯净物是化学术语：只由一种物质组成。蒸馏水是纯净物——不管脏不脏，它只有水这一种物质；你喝的矿泉水是混合物——里面有水，还有溶解的矿物质。判断标准是"几种物质"，不是"脏不脏"。

误会二："单质"＝"单个的物质"？不。单质＝只由一种元素组成的纯净物。氧气（O₂）是单质（只有氧元素）；但二氧化碳（CO₂）虽然只含碳、氧两种元素里"一种碳元素"，它有两种元素，是化合物。注意两个"一"：一种物质（纯净物）+ 一种元素（单质），缺一不可。

记号一：化学式下标。H₂O 里的"2"表示一个分子里有 2 个氢原子、1 个氧原子（"1"不写）。

记号二：化合价。这节用"碳元素显 +4 价"这种横写方式（初中你可能在符号正上方见过 ⁴⁺ 顶写，是同一个意思）。规则一条：化合物里各元素化合价代数和为零。常见值先记三个：氧通常 −2，氢通常 +1，金属钠 +1。

记号三：纳米（nm）。1 nm = 10⁻⁹ m，也就是十亿分之一米。头发直径约 0.05–0.1 mm = 5万–10万 nm。这节用它给混合物"分家"。

第1站元素与物质的关系：一棵分类树（p44–45）

教材开场（p44）：110 多种元素组成了各种各样的物质。物质千千万，元素只 110 多种——多出来的"千万"，全靠元素的不同组合。所以教材说："根据物质的元素组成，可以对物质进行分类"（p45）。

先把树根剪开：物质按"含几种物质"分两枝——混合物（含两种或以上物质，如空气、矿泉水、盐酸）和纯净物（只含一种物质，如氧气、蒸馏水）。纯净物再按"含几种元素"剪：单质（一种元素）和化合物（两种或以上元素）。这就是 p45 影印原文的定义：

仅由一种元素组成的纯净物称为单质；其中，由金属元素组成的单质称为金属单质，由非金属元素组成的单质称为非金属单质。由两种或两种以上的元素组成的纯净物称为化合物，化合物又可以分为氧化物、酸、碱、盐等。（p45 逐字锚）

化合物这一枝按组成再分四格：氧化物＝两种元素且其中一种是氧（如 H₂O、CO₂、Fe₂O₃）；酸（如盐酸 HCl、硫酸 H₂SO₄）；碱（如氢氧化钠 NaOH、氢氧化钙 Ca(OH)₂）；盐（如碳酸钠 Na₂CO₃、氯化钠 NaCl）——酸碱盐的精确定义在 2.2 和第 3 章陆续给你，本节先学会"对号入座"。

还有两个描述元素"存在方式"的词（p45）：元素以单质形式存在，称为元素的游离态；以化合物形式存在，称为化合态。比如：氧气里的氧元素是游离态，CO₂ 里的氧元素是化合态；钠单质（金属钠）里的钠是游离态，食盐 NaCl 里的钠是化合态。

这张图在说什么：教材图2-1-2（p45）"根据元素组成对物质进行分类"的树状图重绘——每一层只问一个问题，任何物质都能落到一个格子里。

30秒自验①（p44交流研讨改编）：把 钠、氧气、蒸馏水、盐酸 四种物质放进柜子。
答：钠＝纯净物→单质→金属单质；氧气＝纯净物→单质→非金属单质；蒸馏水＝纯净物→化合物→氧化物；盐酸＝混合物（HCl气体溶于水所得，p46活动探究把它列在"酸"类物质中）。——对不上的回第1站重读"单质＝一种元素+纯净物"那句。

第2站价—类二维图：一种元素的"多张身份证"（p45）

同一种元素可以在不同类别的物质里"换身份"（p45）：碳元素可以存在于碳单质（游离态）、碳的氧化物（一氧化碳、二氧化碳）、碳酸盐（碳酸钠）等物质中；铁元素可以存在于铁单质、铁的氧化物（氧化亚铁、三氧化二铁）、铁盐（氯化亚铁、氯化铁）等物质中。

不但类别会变，化合价也会变（p45 原文数据）：碳元素在一氧化碳中呈现 +2 价，在二氧化碳、碳酸钠等物质中呈现 +4 价；铁元素在氯化亚铁中呈现 +2 价，在氯化铁中呈现 +3 价。用"代数和为零"你自己就能算：CO₂ 中，碳价 x + 2×(−2) = 0，得 x = +4。

把"化合价"（纵轴）和"物质类别"（横轴）拼在一起，就是 p45 的价—类二维图：每种含碳物质都有一张"坐标卡"，横坐标报类别、纵坐标报价数。

这张图在说什么：教材图2-1-3（p45）"碳及其化合物的价—类二维图"重绘——同一行（同价）可以跨多个类别，比如 +4 价的碳既在氧化物格（CO₂），也在酸格（H₂CO₃）、盐格（Na₂CO₃）。

教材点睛（p45）：基于核心元素的化合价和物质类别研究物质，为我们认识物质性质和实现物质转化提供了新思路——这张图是第3章"铁的多样性、硫的转化、氮的循环"的通用地图，往后每一章你都会重新画它。

30秒自验②：用"代数和为零"算氯化铁 FeCl₃ 中铁的化合价（氯为 −1）。
答：x + 3×(−1) = 0 → x = +3。若算成 +1，多半是把"3个氯、每个−1"当成了"3只算一次"——代数和是"每种原子的个数×它的价"再全部相加。

第3站类别→性质：给陌生物质"算命"（p46–47）

分类不是白分的。教材（p46）：同一类别的物质具有一定的相似性。分门别类地研究物质的组成、性质、用途，可以找到规律，发现同类物质之间的内在联系。p46 活动探究让你把 17 种物质（金属铁、碳单质、二氧化碳、碳酸钙、碳酸钠、氧气、氧化钙、氢氧化钙、盐酸、氯化钠、氯化钡、硫酸、硫酸钠、硫酸铜、氢氧化铜、氢氧化钠、硝酸银）先分类，再预测同类物质的相似性质，最后设计实验验证——"分类→预测→实验验证"就是研究一类物质的标准流程。

氧化物这格还能再剪一刀（p47 原文）：

酸性氧化物（acidic oxide）：能与碱反应生成盐和水，如二氧化碳、二氧化硫；碱性氧化物（basic oxide）：能与酸反应生成盐和水，如氧化钠、氧化钙。多数非金属氧化物属于酸性氧化物，多数金属氧化物属于碱性氧化物。（p47 逐字锚）

每一类物质都有"一般性质"（p47，四句话）：酸通常能与活泼金属、碱、盐或碱性氧化物等类别的物质反应；碱通常能与酸、盐或酸性氧化物反应；酸性氧化物通常能与碱或碱性氧化物反应；碱性氧化物通常能与酸或酸性氧化物反应；部分酸性氧化物和部分碱性氧化物能分别与水反应生成相应的酸和碱。

知道了一般性质，就能按 p47"方法导引"给陌生物质"算命"，四步：

步动作以"陌生白色固体 X₂O₃"为例
1判断它属于哪一类两种元素、含氧 → 氧化物；若是金属元素 → 候选碱性氧化物
2套用该类别的一般性质碱性氧化物 → 预测"能与酸反应生成盐和水"
3选各类代表物，推断具体反应选盐酸：预测 X₂O₃ + 6HCl → 盐 + 水
4实验验证预测取少量加盐酸，观察是否溶解成盐溶液

预测是否正确，需要用实验验证——"算命"只负责给方向，实验才是法官（p47 方法导引原文要点）。

分类的角度还有很多（p47 收尾）：根据在水溶液中或熔融状态下能否导电，可将化合物分为电解质和非电解质（2.2 见）；根据反应中元素化合价是否改变，可将物质分为氧化剂和还原剂（2.3 见）；根据被分散物质的颗粒大小，将分散系分为溶液、浊液和胶体——第三种马上讲。

30秒自验③：利用类别关系，预测 CO₂ 与 NaOH 溶液能否反应，产物是什么类别？
答：CO₂ 是酸性氧化物，NaOH 是碱——酸性氧化物能与碱反应生成盐和水，所以能反应，产物是盐（碳酸钠 Na₂CO₃）和水。这正是"喝汽水打嗝"背后碳酸体系的一角，也顺手回答了 p51 练习第2题（酸性氧化物一般不具有的性质是"与酸反应生成盐和水"——它跟碱玩，不跟酸玩）。

第4站胶体：按颗粒大小切的第三刀（p47–49）

把一种（或几种）物质（分散质）分散到另一种物质（分散剂）里，就得到分散系（p48）。混合物这枝按"分散质颗粒直径"再切三段（p48 影印数据）：

分散系分散质直径宏观特征教材例
溶液小于 1 nm透明、均一、稳定KNO₃ 溶液（图2-1-5 左）
胶体1～100 nm介于两者之间，较稳定氢氧化铁胶体、碘化银胶体（图2-1-6）
浊液（悬浊液/乳浊液）大于 100 nm浑浊、不稳定泥土悬浊液（图2-1-5 右）
分散质的微粒直径介于 1～100 nm 的分散系，称为胶体（colloid）。（p48 逐字锚）
最容易踩的坑："胶体"带个"体"字，很多同学以为它像"胶水"是一种化合物。错！胶体是混合物（分散系的一种），本质是"颗粒尺寸落在 1–100 nm 的混合物"。云、雾、烟都是胶体（分散剂是空气，分散质是微小液滴或固体颗粒，p48）——它们既不是胶水，也不是化合物。另一坑：判断胶体看颗粒直径范围，不看颜色、不看"黏不黏"。

胶体三件套性质（怎么识别、怎么提纯、怎么破坏）：

① 丁达尔现象——识别它。当可见光束通过胶体时，在入射光侧面可观察到光亮的"通路"，这种现象称为丁达尔现象（丁达尔效应，Tyndall effect）（p48）。原理：胶体微粒对可见光（波长 400～700 nm）散射而成。它可用于实验室鉴别一种分散系属于胶体还是溶液——溶液颗粒太小（<1 nm），几乎不散射，没有光路。清晨密林里的一缕缕光束、阳光透过墙上小孔在暗室里打出的光柱，都是丁达尔现象（p48）；p49 图2-1-8 用激光笔照三支试管：氢氧化铁胶体（红褐色）里有红色光路，旁边的盐酸（溶液）没有。

② 渗析——提纯它。胶体的分散质微粒比溶液的大，能透过滤纸，但不能透过半透膜（如动物肠衣、鸡蛋壳膜、羊皮纸、胶棉薄膜、玻璃纸等）（p48）。半透膜孔隙比滤纸更细小，只有小分子、离子能透过——用半透膜把胶体里的杂质离子、小分子"筛"出去，这种提纯、精制胶体的方法称为渗析。教材图2-1-7（p48）一张图说清三道门的排序：浊液颗粒连滤纸都过不去；胶体颗粒过得了滤纸、过不了半透膜；溶液里的分子离子连半透膜也拦不住。

③ 电泳与聚沉——它带电、它怕盐。（p49 拓展视野）胶体分散质比表面积巨大，能吸附带电离子形成带电微粒，在外电场作用下发生定向移动，例如氢氧化铁胶体微粒带正电荷，通电后向与直流电源负极相连的一极移动，这种现象称为电泳（电泳电镀就是用它把油漆、乳胶、橡胶微粒均匀沉积在镀件上）。把酸、碱、盐加入胶体，溶解出的阳离子或阴离子中和了胶体微粒的电荷，微粒聚集成较大颗粒，在重力作用下沉淀析出，这种现象称为聚沉（p49 图2-1-10：氢氧化铁胶体加入 Na₂SO₄ 溶液后析出沉淀）；加热或搅拌也可能引起聚沉。生活锚：向豆浆（一种胶体）中加入硫酸钙使蛋白质等聚沉，就制成了可口的豆腐（p49 原文）。

应用锚（p49）：净水时向水中加入可以形成胶体的无害物质，利用胶体分散质巨大的比表面积（单位质量的微粒具有的表面积）形成较强吸附能力，吸附水中的色素、悬浮固体等达到净水目的。

卡住有出路：三件套分不清用场合记——要"认出"胶体→丁达尔（光路）；要"提纯"胶体→渗析（半透膜）；要"破坏/利用"胶体→聚沉（加盐/加热，豆腐）；要"搬运"胶体微粒→电泳（通电）。四句话各管一件事，互不冒充。半径单位别背反：溶液 <1 nm ⊂ 胶体 1–100 nm ⊂ 浊液 >100 nm，从左到右颗粒越来越大、越来越不稳定。

收口三句话带走 + 自测四连

三句话带走：① 物质按"几种物质、几种元素"连剪两刀，得到"混合物/纯净物→单质/化合物→氧化物·酸·碱·盐"档案柜；② 陌生物质先归类，用"类别一般性质+价—类二维图"预测反应，最后实验验证；③ 按 1–100 nm 这把刀，混合物再分出胶体——丁达尔认它、渗析提它、聚沉豆腐靠它。

自测四连（前两题改自教材 p51–52"练习与活动"原题，标注页码）：

S1.（p51 第1题改）把 SO₂、Fe(OH)₃、Ca、硫酸钠 各放进哪个柜子？
SO₂：化合物→氧化物→酸性氧化物；Fe(OH)₃：化合物→碱；Ca：纯净物→单质→金属单质；硫酸钠：化合物→盐。连线题失分多半在 SO₂——"含氧"不等于"碱性氧化物"，要看它跟谁反应生成盐和水（跟碱反应→酸性）。

S2.（p51 第4题）下列操作能区分溶液和胶体的是（　）：A.观察颜色　B.过滤　C.利用半透膜渗析　D.丁达尔现象
答案 D（C 也能区分但属分离提纯手段，教材本题主判据=丁达尔）。提醒：过滤拦不住胶体微粒，B 不能区分。

S3.氢氧化铁胶体通电，微粒向哪极移动？为什么？
向负极——氢氧化铁胶体微粒带正电荷（p49 拓展视野），异性相吸。顺带记聚沉：加入电解质（如 Na₂SO₄）或加热，微粒电荷被中和就聚沉。

S4.（p52 第7题改）制备氢氧化铁胶体的化学方程式 FeCl₃ + 3H₂O ＝Δ＝ Fe(OH)₃（胶体）+ 3HCl 中，分散质微粒直径范围是多少？判断制备成功用什么现象？
1～100 nm；用丁达尔现象——有光亮通路即得胶体（p52 原题"你认为可以用什么方法判断胶体的制备是否成功"）。

高考怎么考（T11 考位锚）：①丁达尔现象鉴别胶体与溶液——实验选择题高频；②"金属单质/非金属单质/酸性氧化物/碱性氧化物/酸/碱/盐"分类连线——物质分类题基本盘；③聚沉（豆腐/三角洲成因）、渗析、电泳的用途判断——STSE 情境题常客。真题锚：对证源池内本节暂无对应真题行，候采不代拟（如实申报，候管理员席采纳后补）。
