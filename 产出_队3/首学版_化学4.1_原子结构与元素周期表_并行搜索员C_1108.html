化学4.1 原子结构与元素周期表

人教版《化学 必修 第一册》第四章第一节 · 印刷页p92–106 · 零基础首学版 v1.0 · 预计40分钟

前几章你学的是"物质怎么分、反应怎么发生"：分散系把混合物分类，氧化还原用化合价升降看清电子转移。但你有没有想过一个问题——同样是单质，钠扔进水里炸出火花，铜扔进水里却什么反应都没有；同样是跟氢气反应，氟在暗处就能爆炸，碘却怎么加热都慢吞吞。性质差别这么大，根源在哪里？答案藏在原子内部：原子核外的电子怎么排、元素在周期表里站哪个位置，几乎决定了它的一切化学表现。这一节我们就把原子"拆开"看个清楚，再认识化学里最重要的"地图"——元素周期表。

读完这节你能
  • 用质量数 = 质子数 + 中子数这个式子，算出任意原子核里有几个质子、几个中子；
  • 画出1~20号元素的原子结构示意图，并说出核外电子排布的三条规律；
  • 说清元素周期表7个横行、18个纵列是怎么排出来的，并从一个方格里读出元素的四种基本信息；
  • 分清核素和同位素两个词，正确称呼像 ¹H、²H、³H 这样"同一家族"的原子；
  • 以碱金属和卤族为例，完成一条推理链：位置 → 结构 → 性质，解释同一族元素为什么性质相似、又有规律地变化。

STEP 1拆开原子：质量数 A = Z + N

初中你已经知道：原子由原子核和核外电子构成，原子核由质子和中子构成。现在补一个关键事实——原子的质量几乎全部集中在原子核上（电子太轻，几乎可以忽略）。教材p92是这样定量描述的：

质子和中子的相对质量都近似为1。如果忽略电子的质量，把核内所有质子和中子的相对质量取近似整数值相加，所得的数值叫做质量数（A）。用符号记：Z = 质子数，N = 中子数。

质量数（A）＝ 质子数（Z）＋ 中子数（N）

（教材p92原式照录。质子数Z决定了它是哪种元素——这就是第二章说过的"元素是具有相同质子数的一类原子的总称"。）

随读随验①

考古测年用的碳原子记作 ¹⁴₆C（左上角是质量数A，左下角是质子数Z）。它的核内有几个质子、几个中子？

做法：Z 直接读左下角 = 6；N = A − Z = 14 − 6 = 8。

这道题就是教材p106"练习与应用"第2题的原题（答案选B），学完这节你要能30秒内做对它。

记住这一步的分工：质子数决定"这是谁"（哪种元素），中子数只影响"它多重"。这个分工后面讲同位素时会反复用到。

STEP 2电子层：核外电子的"楼层"

原子核外有很多电子时，它们不是乱挤在一起的，而是在能量不同的区域内运动。教材p92把这些区域简化成不连续的壳层，就叫电子层——可以想象成一栋楼：离地（原子核）越近的楼层，电子能量越低；越远的楼层能量越高。

楼层编号：从内到外共7层，两套记号等价——数字 n = 1,2,3,4,5,6,7，或字母 K L M N O P Q（K=第1层，L=第2层……）。

入住规则（教材p93原文，三条）：

  • 先内后外：一般先从内层排起，一层充满后再填充下一层；
  • 第n层最多住 2n² 个：K层2、L层8、M层18、N层32……；
  • 最外层不超过8个（若最外层就是K层，则不超过2个）。最外层住满8个电子（K层为最外层时2个）的结构是相对稳定结构。

钠原子（11号）的核外电子排布：2、8、1（对位教材图4-1/4-2重绘）

排布规律可以从稀有气体原子的"满员"排布里看得最清楚（教材p93表）：

元素核电荷数KLMNOP
氦 He22—————
氖 Ne1028————
氩 Ar18288———
氪 Kr3628188——
氙 Xe542818188—
氡 Rn86281832188

看点：M层明明能住18个，Ar却只住8个就"关门"了——因为此时M层是最外层，受"最外层≤8"约束。稀有气体正是最外层满员（8或2），化学性质才格外不活泼。

随读随验②

不查答案，先自己画：17号元素氯（Cl）的核外电子排布是？

提示：17 = 2 + 8 + 7。前三层依次住满：K层2个、L层8个，剩下7个进M层（最外层7个≤8，合法）。

答案：2、8、7。顺手验证一下：2×1²+2×2²+2×3² = 2+8+18，M层容量18确实够住7个。

易踩坑

坑：把"第n层最多2n²"当成每层实际住满2n²。2n²只是容量上限，实际住几个要同时满足"先内后外"和"最外层≤8"。比如Ar的M层容量18，实际只住8个。

自验口令：画完示意图，把各层电子数加起来，总和必须等于核电荷数（原子不带电）。加起来不对，一定是排错了。

STEP 3元素周期表：给118种元素安家

1869年，俄国化学家门捷列夫把当时已知的元素按相对原子质量由小到大排列、性质相似的放在一起，制出了第一张元素周期表。后来原子结构的奥秘被揭示，排序依据改成了原子的核电荷数，逐渐演变成今天通用的形式（教材p94）。按顺序给元素编号，就得到原子序数：

原子序数 ＝ 核电荷数 ＝ 质子数 ＝ 核外电子数

四个数对原子（不带电时）永远是同一个数——这是全节最重要的"万能换算"，考题里反复让你来回换算。

周期表的排法只有两句话（教材p95原文）：

  • 横行 → 周期：把电子层数相同的元素，按原子序数递增从左到右排成一行。共7个周期；周期序数 = 该周期元素的电子层数。第1周期只有2种元素，第2、3周期各8种——这三个周期叫短周期，其余（4~7）叫长周期。
  • 纵列 → 族：把最外层电子数相同的元素，按电子层数递增从上到下排成一列。共18个纵列；其中8、9、10三个纵列共同组成第Ⅷ族。主族（族序数后标A）由短周期和长周期元素共同构成；副族（标B，除Ⅷ族）完全由长周期元素构成。稀有气体化学性质极不活泼、化合价定为0，叫0族。有些族有专名：第ⅠA族（除氢）叫碱金属元素，第ⅦA族叫卤族元素。

周期表骨架示意（只画族边缘和本节主角：蓝=ⅠA碱金属、红=ⅦA卤族、灰绿=0族稀有气体）

再看教材p96的方格。周期表里每个方格一般标四种信息，以氢为例：原子序数1、元素符号H、元素名称氢、相对原子质量1.008。会读方格，周期表就是你的"元素身份证库"。

随读随验③

第3周期、第ⅦA族的元素是谁？它原子核外怎么排布？

推理链：第3周期 → 电子层数3；ⅦA → 最外层7个。核电荷数 = 2+8+7 = 17，正是氯（Cl）。你看——只凭"地址"（周期和族）就倒推出了"户型"（电子排布），这就是周期表的威力。

STEP 4核素与同位素：同一元素的"孪生兄弟"

有了 A = Z + N，就能解释一个新现象：同一种元素（Z相同）的原子，中子数不一定相同。氢就有三种（教材p96表4-1）：

原子名称原子符号（ᴬZ X）质子数Z中子数N
氕（piē）¹₁H10
氘（dāo）²₁H 或 D11
氚（chuān）³₁H 或 T12

两个定义（教材p96原文）：

  • 把具有一定数目质子和一定数目中子的一种原子叫做核素。¹H、²H、³H就各为一种核素。
  • 质子数相同而中子数不同的同一元素的不同原子互称同位素（即同一元素的不同核素互称同位素）。

"同位"的意思：它们质子数相同，在元素周期表中占有同一个位置——所以叫"同"位。

记号 ᴬZ X 统一读法：左上角质量数A、左下角质子数Z。比如教材p106提到的117号元素Ts（2016年由IUPAC命名，中文名生僻字在文本层显示不全，以"音tián"如实照录、原字以影印页为准），中子数176，写成 ²⁹³₁₁₇Ts（A = 117+176 = 293）。

易踩坑

坑一：以为"中子数不同就是不同元素"。错。决定元素身份的只有质子数。¹²C、¹³C、¹⁴C的Z都是6，它们是同一种元素（碳）的三种核素。

坑二：以为"质量数相同就是同位素"。同位素先看Z是否相同。¹⁴₆C和¹⁴₇N质量数都是14，但Z一个是6一个是7，是两种元素，谈不上同位素（这正是教材p106练习1(2)的考点）。

同位素到处都是：氧有 ¹⁶O、¹⁷O、¹⁸O 三种核素；碳有 ¹²C、¹³C、¹⁴C 等；铀有 ²³⁴U、²³⁵U、²³⁸U 等（教材p97）。天然存在的同位素相互间保持一定比率，所以——

元素的相对原子质量 = 按该元素各种核素所占的百分比（丰度）计算出来的平均值（教材p97口径，与第一章"相对原子质量"初中已知数据相衔接）。

自编例（非教材原题·本席自拟用于演练加权平均）：氯有两种主要核素 ³⁵Cl（相对原子质量34.969，丰度约75.8%）和 ³⁷Cl（36.966，约24.2%）。平均 = 34.969×0.758 + 36.966×0.242 ≈ 35.45——正好落在35和37之间，也解释了方格里Cl标"35.45"这个"非整数"。

同位素不只是考试概念，它在真实世界里很重要（教材p97）：考古用 ¹⁴C 测定文物年代；²H 和 ³H 用于制造氢弹；放射性同位素释放的射线可以育种、给金属探伤、诊断和治疗疾病。比如美国科学家利比发明了¹⁴C断代法（利用死亡生物体中¹⁴C不断衰变测定年代），因此获1960年诺贝尔化学奖（教材p97"化学与职业"栏目）。

随读随验④

（自编·非教材原题）¹⁴C 测年为什么测的是"死物"？（提示结合正文一句话即可）

答案要点：¹⁴C会不断衰变。生物活着时与外界交换物质，体内¹⁴C比例与大气一致；死亡后不再交换，¹⁴C只衰变不补充，比例随时间下降——比较剩余比例就能倒推死亡年代（教材p97"利用死亡生物体中¹⁴C不断衰变的原理对文物进行年代测定"）。

STEP 5同族找规律：碱金属与卤族

先立一个总纲（教材p98）：金属元素的原子最外层电子一般少于4个，反应中容易失去电子，具有金属性；非金属元素的原子最外层电子一般多于4个，容易得到电子，具有非金属性——原子结构决定元素的性质。同族元素最外层电子数相同，所以化学性质相似；从上到下电子层数增多，所以性质又规律地变化。教材选了两族代表来验证。

5.1 碱金属（第ⅠA族，除氢）：Li → Na → K → Rb → Cs

元素核电荷数电子排布最外层电子数原子半径/nm
锂 Li32、110.152
钠 Na112、8、110.186
钾 K192、8、8、110.227
铷 Rb372、8、18、8、110.248
铯 Cs552、8、18、18、8、110.265

（教材p99表照录，各电子层电子数之和均等于核电荷数。）

相似性：最外层都只有1个电子，都容易失去1个电子，产物中化合价都是+1价。都能与氧气、水反应：

4Li + O₂ =（加热）= 2Li₂O　　2Na + O₂ =（加热）= Na₂O₂

2Na + 2H₂O = 2NaOH + H₂↑　　2K + 2H₂O = 2KOH + H₂↑

（教材p101原式照录。注意：钠加热生成的是过氧化钠Na₂O₂，不是氧化钠。）

递变性：从锂到铯，核电荷数增加 → 电子层数增多、原子半径增大 → 原子核对最外层电子的引力减弱 → 失电子能力增强，金属性增强。表现：与水反应一个比一个剧烈——钠比锂剧烈、钾比钠剧烈，铷、铯遇空气或水立即燃烧，遇水甚至会爆炸（教材p101）。物理性质也有规律：熔点从Li的180.5℃一路降到Cs的28.40℃（教材p101表4-2）。

5.2 卤族（第ⅦA族）：F → Cl → Br → I

单质颜色（常态）状态
F₂淡黄绿色气体
Cl₂黄绿色气体
Br₂深红棕色液体
I₂紫黑色固体

（教材p102表4-3。四原子最外层都是7个电子：F 2,7；Cl 2,8,7；Br 2,8,18,7；I 2,8,18,18,7——教材图4-10。）

相似性：最外层都是7个电子，都容易得1个电子，都能与氢气化合生成卤化氢：

H₂ + F₂ = 2HF　暗处剧烈化合并爆炸，HF很稳定

H₂ + Cl₂ =光照或点燃= 2HCl　反应较易，HCl较稳定

H₂ + Br₂ =加热= 2HBr　加热至一定温度才反应，HBr不如HCl稳定

H₂ + I₂ =不断加热= 2HI　缓慢反应，HI不稳定，同条件下同时分解（可逆反应，第五章介绍）

（教材p103表4-4照录：条件越来越苛刻、产物越来越不稳定。）

递变性——看一个能"当场分胜负"的反应：置换。实验4-1（教材p104）：向KBr溶液和KI溶液中加氯水、向KI溶液中加溴水，能看到卤素"以强换弱"：

2NaBr + Cl₂ = 2NaCl + Br₂（教材p103照录）　　Cl₂ + 2KI = 2KCl + I₂

谁把谁换出来，谁的单质就更强。结论（教材p104）：氧化性 F₂ ＞ Cl₂ ＞ Br₂ ＞ I₂，逐渐减弱。

同主族元素，从上到下：电子层数依次增多 → 原子半径逐渐增大 → 失电子能力逐渐增强（金属性↑），得电子能力逐渐减弱（非金属性↓）。

碱金属（最外层1，易失）验证了"金属性增强"半句；卤素（最外层7，易得）验证了"非金属性减弱"半句。合成一句：位置（同族上下）→ 结构（层数、半径）→ 性质（得失电子能力）。

随读随验⑤

教材p102"方法导引"教了一招叫预测：铷（Rb）与钠、钾同属ⅠA族，预测铷能否与水反应？

答案：能，而且比钾更剧烈。推理链：同族最外层都是1个电子 → 性质相似（都能与水反应）；铷在钾下方 → 金属性更强 → 反应更剧烈。教材原文的例子正是"根据位置—结构预测铷也能与水反应"。

收口：三句话带走这一节

第一句：原子 = 原子核（质子Z+中子N）+ 核外电子；A = Z + N，原子序数 = 核电荷数 = Z = 核外电子数。

第二句：核外电子按层排布（先内后外、第n层最多2n²、最外层≤8）；周期表把电子层数相同的排成行（7个周期），最外层电子数相同的排成列（18个族），周期序数=电子层数。

第三句：同种元素的不同核素（Z同N不同）互为同位素；同主族从上到下，金属性增强、非金属性减弱——位置、结构、性质是一条推理链。

原子结构模型的演变（教材p94"科学史话"）：人类对原子的认识是一步步修正的——道尔顿模型（1803年）：原子是不可再分的实心球；汤姆孙模型（1904年）：正电荷球体里镶嵌电子；卢瑟福模型（1911年）：中心有一个带正电的核，电子绕核运转如行星绕太阳；玻尔模型（1913年）：电子在一定轨道上绕核高速圆周运动；电子云模型（1926~1935年）：电子没有确定轨道。教材提醒：人类认识原子的过程"是漫长的，也是无止境的"。

周期表也有"抢发明权"的故事（教材p98"科学史话"）：德国化学家迈尔1864年就指出相对原子质量的规律性，还画过与门捷列夫十分相似的表，但1880年他坦言："我没有足够的勇气作出像门捷列夫那样深信不疑的预言。"门捷列夫敢给未知元素留空位并预言其性质——胆识也是科学的一部分。1913年莫塞莱证明原子序数=核电荷数，周期表才有了今天的牢固地基。
