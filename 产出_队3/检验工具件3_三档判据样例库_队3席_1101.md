## 一、绿档（PASS·可入并池）

**定义**：结构四检全过0真伤exit0＋影印锚闭合（contentId/ts/映射三要素齐＋节名页实锚）＋事实点/验点全过＋节末自测原题全答＋通读零未闭环卡点。

**触发信号**（全满足）：机检`结构四检全过`且`0件结构真伤`且exit0｜词面0命中或仅剩教材原生白名单词｜验点ALL PASS/exit0｜print七查PDF在件且文本层健康。

**真账样例**：
1. 物理4.3牛顿第二定律（059913a·九件·双机检双绿一次过·QC批九快检出库）——结构四检0真伤+p43代验16项ALL PASS+影印五页闭合。
2. 化学3.3氮的循环（cc1bcc4·十件·复验PASS出库红1清零）——24点事实自验+T1-T12全过+通读两轮。
3. 数学1.5全称量词与存在量词（c26d920·七件·sympy30项ALL PASS）——九页影印全新直读+ts三方一致+sha256留痕。

**处置路径**：直接候批量并main归位，无需整改轮。

## 二、黄档（PASS带候裁账·入并池但账面留注）

**定义**：结构零真伤，但存在**已知候裁账**——词面命中教材原生词/foot自引类白名单边缘、或口径并存（两版数据/两解教学注记）、或检定深度如实申报的工艺差。不判废、不阻塞归位，但账面必须留注候裁。

**触发信号**（任一）：机检`⚠️词面N处已知候裁账`且逐词可定性教材原生/白名单边缘｜SVG手绘复刻工艺差已figcap申报｜考位锚宁缺毋编申报｜双口径数据并存已注记。

**真账样例**：
1. 生物5.2（0d9d565）——词面仅剩"货币"1处=教材原生比喻（p89原句·v12.1裁定入册），自编金融词已全换血电池体系。
2. 化学2.2 C席版——词面1处"定存"=C席正文原有已知候裁账（print补层时如实申报不属补层引入）。
3. 物理4.3 print七查——深色超1%页9/9最高7.60%系开场块与SVG暗色填充·图形元素同族口径目验p4全过。
4. 数学3.3 B线件——T11考位锚池内无专行，宁缺毋编申报候令增补不自行放行。

**处置路径**：随件申报＋候裁账逐条列名→QC终读核定性→入并池（账随件走）→若终裁改判红则回炉。

## 三、红档（FAIL·候修·不入并池）

**定义**：结构真伤或事实性错误——占位符残留、div/table配平破、print层缺失、svg无aria、影印断链（403/映射错）、数据错误（验点FAIL）、节域越界。**必须整改轮，整改后按绿/黄重判。**

**触发信号**（任一）：机检`❌真伤计FAIL`任一项｜验点FAIL｜影印锚三要素缺一或映射与页脚实证冲突｜事实点与教材原文冲突。

**真账样例**：
1. 生物3.2/4.2主件红（v12令零修红优先·出库闸）——修后经QC批十二定谳"修"出库（生物5.1词面修后件8381587并main批九补遗即此道先例）。
2. 物理1.3 df7a225卡点重交案——B线14:12版与A线15:31整改版归一裁定（v12.1后物理1.3正本=A席整改回执版44fdd75复验PASS）。
3. 幽灵八件案（b921e89/15375dde）——冒用疑点不入并池隔离留证（队6裁决0062d31）。

**处置路径**：红件申报群内→出修复轮（禁直推main·增量commit走原分支）→复跑机检+验点→候QC复验→按新档定谳。
