电解质的电离 离子反应：盐水为什么导电、"酸碱相遇"到底发生了什么

化学 2.2 · 鲁科版《必修 第一册》第2章第2节 · 教材印刷页 p53–65 · 零基础首学版 v1.0（出品：并行搜索员C·队3席·1031）
先看一个日常现象：泡腾片放进水里，"滋——"地冒出一大堆气泡，药水喝起来像汽水（教材 p53 图2-2-1）。可它明明是干燥的固体，平时不冒一个泡，为什么一进水就变了？答案藏在"水里到底发生了什么"——这正是本节要拍慢镜头的地方：物质溶进水以后，会散架吗？散成的碎片是什么？两杯"碎片水"倒在一起，又是谁在和谁反应？
读完这节你能：
  • 判断一种化合物是不是电解质，并写出它的电离方程式；
  • 说清离子反应的定义和发生条件，认出"酸+碱"这类反应的真面目；
  • 按四步法写出并检查离子方程式，还能用它解释"检验 Cl⁻ / SO₄²⁻"和"粗盐水除杂"。
    • 开讲前的三件预备（都没有就先补这三件）：

    ① "纯净物"不是"干净"：它是2.1节的概念——只由一种物质组成。盐酸是 HCl 气体溶在水里，是混合物，别把它当纯净物。

    ② 离子符号怎么读：右上角的小数字是带的电荷。Na⁺ 读"钠离子，带一个单位正电荷"；SO₄²⁻ 读"硫酸根离子，带两个单位负电荷"。电荷守恒配平时全靠它。

    ③ "电导率"：仪器给溶液导电能力打的分，数值越大导电越强（p56 图2-2-6 的 pH 计是另一个仪器，测酸碱度）。

    第①站三态导电实验：NaCl 在什么情况下"通电亮灯"

    教材 p53–54 先做了一个三连实验（观察·思考：研究氯化钠的导电性），把干燥的氯化钠摆出三种形态，逐个接上直流电源和电灯泡：

    样品（p54 观察记录表）能否导电一句话解释
    固态氯化钠（干晶体）不导电Na⁺ 和 Cl⁻ 被静电作用"锁"在晶格里，不能自由移动
    熔融状态的氯化钠（加热化开）导电受热破坏了离子间的相互作用，出现能自由移动的离子
    NaCl 溶液（溶进水里）导电水分子把 Na⁺、Cl⁻ 拉离晶体表面进入溶液，同样自由了

    结论就一句话（p54 原文逻辑）：晶体里的离子"动不了"所以不导电；一旦熔化或溶进水，离子自由了、能在电场里定向移动，就导电。灯泡亮不亮，看的不是"有没有离子"，而是"离子能不能自由跑"。

    像氯化钠这样，溶于水或受热熔化时解离成能够自由移动的离子的过程称为电离（ionization）（p54）。

    电离能写成一个式子，叫电离方程式（ionization equation）（p55）：

    NaCl ═══ Na+ + Cl−
    验一验①（30秒）：KNO₃ 溶于水，溶液里该有哪些自由移动的离子？
    K⁺ 和 NO₃⁻——KNO₃ 电离成钾离子和硝酸根离子（K⁺、NO₃⁻ 电荷相加恰好抵消）。

    第②站给化合物贴标签：电解质，以及"酸碱盐"的水中身份

    实验表明（p55）：氯化氢气体、氢氧化钠固体等很多物质溶于水后都能电离导电；NaOH、K₂SO₄ 等在熔融状态下也能电离导电。据此教材给出定义：

    在水溶液中或熔融状态下能够导电的化合物称为电解质（electrolyte）（p55）。
    坑点1：电解质必须是化合物，而且判断看"能否导电"这个行为。铜丝能导电但它是单质不是化合物，所以铜不是电解质（导电的金属单质不是电解质）；蔗糖溶于水不电离也不导电，是非电解质（p56 首段预告了溶液性质只属于电解质溶液）。坑点2："溶液导电"是必要条件之一："水溶液中或熔融状态下"——两个条件占一个就行，但都要落在"化合物"身上。

    酸、碱、盐都是电解质。溶进水里电离之后，看生成的离子"长相"就能分类（p55）：

    类别电离时的标志（p55 原文口径）例子与电离方程式（p55）
    酸（acid）生成的阳离子全部是 H⁺ 的化合物HCl ═══ H⁺ + Cl⁻
    碱（base）生成的阴离子全部是 OH⁻ 的化合物NaOH ═══ Na⁺ + OH⁻
    盐（salt）能生成金属阳离子（或铵离子）和酸根离子的化合物K₂SO₄ ═══ 2K⁺ + SO₄²⁻
    注意"全部"两个字（p55 原文着重口径）：NaHSO₄ 电离也会出 H⁺，但同时还有 Na⁺，阳离子不是"全部"是 H⁺——按教材口径它不按"酸"论，分类看电离产物的全集，不是看有没有某种离子。
    拓展视野（p55）：强电解质和弱电解质。相同温度、相同浓度下，盐酸比醋酸导电强——因为 HCl 在水中完全电离，醋酸只部分电离。完全电离的叫强电解质：强酸（H₂SO₄、HNO₃、HCl）、强碱〔NaOH、KOH、Ba(OH)₂〕、大部分盐（NaCl、KNO₃、CuSO₄）；部分电离的叫弱电解质：弱酸（H₂CO₃、CH₃COOH）、弱碱（NH₃·H₂O）等。水是一种极弱的电解质。

    电解质溶液里既然有自由移动的离子，溶液就会表现出颜色、酸碱性、导电性等性质（p56）：离子浓度越大颜色越深，可以用比色计测离子浓度；H⁺ 或 OH⁻ 让溶液显酸性或碱性，可以用酸碱指示剂检验、用 pH 计测浓度。教材还给了两个真实落点：水培营养液按 K⁺、NH₄⁺、NO₃⁻、PO₄³⁻ 的浓度要求选盐配制（p56 迁移·应用）；人体大量出汗或腹泻时 Na⁺、K⁺、Cl⁻ 随汗液流失，会恶心、呕吐、肌肉痉挛，所以要补水分和盐分——电解质饮料里 Na⁺ 约 21 mmol/L、K⁺ 约 5.4 mmol/L（p56–57 身边的化学+图2-2-7），自制时 1 L 水加 2 g 左右食盐即可（p57）。

    验一验②（30秒）：Ba(OH)₂ 是酸、碱还是盐？写出电离方程式。
    碱——它电离出的阴离子全部是 OH⁻。Ba(OH)₂ ═══ Ba²⁺ + 2OH⁻（p59 方法导引原式）。

    第③站离子反应：两杯"碎片水"相遇，谁动了谁的浓度

    电解质溶于水电离出自由离子，所以它们在水溶液中的反应一定与这些离子有关（p57）。教材做了一支"慢镜头"实验（观察·思考，p57–58）：向滴有酚酞的 Ba(OH)₂ 溶液中匀速滴加稀硫酸，用电导率传感器全程记录——

    这张图在说什么：电导率先跌到谷底再回升（图2-2-8 p58 实验曲线示意）。谷底=溶液里几乎没有自由离子了——H⁺、OH⁻、Ba²⁺、SO₄²⁻ 四种离子刚好"两两配对跑光"。

    为什么？看溶液里原本有什么（p58 原文逻辑）：硫酸电离出 H⁺ 和 SO₄²⁻，Ba(OH)₂ 电离出 Ba²⁺ 和 OH⁻。混合后：

    H+ + OH− → 难电离的 H2O　　Ba2+ + SO42− → BaSO4 沉淀

    四种离子两两"抱团"变成水（难电离）和硫酸钡（沉淀），溶液里自由离子急剧减少——电导率跌到谷底。这就是反应的实质。类似地，盐酸与 NaOH 溶液反应的实质就是 H⁺ 与 OH⁻ 结合生成水，Na⁺ 和 Cl⁻ 根本不参与（p58）。

    在溶液中有离子参加的化学反应称为离子反应（ionic reaction）（p58）。溶液中的某种或某些离子的浓度发生改变时，离子反应才能发生。

    酸、碱、盐在溶液里的复分解反应，生成难溶的物质（沉淀）、难电离的物质（如 H₂O）或挥发性物质（气体），都会让某些离子浓度降低——所以复分解反应都属于离子反应（p58）。

    验一验③（30秒）：NaCl 溶液和 KNO₃ 溶液倒在一起，有离子反应吗？
    没有。混合后四种离子（Na⁺、Cl⁻、K⁺、NO₃⁻）依然全部自由游离，没有任何离子浓度降低——不生成沉淀、难电离物或气体，离子反应不发生（p58 条件反推）。

    第④站离子方程式：把"一类反应"写成一行

    离子反应用离子方程式（ionic equation）表示（p59）。NaOH 溶液与稀盐酸的反应，化学方程式有千千万万个，但它们的离子方程式都是同一行：

    OH− + H+ ═══ H2O

    离子方程式表示的不仅仅是一个反应，而是一类反应，并且揭示了这类反应的实质（p60）——这就是它比化学方程式"值钱"的地方。

    写法A：教材方法导引三步（p59–60，以稀硫酸+Ba(OH)₂为例）

    第1步 定存在形式和数量关系：易溶于水且易电离的反应物（强酸、强碱、可溶性盐）按电离方程式写成离子符号，其他写化学式。H₂SO₄ ═══ 2H⁺ + SO₄²⁻（离子比 2:1）；Ba(OH)₂ ═══ Ba²⁺ + 2OH⁻（离子比 1:2）。

    第2步 确定真正反应的微粒、产物和数量关系：H⁺ 配 OH⁻ 生成水，Ba²⁺ 配 SO₄²⁻ 生成沉淀；生成的水是硫酸钡的 2 倍（p60 交叉配对图）。

    第3步 写出并配平：按电荷守恒+原子种类和数量守恒配平：

    2H+ + 2OH− + Ba2+ + SO42− ═══ 2H2O + BaSO4↓

    写法B：资料在线"改写法"四步（p61）

    步操作（p61 原文口径）以盐酸+NaOH为例
    1写出化学方程式HCl + NaOH ═══ NaCl + H₂O
    2改写：易溶易电离的拆成离子符号；难溶物、挥发物和水保留化学式H⁺+Cl⁻+Na⁺+OH⁻ ═══ H₂O+Na⁺+Cl⁻
    3删去未参与反应的离子删 Cl⁻、Na⁺
    4检查：电荷守恒+原子守恒H⁺ + OH⁻ ═══ H₂O ✓
    坑点2："拆不拆"只认三条——易溶、易电离、在溶液里。p64 练习4(1)是教材埋的正题：向碳酸钙（难溶固体）里加盐酸，CaCO₃ 必须整体写化学式，不能拆成 Ca²⁺+CO₃²⁻；同理氢氧化铜悬浊液也不拆。写成"CO₃²⁻+2H⁺=H₂O+CO₂↑"就是错的——错在把不在溶液里的东西当成自由离子了。
    卡住了？三步急救包：
    ① 忘了"谁拆谁不拆"→ 只背一句：强酸、强碱、可溶性盐拆；沉淀、气体、水、氧化物、弱电解质、难溶物不拆（写法B第2步原文口径）。
    ② 配平配不动 → 先配电荷（左右两边电荷代数和必须相等），再配原子个数；两个都平才算平。
    ③ 分不清"离子方程式对不对"→ 回到定义自查：它有没有让某些离子浓度降低？拆掉的微粒在操作条件下真的自由存在吗（p64 练习4 的判断标准）。

    离子反应的三个"实战应用"（p61）

    用途操作（p61 原文口径）离子方程式
    检验 SO₄²⁻先滴稀盐酸无明显现象，再滴 BaCl₂ 溶液出白色沉淀Ba²⁺ + SO₄²⁻ ═══ BaSO₄↓
    检验 Cl⁻滴 AgNO₃ 出白色沉淀，再滴稀硝酸沉淀不溶解Ag⁺ + Cl⁻ ═══ AgCl↓
    除杂分离用 CO₃²⁻ 除去溶液中的 Ca²⁺Ca²⁺ + CO₃²⁻ ═══ CaCO₃↓

    教材还安排了学生必做实验「食盐的精制」（p62–63）：氯碱工业用的粗食盐水中含 Ca²⁺、Mg²⁺、SO₄²⁻ 三种杂质离子，用 BaCl₂、NaOH、Na₂CO₃ 等把它们分别转化为沉淀，再定试剂添加顺序（后加的试剂要能顺便收走前面过量试剂引入的新杂质）并检验是否除净——这是"除杂五步法"（p62 方法导引）的完整落地。

    验一验④（挑战，1分钟）：K₂CO₃ 溶液与足量稀硫酸反应，写出离子方程式。
    K₂CO₃ 拆成 2K⁺+CO₃²⁻，H₂SO₄ 拆成 2H⁺+SO₄²⁻；真正反应的是 CO₃²⁻ 与 H⁺：CO₃²⁻ + 2H⁺ ═══ H₂O + CO₂↑（p64 练习2(3)同型·K⁺、SO₄²⁻ 旁观删去）。

    收口：把这一节带走

    三句话（能默写才算读完）：

    ① 溶于水或熔化时解离出自由离子=电离；能这么干的化合物=电解质（酸：阳离子全是 H⁺；碱：阴离子全是 OH⁻；盐：金属阳离子或铵离子+酸根）。

    ② 溶液里有离子参加、且某些离子浓度因此降低的反应=离子反应；复分解生成沉淀、水、气体，全都属于离子反应。

    ③ 离子方程式拆"强酸强碱可溶盐"、留"沉淀气体水"，按电荷守恒+原子守恒配平——它表示的是一类反应的实质。

    自测四连（自编，素材改编自教材 p64–65 练习与活动，答案侧自编并标注）：
    1．（改编自 p64 练习1(2)）KCl 溶液里大量存在的微粒是？——K⁺、Cl⁻（还有 H₂O；几乎无 KCl"分子"，因为它是可溶盐、在水中完全电离）
    2．（改编自 p64 练习3）H⁺ + OH⁻ ═══ H₂O 可以表示哪些反应？举两个。——盐酸+NaOH、稀硫酸+KOH 等强酸与强碱的中和（生成物只有难电离的水·Na⁺/K⁺ 与 Cl⁻/SO₄²⁻ 旁观）
    3．（改编自 p65 练习5）只取 E（0.1 mol·L⁻¹ Ba(OH)₂ 溶液），溶液里的离子及浓度是？——Ba²⁺ 0.1 mol·L⁻¹、OH⁻ 0.2 mol·L⁻¹（电离比 1:2，且电荷平衡 0.1×2=0.2×1）
    4．（改编自 p65 练习7(1)）显酸性的废水（含大量 Na⁺、Cu²⁺、Cl⁻、SO₄²⁻、NO₃⁻）中，Ag⁺ 和 CO₃²⁻ 能大量共存吗？——都不能：Ag⁺ 遇 Cl⁻ 生成 AgCl 沉淀（p61 检验反应）；CO₃²⁻ 遇 H⁺ 生成水和 CO₂（p64 练习3(4)）——离子浓度都会降低，离子反应发生
    高考怎么考（考位锚）：本节是全册"水中反应观"的地基。①离子共存判断（题面给酸性/碱性/某离子，问不能大量共存——实质=会不会发生离子反应）；②离子方程式正误判断与书写（拆留、守恒、按量反应）；③离子检验与除杂流程（Cl⁻/SO₄²⁻ 的"先酸化"防干扰逻辑、粗盐水除杂试剂顺序）。考法示意，真题锚候采如实申报、不代拟。
