校准件 · 化学1.1 走进化学科学
教材形态·首学版 v1.0 · 零基础

模块定位：本件属于「认识化学科学」模块——高中化学第一课，全书零前置，跟着走就行。教材＝山东科学技术出版社《化学》必修第一册（鲁科版2019）第1章第1节，印刷页2—9。版本链见文末foot。

开场：你翻开高中化学第一页，教材先替人类问了一个几千年的问题——物质究竟是什么？物质是由什么组成的？物质为什么会发生变化，又是如何发生变化的？（印刷页2原句）别慌，这一节不考你任何计算，它只干一件事：带你认识"化学"这门学科本身——它是怎么来的、它靠什么本事吃饭、它将来要往哪儿去。

✅ 节首清单（读完这节你能做到这4条，全部可自查）：
  1. 说出化学的定义，并指出定义里的研究对象和"原子、分子水平"这个层次；
  2. 排出近代化学五个里程碑的先后顺序，并把每个人和他的贡献对上号；
  3. 配对化学科学的三大特征和青蒿素之旅的对应环节（哪个环节体现哪个特征）；
  4. 举例说明"化学是一门具有创造性的科学"和"现代化学是实验与理论并重的科学"。
🧗 预备块（零基础30秒）——三个词先过一遍，后面全程要用： 原子：组成物质的最小微粒之一，好比盖楼的砖；分子：由原子按一定方式组合成的小集团，好比几块砖砌成的一小段墙；元素：同一类原子的总称（比如所有氧原子的统称就叫氧元素）。化学＝研究"变化的科学"——研究物质怎么组成、怎么变、怎么造出新的。

一、化学科学的形成与发展 站1

教材把化学的过去分成三段：古代实用技术 → 近代理论奠基 → 现代全面发展。我们一段段走。

第1段：古代——从"会用"到"想要更多"

早在远古时代，我们的祖先就知道了如何取火和保存火种。可以说，从那时起人类就开始了"化学活动"（印刷页2）。在长期的生产和生活实践中，人们学会了烧制陶瓷、冶炼金属、酿造酒类。教材还记了一笔有意思的账：有一些被称为炼丹家或炼金士的人，试图炼出使人长生不老的丹药，或把廉价金属炼成贵重的金——目标虽未达成，但"用手段促使物质转化"这个化学的核心动作，他们已经在做。◎辅助理解｜炼丹炼金算不算化学？教材的观点很宽容：它们是"化学活动"的蒙昧阶段——方向错了，动作没错。

第2段：近代——五个人，五块里程碑（本节第一个必背点）

进入近代，化学科学体系逐渐形成。在实践活动的基础上，化学家经过不断的努力，建立起科学的元素观，提出了氧化学说、原子论和分子学说，发现了元素周期律（印刷页3）。具体里程碑按时间线排：

这张图在说什么：五个里程碑按年份排成一条时间线——1661波义耳起（近代化学诞生）、1869门捷列夫收（统一理论体系），中间三格按"氧→原子→分子"的顺序推进。
📌 记忆锚（自编）：五个里程碑只锚"首尾两个钉子+中间三个顺口溜"——首钉1661波义耳=近代化学诞生，尾钉1869门捷列夫=统一理论体系；中间三个按"氧→原子→分子"的顺序背：拉瓦锡氧化学说（1777）→道尔顿原子论（1803）→阿伏加德罗分子学说（1811）。年份不用死背，会排序即可。
⚠ 易错（红笔旁批）：①"标志着近代化学诞生"的是波义耳，不是门捷列夫；②提出分子学说的是阿伏加德罗（意大利），别跟提出原子论的道尔顿（英国）串线；③门捷列夫是发现元素周期律（俄国人），周期律不是他"发明"的，是"发现"的。
自验①（30秒，答案就近可见）：把下面两列配对——
A.波义耳　B.拉瓦锡　C.道尔顿　D.阿伏加德罗　E.门捷列夫
①原子论　②化学元素概念　③元素周期律　④分子学说　⑤氧化学说
答案：A-②　B-⑤　C-①　D-④　E-③。全对进站2；错一个，回上面的时间线找那一格再看一眼。

第3段：现代——认识升级+出手带动别的学科

进入20世纪后，随着人们对物质世界的认识由宏观向微观、由定性向定量、由静态向动态的不断深入，化学科学迅速发展，进入了辉煌的现代化学时代（印刷页3）。三个"由…向…"就是现代化学的三级跳：看得更小（宏观→微观）、算得更准（定性→定量）、盯得更活（静态→动态）。教材列出的现代重大成就有：放射性元素的发现、现代量子化学理论的建立、化学热力学与动力学的开创性研究、创造新分子的合成化学的崛起、高分子化学的创立以及化学工业的快速发展（印刷页3-4）。◎辅助理解｜"定性"＝只问有没有/是不是，"定量"＝要算出具体是多少；"热力学与动力学"＝研究变化"能不能发生"和"发生得快慢"的两个分支，这里认个名就行。

更值得注意的是教材专门强调的"带动作用"——现代化学不仅自己完善，还带动了相关科学：

  • 带动生命科学：1965年，我国科学家成功地合成了结晶牛胰岛素，在世界上首次实现了蛋白质的人工合成（印刷页4）；
  • 带动生态学：研究生物之间化学联系及其机制的化学生态学于20世纪50年代末诞生，为病虫害治理、生物多样性保护、生物资源合理利用提供科学模式和理论依据（印刷页4）；
  • 推动人类文明：教材连发三问——没有合成氨的化工技术，哪来促进粮食增产的大量氮肥？没有新药物的成功研制，如何战胜危及生命的疾病？没有合成高分子材料和以硅及其化合物为原料造出的芯片和光导纤维，生活怎么会像现在这样丰富多彩？（印刷页4）
【课外可选·自编】教材印刷页5"资料在线"列了六位研究领域与化学相关的国家最高科学技术奖获得者（闵恩泽、徐光宪、师昌绪、张存浩、屠呦呦、赵忠贤、王泽山）。想加分了解可查每人贡献；不想看完全不影响本节——这块教材本身就标了"资料在线"，属于自主阅读栏。

二、化学科学的主要特征 站2

这一站是全节的核心考位——定义+三大特征。教材原句一个字都要读进去：

化学是在原子、分子水平上研究物质的组成、结构、性质、转化及其应用的一门基础学科，其特征是从宏观和微观两个角度认识物质、以符号形式表征物质、在不同层面上创造物质（印刷页5）。

把这句定义拆成三小块记：

  1. 研究什么：物质的组成、结构、性质、转化及其应用——五个词，就是后面整本书的目录骨架；
  2. 在什么层次研究：原子、分子水平——比肉眼看到的小十亿倍的那个世界；
  3. 怎么研究（三大特征）：宏观和微观两个角度认识物质（既看看得见的颜色状态，又想看不见的分子原子）＋以符号形式表征物质（用化学式等符号代实物）＋在不同层面上创造物质。
📌 记忆锚（自编）：三大特征＝"两个角度看、一套符号写、各种层面造"。

特征①的展开——创造性：利用化学方法，人们不仅从矿物和动植物体中发现并提取有用物质，还能根据需要创造出自然界中原本不存在的、具有特殊性质或功能的新物质。现在，化学家已发现和创造了上亿种物质。从这一角度来看，化学科学是一门具有创造性的科学（印刷页5）。

特征②的展开——实验与理论并重：现代化学已经成为实验与理论并重的科学（印刷页5）。一手是实验：分析和测试物质结构、跟踪化学反应过程的技术，如波谱、色谱、X射线衍射、飞秒化学、原子示踪等（教材配了质谱仪、核磁共振仪、X射线衍射仪三张仪器图，印刷页6）；另一手是理论：理论计算辅以计算机模拟来研究物质的结构、预测物质的反应活性、研究反应的微观过程（印刷页6）。◎辅助理解｜五个技术名词考试不考原理，认字即可；考的是"实验与理论并重"这句话本身。

本站压轴案例：青蒿素——化学三大特征的活教材

2015年10月，我国科学家屠呦呦获诺贝尔生理学或医学奖，颁奖词写道："屠呦呦发现了青蒿素，这种药品有效降低了疟疾患者的死亡率""对全球的影响及对人类福祉的改善是无可估量的"（印刷页6）。教材用整页时间线（图1-1-12，印刷页7）还原了青蒿素的发现、研究与应用之旅——注意看，这条旅程正好把"组成、结构、性质、转化、应用"五环节走了一遍：

这张图在说什么：一个药从"发现"到"上柜救命"要走七站——提取→晶体→组成→结构→合成→应用，年份从1967到2001跨越三十多年，每一站都是化学基本特征的一次实战。

逐站挑重点说：

  • ②提取是"性质决定分离方法"的示范：水煎熬无效、乙醇提取药效也不高——受《肘后备急方·治寒热诸疟方》"青蒿一握，以水二升渍，绞取汁，尽服之"绞取法启发，改用沸点比乙醇更低的乙醚（34.6℃）冷提取，1971年10月4日测得对疟原虫的抑制率达100%（印刷页7）；◎辅助理解｜乙醚沸点低意味着"温柔"——高温会破坏有效成分，低温提取正好保住它。青蒿素的提取利用了物质"易溶于乙醚、受热易破坏"的性质。
  • ④确定组成：用高分辨率质谱仪测得相对分子质量，结合碳氢分析数据确定分子式C₁₅H₂₂O₅——数一数：15+22+5＝42个原子（印刷页7）；
  • ⑤测定结构：1975年用X射线衍射技术确定42个原子的空间位置；
  • ⑥合成与修饰：1978到1984年初历时5年多实现全合成，为衍生药物（双氢青蒿素、蒿甲醚）开发奠基；1986年获一类新药证书（印刷页7）；
  • ⑦广泛应用：2001年世界卫生组织向恶性疟疾流行国家推荐以青蒿素为基础的联合疗法，2004年正式将青蒿素复方药物列为治疗疟疾的首选药物（印刷页7）。
自验②（40秒，答案就近可见）：
(1) 化学定义中的五个研究对象词是____、____、____、____、____。
(2) 三大特征中"以符号形式表征物质"，在青蒿素之旅里对应哪一站？
答案：(1)组成、结构、性质、转化、应用（顺序可换）。(2)对应第④站——"C₁₅H₂₂O₅"就是用一串符号代替了青蒿素这个实物分子。
🧗 卡住了？（站2常见两个卡点）①"三大特征背了就忘"——出路：别背名词，回想三件事：化学家看物质要两副眼（宏观+微观），写物质用一行符号，造物质在各个层面（分子/材料/工业）——动作记住了，名词自然长回来。②"青蒿素七站记不全"——出路：只抓主线"找得到（提取）→算得清（组成）→看得见（结构）→造得出（合成）→用得上（应用）"，年份全不用背。

三、化学科学的探索空间 站3

学科版图：现代化学已具有庞大的学科体系——在原有的有机化学、无机化学、物理化学、分析化学和高分子化学等学科基础上，发展出许多新兴分支学科，并与材料、资源、能源、生态、环境、医药、生命、国防、信息技术九大领域形成很强的交叉融合（印刷页8）。

四个大显身手的方向（教材展望，印刷页8-9，记忆时抓各句动词）：

  1. 微观领域：化学家已能在微观层面上操纵分子和原子，组装分子材料、分子器件和分子机器（教材配图"分子齿轮"）；
  2. 资源与能源：更加科学、合理地开发与利用；
  3. 材料科学：使各种新型材料的制造成为可能；
  4. 环境问题：为解决环境问题提供有力保障，使环境监测和治理手段更加快速、灵敏，实现科学防治。

两个"资料在线"（自主阅读栏，考概念不考细节）：

  • 大连相干光源（印刷页8）：由我国化学家设计、90%仪器设备为我国自主研发，是当今世界上唯一运行在极紫外波段的自由电子激光装置，也是世界上最亮的极紫外光源——它能给分子、原子在化学反应中"拍电影"，为揭示反应微观过程提供支撑。
  • 油水分离膜材料（印刷页9）：我国化学家合成了在水中具有超疏油性的膜材料——油水混合物穿过它时，水自由通过、油被阻隔富集，这种材料是超亲水性和超疏油性两种功能的复合体。

收束句：化学还将为生命科学（从分子层次了解生命本质、研制新药物）和信息科学（研制电子材料、光电子材料，支撑传感、通信和计算机技术）作出更大贡献——现代化学作为一门"中心科学"，正在以崭新的姿态与人类经济社会的各个领域保持着密切的联系（印刷页9）。

自验③（30秒，答案就近可见）：化学将在哪些领域"大显身手"？请说出至少四个方向。
答案：微观领域（操纵分子原子/分子机器）、资源和能源的开发利用、材料科学（新型材料）、环境问题（监测治理科学防治）；再加分项：生命科学（分子层次/新药物）、信息科学（信息材料）。
【课外可选·自编】"分子机器"不是教材内容，给你一个延伸钩子：2016年诺贝尔化学奖即授予了分子机器的设计与合成（三位获奖人那一年把"分子齿轮/分子电梯"从图纸变成了实物）——教材印刷页8"分子齿轮"图正是这一方向的示意。想深挖再去查，本节考试范围不含此条。

收口 · 三句话 终

①定义了什么：化学＝在原子、分子水平上研究物质的组成、结构、性质、转化及其应用的基础学科。
②怎么用：看到任何化学成就，用"三特征"切一刀——两个角度认识的？符号表征的？哪个层面创造的？再用"五环节"走一遍——组成→结构→性质→转化→应用卡到了哪格（青蒿素就是全链示范）。
③最易错：诞生归波义耳、原子论归道尔顿、分子学说归阿伏加德罗、周期律是门捷列夫"发现"的——四个人名别串线；"创造新物质"≠"发明新元素"。

本节为绪论性质单元，高考直接命题少，常见考法为学科特征判断题（创造性/实验理论并重/宏观微观结合）与化学史排序配对（五里程碑）。
