📍 本件属于第2章"元素与物质世界"模块，前面已学：2.1元素与物质分类（物质家族树）→ 2.2离子反应（电解质·电离）。没读过2.2？看这句就够：氯化钠溶于水会"散架"成Na⁺和Cl⁻——本节要盯的正是这些离子得失电子的过程。

初中你跟"铜"打过四次交道（教材p66"联想·质疑"）：铜丝在空气中加热变黑、用氢气还原氧化铜、把铁丝插进CuSO₄溶液长出"铜树"、向CuSO₄溶液滴加NaOH溶液析出蓝色沉淀。

前三个和第四个"长得"不一样：前三者里有些元素的化合价变了，第四个里谁的化合价都没动。教材问：前三者与最后一者的特征有什么不同？本质是怎样的？

本节就干一件事：给化学反应换上"化合价／电子转移"这副透视眼——看清前三类反应里电子是怎么搬家的，并学会给搬家的双方派角色、算账目、找用途。

读完这节你能

① 用"有没有元素化合价变化"给化学反应再分类，一句话说清什么是氧化还原反应；

② 说清四组概念的连环对应：氧化反应／还原反应 → 氧化剂／还原剂 → 氧化性／还原性；

③ 用双线桥、单线桥两种方式标出电子转移，并从价态趋势预测物质的氧化性／还原性（配实验验证思路）；

④ 说出氧化还原反应的三大用途（研究物质性质／实现物质转化／获得能量）与工业实例（冶炼三法、实验室制氯气、钛与硅的制备、燃料电池）。

先拆掉两个旧印象

误会一："氧化反应 = 物质与氧结合，还原反应 = 氧化物失去氧"。这是初中的口径，没错，但太窄。本节的"氧化／还原"范围大得多：凡是元素化合价升高就叫氧化，化合价降低就叫还原——有没有氧参加都行。比如金属钠在氯气里燃烧生成NaCl，整个体系里压根没有氧，它照样是教科书级的氧化还原反应（p67–68）。

误会二："氧化剂、还原剂是危险的'坏东西'"。它们是化学视角里的中性角色：84消毒液、医用双氧水消毒靠的是氧化性；冶金炼铁、电池供电靠的是还原剂一方。教材p72原话——氧化还原反应"在人类的生产和生活中无处不在"，角色本身没有善恶，用对地方才是关键。

名词补齐（进门前对齐三件事）：
① 化合价——初中你已经会给常见物质标价态（如H₂O中H为+1、O为−2；单质为0），本节全部用法从这一技能出发；
② redox——教材注英文 redox reaction（p67），它是 reduction（还原）+ oxidation（氧化）的拼合词，一个词提醒你：升与降永远成对出现；
③ 电子转移——电子从一个原子（或离子）身边跑到另一个原子（或离子）身边，本节将证明它是化合价升降的幕后推手。

第1步给化学反应换上"化合价眼镜"

把p66–67那四个反应连同化合价一起摆上台面（价态标注依教材p67原样）：

  • 2Cu + O₂ ==Δ== 2CuO　Cu：0→+2，O：0→−2 （有升降）
  • H₂ + CuO ==Δ== Cu + H₂O　H：0→+1，Cu：+2→0 （有升降）
  • Fe + CuSO₄ == Cu + FeSO₄　Fe：0→+2，Cu：+2→0 （有升降）
  • CuSO₄ + 2NaOH == Cu(OH)₂↓ + Na₂SO₄　Cu、S、O、Na、H逐个查：全部原地不动 （无升降）
定义（p67原句）：从反应过程中有无元素化合价变化的角度，可以将化学反应分为两大类。在反应过程中有元素化合价变化的化学反应称为氧化还原反应（redox reaction）；没有元素化合价变化的化学反应则不属于氧化还原反应。

再往反应内部看一层（p67原句）：反应物所含某种（或某些）元素化合价升高的反应称为氧化反应（oxidation）；元素化合价降低的反应称为还原反应（reduction）。例如H₂与CuO的反应中，氢元素化合价升高发生氧化反应，铜元素化合价降低发生还原反应。

对立统一（p67原话）：氧化反应和还原反应这两个对立的过程相互依存，统一于一个氧化还原反应之中。想一想就明白：一方升价=交出电子，另一方降价=收进电子——有升必有降，一份电子不可能只交不收。所以"氧化"与"还原"永远捆绑出现。

第2步往下挖一层：升降的背后是电子转移

化合价为什么会变？教材给了两台"显微镜"（p68）：

镜头一：钠在氯气里燃烧——原子变离子

当金属钠与氯气反应时，钠原子失去1个电子形成Na⁺，钠元素化合价由0价变为+1价；氯原子得到1个电子形成Cl⁻，氯元素化合价由0价变为−1价。Na⁺和Cl⁻通过静电作用形成氯化钠（p68原句）。可见：升降1格 ⇋ 转移1个电子，价态的账本和电子的账本一一对账。

镜头二：铁与硫酸铜溶液——电子真的在"流动"

铁与CuSO₄溶液反应时，铁原子把电子转移给Cu²⁺形成Fe²⁺，Cu²⁺得到电子形成铜原子（p68原句）。这个实验（p67交流·研讨第2问·图2-3-2）妙在装置里铁片与碳棒隔着CuSO₄溶液、外接电流表——电流表指针偏转说明电子真的在导线里定向流动。这一现象给你的启示：氧化还原反应里电子的转移是可以实测的物理事实，不是抽象比喻。

结论（p68原句）：研究表明，所有的氧化还原反应中都存在电子转移，电子转移是氧化还原反应的实质。元素化合价的变化是电子转移的外在表现——可以通过分析反应中是否有元素的化合价发生变化，来判断某个反应是否属于氧化还原反应。

红笔旁批：桥上"失去1e⁻×2"——×2是原式系数（2Na共2个原子），1e⁻是单个原子转移数，合计转移2e⁻。两个数抄反=白写（自测四连第2题埋了这个点）。

易错坑

问"本质"答"电子转移"，问"判断依据（外在表现）"答"化合价有无变化"。两个词混着写要丢分：本质在前台看不见，看得见的是价态——透过价态看电子，才是"透视眼"的正确用法。

方法导引：两种标电子转移的方式（p68蓝框）

规则（p68原话）：在氧化还原反应中，某种元素的一个原子或离子失去电子，则该元素的化合价升高，而且失去电子的数目与化合价升高的数值相等；得到电子，则化合价降低，而且得到电子的数目与化合价降低的数值相等。

对应关系（p68框原话）：元素化合价升高 ⇋ 原子或离子失电子 ⇋ 发生氧化反应；元素化合价降低 ⇋ 原子或离子得电子 ⇋ 发生还原反应。

第3步氧化剂和还原剂：谁"使谁"变

教材先用三道反应让你摸规律（p69交流·研讨）：（1）2Cu+O₂=Δ=2CuO（2）H₂+CuO=Δ=Cu+H₂O（3）3CO+Fe₂O₃=高温=2Fe+3CO₂——哪种反应物含化合价升高的元素？哪种含降低的？盯住"升／降"就能派角色了。

定义（p69原句）：在氧化还原反应中，所含某种（或某些）元素化合价降低的反应物称为氧化剂（oxidizing agent）；所含某种（或某些）元素化合价升高的反应物称为还原剂（reducing agent）。氧化剂具有氧化性，在氧化还原反应中被还原，发生还原反应；还原剂具有还原性，在氧化还原反应中被氧化，发生氧化反应。

四连环对应（把p69定义拆成流水线）：氧化剂→降价→收电子→被还原→发生还原反应→具有氧化性；还原剂→升价→交电子→被氧化→发生氧化反应→具有还原性。

卡住了？换个说法

把反应想成"电子搬运现场"：还原剂是捐电子的，氧化剂是收电子的。捐出=升价=被氧化；收进=降价=被还原。最容易拧巴的是"剂"与"性"——记住四个字：剂性相反（还原剂表现的是还原性，干的却是被氧化的活；氧化剂反着来）。例（p69原句）：H₂与CuO反应，CuO中铜元素化合价降低，CuO是氧化剂；氢气中氢元素化合价升高，H₂是还原剂。

价态趋势：预测氧化性／还原性的"罗盘"（p69）

教材原话：氧化还原反应为我们认识和研究物质增添了新的视角——从氧化性、还原性的角度认识和研究物质的性质。当某物质所含元素处于较高价态时，元素有降低价态的趋势，该物质可能具有氧化性；当某物质所含元素处于较低价态时，元素有升高价态的趋势，该物质可能具有还原性。例如高锰酸钾中的锰元素为+7价，为锰的最高价态，高锰酸钾具有氧化性；碘化钾中的碘元素为−1价，为碘的最低价态，碘化钾具有还原性。

图B 价态趋势罗盘——最高价只降（KMnO₄·Mn为+7）·最低价只升（KI·I为−1）·中间价态可升可降（H₂O₂·O为−1·即本节活动·探究对象；"兼有两种性质"由教材价态趋势句与探究活动合乎逻辑地推出·成稿已标"推论"）

教材实证（p69–70·图2-3-3）：向酸性KMnO₄溶液（紫色）滴加KI溶液，溶液由紫色变成棕黄色，有碘单质和Mn²⁺生成。锰元素化合价降低，高锰酸钾做氧化剂；碘元素化合价升高，碘化钾做还原剂。

常见氧化剂／还原剂清单（p70原句·建议整段背）

  • 常见氧化剂：氧气、氯气等活泼的非金属单质；硝酸、浓硫酸等含较高价态元素的含氧酸；高锰酸钾、氯酸钾、氯化铁等含较高价态元素的盐。
  • 常见还原剂：活泼的金属单质；碳单质、氢气等非金属单质；一氧化碳、二氧化硫等含较低价态元素的氧化物；碘化钾、亚硫酸钠、硫酸亚铁等含较低价态元素的盐。

第4步学了做什么：研究性质 · 实现转化 · 获得能量

用途1 研究物质的性质（三、1·p70）

思路（p70原句）：我们可以利用氧化还原反应，通过分析物质所含元素化合价的升降趋势，研究物质的还原性或氧化性。

教材活动·探究：探究物质的氧化性或还原性（p70）——过氧化氢（H₂O₂）中氢元素为+1价、氧元素为−1价。氧处于−1价：往下降可以到H₂O中的−2，往上升可以到O₂中的0——两种方向都"有路"，故预测H₂O₂可能两种性质兼备。实验用品（p70原单）：5% H₂O₂溶液，酸性KMnO₄溶液，KI溶液，淀粉溶液；试管，胶头滴管。

方法导引（p71蓝框·原话两步）：①根据物质所含元素化合价升高或降低的可能性，预测物质可能具有还原性或氧化性——价态有升高趋势说明可能有还原性，反之可能有氧化性；②如果预测某物质具有氧化性，就需要寻找具有还原性的另一物质，通过实验检验两者能否发生氧化还原反应，以验证预测是否正确（预测具有还原性时反过来找氧化性物质）。

强弱与环境（p71原句）：物质的氧化性或还原性的强弱是由物质得失电子的能力决定的；借助氧化还原反应可以比较不同物质氧化性或还原性的强弱。环境条件也会影响强弱——例如常使用酸性条件下的KMnO₄溶液做氧化剂（实际上是其中的MnO₄⁻参与氧化还原反应），因为大部分含氧酸的酸根离子做氧化剂时，溶液的酸性越强，含氧酸根离子的氧化性就越强。

用途2 实现物质转化与获得能量（三、2·p71–73）

图C 金属冶炼三法殊途同归（依教材p71原文重绘·SVG坐标python脚本生成·留痕随附件2）

教材原句：以金属的冶炼为例，热还原法、金属置换法、电解法都是常见的方法。热还原法是以碳、一氧化碳等物质作为还原剂，在加热条件下将金属氧化物还原为金属单质（如用一氧化碳还原铁的氧化物得到金属铁）；金属置换法是利用置换反应，以活泼金属为还原剂，将目标金属从其盐溶液中还原出来（如用铁从CuSO₄溶液中置换出铜）；电解法是利用外加电源提供电子，使金属元素的化合价降低，从而获得金属单质（如电解氧化铝制备金属铝）。无论哪种冶炼方法，本质都是利用氧化还原反应中的电子转移，使被还原的化合物中的金属元素化合价从正价降低至0价，生成金属单质。

获得能量（p71+p73）：氧化还原反应不仅是获得物质的重要方式，也是获得能量的重要途径——利用可燃物作还原剂、选择合适的氧化剂与之反应可获得热能；还可以利用氧化还原反应获得电能：燃料电池利用氢气、天然气等燃料做电池负极反应物，发生氧化反应；利用空气中的氧气做电池正极反应物，发生还原反应；连接外电路时，电子从负极移向正极形成电流（p73原句）。

第5步实战认证：舍勒的氯气与身边的化工

案例一 实验室制氯气（p72迁移·应用）

史实（p72原句）：瑞典化学家舍勒（C.W.Scheele）是最早发现氯气的人。他在研究软锰矿矿石（主要成分是二氧化锰）时，把浓盐酸和软锰矿矿石混合加热，意外地得到了氯气。至今，实验室中还用这种方法制取氯气：

MnO₂ + 4HCl(浓) ==Δ== MnCl₂ + Cl₂↑ + 2H₂O

三问解析（p72原题·解析为成稿给出）：

  • (1) 属于氧化还原反应吗？——Mn由+4→+2（降低），Cl由−1→0（升高；注意4个Cl中只有2个变成Cl₂，另2个留在MnCl₂里价态不变）→属于；氧化剂=MnO₂，还原剂=HCl。
  • (2) NaOH吸收尾气+提纯——Cl₂+2NaOH=NaCl+NaClO+H₂O：Cl₂中的一个Cl降到−1、另一个升到+1，氯气既是氧化剂又是还原剂，既表现氧化性又表现还原性（NaClO为次氯酸钠·名称后续章节正式学）。若要纯净氯气，收集前需加盛饱和食盐水的洗气瓶（除挥发出的HCl）和盛浓硫酸的洗气瓶（干燥）（方案为成稿解析·拓展标注）。
  • (3) 高锰酸钾与浓盐酸常温制氯气——预测依据：KMnO₄中Mn为+7最高价态（图B罗盘"只能降"），常温即可氧化Cl⁻。方程：2KMnO₄ + 16HCl(浓) = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O（成稿解析·与p69–70 KMnO₄/KI反应同族逻辑）。

案例二 化工一线两例（p72–73化学与技术框·原句）

钛：金属钛性能优异，是航空、军工、电力等领域的必需材料。大规模生产两步走——第一步，让金红石（主要成分TiO₂）、碳单质在高温下与氯气反应制得四氯化钛（TiCl₄）；第二步，在氩气氛围中加热，使金属镁与四氯化钛反应制得金属钛（钛合金广泛应用于飞机制造业·图2-3-5）。

硅：硅元素在自然界不以单质形式存在，主要以SiO₂形式存在。用碳单质还原二氧化硅制得粗硅；使粗硅与氯气反应生成四氯化硅（SiCl₄），净化后再用氢气还原四氯化硅，可制得比较纯净的硅单质——芯片与光导纤维的原料之路。

三句话带走 + 自测四连

① 判断氧化还原反应看化合价有无变化（外在表现），它的实质是电子转移；

② 一句口诀挂墙上：升失氧、降得还；剂与性，正相反——氧化剂被还原、还原剂被氧化，四连环一路推；

③ 价态是罗盘：最高价只有氧化性（KMnO₄）、最低价只有还原性（KI）、中间价两性兼备（H₂O₂）；研究新物质的思路=价态预测＋找另一反应物实验验证；它支撑冶炼三法、燃料电池与整个化工的"物质转化+能量获取"。

自测四连

1. "有单质参加的反应一定是氧化还原反应"对吗？

✗。反例：2O₃=3O₂（同素异形体互变·氧始终0价）；石墨→金刚石同款。（反例为成稿补充·拓展标注；正例如Fe+CuSO₄）

2. 双线桥上"失去1e⁻×2"是什么意思？

1个原子失1个e⁻、共2个原子参与——×号前是单个原子的转移数，×号后是参与原子数（即系数），合计转移2e⁻。

3. H₂O₂与酸性KMnO₄反应，H₂O₂是什么剂？

还原剂——O由−1→0升高，表现还原性（紫红色褪去的那个反应）。

4. 燃料电池里电子往哪流？

负极（燃料·氧化反应）→外电路→正极（O₂·还原反应），形成电流（p73原句）。
