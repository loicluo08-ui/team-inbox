氧化还原反应：谁丢了电子，谁捡了电子——从"化合价变了"追到"电子搬家"

化学 2.3 · 鲁科版《必修 第一册》第2章第3节 · 教材印刷页 p66–75 · 零基础首学版 v1.0（出品：并行搜索员B·队3席B线·1031）
初中你学过一把老尺子：得氧、失氧。碳在氧气里燃烧，碳"得氧"被氧化；氢气把氧化铜还原成铜，氢气"得氧"被氧化、氧化铜"失氧"被还原。这把尺子好用，但教材 p66 的四个实验里藏着一个它解释不了的：把铁丝插进 CuSO₄ 溶液，铁丝上长出红色的"铜树"（图2-3-1）——这个反应和"碳燃烧"很像，可里面根本没有氧气，"得氧失氧"从哪谈起？老地图失效了。这一节我们换一把新尺子：盯住化合价，谁升价、谁降价，一眼分清；再往深处追一层，会发现化合价升降的背后，是电子在微粒之间搬家。
读完这节你能：
  • 用化合价判断一个反应是不是氧化还原反应，指出哪个元素升价（被氧化）、哪个降价（被还原）；
  • 说清它的实质=电子转移，会用双线桥 / 单线桥标出电子转移的方向和数目；
  • 认出反应里的氧化剂和还原剂，并用"高价态→氧化性、低价态→还原性"预测物质性质；
  • 说出氧化还原反应的三大用途：预测性质、冶炼金属（热还原/置换/电解）、获得能量（燃料电池）。
    • 开讲前的三件预备（都没有就先补这三件）：

    ① 化合价尺子（本节全程的判断工具）：常见元素在化合物里的价态——K、Na 为 +1，Ca、Mg 为 +2，Al 为 +3，H 为 +1，O 为 −2，Cl 为 −1；单质一律 0 价；化合物里各元素价态的代数和=0（比如 KMnO₄：+1 + Mn + 4×(−2)=0，解出 Mn=+7）。本节所有判断都从"标价态"开始。

    ② 初中旧定义（即将被升级）："得氧→被氧化、失氧→被还原"。记住它的适用范围：只对有氧气参与的反应有效。

    ③ e⁻ 怎么读：e⁻ 表示 1 个电子，2e⁻ 表示 2 个电子。"失去 1e⁻ × 2"= 每个原子失 1 个电子、共有 2 个原子在失，合计 2 个电子（×2 标的是原子个数，不是电子数）。

    第①站化合价变了没有：氧化还原反应的"长相"（p66–67）

    教材把四个"铜的化学"摆在一起（p66 联想·质疑，图2-3-1），让我们给它们标价态。化合价一标，高下立判（p67）：

    反应（p67）化合价变化判断
    2Cu + O₂ Δ 2CuOCu：0→+2（升）；O：0→−2（降）有升降 → 算
    H₂ + CuO Δ Cu + H₂OH：0→+1（升）；Cu：+2→0（降）有升降 → 算
    Fe + CuSO₄ ═══ Cu + FeSO₄Fe：0→+2（升）；Cu：+2→0（降）有升降 → 算
    CuSO₄ + 2NaOH ═══ Cu(OH)₂↓ + Na₂SO₄Cu、S、O、Na、H 全都没变全没变 → 不算

    于是定义水到渠成：

    在反应过程中有元素化合价变化的化学反应称为氧化还原反应（redox reaction）（p67）。反应物所含某种（或某些）元素化合价升高的反应称为氧化反应（oxidation）；化合价降低的反应称为还原反应（reduction）（p67）。

    注意教材的收尾一句：氧化反应和还原反应是两个对立的过程，相互依存，统一于同一个氧化还原反应之中（p67）——有升必有降，像天平两端，不可能只出现一个。

    验一验①（30秒）：CH₄ + 2O₂ 点燃 2H₂O + CO₂（甲烷燃烧）算不算氧化还原反应？
    算。C：−4→+4（升·被氧化），O₂ 里的 O：0→−2（降·被还原）；H 不变（+1）。只要有升降就算——和有没有"氧参加"无关，O₂ 在这里只是"恰好是降价的一方"。
    坑点1：判断只认"化合价变没变"，不看别的。两个反例夹住它：CaCO₃ 高温 CaO + CO₂↑——虽然拆成了新物质，但 Ca、C、O 价态全没变，不是氧化还原反应（p74 练习1(1)）；2KMnO₄ Δ K₂MnO₄ + MnO₂ + O₂↑——Mn：+7→+6 和 +4（降），O：−2→0（升），是。别用"有没有单质参加/生成"来当判据，那只是线索。

    第②站镜头拉近：升价的背后，是电子在搬家（p67–68）

    化合价为什么会变？教材先让你做一个思想实验（p67 交流·研讨）：金属钠在氯气里剧烈燃烧生成 NaCl——反应前是钠原子（Na，0 价）和氯原子（Cl，0 价），反应后却是 Na⁺ 和 Cl⁻（p67）。从原子变离子，发生了什么？再看一个真实验（p67 图2-3-2）：把铁片和碳棒插进 CuSO₄ 溶液、接上电流表——指针偏转了。电流=电子在流动。这两个线索拼在一起，答案就出来了：

    这张图在说什么：钠原子把最外层的 1 个电子"让"给氯原子——Na 从 0 价升到 +1 价，Cl 从 0 价降到 −1 价（p68 原文过程）。化合价的升降，就是电子得财务馆的"账本"。

    教材的原文结论（p68）值得逐句读：

    所有的氧化还原反应中都存在着电子转移，电子转移是氧化还原反应的实质。元素化合价的变化是电子转移的外在表现，可以通过分析反应中是否有元素的化合价发生变化，来判断某个反应是否属于氧化还原反应（p68）。

    这句话给了一件很实用的事：肉眼看不见电子，但化合价可以查——所以"标价态"成了判断氧化还原的标准动作。Fe 与 CuSO₄ 的反应同理：铁原子把电子转移给 Cu²⁺ 生成 Fe²⁺，Cu²⁺ 得电子变回铜原子（p68）——电流表偏转正是电子在外电路流动的证据。

    把电子转移"画"出来：双线桥与单线桥（p68 方法导引）

    教材用 2Na + Cl₂ 的两个方程教了两种画法。先看双线桥（箭头从反应物指向生成物里"变价后的同种元素"，桥上写"升降/得失电子数/被氧化或被还原"）：

    这张图在说什么：双线桥=同种元素"变身前后"各画一个箭头。Na：0→+1，每个 Na 失 1e⁻、共 2 个 Na，所以"失去 1e⁻ × 2"；Cl：0→−1，"得到 1e⁻ × 2"。两条桥上的电子数必然相等（p68）。

    再看单线桥（一根箭头，从失电子方直接指到得电子方，桥上只写转移的电子总数）：2Na + Cl₂ 上方一根桥线，标"2e⁻"（p68）——2 个 Na 各失 1 个电子，共 2 个，全部转给 Cl。双线桥重在"谁升谁降"，单线桥重在"电子从谁给谁"，考试里按题目要求选画法。

    验一验②（30秒）：Fe + CuSO₄ ═══ FeSO₄ + Cu 里，电子从谁搬到谁？搬了几个？
    从 Fe 搬到 Cu²⁺：Fe 0→+2 失去 2e⁻，Cu +2→0 得到 2e⁻，转移电子数 2e⁻（得失相等，各 2 个）。
    卡住了？三步急救包：
    ① 分不清升降价 → 自编口诀（显式标注）："升失氧、降得还"——化合价升、失电子、被氧化（三件事绑在同一个元素身上）；价降、得电子、被还原。再用代数和=0 复核一遍标价。
    ② 双线桥的 ×2 老写错 → 记住"每原子 × 原子个数"：1e⁻ × 2 表示"每个原子 1 个、共 2 个原子"；若每个原子失 2e⁻、共 3 个原子，就写 2e⁻ × 3。
    ③ 桥线画到谁头上拿不准 → 双线桥永远"同种元素变身前后"连线（Na→Na 的位置）；单线桥永远"失方→得方"。画完自查：两条桥（或一根桥）的电子总数必须相等。

    第③站给反应物发角色牌：氧化剂和还原剂（p69–70）

    站内反应看清了，现在回头看反应物：谁在"抢电子"、谁在"送电子"？教材用三个方程让你先练一遍（p69 交流·研讨：2Cu+O₂ / H₂+CuO / 3CO+Fe₂O₃ 高温 2Fe+3CO₂），然后给出定义：

    在氧化还原反应中，所含某种（或某些）元素化合价降低的反应物称为氧化剂（oxidizing agent）；化合价升高的反应物称为还原剂（reducing agent）（p69）。氧化剂具有氧化性，在反应中被还原，发生还原反应；还原剂具有还原性，在反应中被氧化，发生氧化反应（p69）。
    坑点2："被氧化"和"做氧化剂"方向正好相反。还原剂是被"氧化"的那位（它升价、失电子、被氧化），氧化剂反而是被"还原"的那位。四个词围着同一个元素转：失电子 → 化合价升高 → 被氧化 → 做还原剂 → 表现还原性（p69 原文链）。H₂ + CuO 里：CuO（Cu 降价）做氧化剂，H₂（H 升价）做还原剂——教材 p69 的双线桥标注图就是这个布局。

    化学家进一步发现一条"看价态猜性质"的规律（p69 原文）：

    这张图在说什么：教材 p69 的三例排进数轴——KI 里 I 为 −1（最低价）→ 还原性；KMnO₄ 里 Mn 为 +7（最高价）→ 氧化性；实验（p70 图2-3-3）：酸性 KMnO₄ 溶液（紫）滴入 KI 溶液后变棕黄——Mn 降价（做氧化剂）、I 升价生成碘单质（做还原剂）。中间价态两头都能走（H₂O₂ 是 p71 思考题的主角）。

    教材把中学常见的"角色牌"整理成了清单（p70）：

    阵营常见成员（p70 原文口径）
    氧化剂（降价方）氧气、氯气等活泼的非金属单质；硝酸、浓硫酸等含较高价态元素的含氧酸；高锰酸钾、氯酸钾、氯化铁等含较高价态元素的盐
    还原剂（升价方）活泼的金属单质；碳单质、氢气等非金属单质；CO、SO₂ 等含较低价态元素的氧化物；KI、Na₂SO₃、FeSO₄ 等含较低价态元素的盐
    验一验③（30秒）：3CO + Fe₂O₃ 高温 2Fe + 3CO₂ 里，谁做氧化剂？谁做还原剂？
    Fe₂O₃ 做氧化剂（Fe：+3→0，降价）；CO 做还原剂（C：+2→+4，升价）。这也是 p69 交流·研讨的三个方程之一——高炉炼铁的主反应。

    第④站拿去用：预测性质、冶炼金属、发电（p70–73）

    用法一：看价态，预测性质（p70–71）

    教材把"预测→验证"写成两步（p71 方法导引）：①根据元素化合价升降的可能性预测——价态可能升 → 可能具还原性；可能降 → 可能具氧化性；②找一张"对手牌"做实验验证——预测有氧化性，就找还原剂搭档试反应；预测有还原性，就找氧化剂搭档。教材的活动·探究（p70）就是这个套路的现场版：过氧化氢 H₂O₂ 里 O 是 −1 价（中间价态，升、降都可能），让你用 5% H₂O₂ 溶液、酸性 KMnO₄ 溶液、KI 溶液、淀粉溶液设计实验验证预测。

    再进一步：氧化性、还原性的强弱由物质得失电子的能力决定，可以用氧化还原反应来比较强弱；环境条件也会插一脚——含氧酸的酸根离子做氧化剂时，溶液酸性越强，氧化性越强，所以我们常用酸性条件下的 KMnO₄ 溶液做氧化剂（实际参与反应的是其中的 MnO₄⁻）（p71）。

    用法二：冶炼金属——把化合价"按"回 0 价（p71）

    方法（p71）怎么干例子
    热还原法以碳、CO 等作还原剂，加热条件下还原金属氧化物CO 还原铁的氧化物得铁
    金属置换法用活泼金属做还原剂，把目标金属从盐溶液中置换出来Fe 从 CuSO₄ 溶液置换出 Cu
    电解法外加电源提供电子，使金属元素化合价降低电解氧化铝制备金属铝

    教材点破本质（p71）：三种方法的共同内核都是利用氧化还原反应中的电子转移，使金属元素的化合价从正价降到 0 价，生成金属单质。氧化还原反应同时还是能量的来源：让可燃物做还原剂、选合适的氧化剂与它反应，获得热能；或者让电子搬家走外电路，获得电能（p71）。

    用法三：从实验室制氯气到燃料电池（p72–73）

    实验室制氯气（p72 迁移·应用）：瑞典化学家舍勒最早发现氯气——把浓盐酸和软锰矿（主要成分 MnO₂）混合加热：

    MnO₂ + 4HCl(浓) Δ MnCl₂ + Cl₂↑ + 2H₂O

    用新尺子分析：Mn +4→+2（降价，MnO₂ 做氧化剂）；4 个 Cl 中只有 2 个 −1→0 升价（这 2 个 Cl 进了 Cl₂，做还原剂），另外 2 个 Cl 价态不变、随 Mn²⁺ 组成 MnCl₂。教材的三问（判断剂/剂、NaOH 尾气吸收、改用 KMnO₄ 与浓盐酸常温反应并预测产物）正是让你把"价态分析"当工具使。

    化学与技术（p72–73）：工业现场的氧化还原。①钛：金红石（TiO₂）、碳与氯气高温反应得 TiCl₄，再在氩气氛围中用金属镁与 TiCl₄ 反应制得金属钛（Mg 做还原剂把 Ti "按"回 0 价）；②硅：碳还原 SiO₂ 得粗硅，粗硅与氯气反应生成 SiCl₄，净化后再用氢气还原，得较纯净的硅单质；③燃料电池：氢气、天然气等燃料做电池负极反应物，发生氧化反应；空气中的氧气做正极反应物，发生还原反应；接通外电路，电子从负极移向正极形成电流——化学能直接变电能。

    收口：把这一节带走

    三句话（能默写才算读完）：

    ① 有元素化合价升降（=有电子转移）的反应是氧化还原反应：升价=被氧化，降价=被还原；实质是电子转移，化合价变化是外在表现（p67–68）。

    ② 氧化剂=含降价元素的反应物（被还原、表现氧化性）；还原剂=含升价元素的反应物（被氧化、表现还原性）；高价态常有氧化性、低价态常有还原性（p69）。

    ③ 应用三板斧：看价态预测性质（再实验验证）；用还原剂把金属"按"回 0 价（热还原/置换/电解）；让电子搬家发电（燃料电池负极氧化、正极还原）（p70–73）。
