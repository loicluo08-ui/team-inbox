铁的多样性：一张"价-类二维地图"走遍铁的化合态与游离态

化学 3.1 · 第3章 物质的性质与转化（鲁科版《普通高中教科书·化学 必修 第一册》·山东科学技术出版社·正文 p86–96 · 影印图92–102）

📍 本件属于第3章"物质的性质与转化"模块首节，前面已学：2.3氧化还原反应（电子转移·氧化剂还原剂·价态趋势）。没读过2.3？看这句就够：化合价升高=失电子=被氧化，化合价降低=得电子=被还原——本节全程用这把钥匙开铁的锁。

看教材p86那张大图（图3-1-1）：绿矾晶体FeSO₄·7H₂O、实验室的铁粉、黄色的FeCl₃溶液、黄铁矿FeS₂、磁铁矿Fe₃O₄、赤铁矿Fe₂O₃，还有墙上的红色涂料、家里的铁锅、药盒里的补铁保健品——全都是"铁"。

同一个元素，在不同物质里"性格"完全不同：有的能被磁铁吸住，有的能让血红蛋白扛着氧气跑，有的能把铜从溶液里"顶"出来。教材说：铁元素在地壳中的含量仅次于氧、硅、铝（p86原句），自然界里有的以游离态（如陨铁）存在，更多的以+2价或+3价的化合态存在。

本节干一件事：给铁建一张"价-类二维地图"——纵轴0／+2／+3三种价态，横轴单质／氧化物／盐／碱四类物质，铁的全部"性格"与"路线"都画在这张图上。

读完这节你能

② 会用KSCN溶液检验Fe³⁺，说清铁盐的氧化性、亚铁盐的"两性"（既氧化又还原）；

③ 画出铁的价-类二维图并标注转化路线（同价态走复分解、异价态走氧化还原）；

④ 设计补铁剂中铁元素价态检验的实验方案（教材学生必做实验）。

先拆掉两个旧印象

误会一："铁锈就是Fe₃O₄"。铁锈的主要成分是Fe₂O₃（红棕色粉末）——所以油漆、涂料、油墨用它当红色颜料（p90原句）；Fe₃O₄是黑色有磁性的固体（磁铁矿·磁性材料），跟铁锈不是一回事。

误会二："+2价的铁盐也叫'铁盐'"。教材的命名规矩（p87）：含+2价铁的盐叫亚铁盐（硫酸亚铁FeSO₄、氯化亚铁FeCl₂），含+3价铁的盐才叫铁盐（硫酸铁、氯化铁FeCl₃）。一个"亚"字，价态差1、性质两重天。

名词补齐 游离态：元素以单质形式存在（如陨铁里的Fe）；化合态：元素藏在化合物里（如Fe₂O₃）。KSCN（硫氰酸钾）：一种盐，它的SCN⁻遇到Fe³⁺会让溶液变红色——本节的"显色试剂"（p88）。

第1步 研究物质的两个基本角度

教材方法导引（p88蓝框原思路）：在研究物质的性质时，可以从物质类别、物质所含核心元素的化合价这两个基本角度预测物质可能具有的性质，并通过实验进行验证。本章所有节都用这把"双角度"尺子，本节拿铁先示范一遍。

活动·探究（学生必做实验）：亚铁盐和铁盐的性质（p87）

实验用品（p87原单）：FeSO₄溶液、FeCl₃溶液、NaOH溶液、酸性KMnO₄溶液、氯水、KSCN溶液、KI溶液、淀粉溶液、铁粉、锌片、铜片；试管、胶头滴管、镊子、药匙。安全提示：氯水、稀硫酸、酸性KMnO₄等有腐蚀性，沾到皮肤立即大量清水冲洗。

预测（两把尺子齐上）：

① 类别角度——亚铁盐、铁盐都属于盐，都能与碱溶液反应生成相应的铁的氢氧化物（p88原句）；

② 价态角度——铁盐含+3价铁（最高价·只能降）→可能具氧化性；亚铁盐含+2价铁（中间价·可升可降）→既可能氧化性又可能还原性。

卡住了？换个说法 把"+2价中间价态"想成楼层：+3是顶楼、0是地面。住在顶楼的Fe³⁺只能下楼（被还原=氧化剂）；住地面的Fe单质只能上楼（被氧化=还原剂）；住中间的Fe²⁺上下楼都行——先上去再下来，或者反过来，全看对手是谁。

第2步 铁盐的氧化性：Fe³⁺的"抢电子"三连

先解决"怎么认出Fe³⁺"：KSCN显色法（p88）

依据Fe³⁺与SCN⁻反应使溶液显红色的性质，可以用KSCN溶液检验Fe³⁺的存在（p88原句）——FeCl₃溶液滴加KSCN，黄色变红色（图3-1-2）。这一手后面每个实验都要用，先装进口袋。

从化合价的角度看，铁盐因含有+3价铁元素而具有氧化性（p88原句）。三个经典离子方程式（p88蓝底原式）：

2Fe³⁺ + Fe = 3Fe²⁺

2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺

2Fe³⁺ + 2I⁻ = 2Fe²⁺ + I₂

三个式子一个道理：Fe³⁺降价（+3→+2·被还原·做氧化剂），对手Fe/Cu/I⁻升价（被氧化）。注意第一式——Fe³⁺连"自己人"单质铁都抢电子，这正是工业上"FeCl₃溶液腐蚀铜箔制印刷电路板"（p96 T12）与"FeCl₂溶液里加铁粉防变质"（p95 T11）的原理两头。

FeCl₂溶液和FeCl₃溶液各是什么颜色？（p94练习T2的易错点）

FeCl₂浅绿色（亚铁·+2价）——不是黄色；FeCl₃黄色（铁·+3价）。答完再想一层：颜色也是"价态身份证"的一部分。

第3步 亚铁盐的两性：上下楼都行的Fe²⁺

亚铁盐因含有+2价铁元素，既具有氧化性，又具有较强的还原性（p88-89原句）。两个方向各给实证（p89）：

① 表现氧化性（Fe²⁺降价+2→0）：与金属锌反应，Fe²⁺被还原为铁单质——Fe²⁺ + Zn = Zn²⁺ + Fe；

② 表现还原性（Fe²⁺升价+2→+3）：与氯水反应，2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻；与酸性KMnO₄溶液反应，紫色褪去（图3-1-4、图3-1-5两个实物对照实验）。

易错 检验Fe²⁺的还原性时，"变色"的证人得选对：FeSO₄里先加好KSCN不变红（证明无Fe³⁺），再滴氯水——变红（Fe³⁺新生成）才能坐实Fe²⁺被氧化（图3-1-4的原设计）。直接往FeCl₃里滴氯水什么也证不了。
⚡ 30秒自验 2

铁分别与氯气、盐酸反应，产物滴KSCN谁会变红？（p95练习T7原题）

只有氯气那管变红——Cl₂是强氧化剂直接把铁"送顶楼"（→Fe³⁺）；盐酸里H⁺是弱氧化剂只到Fe²⁺（KSCN不认）。边界补一刀：CuSO₄那管也只到+2（Fe+Cu²⁺=Fe²⁺+Cu）。

随手解一道教材题：实验室怎么保存FeSO₄溶液？（p87思考4问·p95 T11）

答案两手：加少量铁粉（万一氧化出了Fe³⁺，2Fe³⁺+Fe=3Fe²⁺就地"还原归队"）＋密封隔绝空气（防O₂慢慢氧化）。

第4步 铁单质、铁的氧化物、铁的氢氧化物（p89-91）

铁单质（0价·只能上楼）

纯净的铁（Fe，iron）是光亮的银白色金属，密度7.86 g·cm⁻³，熔点1538℃；抗腐蚀能力强，延展性导热性良好，导电性比铜、铝差，能被磁铁吸引（p90原句）。化学上：与稀盐酸、稀硫酸发生置换反应放出氢气（0→+2·还原剂本色）；与某些盐溶液发生置换反应生成亚铁盐（如Fe+CuSO₄）；不能与冷水、热水反应，但能与水蒸气在高温下反应（p89）：

3Fe + 4H₂O(g) ==高温== Fe₃O₄ + 4H₂

图3-1-6装置：硬质试管里湿棉花（水源）+还原铁粉，加热后肥皂液里吹出气泡——点火有爆鸣声=氢气（实验现象分析见p89交流·研讨2问）。

三种氧化物（+2／+2与+3混合／+3）

FeO黑色粉末，可作色素（瓷器釉呈绿色）；Fe₃O₄有磁性的黑色固体（磁性材料）；Fe₂O₃红棕色粉末（油漆涂料油墨的红色颜料）。铁的氧化物都不溶于水，也不与水反应；FeO与Fe₂O₃都是金属氧化物，皆能与稀盐酸或稀硫酸反应（p90原句）：

FeO + 2H⁺ = Fe²⁺ + H₂O　　Fe₂O₃ + 6H⁺ = 2Fe³⁺ + 3H₂O

（注：Fe₃O₄中Fe为+2、+3混合价态·教材本页未展开其与酸的离子方程——宁缺毋编·留待后续课程。）

两种氢氧化物：一个"短命"，一个"稳定"（p90-91）

Fe(OH)₂[iron(II) hydroxide]白色固体，难溶于水；Fe(OH)₃[iron(III) hydroxide]红褐色固体，也难溶于水。都能与稀盐酸或稀硫酸反应（复分解·同价态路线）：

Fe(OH)₂ + 2H⁺ = Fe²⁺ + 2H₂O　　Fe(OH)₃ + 3H⁺ = Fe³⁺ + 3H₂O

价态角度：Fe(OH)₂里铁+2价（可升）→很不稳定，容易被氧化。FeSO₄溶液与NaOH溶液反应产生的白色沉淀，在空气中迅速变成灰绿色，最后变成红褐色——被O₂氧化成Fe(OH)₃的"变色三连"（p90-91原句+图3-1-8）：

4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃

图C 白→灰绿→红褐变色三连——Fe(OH)₂被空气中O₂氧化的全程（依p91图3-1-8复绘·SVG坐标python脚本生成）

红笔旁批：这"白→灰绿→红褐"是高中化学最著名的颜色序列之一，实验题问"预测现象"就按这个顺序写全三段，只写两端要丢分。

第5步 转化关系：把全部路线画成一张图（p91-93）

教材交流·研讨（p91）：在"价—类"二维图（纵轴0／+2／+3价，横轴单质／氧化物／盐／碱）上标注含铁物质并画转化箭头。实现转化只有两条路（p91原句）：

① 同价态的转化（如Fe²⁺↔Fe(OH)₂、Fe³⁺↔Fe(OH)₃、氧化物↔盐）——可借助复分解反应等实现；

② 不同价态的转化（如Fe↔Fe²⁺↔Fe³⁺）——可借助氧化还原反应实现。

图B 铁的价—类二维地图——纵轴价态0／+2／+3·横轴单质／氧化物／盐／碱·实线箭头为转化路线（依p93"概括·整合"示例图复绘·SVG坐标python脚本生成）

这张图怎么用？看两个实例：制备——想要Fe(OH)₃，就从图上找Fe³⁺（如FeCl₃）加碱走复分解；想要Fe单质，就找含+2、+3价的东西还原（工业高炉/铝热p89）。保存——亚铁盐怕氧化，加铁粉"备一个向下拉的把手"（2Fe³⁺+Fe=3Fe²⁺）。

活动·探究（学生必做实验）：补铁剂中铁元素价态的检验（p92）

背景（p92原句）：补铁口服液除含铁化合物外，常添加抗氧化物质（如维生素C）等，某补铁口服液100 mL含铁元素20~30 mg、维生素C200~300 mg。实验目的：检验某补铁口服液中铁元素的价态。实验用品：某补铁口服液、H₂SO₄溶液、NaOH溶液、酸性KMnO₄溶液、氯水、KSCN溶液；试管、胶头滴管。

实验步骤实验现象实验结论

第6步 身边的化学：铁元素与人体健康（p93）

铁元素是人体中含量最高的生命必需微量元素。血红蛋白分子含有Fe²⁺——正是这些Fe²⁺使血红蛋白具有载氧功能，把肺部的氧气输送到全身；若Fe²⁺被氧化成Fe³⁺，血红蛋白就丧失载氧能力（p93原句——"价态决定性质"在身体里的版本）。人体只能吸收Fe²⁺；维生素C具还原性，能把Fe³⁺还原成Fe²⁺促进吸收——所以补铁剂里要加维C，吃菠菜时配点维C高的水果也是同款道理（p93框原意）。

练习与活动（p94–96）·答案速查

高考怎么考（考位导览·三行）

① KSCN检验+离子方程式书写（Fe³⁺/Fe²⁺转化）——选择题与填空双高频；② 实验方案设计（价态检验/除杂/保存）——实验题核心素材；③ 价-类二维图转化路线——推断题骨架。命题频率：高（元素化合物主干节·学生必做实验双落点）。

T1 连线（p94）：具有磁性的黑色固体→Fe₃O₄｜治疗缺铁性贫血→亚铁盐｜涂料红色颜料→Fe₂O₃｜保存亚铁盐溶液→铁单质｜空气中很不稳定→Fe(OH)₂｜遇KSCN变色→铁盐。

T2 不正确的是 A——FeCl₂是浅绿色不是黄色（FeCl₃才黄）。

T3 与稀盐酸反应且铁元素被氧化的是 A（Fe）——0→+2；B/C/D铁价态不变（复分解）。

T4 Fe³⁺表现氧化性的是 A——使淀粉碘化钾试纸变蓝（2Fe³⁺+2I⁻=2Fe²⁺+I₂）；B/C为复分解·D中Fe³⁺在变化但问的是"表现氧化性"且D是Fe³⁺被还原的题眼变体（铁粉消失=Fe³⁺→Fe²⁺）——按题意答案A（试纸变蓝是I⁻被氧化的直接证据）。

T5 不能一步实现的是 D——Fe与HCl只能到FeCl₂（H⁺是弱氧化剂）；A（Cl₂强氧化剂直接+3）/B（点燃+O₂）/C（高温水蒸气）均可一步。

T6 讨论Fe²⁺的还原性：理论（+2中间价可升）→实验事实（被Cl₂/酸性KMnO₄/H₂O₂氧化·p89图3-1-4/3-1-5）→实际应用（FeSO₄保存加铁粉·防O₂）。

T7 与铁反应产物能与KSCN显红的是 B（氯气）——Cl₂把Fe氧化到+3；盐酸/稀硫酸/CuSO₄都只到+2。

T8 错误的是 B——事实是Cl₂氧化Fe²⁺，氧化性Cl₂＞Fe³⁺（不能反写）；A/C/D均对。

T9 不会出现的是 D（有铁无铜）——Fe³⁺先氧化谁？Cu还原性＜Fe，若连Cu都没反应完铁不可能消失；"铁、铜均无"只在Fe³⁺足量时出现（D为不可能·因铁粉先失电子）。（解析为成稿给出）

T10 除杂：FeCl₂中除FeCl₃→加过量铁粉后过滤（2Fe³⁺+Fe=3Fe²⁺）；FeCl₃中除FeCl₂→通足量Cl₂（2Fe²⁺+Cl₂=2Fe³⁺+2Cl⁻·不引入新杂质）。

T11 探究FeCl₂：（1）加铁粉目的=防止Fe²⁺被空气氧化；（2）预测依据=Fe为+2价中间价态·既可升可降；（3）①滴氯水探究的是Fe²⁺的还原性·2Fe²⁺+Cl₂=2Fe³⁺+2Cl⁻；②选KSCN溶液·变红；③证明氧化性：向FeCl₂溶液加入锌片，锌片表面析出黑色（灰）固体、溶液质量变化——Fe²⁺+Zn=Zn²⁺+Fe（解析为成稿给出）。

T12 印刷电路板：（1）2Fe³⁺+Cu=2Fe²⁺+Cu²⁺·未被油墨覆盖的Cu被Fe³⁺氧化溶解；（2）①Fe（过量铁粉）②FeCl₂ ③Cu与Fe（滤渣）④盐酸（过量·溶Fe留Cu）⑤FeCl₂ ⑥Cl₂（合并滤液通氯气重获FeCl₃）；B方程式：Fe+2FeCl₃=3FeCl₂／Fe+2HCl=FeCl₂+H₂↑／2FeCl₂+Cl₂=2FeCl₃（解析为成稿给出）。

三句话带走 + 自测四连

① 研究铁的"双角度"：类别定通性（盐遇碱沉淀·碱性氧化物遇酸成盐），价态定性格（+3只降=氧化剂·0只升=还原剂·+2上下都行）；

② 一句口诀挂墙上：三点一线记转化——同价态复分解换装、异价态氧化还原搬家；KSCN专认Fe³⁺（红）；

⚡ 自测四连（先做再看答案·答案直接可见）

1. Fe₂O₃+6H⁺=2Fe³⁺+3H₂O属于氧化还原反应吗？

不属于——Fe+3→+3、H+1→+1，全无升降，纯复分解（同价态路线）。

2. 把Fe³⁺变Fe²⁺，选铁粉还是氯水？

铁粉（2Fe³⁺+Fe=3Fe²⁺·Fe³⁺被还原）；氯水干的是反方向（把Fe²⁺变Fe³⁺）。

3. 补铁剂里加维C，用了铁的哪条性质？

维C的还原性——把可能被氧化的Fe³⁺拉回Fe²⁺（人体只吸收Fe²⁺·p93），呼应"剂性正相反"。

4. Fe(OH)₂白色沉淀久置为什么最后是红褐色而不是"铁锈色"焦虑？

就是被O₂氧化成了Fe(OH)₃（红褐）——4Fe(OH)₂+O₂+2H₂O=4Fe(OH)₃；"灰绿色"是过渡态的中间颜值。
