①物理性质=不用把物质变成别的物质就能观察或测量的性质（颜色、状态、气味、熔点、沸点、密度、硬度）；化学性质=物质在变成别的物质的过程中表现出来的性质（能不能燃烧、能不能跟水反应等）。②化学方程式怎么读：等号左边是"反应物"（参加反应的物质），右边是"生成物"（反应后新生成的物质），等号表示"两边原子个数守恒"（配平），"↑"表示生成物是气体，条件（如"点燃""Δ"加热）写在等号上方。装好这两个插件，正文里的每个方程式你都能"读出声"。
站1｜基本方法（上）：观察——钠的"第一印象"

1. 观察的定义和要点（教材原话）

观察是一种有计划、有目的地运用感官考察研究对象的方法。（印刷页10）人们既可以直接用肉眼观察物质的颜色、状态、用鼻子闻气味，也可以借助仪器做更细致的观察。教材特别提醒两句：①不仅要用感官搜集信息，还要动脑思考并及时储存和处理信息；②观察要有明确而具体的目的，要对观察到的现象进行分析和综合（印刷页10）。

2. 案例①（上）：观察金属钠——"观察·思考"栏目全程照录

教材第一个案例：观察金属钠及金属钠与水的反应（印刷页11）。观察目的2条：①认识金属钠的颜色、状态、硬度和密度的相对大小以及熔点的相对高低；②认识金属钠与水的反应。观察内容2条：①从试剂瓶中用镊子取出金属钠，用滤纸吸干表面的煤油，在玻璃片上用小刀切下一小块，观察钠块的切面；②向培养皿加水、滴入1~2滴酚酞溶液，取绿豆粒大小的钠放入水中观察（印刷页11）。

⚠ 安全提示（教材原话·印刷页11）：金属钠与皮肤接触会腐蚀皮肤，千万不要用手直接接触金属钠！

教材在这里给出两张空记录表让你自己填：一张"金属钠的物理性质"（颜色／状态／硬度的相对大小／密度的相对大小／熔点的相对高低），一张"金属钠与水的反应"（实验现象／分析及结论）——观察方法的落地动作就是"带着目的记录"（印刷页11）。随后教材公布"标准答案"：钠（Na，sodium）是银白色金属，通常保存在煤油或石蜡油中；熔点97.8℃、沸点882.9℃、密度0.97 g·cm⁻³（印刷页12）——对照一下：密度0.97比水小（所以钠浮在水面），熔点97.8℃很低（所以钠块能在反应中熔成小球），这两个数据回头都能解释现象。

📌 记忆锚（自编）：钠的四个数据只记"一低一小一软一白"——熔点低（97.8℃）、密度比水小（0.97 g·cm⁻³）、质软（小刀能切）、银白色。保存在煤油里=因为它太活泼，怕水和氧气。

钠与水反应的结论（印刷页12）：金属钠能与水发生反应生成氢氧化钠和氢气。

2Na + 2H₂O ══ 2NaOH + H₂↑

◎辅助理解｜把这句话翻译成人话：钠遇到水，"让"出水里的氢，自己变成碱（NaOH，酚酞变红的原因）。教材p11滴酚酞，就是为了让"生成了NaOH"这件事现形——液体变红。

3. 顺带认识：实验的定义（教材原话）

实验是根据科学研究的目的，尽可能排除外界影响、突出主要因素，并利用一些专门的仪器设备，人为地变革、控制或模拟研究对象，使某一现象或过程发生或再现的研究方法。（印刷页12）研究物质性质时，可用实验验证预测或探究未知性质；实验前明确目的、用品、方案，实验中仔细观察并记录，实验后分析结果写好报告；要控制温度、压强、溶液浓度等条件——因为同样的反应物在不同条件下可能发生不同的反应（印刷页12）——这句话是本节的"总开关"，下一站马上用钠来演示。

自验①（30秒，答案就近可见）：把"观察"和"实验"各配一个正确描述——A．有计划有目的地用感官考察对象　B．人为变革、控制或模拟研究对象使现象发生或再现　C．要用感官搜集信息并动脑处理　D．要注意控制温度压强等条件。观察=A+C；实验=B+D。易错点：C/D是"交叉项"——观察也要动脑（C属观察），实验要控条件（D属实验）；背定义时把"目的"跟"谁"锁死。
站2｜基本方法（下）：实验+分类+比较+假说模型——钠的"变脸实验"

1. 条件控制第一次亮相：钠与氧气

活动·探究"金属钠与氧气的反应"（印刷页12-13）：实验方案2条——①将切好的金属钠放置在空气中，观察现象；②将一小块金属钠放入坩埚中加热，观察现象。结论（印刷页13）：金属钠放置在空气中会迅速被氧化，失去金属光泽，生成白色的氧化钠（Na₂O）；金属钠在空气中加热会生成过氧化钠（Na₂O₂）。

4Na + O₂ ══ 2Na₂O
2Na + O₂ ═(Δ)═ Na₂O₂（过氧化钠）
⚠ 易错（红笔旁批）：同样是钠+氧气，常温→Na₂O（白色），加热→Na₂O₂（淡黄色）——条件不同产物不同！这就是教材p12那句"同样的反应物在不同的条件下可能会发生不同的反应"的实物证据。做题先看条件再看产物。

过氧化钠的用场（印刷页13）：淡黄色固体粉末，与水或二氧化碳反应皆可产生氧气，常用于呼吸面具和潜水艇里的氧气供给：

2Na₂O₂ + 2H₂O ══ 4NaOH + O₂↑
2Na₂O₂ + 2CO₂ ══ 2Na₂CO₃ + O₂

2. 分类、比较、假说、模型（印刷页14·方法四连补齐）

教材原话：除了观察和实验外，分类和比较也是研究物质性质时的常用方法——分类可总结各类物质的一般性质并据类别预测；比较可认识物质性质间的异同与内在联系。此外还会用到假说和模型：在已有事实和科学理论基础上提出假说作推测性说明、建构模型作简化模拟；假说和模型具有解释性功能和预见性功能，但是否正确还需通过实验来验证；随着研究深入，往往是旧的假说或模型被推翻而建立新的假说或模型（印刷页14）。

🚧 卡住了？——六个方法名记不全？出路：先记"两大金刚"观察+实验（直接跟物质打交道），再记"两大参谋"分类+比较（帮你想、帮你比），最后记"两大预测器"假说+模型（先猜后验）。本节案例里真刀真枪上场的是观察和实验，其余四个先"认脸"即可。
自验②（30秒，答案就近可见）：判断下列说法：(1)金属钠在空气中加热生成氧化钠；(2)只要反应物相同，产物就相同；(3)过氧化钠里氧元素的质量分数比氧化钠高。(1)错——加热生成过氧化钠；(2)错——条件不同产物可能不同；(3)对——Na₂O₂里氧多一个原子（机器核验：Na₂O中O质量分数≈25.8%，Na₂O₂≈41.0%）。
站3｜基本程序：四步流水线——氯气案例全程走一遍

1. 程序总图（据教材图1-2-6重绘·印刷页14）

这张图在说什么：研究一种物质的性质，先"看长相"（①），再"猜脾气"（②，用分类法），然后"动手试"（③），最后"下结论"（④）；实验中发现反常现象，就带着新问题回到②继续猜——它是一条能循环的流水线。

◎辅助理解｜SVG里的④"解释和结论"框请看下方文字版：对实验现象进行分析、综合、推理，得出结论；并运用比较的方法，归纳总结一类物质的共性和差异（印刷页14图注文字）。

2. 案例②：研究氯气的性质——按程序逐步走（印刷页15-19）

第①步·观察外部特征+认识物理性质：氯气（Cl₂，chlorine）是具有重要用途的气体，工业上大量用于制造盐酸、有机溶剂和杀菌消毒剂等（印刷页15）。【实验1】观察颜色：稍打开玻璃片用手轻轻扇动闻气味（扇闻——教科书级规范动作）；【实验2】盛满氯气的试管倒扣在水槽中静置观察（印刷页15）。教材随后给结论（印刷页17）：氯气在常温、常压下是一种黄绿色气体；有强烈的刺激性气味，吸入少量时会使鼻腔和喉头黏膜受到刺激并引起胸痛和咳嗽，吸入较多时会使人窒息死亡；密度比空气大；易液化，经压缩可液化成黄绿色液氯；可溶于水，常温下1体积水可溶解约2体积氯气。方法框提醒：熔点沸点等要借助仪器研究（印刷页15）。

第②步·预测化学性质：方法框（印刷页15）：通常可以根据物质所属类别认识化学性质——氯气是非金属单质，根据氧气等非金属单质的性质，可初步预测它能与哪些类别的物质反应（以后还将学会用化合价预测）。

⚠ 安全提示（印刷页16原话）：氯气有毒，有关氯气性质的实验要在通风条件下（如在通风橱里）进行。

第③步·实验验证（印刷页16，四个实验+图1-2-8~11）：①钠：绿豆粒大小金属钠吸干煤油切去表层，石棉网上微热，熔成球状时将盛氯气的集气瓶迅速倒扣在钠球上方观察；②铁丝：坩埚钳夹住灼烧后立刻放入氯气瓶，再注入少量水振荡观察溶液颜色；③铜丝：同法；④氢气：在空气中点燃（点燃前要"验纯"），导管伸入氯气瓶观察燃烧现象。结论（印刷页17）：与氧气类似，氯气是一种非常活泼的非金属单质，容易与钠、铁、铜等金属单质以及氢气等非金属单质发生反应。

2Na + Cl₂ ═(点燃)═ 2NaCl
2Fe + 3Cl₂ ═(点燃)═ 2FeCl₃
Cu + Cl₂ ═(点燃)═ CuCl₂
H₂ + Cl₂ ═(点燃)═ 2HCl

第④步·发现特殊现象，进一步研究（印刷页17-18）：提出问题——在研究氯气的溶解性时，将氯水密闭放置一段时间后会发现氯水的颜色变浅。这说明氯气具有什么性质呢？预测与依据、实验方案设计两栏空表留给学生填；教材给出方法（印刷页18）：将干燥的氯气依次通过内有干燥红纸条的广口瓶A和内有湿润红纸条的广口瓶B——通过红纸条是否褪色可以推断氯气能否与水发生反应；再检验氯水中有没有除氯气和水以外的新物质，进一步确定反应是否发生（对照实验思想+产物检验）。实验用品：氯气、紫色石蕊溶液、AgNO₃溶液、红纸条、试管等（印刷页18）。结论：

Cl₂ + H₂O ══ HCl + HClO（次氯酸）

次氯酸（HClO，hypochlorous acid）能使有色物质褪色，并能杀灭细菌，因此次氯酸具有漂白作用和消毒作用。（印刷页18）——干燥红纸条不褪、湿润红纸条褪色，说明"凶手"不是氯气本身而是氯气与水反应的产物。

⚠ 易错（红笔旁批）：①"氯水能使有色物质褪色"≠"氯气能漂白"——干燥氯气没有漂白性（对照实验A/B就是证据）；②教材练习2(1)B项"氯气、液氯和氯水是同一种物质"是错的：液氯是纯净物（液化后的Cl₂），氯水是氯气溶于水得到的混合物。

氯气还能与碱反应（印刷页19）：氯气与碱反应生成盐酸盐、次氯酸盐和水——将氯气通入NaOH溶液得到氯化钠、次氯酸钠（NaClO）和水：

Cl₂ + 2NaOH ══ NaCl + NaClO + H₂O

3. 身边的化学：含氯化合物的漂白与消毒（印刷页19·教材栏目照录要点）

次氯酸、次氯酸盐、二氧化氯等有漂白消毒作用；次氯酸不稳定，见光易分解，所以通常用次氯酸盐做漂白剂消毒剂的主要成分；次氯酸盐与空气中的二氧化碳和水蒸气反应可生成次氯酸发挥效用；84消毒液主要成分=次氯酸钠（图1-2-13）；漂白粉主要成分为次氯酸钙和氯化钙（有效成分次氯酸钙），由氯气与石灰乳反应制成——2Cl₂+2Ca(OH)₂═CaCl₂+Ca(ClO)₂+2H₂O；二氧化氯（ClO₂）漂白消毒能力比氯气强、更安全，正越来越多取代次氯酸盐类；含氯漂白剂和消毒剂通常应避光并置于阴凉处密封保存（印刷页19）。

教材p20"概括·整合"给出双案例示范图：钠（银白色固态质软／黄绿色气态有刺激性气味分别填入"观察外部特征"）沿同一程序走完四步，结论框各给一句——钠：与常见的铁、铜等金属相比，钠是一种非常活泼的金属单质，更易与氧气等非金属单质发生反应，且能与水发生剧烈反应；氯气：与氧气类似，氯气也是一种非常活泼的非金属单质，易与金属单质、非金属单质等发生反应，另外氯气还能与水、碱溶液发生反应（印刷页20）。

例题四段式（教材印刷页21练习1(1)原题）

题干：下列关于金属钠的叙述中，正确的是（　　）A．金属钠是银白色金属，硬度很大　B．在空气中加热时，金属钠剧烈燃烧，产生黄色火焰，生成过氧化钠　C．金属钠在空气中燃烧，生成氧化钠　D．金属钠的熔点很高
解答：A错——钠质软（小刀可切，p11观察内容）；B对——p13原句"在空气中加热，剧烈燃烧，产生黄色火焰"（p20概括整合图内）＋生成过氧化钠；C错——常温放置才生成Na₂O，燃烧生成Na₂O₂；D错——熔点97.8℃很低。答案B。
思维标注：本题四个选项全部回锚两个证据点——"钠的物性四数据"（p12）和"条件不同产物不同"（p13）。A/C/D都是拿"别的金属的默认印象"套钠（硬度大/熔点高是多数金属印象，钠是例外）；C是"常温与加热"条件偷换。
定级：本节最高频题型——"钠的性质叙述正误判断"，会考必考级。
变式（教材印刷页21练习2(1)·同类）：有关氯气叙述不正确的是（　）A．黄绿色、有刺激性气味的气体　B．氯气、液氯和氯水是同一种物质　C．氯气能溶于水　D．氯气是一种有毒气体——答案B（液氯是纯净物、氯水是混合物；其余三项p17原文可锚）。两题连做：一题验钠一题验氯，条件-产物对应关系是共同考点。

自测（先做后看，答案直接可见）

  1. 【教材印刷页21·1(2)】金属钠通常保存在煤油中，原因是＿＿。钠性质活泼、易与氧气和水反应，且不与煤油反应、密度比煤油大——隔绝空气和水（要点自编·基于p11-12归纳）。
  2. 【教材印刷页21·2(2)】将氯气通入NaOH溶液制84消毒液，化学方程式为＿＿。Cl₂+2NaOH═NaCl+NaClO+H₂O（p19原式·机器配平核验过）。

收口（合上件，自说三句话）：
①定义了什么：四个基本方法（观察=有计划有目的地用感官考察；实验=人为变革控制模拟研究对象）+四步基本程序（观察外部特征→预测性质→实验和观察→解释和结论，外加"特殊现象→新问题→进一步研究"回路）；钠和氯气两个案例把方法和程序各演了一遍。
