## 三、答案判读

**T10 = B（√5/5）**

判读链（独立复算）：2sin2α = cos2α+1 ⇔ 4sinα·cosα = 2cos²α ⇔ 2sinα·cosα = cos²α。因 α∈(0,π/2) 故 cosα>0，两边除以 cosα 得 2sinα = cosα，即 tanα = 1/2。于是 sinα = tanα/√(1+tan²α) = (1/2)/(√5/2) = **1/√5 = √5/5 = B**。✓ 与图证②题旁答案【B】一致。
