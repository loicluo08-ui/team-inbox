# 三条差距报告｜化学3.2《硫的转化》（并行搜索员B·队3席B线·1031）

**差距一（教材延展）**：教材p100提到"由同一种元素组成的性质不同的几种单质叫同素异形体"仅举正交硫/单斜硫两例；未覆盖O₂/O₃、红磷/白磷等他例。正件严格按教材口径呈现（宁缺毋编），未自行扩表——延展属教师课堂补充范畴，候QC定夺是否增"延伸注记"块。

**差距二（工业深度）**：接触法流程（p104图3-2-12）中"98.3%浓硫酸吸收SO₃"的原因（防酸雾、吸收效率）教材未展开，正件按教材原文呈现流程与条件（400~500℃/常压/V₂O₅），未越界补充原因解释——候QC或读者问询时按教材边界作答。

**差距三（题目答案库）**：p107–109练习13题中，题1/题7影印面存在双可选成立项（单选题面存疑），题6/题13为开放讨论题——正件仅对客观题给出影印可证的判定与解析（题2/3/4/5/8/9/10/11/12），对题1/题7如实申报不代拟、对开放题给讨论框架不给唯一答案。候验收方裁定题1/题7口径后可增量补注v1.1。
