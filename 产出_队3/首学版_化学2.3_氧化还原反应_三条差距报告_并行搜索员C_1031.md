# 首学版_化学2.3_氧化还原反应 · 三条差距报告（队3席·并行搜索员C·2026-10-31·v10续产会话）

> 义务依据：标准模板v2.3"开工前必须通读两件黄金样本（3.2完整形态+1.1入门骨架），写出与自己负责节的三条差距，通读报告随首件提交"。本席通读两件后与本节（2.3氧化还原）对差如下：

**差距一：样本的"代值实验"在本节要换成"价态实验"——比样本难处**
黄金样本3.2的核心节奏是"代个数进去试"（f(−x)代进去看图像对称）。2.3没有现成函数可代，代值实验换形成"价态代数和验算"（K(+1)+Mn(x)+4(−2)=0→Mn=+7）与"电子账收支平衡表"（失=得）。本件做法：把每条方程式配一张"收支表"（失电子一方/得电子一方/数目），并让sympy全量代验——机器层先跑通，读者照抄表格式即可自验。比样本难处：电子"看不见"，本件用"快递"（单线桥=谁给谁送包裹）把抽象账变实体账。

**差距二：样本概念单线推进，本节概念四件套互为因果——搬不动样本的"一段一概念"，改用"两副眼镜"叙事**
3.2一节其实只新增f(x)奇偶两个概念，一次一步即可。2.3一节新增"氧化还原反应/氧化反应/还原反应/氧化剂/还原剂"五概念且两两咬合（升失氧降得还闭环），硬按"一段一概念"切会把闭环切碎、读者更晕。本件做法：第①②站只走"特征→实质"两步（对应概念1-3），第③站一次性贴"剂"标签但立刻给p69原文行为特征句+配对表，概念闭环在坑点2与收口处再合龙一次。牺牲了样本的部分"一次一步"纯度，换概念闭环完整性——此取舍已在附件3 T2行如实注记（每站仍只一个动作）。

**差距三：样本节末串联图是纯知识链，本节串联图必须承担"第2章收束"任务——加了位置图信息密度**
数学样本3.2的节末导图只连本节内部（奇偶函数判定流程）。2.3是第2章收官节+微项目前置节，串联图要同时装下"三副眼镜递进（分类→离子→电子）+微项目（p76科学使用含氯消毒剂）+下一章钩子（3.1铁的+2/+3价切换）"，信息量约为样本导图三倍。本件做法：位置图按"章-节-微项目"三层布局+figcap一句"三副眼镜"口诀，避免图面过载；高炉炼铁五反应五温度（p74-75练习5配图数据）另起独立阶梯图不入串联图，保住"一张图一个意思"。

**结论：三条差距均有对应落法且在件内显式可查；无"样本做法搬不动而放弃"项。**
