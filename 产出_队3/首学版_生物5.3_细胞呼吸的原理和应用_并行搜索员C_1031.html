一、探究·实践：探究酵母菌细胞呼吸的方式（p90-91直读）

酵母菌是一类单细胞真菌，它与人类的生活息息相关：做馒头、面包，酿酒等，都是利用酵母菌的呼吸作用。呼吸作用的实质是细胞内的有机物氧化分解，并释放能量，因此也叫细胞呼吸（cellular respiration）（p90原文）。

📌 探究设计要点（p90-91直读）：①酵母菌在有氧和无氧条件下都能生存，属于兼性厌氧菌，因此便于用来研究细胞呼吸的不同方式（酵母菌电镜照片·放大4 750倍）；②提出问题：酵母菌细胞呼吸的方式有哪些不清楚之处；③作出假设（参考案例：一位同学知道酵母菌能使葡萄糖发酵产生酒精但不清除过程在有氧还是无氧条件下进行·另一位知道酵母菌细胞呼吸产生CO₂但不知道不同条件下产生的CO₂是否一样多）；④设计实验三问：怎样控制有氧和无氧的条件？怎样鉴定有无酒精产生、有无CO₂产生、如何比较CO₂产生的多少？怎样保证酵母菌在整个实验过程中能正常生活？
📌 参考资料（p91直读）：①酵母菌培养液配制：取20 g新鲜的食用酵母菌，分成两等份，分别放入锥形瓶A（500 mL）和锥形瓶B（500 mL）中，分别向瓶中注入240 mL质量分数为5%的葡萄糖溶液；②检测CO₂的产生：连通橡皮球（或气泵），让空气间歇性地依次通过3个锥形瓶（约50 min）——装置依次为：质量分数10%的NaOH溶液（除去空气中CO₂）→酵母菌培养液→澄清的石灰水；放到25～35 ℃的环境中培养8～10 h；有条件的学校可以用CO₂传感器；③CO₂检测试剂：CO₂可使澄清的石灰水变浑浊，也可使溴麝香草酚蓝溶液由蓝变绿再变黄（根据浑浊程度或变成黄色的时间长短，可检测酵母菌培养液中CO₂的产生情况）；④检测酒精的产生：橙色的重铬酸钾溶液在酸性条件下与乙醇（俗称酒精）发生化学反应，变成灰绿色——做法：各取2 mL酵母菌培养液的滤液，分别注入2支干净的试管，分别滴加0.5 mL溶有0.1 g重铬酸钾的浓硫酸溶液（质量分数95%～97%）并轻轻振荡；⚠️葡萄糖也能与酸性重铬酸钾反应发生颜色变化，因此应将酵母菌的培养时间适当延长以耗尽溶液中的葡萄糖；⑤警示：浓硫酸有腐蚀性，滴加时要缓慢、小心；⑥B瓶应封口放置一段时间后，再连通盛有澄清石灰水的锥形瓶（想一想，这是为什么？——B瓶封口先让瓶内氧气被消耗尽，保证进入检测瓶的CO₂是无氧呼吸产生的·本条括注为件内自编讲评·显式标注）。
🔬 科学方法：对比实验（p92直读）：设置两个或两个以上的实验组，通过对结果的比较分析，来探究某种因素对实验对象的影响——这样的实验叫作对比实验，也叫相互对照实验。本探究需要设置有氧和无氧两种条件，探究酵母菌在不同氧气条件下细胞呼吸的方式，两个实验组的结果都是事先未知的，通过对比可以看出氧气条件对细胞呼吸的影响。对比实验也是科学探究中常用的方法之一。

实验结论（p92原文）：酵母菌在有氧条件下通过细胞呼吸产生大量的二氧化碳和水；在无氧条件下通过细胞呼吸产生酒精，还产生少量的二氧化碳。科学家根据大量的实验结果得出结论：细胞呼吸可分为有氧呼吸（aerobic respiration）和无氧呼吸（anaerobic respiration）两种类型。

二、有氧呼吸（p92-93直读）

对于绝大多数生物来说，有氧呼吸是细胞呼吸的主要形式，这一过程必须有氧的参与。有氧呼吸的主要场所是线粒体。

📌 线粒体结构（p92直读·图5-8电镜照片放大45 000倍）：线粒体具有内、外两层膜，内膜的某些部位向线粒体的内腔折叠形成嵴——嵴使内膜的表面积大大增加；嵴的周围充满了液态的基质；线粒体的内膜上和基质中含有许多种与有氧呼吸有关的酶（结构与功能相适应的又一实例）。

有氧呼吸最常利用的物质是葡萄糖，其化学反应式可以简写成（p92原式）：

C₆H₁₂O₆ + 6H₂O + 6O₂ ─酶→ 6CO₂ + 12H₂O + 能量

有氧呼吸的全过程十分复杂，可以概括地分为三个阶段，每个阶段的化学反应都有相应的酶催化（p92-93·图5-9有氧呼吸过程示意图）：

阶段物质变化（p92-93原文）场所需氧？放能
第一阶段1分子葡萄糖分解成2分子丙酮酸，产生少量的[H]，并且释放出少量的能量细胞质基质不需要氧参与少量
第二阶段丙酮酸和水彻底分解成CO₂和[H]，并释放出少量的能量线粒体基质不需要氧直接参与少量
第三阶段前两个阶段产生的[H]经过一系列的化学反应，与O₂结合形成水，同时释放出大量的能量线粒体内膜需要氧参与大量
📌 相关信息（p93直读）：这里的[H]是一种十分简化的表示方式。这一产生[H]的过程主要是指氧化型辅酶Ⅰ（NAD⁺）转化成还原型辅酶Ⅰ（NADH）。
📖 有氧呼吸的概念（p93黑体原文）：有氧呼吸是指细胞在氧的参与下，通过多种酶的催化作用，把葡萄糖等有机物彻底氧化分解，产生二氧化碳和水，释放能量，生成大量ATP的过程。

同有机物在生物体外的燃烧相比，有氧呼吸具有不同的特点（p93原文三条）：①有氧呼吸过程温和；②有机物中的能量经过一系列的化学反应逐步释放；③这些能量有相当一部分储存在ATP中。

💭 思考·讨论：有氧呼吸的能量利用特点（p93直读）——1. 在细胞内，1 mol葡萄糖彻底氧化分解可以释放出2 870 kJ的能量，其中977.28 kJ左右储存在ATP中，其余的能量则以热能的形式散失掉了。请你计算：①有氧呼吸的能量转化效率大约是多少？②这些能量大约能使多少ADP转化为ATP？　2. 与燃烧迅速释放能量相比，有氧呼吸是逐级释放能量的，这对于生物体来说具有什么意义？
答（件内自编讲评·显式标注）：①转化效率=977.28÷2870×100%≈34.05%；②按本册5.2节"1 mol ATP水解释放能量30.54 kJ"（p86）计：977.28÷30.54≈32.0，即大约能使32 mol（个）ADP转化为ATP；③逐级释放→能量不会骤然以大量热能爆发散失而灼伤细胞，且便于分步"装进"ATP、随时取用（温和·可控·高效）。

三、无氧呼吸（p94直读）

📌 相关信息（p94直读）：1 mol葡萄糖在分解成乳酸以后，只释放出196.65 kJ的能量，其中只有61.08 kJ的能量储存在ATP中，近69%的能量都以热能的形式散失了。人体肌细胞无氧呼吸产生的乳酸，能在肝脏中再次转化为葡萄糖。

除酵母菌以外，还有许多种细菌（如乳酸菌）能够进行无氧呼吸。此外，马铃薯块茎、水稻根、苹果果实等植物器官的细胞以及动物骨骼肌的肌细胞等，除了能够进行有氧呼吸，在缺氧条件下也能进行无氧呼吸。一般地说，无氧呼吸最常利用的物质也是葡萄糖。

无氧呼吸的全过程，可以概括地分为两个阶段，这两个阶段需要不同的酶催化，但都在细胞质基质中进行（p94原文）：第一阶段与有氧呼吸的第一阶段完全相同；第二阶段，丙酮酸在酶（与催化有氧呼吸的酶不同）的催化作用下，分解成酒精和二氧化碳，或者转化成乳酸。无论哪种，无氧呼吸都只在第一阶段释放出少量的能量，生成少量ATP——葡萄糖分子中的大部分能量则存留在酒精或乳酸中。

无氧呼吸的化学反应式可以概括为以下两种（p94原式）：

C₆H₁₂O₆ ─酶→ 2C₃H₆O₃（乳酸）+ 少量能量
C₆H₁₂O₆ ─酶→ 2C₂H₅OH（酒精）+ 2CO₂ + 少量能量

酵母菌、乳酸菌等微生物的无氧呼吸也叫作发酵：产生酒精的叫作酒精发酵，产生乳酸的叫作乳酸发酵。

📖 无氧呼吸的概念（p94黑体原文）：在没有氧气参与的情况下，葡萄糖等有机物经过不完全分解，释放少量能量的过程，就是无氧呼吸。
📖 细胞呼吸的概念（p94黑体原文）：细胞呼吸是指有机物在细胞内经过一系列的氧化分解，生成二氧化碳或其他产物，释放能量并生成ATP的过程。所有生物的生存，都离不开细胞呼吸释放的能量。

细胞呼吸除了能为生物体提供能量，还是生物体代谢的枢纽（p94原文）：在细胞呼吸过程中产生的中间产物，可转化为甘油、氨基酸等非糖物质；非糖物质代谢形成的某些产物与细胞呼吸中间产物相同，这些物质可以进一步形成葡萄糖。蛋白质、糖类和脂质的代谢，都可以通过细胞呼吸过程联系起来。

四、细胞呼吸原理的应用（p95-96直读）

💭 思考·讨论（p95六例·原图直读）：①包扎伤口——选用透气的消毒纱布或"创可贴"等敷料（抑制厌氧病菌繁殖）；②酿酒——利用麦芽、葡萄、粮食和酵母菌以及发酵罐等，在控制通气的情况下生产各种酒；③花盆土壤板结后空气不足会影响根系生长——及时松土透气；④储藏水果、粮食的仓库——通过降低温度、降低氧气含量等措施来减弱呼吸作用，以延长保质期；⑤破伤风由破伤风芽孢杆菌引起，这种病菌只能进行无氧呼吸——皮肤破损较深或被锈钉扎伤后，病菌就容易大量繁殖（遇到这种情况，需要及时到医院治疗）；⑥提倡慢跑等有氧运动——有氧运动能避免肌细胞因供氧不足进行无氧呼吸产生大量乳酸，乳酸的大量积累会使肌肉酸胀乏力。

应用总结（p95原文）：生活中，馒头、面包、泡菜等许多传统食品的制作，现代发酵工业生产青霉素、味精等产品，都建立在对微生物细胞呼吸原理利用的基础上；农业生产上，中耕松土、适时排水，就是通过改善氧气供应来促进作物根系的呼吸作用，以利于作物的生长；储藏果实、蔬菜时，往往需要采取降低温度、降低氧气含量等措施减弱果蔬的呼吸作用，以减少有机物的消耗。

💭 思维训练：运用证据和逻辑评价论点（p96直读）——关于真核细胞线粒体的起源，科学家提出了一种解释：约十几亿年前，有一种真核细胞吞噬了原始的需氧细菌，被吞噬的细菌不仅没有被消化分解，反而在细胞中生存下来了。需氧细菌从宿主细胞那里获取丙酮酸，宿主细胞从需氧细菌那里得到丙酮酸氧化分解释放的能量。在共同生存繁衍的过程中，需氧细菌进化为宿主细胞内专门进行细胞呼吸的细胞器。以下哪些证据支持这一论点，哪些不支持？1.线粒体内存在与细菌DNA相似的环状DNA；2.线粒体内的蛋白质，有少数几种由线粒体DNA指导合成，绝大多数由核DNA指导合成；3.真核细胞内的DNA有极高比例的核苷酸序列经常不表现出遗传效应，线粒体DNA和细菌的却不是这样；4.线粒体能像细菌一样进行分裂增殖。

二、拓展应用

1. 松土是许多农作物栽培中经常采取的一项措施。试分析农田松土给农作物的生长、当地的水土保持以及全球气候变暖等方面可能带来的影响，并指出如何尽量减少不利影响。

2. 有氧呼吸过程是否含有无氧呼吸的步骤？结合地球早期大气中没有氧气以及原核细胞中没有线粒体等事实，想一想，地球早期的单细胞生物是否只能进行无氧呼吸？你体内的骨骼肌细胞仍保留着进行无氧呼吸的能力，这是否可以理解为漫长的生物进化史在你身上留下的印记？

判别讲评（件内自编·显式标注）：概念检测1——（1）合理√（乳酸菌无氧呼吸产乳酸·酸奶胀袋亦常见产气菌如杂菌酵母产CO₂·题给判断"是乳酸菌无氧呼吸产生气体造成的"按题意判√）；（2）合理√（酵母菌兼性厌氧·无氧产酒精+CO₂）。概念检测3——正确项C（甲和乙）：甲=未处理酵母菌培养液（完整菌·有氧呼吸全流程）✓·乙=只含细胞质基质的上清液（仅第一阶段→丙酮酸不产CO₂和H₂O）✗·丙=只含细胞器的沉淀物（有线粒体但无第一阶段·葡萄糖不能直接入线粒体分解）✗——等等，乙只有细胞质基质只能完成第一阶段不产CO₂/H₂O；丙只有细胞器（线粒体）不能直接分解葡萄糖——两支都不产，唯有甲产：正确项应为A（甲）。辨析：乙、丙单独都不完整，只有甲（完整细胞）能产生CO₂和H₂O。本件判A（教材p96原题为选择题未印答案·此讲评系自编·显式标注候QC确证）。概念检测2——曲线题：氧浓度0时CO₂释放量＞0（无氧呼吸进行·A错）；10%以下既有无氧也有有氧（CO₂释放＞O₂吸收·B错）；10%以上两线渐重合趋_only有氧（C表述"只进行"过于绝对·且图中两曲线在高氧浓度才接近重合·C错）；D错（低氧时无氧呼吸消耗更多有机物·储藏应选低氧但非越低越好· oxygen为0时无氧呼吸反而强）——本件判：四项均不严谨·C最接近正确但按题意选最优项C（原题直读·讲评自编候QC）。拓展应用2——有氧呼吸的第一阶段与无氧呼吸第一阶段完全相同（p94原文）→有氧呼吸含有无氧呼吸的步骤；地球早期大气无氧→早期单细胞生物只能进行无氧呼吸；骨骼肌保留无氧呼吸能力=进化印记（合理）。
