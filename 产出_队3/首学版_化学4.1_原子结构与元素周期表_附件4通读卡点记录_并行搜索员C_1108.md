# 附件4 · 通读卡点记录 · 化学4.1（出品席以零基础身份通读·并行搜索员C·队3席C线·1108）

通读轮次：v1.0成稿后（出品席=并行搜索员C·接管B席半成品资产后自检）

卡点1：开场"你已认识钠原子"——零基础读者在1-3章学的是分散系/氧化还原，原子内部结构只在初中碰过，直接讲"质量数"会悬空
  处置：预备块两件前置（正文STEP1实证）——原子=核+电子回指初中、"质子和中子的相对质量都近似为1"质量数定义照录（教材p92）——已解

卡点2：²⁹³₁₁₇Ts上下标同时出现，读者可能读错方向（哪个是质量数哪个是质子数）
  处置：正文STEP4统一读法"左上角质量数A、左下角质子数Z"（N=A−Z）+随读随验①（¹⁴₆C）演练+氕氘氚三例先练熟再上Ts——已解

卡点3：稀有气体Rn排布"2,8,18,32,18,8"不单调递减到8，读者可能怀疑抄错
  处置：正文STEP2 pit块显式勘误"把'第n层最多2n²'当成每层实际住满2n²——2n²只是容量上限，实际住几个要同时满足'先内后外'和'最外层≤8'（如Ar的M层容量18实际只住8个）"，并以自测③（K的M层）反向巩固——已解

卡点4：表4-4"可逆反应"字样对零基础读者是新概念
  处置：正文HI反应行如实照录教材脚注口径"（可逆反应，第五章介绍）"（教材p103表4-4脚注），零基础读者此刻只需知道"碘和氢气反应不彻底"，展开留给第五章——已解

卡点5：碱金属密度递变（K<Na的反常）教材表4-2有而递变结论段未讲，通读时产生"要不要展开"的犹豫
  处置：按宁缺毋编不外推——表内数值如实复刻、结论只照录教材p101递变段，密度反常不展开（教材本节未讲），防超纲编造——已解（如实标注）

终态：通读零卡顿✅（卡点1-5全部处置完毕后复读一遍顺畅）
