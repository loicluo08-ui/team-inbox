# 首学版_化学3.1_铁的多样性 · 三条差距报告（队3席·并行搜索员C·2026-10-31·v10续产会话）

> 依据标准模板v2.3：通读黄金样本3.2（完整形态）+1.1（入门骨架）后与本节对差三条（随件提交）：

**差距一：样本全节只有一条判定方法，本节是"检验+互转+地图"三件套并行——密度比样本高**
数学3.2黄金样本的核心只有"代−x进去看对不对"一把尺子。3.1一节教材自带三件套（Fe³⁺检验/Fe²⁺Fe³⁺互转/价—类二维图）外加两个学生必做实验。硬照搬样本"一站一尺"会缺件。本件做法：三件套拆成①站（检验+互转）与③站（地图），实验要素压缩进对应站内表格，两个"必做实验"章标在正文如实标注不扩写——保证密度到位、节奏不断。

**差距二：样本的数字都来自函数计算，本节大量"颜色证据"无法用sympy代验——验证手段必须换轨**
样本验点全走数值代值。本节核心证据一半是颜色（浅绿/黄色/白色→灰绿→红褐/血红色/紫色褪去），sympy只能代验价态与电子账，颜色只能靠影印照片锚定。本件做法：颜色事实全部标注图号（图3-1-2/3/4/5/8）+附件1逐字锚；可代验部分（16验点：价态/电子账/配平）全量过sympy——两条验证轨在附件2分列，不混装。

**差距三：样本导图是单线流程，本节"价—类"二维图是全件信息密度最高点——一张图承载九物质九箭头**
3.2样本的节末导图是单链。p93官方示例图（本节灵魂）一张图装9种物质9根箭头，零基础读者第一眼必花。本件做法：图按"0/+2/+3三行重排+横排箭头与跨行箭头分色"+figcap一句"横排=复分解·跨行=氧化还原"+收口处再复述一次；先在第①站用"互转天桥"小图热身（只有Fe²⁺⇌Fe³⁺两个节点），读者到③站看大图时已有肌肉记忆。

**结论：三条差距均有落法且件内显式可查；无放弃项。**
