## 课时开篇页

**本节知识点清单**：钠的本性与保存（最外层1个电子→强还原剂→煤油封存沉底）·钠与氧气"条件不同产物不同"（常温Na₂O白色/点燃Na₂O₂淡黄）·钠与水"浮熔游响红"现象五连（逐条对应性质）·钠与盐溶液"先水后盐"（CuSO₄陷阱）·焰色反应（物理变化/元素性质/Na黄K紫钴玻璃）·过氧化钠Na₂O₂（氧-1价/歧化/与水与CO₂放O₂/质量账78-18-44-16）·碳酸盐对五道分水岭（溶解性/遇酸剧烈度/遇碱/遇Ca(OH)₂与CaCl₂/热稳定性与相互转化）·"结构决定性质，性质决定用途"总纲

**学完这节你能做到**（4条，全部可自查）：
1. 合书脑内播放"钠入滴了酚酞的水"完整视频——浮、熔、游、响、红逐条报出，并给每条现象配上性质解释（密度/熔点/气体/放热/生碱）
2. 默写Na₂O₂与H₂O、与CO₂两个方程式，标出氧的价态走向（-1→0和-2），算出固体增重
3. 只用一种试剂区分Na₂CO₃与NaHCO₃溶液，并说清为什么"都冒泡"的稀盐酸不合格
4. 见到"活泼金属+盐溶液"先答"先与水反应"再动笔写方程式，产物一步不错

**难点预警**（3条，说话式）：
- 钠入CuSO₄溶液，你脑补的是"钠把铜置换出来"——大错。钠先抢水里的H⁺：水是溶剂、数量压倒性，等Na变成Na⁺进入溶液，已经没有金属钠剩下跟Cu²⁺反应了。写错产物整题归零，这是本节最高频的陷阱（v18原话）
- Na₂O₂里氧是-1价——不是-2。"歧化反应"（既是氧化剂又是还原剂）在这里第一次露面，§2.3氧化剂和还原剂会正面开课，这里先认脸
- 碳酸盐对（Na₂CO₃/NaHCO₃）五道分水岭混一条错一片：遇酸谁剧烈、遇CaCl₂谁沉淀、受热谁分解——逐条对表，别靠"感觉差不多"

**前置依赖**：簇1物质分类（Na₂O₂属氧化物、Na₂CO₃/NaHCO₃属盐——归属判断要用）；簇3氧化还原（失电子/价态升降——钠全部反应的底层引擎）；初中金属活动性顺序（钠排最前排——"暴烈"的资格证）。

## 正文

### 一、钠的本性与保存：一个事实管全部反应

结论先行：**Na最外层1个电子，极易失去——强还原剂（v18完整展开原话）。钠的全部反应都由这一条本性发动**。

结构决定性质：最外层1个电子，失去倾向极大，见谁都给。这条本性直接决定保存方式：**保存在煤油里（隔绝空气和水，钠密度比煤油大沉底）**。空气里的O₂、水、盐溶液里的反应对象它都想抢——保存的本质就是把这几样全部挡开。

安全一条（v18常见误解①原话）："钠着火了用水浇"——大错！钠与水剧烈反应还会爆炸，必须用干燥沙土盖灭。沙土同时隔空气隔水；水浇=往火上加反应物。

**【到此记住】** 最外层1e⁻→强还原剂→煤油封存沉底；着火用干沙盖，绝不碰水。

### 二、钠与氧气：条件不同，产物不同

结论先行：**同一反应物、条件不同、产物不同——这是"条件影响产物"的经典案例（v18原话）**。

- 常温：4Na+O₂=2Na₂O——白色，氧化钠，普通氧化物（氧-2价）
- 加热/点燃：2Na+O₂=点燃=Na₂O₂——淡黄色，过氧化钠（氧-1价）

把研究动作拆开看：观察颜色（白/淡黄）→比较条件（常温/点燃）→归类（普通氧化物/过氧化物）→由类别预测性质。常温下也得氧但不彻底，点燃才"抢得更狠"——条件越猛，产物越深。这个"控条件、做对比"的动作在碳酸盐对（§六）还要再用一次。

**【到此记住】** 常温Na₂O白色（氧-2价）；点燃Na₂O₂淡黄（氧-1价）；条件写进方程式=条件影响产物的落笔处。

### 三、钠与水：浮熔游响红，五连现象各有出处

结论先行：**2Na+2H₂O=2NaOH+H₂↑——五个现象字字对应一条性质，背现象更要背"为什么"（v18完整展开原话）**。

- **浮**：钠密度比水小
- **熔**：熔点低，反应放热把它熔成小球
- **游**：生成的H₂推动小球四处游
- **响**：嘶嘶声
- **红**：滴酚酞变红——生成NaOH（碱）

记忆与检验合一（v18最小验证原话）：想象一杯水滴两滴酚酞，投入绿豆大钠粒——你能在脑内播放完整视频吗：浮起来、熔成闪亮小球、四处游动、嘶嘶响、红色扩散轨迹？**视频卡壳的位置就是你没记住的位置**。

**【到此记住】** 浮（密度小）熔（熔点低）游（H₂推）响（气体逃逸）红（生碱）；五个字五个证据，逐条挂接。

### 四、钠与盐溶液：先水后盐，最高频陷阱

结论先行：**钠入盐溶液，先与水反应，再考虑与盐反应——不是置换出金属！这是"溶液中活泼金属行为"的最高频陷阱（v18原话）**。

Na入CuSO₄溶液，两步走：

> 2Na+2H₂O=2NaOH+H₂↑
> 2NaOH+CuSO₄=Cu(OH)₂↓+Na₂SO₄
> 合并离子式：2Na+2H₂O+Cu²⁺=2Na⁺+Cu(OH)₂↓+H₂↑

为什么（v18深度追问原话逻辑）：置换反应"金属+盐溶液"成立的前提是金属先接触盐的离子。钠太猛，先抢了水里的H⁺（水是"溶剂"，数量巨大），等Na变成Na⁺进入溶液，已经没有金属钠剩下跟Cu²⁺反应了。本质：**Na的活动性强到"水都拦不住它"，水优先被反应**。

**【到此记住】** 活泼金属入盐溶液两步写（先水后盐）；产物=碱+新盐+氢气，见Cu²⁺出蓝色Cu(OH)₂↓，不是红色的铜。

### 五、过氧化钠Na₂O₂：-1价氧的两面与供氧剂

结论先行：**Na₂O₂中氧是-1价（过氧化物标志）——既可升到0（歧化出O₂）也可降到-2，所以Na₂O₂既是氧化剂又是还原剂（歧化反应）（v18原话）**。

- 与水：2Na₂O₂+2H₂O=4NaOH+O₂↑
- 与CO₂：2Na₂O₂+2CO₂=2Na₂CO₃+O₂
- 用途：供氧剂（潜艇/呼吸面具）——"人呼出的CO₂和水蒸气都变氧气"

质量关系金句（v18原话）：每78g Na₂O₂吸收18g H₂O（或CO₂ 44g）放出16g O₂——**固体增重=被吸收气体的质量−放出的O₂质量**。两式都走这条账（例1实算）。

跨簇连接（v18 CX原话）：Na₂O₂与水的反应里，谁是氧化剂谁是还原剂？——都是Na₂O₂自己（歧化）：氧从-1价一半升到0（O₂）、一半降到-2（NaOH）。每2mol Na₂O₂转移2mol电子，用双线桥画出来转移电子数算清楚——这个反应是簇3"歧化反应"概念的完美练习场（例3完整走一遍）。

**【到此记住】** -1价氧=歧化资格证；两式都放O₂；78吸18/44放16，增重=进−出。

### 六、碳酸盐对：五道分水岭逐条过

结论先行：**Na₂CO₃（纯碱/苏打）与NaHCO₃（小苏打）是"一对"高频考点——每道分水岭都是"一个反应一个不反应"或"剧烈程度不同"，逐条对表（v18完整展开）**。

◎辅助理解｜Na₂CO₃和NaHCO₃像"全副武装的士兵vs背着半套装备的士兵"——HCO₃⁻还背着一个可电离的H，所以遇酸更急（一步放气）、遇碱交装备（变正盐）、受热也沉不住气（易分解）（v18类比锚原话）。

| 分水岭 | Na₂CO₃ | NaHCO₃ |
|---|---|---|
| 溶解性 | 大 | 较小（同温下） |
| 与H⁺ | Na₂CO₃+2H⁺=2Na⁺+H₂O+CO₂↑（两步：先变HCO₃⁻再放气） | NaHCO₃+H⁺=Na⁺+H₂O+CO₂↑（一步放气）——同浓度下更剧烈 |
| 与NaOH | 不反应 | NaHCO₃+NaOH=Na₂CO₃+H₂O（酸式盐遇碱变正盐） |
| 与Ca(OH)₂ | CaCO₃↓ | 也CaCO₃↓（碱足量时NaHCO₃+Ca(OH)₂=CaCO₃↓+NaOH+H₂O——"量比又来了"，v18原话） |
| 与CaCl₂ | 白色沉淀CaCO₃↓ | 不反应（Ca(HCO₃)₂可溶）——**可靠鉴别法** |
| 热稳定性 | 受热不分解 | 2NaHCO₃=Δ=Na₂CO₃+H₂O+CO₂↑（试管内固体质量差可用于计算） |
| 相互转化 | →NaHCO₃：+CO₂+H₂O | →Na₂CO₃：Δ或+NaOH |

鉴别纪律（v18 LE例2原话逻辑）：**CaCl₂溶液是正选——一个沉淀一个不反应，现象不同；稀盐酸两者都冒泡，只是剧烈程度差异需"同浓度同量"控制，操作不严谨**。鉴别试剂的判据=现象不同，不是"都反应但程度不同"。

**【到此记住】** 五道分水岭=溶、酸、碱、钙、热；CaCl₂一沉一无=可靠鉴别；HCO₃⁻多个H，处处"急半步"。

### 七、焰色反应与总纲：物理变化、元素性质

结论先行：**焰色反应是物理变化（电子跃迁发光），且焰色的是元素——不是化学性质，无新物质生成（v18原话）**。

Na=黄色，K=紫色（透过蓝色钴玻璃滤去黄光干扰）。两个易混点（v18常见误解③+适用边界②原话）：①焰色反应是**元素**的性质，说的是Na元素而不是"钠单质专属"——任何含钠化合物灼烧都是黄焰，Na⁺和Na焰色相同。②物理变化与化学变化的判断标准=有无新物质生成，发光不等于生成了新物质。

本节收束到总纲（v18思维升维原话）：钠这一族的知识结构=**结构（最外层1e⁻）→性质（强还原性）→用途与保存**。以后学K、Ca、Mg、Al、Fe、Cu全部走这条路——**"结构决定性质，性质决定用途"是元素化合物的总纲**。回看本节研究钠的整套动作：由结构定位（§一）→控条件做实验逐条记录现象（§二§三）→比较归类找规律（§六对表）——这条以钠走完的路，就是研究物质性质的程序本身，后面每个元素都按它重演一遍。

**【到此记住】** 焰色=物理变化=元素性质（Na黄K紫钴玻璃）；总纲=结构→性质→用途。

## 经典例题

### 例1【保底】差量法经典：Na₂O₂双线过账（四段式）

**【题干】** 将足量Na₂O₂投入18g H₂O与44g CO₂的混合气体中，求放出的O₂总质量与固体增重。（v18 LE例1原题）

**【解答】**（v18原解）分两条线各自过账：

- H₂O线：2Na₂O₂+2H₂O=4NaOH+O₂↑。18g H₂O=1mol，耗1mol Na₂O₂（78g），放出0.5mol O₂（16g），固体增重=2mol NaOH（80g）−78g=2g（验算：进18g−出16g=2g ✓）
- CO₂线：2Na₂O₂+2CO₂=2Na₂CO₃+O₂。44g CO₂=1mol，耗1mol Na₂O₂（78g），放出0.5mol O₂（16g），固体增重=1mol Na₂CO₃（106g）−78g=28g（验算：进44g−出16g=28g ✓）
- 合计：O₂总质量32g，固体增重30g（=50−32，总账再平一次 ✓）

**【思维标注】** 本题唯一正确做法=两条线各自独立过账再合并总账，三处互验（每线验算+总账守恒）。为什么背"78-18-44-16"数字必翻车：金句要背但不够用，题目改配比后要会重算——套路是"写方程式→只盯固体侧进与出→增重=进−出，最后用总账守恒校验"（v18"带走这一句"原话）。另注：差量法只适用于方程式系数已知的反应，别对没配平的式子套用（v18适用边界③原话）。

**【定级】** 保底｜自编示例·对标真题考法（v18 LE；母题真题库候C件合流补入）｜考点=Na₂O₂双线计算+差量法

**【同类一题自测】**（先试后看，做完再对）：78g Na₂O₂与足量CO₂充分反应，固体增重多少？
答案：78g=1mol Na₂O₂，吸1mol CO₂（44g）放0.5mol O₂（16g），增重=44−16=28g（验算：1mol Na₂CO₃共106g−78g=28g ✓）。

### 例2【标准】只用一种试剂鉴别碳酸盐对（四段式）

**【题干】** 只用一种试剂鉴别Na₂CO₃和NaHCO₃两种白色固体溶液，选什么？（v18 LE例2原题）

**【解答】** 正选CaCl₂溶液：Na₂CO₃生成白色沉淀，NaHCO₃不反应（Ca(HCO₃)₂可溶）——现象一有一无，一步区分。

**【思维标注】** 本题唯一正确做法=按"现象不同"筛试剂。为什么选稀盐酸必翻车：两者都冒泡，只是剧烈程度差异需"同浓度同量"控制，操作不严谨——**鉴别试剂的判据=现象不同，不是"都反应但程度不同"**（v18"带走这一句"原话）。CaCl₂法的另一半价值：NaHCO₃与CaCl₂不反应（生成可溶Ca(HCO₃)₂），"不反应"本身就是可靠现象。对照表第五行就是本题的判定依据（§六）。

**【定级】** 标准｜自编示例·对标真题考法（v18 LE）｜考点=碳酸盐对鉴别（高考接口②）

**【同类一题自测】**（先试后看）：现有Na₂CO₃与NaHCO₃两瓶固体（标签脱落），不用任何试剂，如何区分？
答案：加热法——2NaHCO₃=Δ=Na₂CO₃+H₂O+CO₂↑，受热分解产生使澄清石灰水变浑浊的气体的是NaHCO₃，无现象的是Na₂CO₃（热稳定性分水岭的直接应用）。

### 例3【进阶】歧化现场：Na₂O₂+H₂O的电子转移（四段式）

**【题干】** Na₂O₂与水反应：2Na₂O₂+2H₂O=4NaOH+O₂↑。指出氧化剂与还原剂，用双线桥标出电子转移，求每2mol Na₂O₂转移电子数。（v18 CX跨簇连接题原题）

**【解答】** 氧从-1价出发，一半升到0（O₂）、一半降到-2（NaOH）——氧化剂与还原剂都是Na₂O₂自己（歧化）。双线桥：桥的两端都落在Na₂O₂上（同种物质内自身得失），每2mol Na₂O₂转移2mol电子（升价的2mol氧原子各失1e⁻，共2mol e⁻）。

**【思维标注】** 本题唯一正确做法=先标价态再定桥：反应物里含变价元素的只有Na₂O₂——H₂O的氧全程-2价不参与升降，它只提供氢、接纳降价的氧。为什么想找"外加氧化剂"必翻车：-1价氧"不上不下"的位置决定它自己内部完成升降——一半升一半降，两条路都在Na₂O₂内部走完。这个反应是簇3"歧化反应"概念的完美练习场（v18 CX原话），§2.3正式开课前的预演。

**【定级】** 进阶｜自编示例·对标真题考法（v18 CX原题）｜考点=歧化反应+电子转移（簇3氧化还原的应用场）

## 易错卡（本节最高频4张）

**卡① 钠入盐溶液写置换**（v18 EC原话）

| 项目 | 内容 |
|---|---|
| 症状 | 写"钠与CuSO₄溶液反应：2Na+CuSO₄=Na₂SO₄+Cu" |
| 错因 | 忽略了"溶液里钠先遇水"——钠抢电子的本事大到先跟数量占绝对优势的水反应，生成的NaOH再沉淀Cu²⁺（v18 EC原话） |
| 维持机制 | 初中"活泼金属置换不活泼金属"的旧规律太顺手；平时练习的金属多不活泼，负反馈缺失 |
| 钉死 | 两步写——2Na+2H₂O=2NaOH+H₂↑；2NaOH+CuSO₄=Cu(OH)₂↓+Na₂SO₄（合并离子式2Na+2H₂O+Cu²⁺=2Na⁺+Cu(OH)₂↓+H₂↑）。不修会怎样：月考与高考双重高频陷阱，写错产物整题归零，且这类错会迁移到所有"活泼金属+盐溶液"场景（v18 EC原话）。口令：先水后盐 |

**卡② "Na₂O₂是碱性氧化物"**（v18常见误解②）

| 项目 | 内容 |
|---|---|
| 症状 | 分类判断题把Na₂O₂归入碱性氧化物 |
| 错因 | 见"与水反应生成碱"就归类——碱性氧化物定义=**与酸反应只生成盐和水**的氧化物；Na₂O₂与酸还放出O₂，它属于过氧化物（v18原话） |
| 维持机制 | "遇水生碱"特征太显眼，定义里"只生成盐和水"的"只"字被滑过 |
| 钉死 | 判氧化物先背定义全句，"只生成盐和水"五个字是硬门；Na₂O₂与酸多放O₂，出列过氧化物——-1价氧是它的身份证（§五） |

**卡③ "焰色反应是化学变化"**（v18常见误解③）

| 项目 | 内容 |
|---|---|
| 症状 | 判断题打勾；认为只有钠单质才有黄焰、Na⁺没有 |
| 错因 | 把"发光"当"新物质生成"——焰色是电子跃迁发光，物理变化；且焰色的是**元素**不是原子/离子，Na⁺和Na焰色相同（v18原话） |
| 维持机制 | "反应"二字误导；焰色与燃烧视觉上难分 |
| 钉死 | 三连答：物理变化（无新物质）→元素的性质（任何含钠化合物灼烧都是黄焰，Na⁺和Na相同）→K要透过蓝色钴玻璃滤去黄光 |

**卡④ "钠着火了用水浇"**（v18常见误解①）

| 项目 | 内容 |
|---|---|
| 症状 | 安全题答"用水浇灭"；实验题灭火方案写水 |
| 错因 | 日常"水灭火"经验直接迁移——钠与水剧烈反应还会爆炸，水是反应物不是灭火剂（v18原话） |
| 维持机制 | 生活模式太强；钠着火场景初中从未见过 |
| 钉死 | 必须用干燥沙土盖灭（隔空气隔水）；实验室钠只存煤油——遇火先排除"水"这个选项（§一保存逻辑直接续用） |

## 应试打法

1. **Na₂O₂计算题**（高考接口①）：差量法三步——写方程式→只盯"固体侧进与出"→增重=进−出，最后用总账守恒校验（例1范式）；NA题常客。
2. **碳酸盐对鉴别**（高考接口②）：三法备选——CaCl₂法（现象一沉一无，最可靠）、加热法（分解/不分解）、同浓度加酸剧烈程度（需控变量）；Ca(OH)₂两者都沉不可用（§六对照表直接对答）。
3. **钠与盐溶液产物判断**（高考接口③）：先答"先水后盐"再写两步方程式——K、Ca、Na都按此办；Fe、Cu投入盐溶液老老实实发生置换（Fe+CuSO₄=FeSO₄+Cu），别把钠的规律过度外推（v18适用边界①原话）。
4. **实验题**（高考接口④）：NaHCO₃受热分解装置与固体质量差计算——加热法鉴别与差量思想的组合拳（§六热稳定性行+例1套路）。
5. **焰色反应操作描述**（高考接口⑤）：铂丝盐酸洗涤→灼烧→蘸取→观察火焰颜色；K要透过蓝色钴玻璃。
6. **月考预警**（v18原话）：月考的元素化合物大题大概率从钠出——本节是绝对主力。
