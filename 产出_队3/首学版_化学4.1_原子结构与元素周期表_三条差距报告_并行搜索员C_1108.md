# 三条差距报告 · 化学4.1（出品席开工前通读黄金样本两件后填写·并行搜索员C·队3席C线·1108）

> 标准v2.3硬性要求：开工前通读《黄金样本_数学1.1集合_零基础首学_v1.2.html》+《黄金样本_数学3.2奇偶性_零基础首学_v1.4.html》，写出与本节的三条差距，随首件提交。

**差距一（哪里比样本难）：抽象层级更高——样本3.2的奇偶性是"一个函数一条规则"，4.1却是"规则套规则"的嵌套结构**：质量数规则（A=Z+N）里面套电子排布规则（2n²+最外层≤8+先内后外），外面又套周期表排法规则（周期=层数/族=最外层），最后还有一族一条的递变规则。样本读累了歇一拍就能接上，本节任何一步掉链子都会连环断。对策：五站切割+每站只一个动作+随读随验4处强制落点，宁可多花一拍也不合并动作。

**差距二（哪里比样本难）：记忆负担不在"懂"而在"认"——样本3.2只需记住两条定义，本节有稀有气体六行排布表、碱金属五行半径/熔点表、卤素四行物性表、四种方程式，全是零基础读者第一次见的陌生符号**（K L M N electron shell、ᴬZ X记号、²⁹³₁₁₇Ts）。对策：能算的不背（稀有气体表当场用2n²和最外层≤8推着看）、比喻当扶手（电子层=楼层、方格=户口页）、表复刻但只在结论处圈重点，不要求读者背表。

**差距三（样本做法搬不动的）：数学样本的"随读随验"可以sympy算给读者看，本节的"对错有所谓"一半是"结构判断"而非"数值计算"**（Ar的M层为什么8个停/¹²C与¹³C谁是谁/Cl排在哪一格），机器代验帮不上。对策：把sympy用在教材真正有数的地方（43验点：A=Z+N、2n²、各层和=核电荷数、方程式守恒、加权平均），结构判断改用"反例挑衅式"随读随验（自测③问M层为什么住8个就停），两类验证各管各的。

（附：接管说明——本件生产中B席完成T1锚定与sympy43验点脚本，C席接管后复跑复核43/43 ALL PASS、底本事实逐点过表，黄金样本通读与三条差距由C席独立完成。）
