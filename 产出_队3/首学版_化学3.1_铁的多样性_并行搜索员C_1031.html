铁的多样性：一种元素，0、+2、+3 三副面孔

化学 3.1 · 鲁科版《必修 第一册》第3章第1节 · 教材印刷页 p86–96 · 零基础首学版 v1.0（出品：并行搜索员C·队3席·1031）
家里那口铁锅是铁单质，墙上刷墙的红色涂料里是三氧化二铁，药店的补铁保健品里是亚铁盐，连打印机墨粉里都有四氧化三铁（教材 p86 图3-1-1，一口气列了八样）。同一种元素，凭什么变出这么多张面孔？答案就两个字：价态。铁有 0、+2、+3 三种常见价态——上一节你刚领的"价态尺"（2.3：最高价只氧化、最低价只还原、中间价两可），铁一个人就把三格全占了。这一节我们看着它在三格之间上蹿下跳，顺便学会两个课本点名的必做实验。
读完这节你能：
  • 用 KSCN 溶液检验 Fe3+，并设计"先看 KSCN 不红、氧化后再红"的两步法确认 Fe2+；
  • 给 Fe2+ 和 Fe3+ 互转选对试剂（铁粉、氯水等）并写出离子方程式；
  • 按"价—类"二维图报出铁单质、三种氧化物、两种氢氧化物、两类盐的颜色与性质，解释 Fe(OH)2"白→灰绿→红褐"全过程；
  • 读懂补铁剂检验和印刷电路板腐蚀两个真实场景里的价态设计。
    • 开讲前的三件预备（2.2/2.3节的旧账，先理清）：

    ① 价态尺（2.3节）：元素处于最高价态→有降低趋势→可能具有氧化性；处于最低价态→有升高趋势→可能具有还原性；中间价态→升、降两种趋势都可能，到底有没有、哪个强，要靠实验说话。铁：0价（最低）、+2（中间）、+3（最高），三格齐活。

    ② KSCN 是什么：硫氰酸钾的化学式，SCN− 是一种阴离子。它有个"专长"：遇到 Fe3+ 会让溶液显红色（p88 原话："依据 Fe3+ 与 SCN− 反应使溶液显红色的性质，可以用 KSCN 溶液检验 Fe3+ 的存在"）。先记住这条，第①站就是它的主场。

    ③ 两种转化（p91 亲口总结）："含有相同价态铁元素的物质之间的转化，可借助复分解反应等实现；含有不同价态铁元素的物质之间的转化，可借助氧化还原反应实现。"——2.2节管前一半，2.3节管后一半，本节全用上。

    第①站亚铁盐和铁盐：两副面孔，互为对手

    先认人（p87）：亚铁盐=含 Fe2+ 的盐（硫酸亚铁、氯化亚铁…）；铁盐=含 Fe3+ 的盐（硫酸铁、氯化铁…）。一字之差，价态差1。

    教材把"研究它们"设计成学生必做实验（p87 活动·探究「亚铁盐和铁盐的性质」）：给出 FeSO₄ 溶液、FeCl₃ 溶液、NaOH 溶液、酸性 KMnO₄ 溶液、氯水、KSCN 溶液、KI 溶液、淀粉溶液、铁粉、锌片、铜片这堆试剂，让你先预测、再选试剂、再实验（实验用品与方案表照录 p87）。预测的抓手就是 p88 的方法导引：

    研究物质性质的两个基本角度（p88 方法导引）：①物质类别（亚铁盐、铁盐都是盐类，都能与碱溶液反应生成相应的铁的氢氧化物）；②核心元素的化合价（Fe3+ 处最高价→有氧化性；Fe2+ 处中间价→氧化性、还原性都可能有）。预测完，通过实验验证。

    先看 Fe3+：三笔"氧化性"的实锤（p88）

    2Fe3+ + Fe ═══ 3Fe2+　　2Fe3+ + Cu ═══ 2Fe2+ + Cu2+　　2Fe3+ + 2I− ═══ 2Fe2+ + I2

    三式里 Fe3+ 全部降价成 Fe2+——铁盐做氧化剂。第一式还顺手告诉你：铁粉能把 Fe3+ "拉回" Fe2+（p88 图3-1-3：黄色 FeCl₃ 溶液加入铁粉变浅色）。这三个离子方程式教材原文给出，直接背。

    再看 Fe2+：+2 的中间价，两头都能打（p88–89）

    Fe2+ + Zn ═══ Zn2+ + Fe　　（Fe2+ 被还原→体现氧化性）
    2Fe2+ + Cl2 ═══ 2Fe3+ + 2Cl−　　（Fe2+ 被氧化→体现还原性）

    p89 给了两张照片当证据（图3-1-4、图3-1-5）：往加有 KSCN 的 FeSO₄ 溶液里滴氯水，红色出现（生成的 Fe3+ 与 SCN− 结合）；往紫色酸性 KMnO₄ 溶液里滴 FeSO₄ 溶液，紫色褪去（Fe2+ 把 MnO₄− 还原了）。一红一褪，两副面孔拍实。

    这张图在说什么：Fe²⁺⇌Fe³⁺ 是一条双向天桥——上行找氧化剂（氯水、酸性KMnO₄），下行找还原剂（Fe、Cu、KI、Zn）。试剂全来自教材 p87–89 实验清单，桥式为自编重绘（自编归纳·p88–89五式对应）。

    验一验①（30秒）：用"价态尺"一句话说明：为什么 Fe2+ 既可能被氧化、又可能被还原？
    +2 介于 0 与 +3 之间=中间价态，升高（→+3）降低（→0）两种趋势都在，到底表现哪种要靠对手试剂和实验（2.3节价态尺直接套用；教材 p88"既具有氧化性，又具有较强的还原性"）。
    坑点1（保存问题·p87 思考4 的答案侧自编）：实验室里 FeSO₄ 溶液要现配现用、加少量铁粉、密封保存。为什么？空气中 O₂ 会把 Fe2+ 慢慢氧化成 Fe3+（"变质"）；加铁粉是让万一生成的 Fe3+ 被 2Fe3++Fe═3Fe2+ "押送回来"——铁粉在这里当"后悔药"。（现象结论为答案侧自编·依据 p87 思考4 与 p88 第一式）

    第②站铁、氧化物、氢氧化物：按"类别"过一遍家底（p89–91）

    p89 交流·研讨先抛三个问题，p90 逐条给料。我们把 p90 的家底整理成一张表：

    物质（价态）外观与身份（p90 原文口径）关键性质
    铁单质 Fe（0价）光亮的银白色金属；密度 7.86 g·cm−3，熔点 1538 ℃；抗腐蚀强、延展导热好、导电比铜铝差、能被磁铁吸引还原性：与稀盐酸/稀硫酸置换出氢气；与某些盐溶液置换出金属；高温被水蒸气氧化（p90）
    氧化亚铁 FeO（+2）黑色粉末，可作色素（瓷器绿釉）三种氧化物都不溶于水、不与水反应；FeO、Fe₂O₃ 皆能与稀盐酸或稀硫酸反应生成相应亚铁盐或铁盐（Fe₃O₄ 情况教材本节未展开，照 p90 口径不外推）
    四氧化三铁 Fe₃O₄（+2/+3混合）具有磁性的黑色固体，常用磁性材料
    三氧化二铁 Fe₂O₃（+3）红棕色粉末，油漆、涂料、油墨的红色颜料
    氢氧化亚铁 Fe(OH)2（+2）白色固体，难溶于水（iron(Ⅱ) hydroxide）与酸成亚铁盐；很不稳定，易被 O₂ 氧化（p90–91）
    氢氧化铁 Fe(OH)3（+3）红褐色固体，难溶于水（iron(Ⅲ) hydroxide）与酸成铁盐（p90）

    两笔"高温交易"是本站的招牌实验（p89）：

    3Fe + 4H₂O(g) ═══ Fe₃O₄ + 4H₂（高温·铁单质与水蒸气·图3-1-6）
    2Al + Fe₂O₃ ═══ 2Fe + Al₂O₃（高温·放出大量热·可用于焊接钢轨·图3-1-7）

    第一式：铁单质 0→+2/混合价，被水"氧化"——铁的还原性实锤；第二式：Fe₂O₃ 里的 +3 铁被降到 0，Fe₂O₃ 当氧化剂——价态尺第二次命中。p89 还留了一问："该反应为什么能够用于焊接钢轨？"——答案就藏在题面里：放出大量热（熔化的铁正好把钢轨焊上）。

    全节最出名的一幕：白色→灰绿色→红褐色（p90–91）

    向 FeSO₄ 溶液中滴加 NaOH 溶液，先得到白色的 Fe(OH)2 沉淀；它在空气中迅速变成灰绿色，最后变成红褐色——因为被空气中的 O₂ 氧化成了 Fe(OH)3（p90 原文叙述+图3-1-8 三连照片）：

    4Fe(OH)2 + O2 + 2H2O ═══ 4Fe(OH)3　（p91）

    这张图在说什么：Fe(OH)₂ 的"变色三连拍"（图3-1-8 口径）——白色是它本来的脸，灰绿色是过渡，红褐色是终点。时间轴为自编重绘，颜色口径与 p90–91 原文一致。

    验一验②（1分钟）：写出"氢氧化亚铁被氧气氧化"的化学方程式，并用电子账核对 O₂ 拿走几个电子。
    4Fe(OH)₂+O₂+2H₂O═4Fe(OH)₃；4 个 Fe 从 +2→+3 共失 4e⁻，1 个 O₂（2个O，0→−2）共得 4e⁻，失=得 ✓（自编答案侧·方程式为 p91 原式）。

    第③站转化关系：把铁的"家族地图"画出来（p91–93）

    这张图在说什么：p93"概括·整合"官方示例的价—类二维图——同一横排（同价态）靠复分解串门，跨价态（斜向/纵向箭头）靠氧化还原搬家。本图按教材示例重绘（箭头走向照 p93 图3-1-9位重排·属结构示意）。

    两种转化关系（p91 原文）：同价态（如 Fe²⁺→Fe(OH)₂、Fe³⁺→Fe(OH)₃）＝复分解反应等；不同价态（如 Fe²⁺⇌Fe³⁺、Fe→Fe²⁺）＝氧化还原反应。先看价变没变，再选工具。

    实战检验：补铁剂里铁是几价？（p92 学生必做实验）

    背景数据（p92 原文）：人体缺铁会贫血，严重时要服补铁剂；某补铁口服液 100 mL 含铁元素 20~30 mg、维生素C 200~300 mg（还常添加抗氧化物质如维生素C、甜味剂、香精）。实验任务：检验其中铁元素的价态。给的试剂：补铁口服液、H₂SO₄ 溶液、NaOH 溶液、酸性 KMnO₄ 溶液、氯水、KSCN 溶液（+试管、胶头滴管）。

    方案思路（答案侧自编·依据 p92 思考1-3 与 p88 检验原理）：取样+稀硫酸溶解→滴 KSCN：变红=有 Fe3+；不红→另取样滴氯水后再滴 KSCN，变红=原本有 Fe2+（被氯水氧化成了 Fe3+）。不能只用 NaOH 溶液检验（p92 思考2）：Fe(OH)2 白色沉淀在空气中迅速变色，颜色证据不可靠；补铁剂里的其他成分（维生素C、甜味剂、香精）也可能干扰现象（p92 思考3）。
    验一验③（想一下）：补铁口服液里为什么要加维生素C？
    看 p93"身边的化学"：人体只能吸收 Fe2+，而维生素C 具有还原性，可把 Fe3+ 还原成 Fe2+——加它是为了保住"能吸收的价态"（p93 原文口径+答案侧组织）。

    顺带把 p93"身边的化学"记成三句

    ①血红蛋白分子含有 Fe2+，靠它载氧；被氧化成 Fe3+ 就丧失载氧能力，人缺氧。②铁主要来自动物血、肝脏、骨髓、蛋黄、菠菜、木耳、葡萄、红枣、大豆、芝麻等食物，在小肠（尤其十二指肠）被吸收，人体只能吸收 Fe2+。③健康成年人合理膳食即可；儿童和孕期妇女需要较多，可额外补充（p93 原文口径）。

    第④站两个真实场景：价态设计在生产里（p94–96 练习域+实际应用）

    场景一：印刷电路板（p96 练习12 题面）。电子工业用 FeCl₃ 溶液腐蚀覆铜板：未被油墨覆盖的铜被"吃掉"，洗掉油墨就是电路板。原理就是第①站第二式：2Fe3++Cu═2Fe2++Cu2+（Fe3+ 做氧化剂）。该题还给了废液回收流程：废液加过量铁粉过滤→滤渣（Cu+Fe）加盐酸得 Cu 与 FeCl₂ 溶液→滤液合并通入 Cl₂ 重新得到 FeCl₃ 溶液——一进一出全是 Fe3+/Fe2+ 互转的价态设计（流程细节为按题面整理·答案侧自编）。

    场景二：除杂（p95 练习10）。FeCl₂ 溶液里混了少量 FeCl₃？加过量铁粉再过滤（2Fe3++Fe═3Fe2+）；FeCl₃ 溶液里混了少量 FeCl₂？通入足量氯水（2Fe2++Cl₂═2Fe3++2Cl−）。一句话：杂质往主要物质的方向"掰"，掰完能分离（答案侧自编归纳）。

    验一验④（30秒）：铁与盐酸反应只能得到 FeCl₂ 得不到 FeCl₃，用价态尺解释。
    H+ 是弱氧化剂，只能把 Fe 从 0 价推到 +2（稀盐酸/稀硫酸置换出氢气，p90）；要一步到 +3 得请强氧化剂 Cl₂（p95 练习5 的 D 项正是考这个）。（答案侧自编·口径锚 p90/p95）

    收口：把这一节带走

    三句话，能默写才算读完：

    ① 检验：KSCN 遇 Fe3+ 显红色；"不红+氯水后红"反推 Fe2+（p88+p89 图3-1-4）。

    ② 互转：Fe2+→Fe3+ 找氧化剂（Cl₂、酸性KMnO₄）；Fe3+→Fe2+ 找还原剂（Fe、Cu、KI）——五个离子方程式 p88–89 原文必背。

    ③ 地图：同价态走复分解、异价态走氧化还原；Fe(OH)₂ 白→灰绿→红褐（4Fe(OH)₂+O₂+2H₂O═4Fe(OH)₃）。

    合上本件，先自问：+2 为什么两头都能打？答案起手式必须是"中间价态"四个字。

    自测四连（先做再看答案·改编自教材 p94–95 练习与活动·题面缩写·答案侧自编）

    题（改编自）问答案与一步解释
    1（p94 练习2）下列说法不正确的是：A. FeCl₂ 溶液和 FeCl₃ 溶液都是黄色的；B. Fe(OH)₂ 是白色的，Fe(OH)₃ 是红褐色的；C. FeO、Fe₂O₃ 都能与盐酸反应；D. FeCl₃、FeCl₂ 溶液都能与 NaOH 溶液反应A。FeCl₃ 溶液黄色（p88 图3-1-3），FeCl₂/FeSO₄ 溶液浅绿近无色（p89 图3-1-4 口径）——两种颜色一句口诀：三黄二绿。B、C、D 均与 p90 一致。
    2（p94 练习3）下列含铁物质能与稀盐酸反应、且铁元素被氧化的是：A. Fe　B. FeCl₂　C. FeCl₃　D. Fe₂O₃A。铁单质 0→+2 价升高被氧化（p90）；D 能与盐酸反应但 +3→+3 价不变（不是被氧化）；B、C 不与盐酸反应。
    3（p94 练习4）下列反应中 Fe3+ 表现氧化性的是：A. 使淀粉碘化钾试纸变蓝；B. 加 NaOH 产生红褐色沉淀；C. 加 AgNO₃ 产生白色沉淀；D. 加少量铁粉铁粉消失A、D。两式里 Fe3+ 均降价为 Fe2+（p88 第二式；A 中 I− 被氧化成 I₂ 使淀粉变蓝）；B、C 是复分解，铁价不动。
    4（p95 练习5）下列变化不能一步实现的是：A. Fe —Cl₂→ FeCl₃；B. Fe —O₂→ Fe₃O₄；C. Fe —H₂O→ Fe₃O₄；D. Fe —HCl→ FeCl₃D。盐酸的 H+ 只能把铁氧化到 +2（p90）；A/B/C 均为教材本节或初中学过的直接反应（Cl₂ 强氧化/点燃与水蒸气高温两式）。
    高考怎么考（考法示意·三行以内）：①Fe2+/Fe3+ 检验与互转试剂选择（KSCN/氯水/铁粉三件套）+离子方程式书写；②除杂与流程题（如 p96 印刷电路板回收：氧化—还原—氧化循环）；③"价—类"二维图填空与转化条件设计；④真实情境（补铁剂、变色沉淀）中价态推理。真题锚候采（对证源池暂无化学3.1行·如实申报不代拟·沿1.2/1.3/2.3件先例）。
