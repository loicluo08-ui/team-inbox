力的作用是相互的——牛顿第三定律：F 与 F′ 永远等大、反向、共线

开场掰手腕赢了，不代表你推他的力更大

教材p68的问题栏只给了一幅很日常的图：力的作用是相互的。相互作用的力其大小有什么关系？例如，大人跟小孩掰手腕，很容易就把小孩的手压在桌面上。那么，他们施加给对方的力，大小相等吗？

直觉会说"当然不等——大人力气大嘛"。但直觉这回错了一半：大人压小孩的手和小孩压大人的手，这两个力的大小永远相等（这就是本节主角牛顿第三定律）。那为什么大人总能赢？因为"力的大小"和"谁扛得住"是两码事——同样大的力作用在小孩手上，小孩的手臂（和手腕的支点位置）承受不起，于是手被压下去了。力的效果还取决于物体自身的状态，这正好呼应我们一直强调的：分析问题，永远先问清楚"这是谁受的力"。

第一步作用力和反作用力——力的"成对出现"法则

用手拉弹簧：弹簧受到手的拉力 F，同时弹簧发生形变，手也受到弹簧的拉力 F′（教材图3.3-1）。坐在椅子上用力推桌子，会感到桌子也在推我们，我们的身体要向后仰。教材p68把这类现象的普遍规律写明了（原文）：观察和实验的结果表明，两个物体之间的作用总是相互的。当一个物体对另一个物体施加了力，后一个物体一定同时对前一个物体也施加了力。

作用力和反作用力（教材p68）：物体间相互作用的这一对力，通常叫作作用力（acting force）和反作用力（reacting force）。作用力和反作用力总是互相依赖、同时存在的。我们可以把其中任何一个力叫作作用力，另一个力叫作反作用力。
图A（重绘自教材图3.3-1/3.3-2）｜这张图在说什么：任何一个力都是成对的——手拉弹簧的同时弹簧拉手；地球"吸"卫星（这就是重力）的同时，卫星也在"吸"地球。教材p68特意提醒：地球和物体之间的作用也是相互的。

验一验①（自编·口头快答）：指出下列各力的施力物体和受力物体，并说出它的"孪生反作用力"作用在谁身上——(a) 桌面上的书受到的支持力；(b) 下落的苹果受到的重力。

(a) 施力物体=桌面，受力物体=书；反作用力=书压桌面，作用在桌面上。(b) 施力物体=地球，受力物体=苹果；反作用力=苹果吸引地球，作用在地球上——地球也在被苹果吸引，只是它质量太大看不出效果。

第二步牛顿第三定律——实验量出"永远等大反向共线"

"大小相等"不能靠嘴说，教材p69先做了一个可以当堂复现的实验（原文）：探究作用力和反作用力的关系，要同时测量这两个力。把A、B两个弹簧测力计连接在一起，B的一端固定，用手拉测力计A。可以看到两个测力计的指针同时移动。这时测力计B受到A的拉力 F，测力计A则受到B的拉力 F′。F 与 F′ 有什么关系？

相等·方向相反
图B（重绘自教材图3.3-3）｜这张图在说什么：B受到A的拉力 F、A受到B的拉力 F′，两个测力计的示数相等、方向相反，且指针同时移动——"同时性"说明这对力没有先后之分。

教材p69追问得很讲究：上面是通过弹力进行的实验，摩擦力满足上面的关系吗？如果是不相互接触的力呢？——牛顿经过研究指出，答案都是肯定的：

牛顿第三定律（Newton's third law·教材p69蓝字原文）：两个物体之间的作用力和反作用力总是大小相等，方向相反，作用在同一条直线上。

三要素一个都不能少：等大（永远，与物体强弱、运动状态无关）＋反向（沿同一直线）＋异体（分别作用在两个物体上——这是它区别于平衡力的命门）。

教材p69给了两幅应用实景：人在划龙舟时，桨向后推水，水就向前推桨，将船向前推进（图3.3-4）；轮船的螺旋桨旋转时向后推水，水同时给螺旋桨一个反作用力，推动轮船前进。

驱动力就是这样产生的：发动机驱动车轮转动，靠轮胎和地面之间的摩擦
图C（重绘自教材图3.3-5）｜这张图在说什么：汽车前进的动力不在发动机里，而在地面对车轮的反作用力上。教材p69连问三句："若把驱动轮架空，不让它跟地面接触，这时车轮虽然转动，但车轮不推地面，地面也就不会产生向前推车的力，汽车就不会前进。陷在泥泞中的汽车，尽管车轮飞转，但是如果泥和车轮之间太滑，车轮得不到足够的摩擦力，车也是出不来的。许多越野车可以按需分别由前轮或后轮驱动，必要时甚至可以四轮同时驱动。"

坑点·"发动机推汽车前进"是错误归因使汽车前进的力，施力物体是地面（摩擦性质的反作用力），不是发动机——发动机只是让车轮有了"推地面"的本事。外部没有摩擦（架空、冰面、泥泞），发动机再强车也不走。同一道理：人走路靠的是地面向前的静摩擦反作用力，游泳靠的是水向前推的反作用力。

验一验②（自编·情境判断）：轮船螺旋桨把水向后推的同时获得前进的动力；直升机悬停在空中，把空气向下推也获得升力。它们的"反作用力"分别来自什么物体？

轮船：来自水（水向前推螺旋桨）；直升机：来自空气（空气向上旋翼的反作用力即升力）。共同点：施力物体都是"被推的那个东西"——没有"推的对象"就没有"被推回来的力"。

第三步物体受力的初步分析——把"异体成对"用在画图上

教材p70把"受力分析"的方法论讲得非常清楚（原文）：分析物体的受力，有两条思路。一是根据物体运动状态的变化来分析和判断其受力情况，这是下一章学习的内容；二是根据各种力的特点，从相互作用的角度来分析物体的受力。在高中物理的力学部分，我们遇到的力主要是重力、弹力和摩擦力。

示范例（教材p70）：一个木块静止在粗糙斜面上，按重力、弹力和摩擦力的顺序来分析它的受力情况：木块受到重力 G，方向竖直向下；木块和斜面接触并相互挤压，木块受到垂直于斜面向上的弹力 FN；假设木块和斜面之间没有摩擦，木块就会向下滑动，由此可以判断，静止的木块相对斜面有向下滑动的趋势，所受的静摩擦力 Ff 是沿斜面向上的（图3.3-7）。

图D（重绘自教材图3.3-7）｜这张图在说什么：斜面上木块只受三个力：重力G（竖直向下）、弹力FN（垂直斜面向上）、静摩擦力Ff（沿斜面向上）。

教材p70接下来一句是本节的"题眼"（原文）：需要强调的是，必须明确我们是在分析哪个物体所受的力。在上面的例子中，涉及木块的作用力和反作用力共有三对：重力 G 和木块对地球的引力、弹力 FN 和木块对斜面的压力、静摩擦力 Ff 和木块对斜面的静摩擦力。由于我们是在对木块的受力情况进行分析，所以只把这三个力画出来了。

受力图上画谁、不画谁（异体成对法则）：木块受到的力画在木块上；木块施加给别物的力（对地球的引力、对斜面的压力、对斜面的静摩擦力）是相应反作用力，画在对方身上，不画在木块身上。数对儿时两两配对：G↔木块对地球的引力，FN↔木块对斜面的压力，Ff↔木块对斜面的静摩擦力——每一对都是"等大反向共线异体"。

验一验③（自编·照图说话）：图D中如果把"木块对斜面的压力"也画进木块的受力图里，错在哪里？木块此刻一共受到几个力？

错在把别人受的力画到它头上：压力的受力物体是斜面，不是木块——同一张受力图里混进"异体力"，合力就全算错了。木块此刻受3个力（G、FN、Ff）；涉及它的作用力-反作用力有3对，但图中只画"受"的那一半。

第四步平衡力 ≠ 作用力和反作用力——猴子吊树的辨析（教材p71）

教材p71开门见山（原文）：在分析物体的受力情况时，不要把某个力的反作用力跟这个力的平衡力混淆。它用一幅猴子吊树的图（图3.3-8）把两对力摆在一起：

图E（重绘自教材图3.3-8）｜这张图在说什么：图甲里猴子静止，树枝对它的拉力 F 与重力 G 是一对相互平衡的力——"大小相等、方向相反，作用在同一条直线上"，且作用在同一物体（猴子）上。图乙里树枝以拉力 F 向上拉着猴子，猴子同时以向下的拉力 F′ 拉着树枝——这是一对作用力和反作用力，分别作用在两个物体（猴子和树枝）上。
辨据一对平衡力（F 与 G）一对作用力和反作用力（F 与 F′）
作用对象同一物体（猴子）两个物体（猴子和树枝）
力的种类不一定同种（F是弹力·G是重力）一定是同一种类的力（F和F′都是弹力）
能否抵消/求合力可以（合力为0·效果互相抵消）不能（作用在不同物体上·各算各的账）
时间关系平衡力撤去一个，另一个可以仍在同生同灭·同时变化（力传感器实测任何时刻都等大反向）

坑点·"等大反向共线"不等于"平衡"大小相等、方向相反、同一直线是两者共有的表面特征，判"平衡力"还是"牛三对"只看一条：作用在几个物体上。同一物体=平衡力（可求合力抵消）；两个物体=牛三对（永不能合成一个力、不能抵消、不能说"合力为零"——讨论"两个物体整体合力"时，这对力也分别属于不同物体，同样不能相加）。

验一验④（自编·快问快答）：(a) "苹果受到的重力与苹果对地球的引力是一对平衡力"——错在哪？(b) 马拉车前进时，车拉马的力与马拉车的力等大反向，为什么车还能被拉动？

(a) 这两个力作用在两个物体上（苹果/地球），是牛三对不是平衡力；苹果受的平衡力应是"重力与树枝（或桌面）的支持力"。(b) 马拉车的力和车拉马的力是牛三对，永远等大反向，但它们作用在不同物体上、各管各的运动：车能否前进取决于车自己受的合外力（拉力−地面阻力），马能否前进取决于马受的合外力（地面对马向前的静摩擦−阻力）——两笔账分开算，谁也不"抵消"谁。

节末自测先自己做，再对答案（教材p71练习与应用原题）

第1题（教材p71原题）　一个物体静止地放在台式弹簧秤上（图3.3-9），试证明物体对弹簧秤的压力大小等于物体所受的重力大小。证明时，请在图上标出所涉及的力。

参考答案（两步走·恰好同时用到"平衡"与"牛三"）：① 对物体受力分析：物体静止，受重力 G（施力者=地球）与弹簧秤支持力 N（施力者=秤），二力作用在同一物体上且物体平衡 → N 与 G 是一对平衡力，N = G。② 对"物体压秤"环节：物体对秤的压力 N′ 与秤对物体的支持力 N 是作用力与反作用力（异体·同种弹力）→ 由牛顿第三定律 N′ = N。联立得 N′ = G，即压力大小等于重力大小。图上应标出：G、N 画在物体上，N′ 画在秤盘上。

第2题（教材p71原题）　小强说："我记得在初中学过，如果两个力的大小相等、方向相反，这两个力就会互相平衡，看不到作用的效果了。既然作用力和反作用力也是大小相等、方向相反的，它们也应该互相平衡呀！"应该怎么解答小强的疑问？

参考答案：小强漏了平衡的前提——两个力必须作用在同一个物体上。作用力和反作用力分别作用在两个物体上，各对各自的物体产生效果，根本不存在"合在一起"的可能。比如手拍桌子：手痛是桌面对手的作用力所致，桌面的形变是手对桌子的反作用力所致——两个效果发生在两个物体上，互不抵消。

第3题（教材p71原题）　如图3.3-10，油桶放在汽车上，汽车停于水平地面。涉及油桶、汽车、地球三个物体之间的作用力和反作用力一共有几对？这几对力中，油桶受哪几个力？汽车受哪几个力？地球受哪几个力？

参考答案：三个物体两两之间共 4对：①油桶与地球间的引力对（重力与"油桶吸地球"）；②油桶与汽车间的弹力对（桶压车/车顶桶）；③汽车与地球间的引力对（车重与"车吸地球"）；④汽车与地球间的弹力对（车压地/地顶车）。受力清单——油桶：重力、汽车的支持力（2个）；汽车：重力、地面的支持力、油桶的压力（3个；静止无相对运动趋势，轮胎与地面间无摩擦力）；地球：油桶对它的引力、汽车对它的引力、汽车对它的压力（3个）。

第4题（教材p71原题）　如图3.3-11，粗糙的长方体木块A、B叠在一起，放在水平桌面上，B木块受到一个水平方向的力的牵引，但仍然保持静止。问B木块受到哪几个力的作用？

参考答案：B受 5个力：重力（地球）、A对B的压力、桌面对B的支持力、水平牵引力 F、以及桌面对B的静摩擦力（与 F 等大反向——B静止但相对桌面有被 F 拉动的趋势，粗糙接触面提供静摩擦）。注意 A、B 之间没有摩擦力：A 静止且水平方向不受其他任何力，若 A、B 间有摩擦 A 就不可能平衡——这也正是"按重力→弹力→摩擦力顺序分析+逐个检验"的价值。
